The main idea is that since the autoencoder has only seen hand-written
digits images, it will not be able to reconstruct the shoe image. Therefore we
expect this image to have the biggest reconstruction error. We can check if
that is the case by taking the top 2 reconstruction errors. For this example,
we have used the MSE for the reconstruction error. You can check the code
of this example at https://adl.toelt.ai . The shoe has the highest
reconstruction error: 0.062. The autoencoder is not able to reconstruct the
image as it can be seen from Figure 10.
