We compare TinyBERT with BERT TINY ,
BERT SMALL6(Turc et al., 2019) and several
state-of-the-art KD baselines including BERT-

BERT (Sun et al., 2020). BERT TINY means
directly pretraining a small BERT, which has the
same model architecture as TinyBERT 4. When
training BERT TINY , we follow the same learning
strategy as described in the original BERT (Devlin
et al., 2019). To make a fair comparison, we use
the released code to train a 4-layer BERT 4-PKD7
and a 4-layer DistilBERT 48and ﬁne-tuning these
4-layer baselines with suggested hyper-paramters.
For 6-layer baselines, we use the reported numbers
or evaluate the results on the test set of GLUE with
released models.
