5.2 Datasets
5.2.1 CNN/Daily Mail Dataset. CNN/Daily Mail dataset ( https://github.com/abisee/cnn-
dailymail ) consists of more than 300 Knews articles and each of them is paired with several
highlights, known as multi-sentence summaries [ 98,119]. We have summarized the basic sta-
tistics of the dataset in Table 3. There are primarily two versions of this dataset. The first ver-
sion anonymizes name entities [ 98], while the second one keeps the original texts [ 119]. In this
article, we used the second version and obtained processed data from See et al. [ 119](https:
//github.com/JafferWilson/Process-Data-of-CNN-DailyMail ).
