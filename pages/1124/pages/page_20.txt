D. Case 4: LeadingOnes + TrailingOnes problem
For this particular study, we consider solving the Leadin-
gOnes and TrailingOnes problems simultaneously using
MFEA-II. The LeadingOnes problem essentially aims to maxi-
mize the number of consecutive 1-bits counting from the left of
a solution string. In contrast, the TrailingOnes problem starts
the search by scanning the solution from the right towards the
left. Both the problems share the same global optimum (i.e.,
the string with all 1’s). For this experimental study, we set the
problem dimensionality and the population size to D= 50
andN= 150 for each of the tasks, respectively.
Notably, while the problems do share a common global
optimum, transfers in the early stage of the optimization phase
is unlikely to be beneﬁcial since each of the tasks begin the
search from opposite ends of the search space. In particular,
Figure 10 demonstrates that MFEA-II is able to identify
this and prescribes lower (near zero) rmp values during the
initial stages. As the search progresses and the tasks becomes
more similar, MFEA-II gradually learns higher rmp values
in order to facilitate fruitful knowledge transfers. As shown
by Figure 11, the transfer adaptation strategy of MFEA-II
