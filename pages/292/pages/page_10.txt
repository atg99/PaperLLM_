3.3.2 Glimpse network
Inspired by how humans perform visual recognition
sequentially, Ba et al. [ 88] proposed a deep recurrent
network, similar to RAM [ 31], capable of processing
a multi-resolution crop of the input image, called aglimpse, for multiple object recognition task. Theproposed network updates its hidden state using a
glimpse as input, and then predicts a new object as
well as the next glimpse location at each step. The
glimpse is usually much smaller than the whole image,
which makes the network computationally eﬃcient.

model consists of a context network, glimpse
network, recurrent network, emission network, andclassiﬁcation network. First, the context networktakes the down-sampled whole image as input to
