3.2.2 GSoP-Net
An SE block captures global information by only using
global average pooling (i.e., ﬁrst-order statistics),
which limits its modeling capability, in particular
the ability to capture high-order statistics.
To address this issue, Gao et al. [ 54] proposed
to improve the squeeze module by using a global
second-order pooling (GSoP) block to model high-
order statistics while gathering global information.
