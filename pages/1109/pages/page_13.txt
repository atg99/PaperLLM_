4.2 BayesiaLab
BayesiaLab ( http://www.bayesia.com/ ) is a commercial desktop application
(Windows/Mac/Unix) with a sophisticated graphical user interface, which pro-
vides scientists a comprehensive \laboratory" environment for machine learning,
knowledge modeling, diagnosis, analysis, simulation, and optimization. Accord-
ing to https://library.bayesia.com/display/FAQ/Score-Based+Learning+
Algorithms , BayesiaLab performs structural learning by using a score-based
approach which optimizes the Minimum Description Length score function.
BayesiaLab oers dierent algorithms in order to increase the probability to
nd the optimal solution. They are using dierent search policies (greedy,
taboo) and/or are exploring dierent spaces (Trees, Bayesian networks, Es-
sential Graphs, Order of nodes).
4.3 Bayesian Network Classiers in Weka
Bayesian Network Classiers in Weka ( https://www.cs.waikato.ac.nz/ ~remco/
weka_bn/ ) is a Java source code available developed by the University of Waikato
and made avalable in 2006 under GPL1 license. Structure learning of Bayesian
networks is achieved by score-based appoach; hill climbing (K2, B, etc) and gen-
eral purpose (simulated annealing, tabu search) algorithms. In particular, the
local score metrics implemented are; Bayes, BDe, MDL, entropy, AIC. Bayesian
Network Classiers in Weka comes with an easy to use graphical user inter-
face. Furthermore, structure learning is made possiblle also accoring to the
constraint-based approach through the ICS, and CI algorithms.
4.4 Bayes Server
Bayes Server ( https://www.bayesserver.com/ ) is a commercial tool for mod-
eling Bayesian networks, Dynamic Bayesian networks and Decision graphs. It
comes wit an eective graphical user interface and a number of advanced APIs,
including all the features of the graphical user interface, are made available.
Structural learning of Bayesian networks can be perfomed according to the
score-based approach, and to the constraint-based approach through the PC
algoritm. Bayes Server API can be used from C#, Java, JavaScript, Python,
R, Matlab, Excel functions and Apache Spark.
