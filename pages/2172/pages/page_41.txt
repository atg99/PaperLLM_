5.2 Test Case Generation
In the following, we survey the test case generation methods for DNNs that have
not been covered in Section 5.1 and that do not employ the existing adversarial
attack algorithms. We will review adversarial attacks in Section 6.
5.2.1 Input Mutation
Given a set of inputs, input mutation generates new inputs (as test cases) by
changing the existing input according to some predened transformation rules
or algorithms. For example, [Wicker et al., 2018] systematically mutates input
dimensions with the goal of enumerating all hyper-rectangles in the input space.
Moreover, aiming at testing the fairness (i.e., free of unintended bias) of DNNs,
AEQUITAS [Udeshi et al., 2018] essentially employs an input mutation technique
to rst randomly sample a set of inputs and then explore the neighbourhood of
the sampled inputs by changing a subset of input dimensions, however, it has
not been applied to DNN model.
