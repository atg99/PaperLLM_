5.4 The VSURF Package
Let us start by illustrating the use of the VSURF package (V ariable Selection Using
Random Forests) on the simulated data toys introduced in Sect. 4.2with n=100
and p=200, i.e., 6 true variables and 194 non-informative variables. The loading
of the VSURF package as well as the toys data, included in the package, is done
using the following commands:
>library (VSURF)
>data ("toys" )
TheVSURF() function is the main function of the package and performs all the
steps of the procedure. The random seed is ﬁxed in order to obtain exactly the sameresults when applying later the procedure step by step:
>set.seed (3101318 )
>vsurfToys <- VSURF (toys $x, toys $y,mtry = 100)
The methods print() ,summary() , andplot() provide information on the
results:
>summary (vsurfToys)
VSURF computation time: 1.2 mins
VSURF selected:
34 variables at thresholding step (in 45 secs)4 variables at interpretation step (in 24.7 secs)3 variables at prediction step (in 1.2 secs)
>plot (vsurfToys)
