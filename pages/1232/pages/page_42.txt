Fig. 2.16 Optimal pruned tree, Vac18 data
We can easily see on the right side of Fig. 2.15 that for leave-one-out cross-
validation, the optimal tree consists of 4 leaves while the 1-SE tree is the same as the
default tree (3 leaves). The optimal tree (Fig. 2.16 ) is obtained using the following
commands:
>VacIndcpOpt <- which.min (VacTreeMaxLoo $cptable[, 4])
>VaccpOpt <- VacTreeMaxLoo $cptable[VacIndcpOpt, 1]
>VacTreeOpt <- prune (VacTreeMaxLoo, cp = VaccpOpt)
>plot (VacTreeOpt)
>text (VacTreeOpt, use.n = TRUE ,xpd = TRUE )
