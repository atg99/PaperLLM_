The structure of the chapters (except the introduction) is always the same. After a
presentation of the concepts and methods, we illustrate their implementation on a
running example. Then, various complements are provided before examining
additional examples.
Throughout the book, each result is given together with the R code that can be
used to reproduce it. All lines of code are available online1making things easy.
Thus, the book offers readers essential information and concepts, together with
examples and the software tools needed to analyze data using random forests.
