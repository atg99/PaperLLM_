functionality  remains constant with time  given that  they are not affected by hazard s. Dynamic ind icators, on the 496 
other hand, are affected by hazard s, and consequently their functionality changes with time. Dynamic indicators 497

the time needed to finish the recovery process.   500 
Each indicator is normalized with respect to a fixed quantity, the target value (TV). The t arget value is an 501 
essential quantity that provides the baseline to measure the resilience of a system. The system’s existing 502 
functionality at any instance of time is compared to the target value to know how much functionality deficiency 503 
is experienced by t he system.  504
