16 4.5 Sensitivity analysis  364 
Sensitivity analysis can help validate the probability parameters of a Bayesian network. It is done by 365 
investigating the effect of small changes in the values (probabilities)  of the input parameters on the output. 366 
Identifying  highly sensitive parameters  allows for a directed allocation of effort in order to obtain accurate 367 
results of a Bayesian network model.  368 
In this example , an algorithm proposed by (Kjærulff and van der Gaag 2000 ) is implemented. Given a set of 369 
target nodes, a complete set of the derivatives of the posterior probability distributions over the target nodes 370 
over each of the numerical parameters of the Bayesian network  are efficiently calculated . These derivatives 371 
indicate the  importance of precision of network numerical parameters for calculating the posterior probabilities  372 
of the targets. A large  derivative of a parameter  p leads to a large variation  in the posteriors of the targets  given 373 
a variation in the parameter p. If the derivative is small, then even large changes in the parameter make little 374 
difference in the poster iors. 375
