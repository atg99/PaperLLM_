Robot operating system 446
This paper uses the ROS (robot operating system) software 447
platform, which is a robot software development platform 448
that includes system software to manage computer hardware 449
and software resources and provide services. ROS uses a 450
cross-platform modular communication mechanism, which 451
is a distributed framework (Nodes) and largely reduces the 452
code reuse rate. ROS is also highly compatible and open, 453
providing a number of functional packages, debugging tools 454
and visualization tools. 455
