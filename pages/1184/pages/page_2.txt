2 Data quality
Semi-supervised learning algorithms try to exploit vast unla-beled data to help machine learning models to improve per-formance. Actually, there are two basic assumptions in semi-supervised learning, i.e., the cluster assumption and the man-
ifold assumption ; both concerns about data distribution. The
former assumes that data have inherent cluster structure and
instances falling into the same cluster have the same class la-bel. The latter assumes that the data lie on a manifold andnearby instances have similar predictions. Semi-supervised
learning helps when the assumption matches the inherent
structure of the data. In other words, when it was broken,semi-supervised learning algorithms would not perform asthe user wish.
