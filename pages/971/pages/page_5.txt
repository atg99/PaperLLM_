As for problem (2) ( safety complexity ), agents need to interact with
environments and sample trajectories, such that the safe RL algorithms
converge to below the constraint bound, and guarantee application safety.

hard to control the balance between exploitation and exploration, especially
when we need to improve reward performance while satisfying cost constraints
(cost is one way of encoding safety). Thus, we need to determine how many
