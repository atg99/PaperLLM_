3.1 Recurrent Neural Networks
3.1.1 Principle and deﬁnition
RNNs have been and are still widely used for data sequence modeling
and generation and sequence-to-sequence mapping. An RNN is a neural
network that processes ordered vector sequences and uses a memory
of past input/output data to condition the current output (Sutskever,
2013; Graves et al., 2013). This is achieved using an additional vector
that recursively encodes the internal state of the network.
