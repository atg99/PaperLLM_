3.3 ModelDeployment
Model deployment is one of the most challenging and time-consuming tasks in the overallmodeling lifecycle, especially when deploying models on the cloud. Implementing mod-els using new cloud service and integrating it with an existing system requires significantamounts of time and effort. For example, our experiments illustrated that given a well-trained model, a graduate student with no prior knowledge of cloud deployment serviceswould spend five to seven days to expose a trained model online, not to mention the needfor creating a simple GUI or a set of APIs to use the deployed model.
