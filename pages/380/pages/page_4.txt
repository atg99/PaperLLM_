V. C ONCLUSION
This paper investigates the effect of SE modules on the
performance of EfﬁcientNet-B0, the basic network model in
the EfﬁcientNets series, by repositioning/removing the SE
modules. The experiments show that repositioning SE module
to the end of block is not a good idea. And we don’t need
to use SE module for all MBConv blocks, there is a trade off
need to be further studied to have a more efﬁcient network.
In the future, it is necessary to modify the architecture of
EfﬁcientNet and MBConv block to make them more efﬁcient.
