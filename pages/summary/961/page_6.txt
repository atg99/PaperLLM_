The paper discusses various dynamic routing methods within neural network architectures, particularly focusing on SuperNets and their routing policies. 

1. **Path Selection in Multi-Branch Structures**: Dynamic routing can be simplified through selective execution of one candidate module per layer, akin to a one-hot probability distribution. This differs from hard mixture of experts (MoE) systems as it activates only one branch without fusion.

2. **Neural Trees and Tree-Structured Networks**: These structures leverage decision trees combined with neural networks to enhance adaptive inference. Soft decision trees (SDT) utilize neural units for routing, generating probability distributions at leaf nodes. However, they execute all paths, impacting efficiency. In contrast, deterministic routing policies allow for hard decisions, eliminating unnecessary computations. Tree-structured deep neural networks (DNNs) route based on coarse classifications and specific sub-networks.

3. **Adaptive Neural Trees (ANT)**: ANT integrates CNN modules as feature transformers and learns the tree structure alongside network parameters during training.

4. **Dynamic Parameters**: This section highlights adapting network parameters to inputs while maintaining fixed architectures. Three adaptation strategies are identified: adjusting trained parameters based on input, directly generating parameters from input, and rescaling features using soft attention.

5. **Parameter Adjustment**: This involves modifying weights based on input during inference, often using techniques like attention weights to enhance representation without significant computational overhead. Kernel shape adaptation is also discussed, where deformable convolutions allow for dynamic field reception by sampling feature pixels from adaptive locations.

The paper emphasizes the efficiency and adaptability of these dynamic routing and parameter adjustment techniques in improving neural network performance while managing computational costs.
