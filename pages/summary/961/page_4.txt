The paper discusses advanced techniques for dynamic layer skipping and adaptive inference in neural networks, focusing on enhancing computational efficiency without sacrificing accuracy. Three primary methods for dynamic layer skipping are presented: 

1. **Halting Score**: This approach utilizes an accumulated halting score to decide whether to forward the hidden state in RNNs or to execute residual blocks in CNNs like ResNet. By adapting the number of executed blocks based on the halting score, this method reduces the number of parameters while maintaining performance.

2. **Gating Function**: This method employs a gating function that generates binary decisions on whether to execute specific layers, allowing for flexible layer skipping. Implementations like SkipNet and Conv-AIG exemplify this approach, where lightweight computational overhead is introduced to facilitate efficient decision-making on layer execution. 

3. **Policy Network**: A policy network can assess the input and directly determine the skipping decisions for all layers in a network, providing a structured way to adaptively manage layer execution.

In addition to dynamic depth, the paper also highlights dynamic width, which involves selectively activating neurons or branches within layers based on input. This is exemplified in two contexts:

1. **Skipping Neurons in Fully-Connected Layers**: Here, not all neurons need to be activated for every input sample, and various techniques, including auxiliary branches, can be employed to control neuron activation adaptively.

2. **Skipping Branches in Mixture-of-Experts (MoE)**: This structure allows multiple parallel branches to act as experts, selectively executed based on the input. Their outputs are combined using data-dependent weights, enhancing model capacity and efficiency.

Overall, these dynamic computation strategies aim to optimize neural network performance by intelligently managing resource usage based on input characteristics.
