In this section, we discuss three state-of-the-art Neural Architecture Search (NAS) algorithms used in our experiments: ENAS, DARTS, and NAO, along with their hyper-parameters during the search phase. ProxylessNAS currently achieves the highest top-1 accuracy of 97.92 on CIFAR-10, but its code is not publicly available for evaluation.

ENAS employs a reinforcement learning sampling strategy using a two-layer LSTM to generate architecture strings. Each candidate architecture is trained on a mini-batch, and after every epoch, the controller samples new architectures evaluated on a validation dataset, updating itself based on these metrics. Detailed hyper-parameter settings can be found in the work of Pham et al.

DARTS vectorizes the architecture strings and optimizes them through a dual gradient-descent scheme. The architecture is trained while fixing the probability vector, which is then updated with the network fixed, alternating this process. The final model is derived from a single path in the directed acyclic graph (DAG), evaluated similarly to other NAS algorithms, using hyper-parameters from Liu et al.

NAO utilizes a gradient-descent algorithm with a variational auto-encoder to learn latent representations of architectures. It ranks architectures based on performance, training an encoder-predictor-decoder network to sample new candidates iteratively. The best architecture is identified as the top performer in the NAO ranking, using the code provided by Luo et al.

BayesNAS introduces Bayesian optimization to the NAS field, adopting a search space similar to DARTS but with modifications. It prunes the fully-connected DAG graph using shared weights to derive accuracy metrics. The algorithm is implemented only in the CNN space, and we incorporate the search and model code from Zhou et al. with our training pipeline.

For our experimental setup, we utilize the Penn Tree Bank dataset for word-level language modeling and the CIFAR-10 dataset for image classification, aiming to find effective recurrent architectures for these tasks.
