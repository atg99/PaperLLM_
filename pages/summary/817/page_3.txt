Filter pruning aims to enhance the efficiency of pre-trained deep neural networks by eliminating redundant convolution filters, thereby reducing memory use and computational costs. In a convolutional neural network (CNN) with L layers, the filters in the l-th layer are denoted as Wl, where the number of filters is M. A general objective for filter pruning can be expressed as minimizing a loss function while constraining the number of filters to be preserved.

The relationship between filters and data is indirect; however, the features produced by these filters in response to input data, under the guidance of labels, can indicate their importance. Instead of directly assessing the filters, the approach focuses on the features generated by them. This leads to a reformulation of the objective function, where the aim shifts to minimizing the loss based on the features while preserving a specified number of features.

A significant challenge in this process is accurately determining the correlation between features and ground-truth labels, while also accounting for various confounding factors. To mitigate the influence of these irrelevant factors, the study introduces a scientific control through the use of knockoff counterparts—random features that share the same shape as the real features but lack any association with the labels. These knockoffs serve as a control group, allowing for a comparison that helps isolate the effect of the real features on the predictions.

The properties of exchangeability and independence are established for the knockoff counterparts, ensuring that while they mimic the real features in distribution, they do not contain information about the labels. This comparison enables a more focused selection process that emphasizes the relationship between features and predictions, ultimately leading to a more reliable identification of important filters in the network.
