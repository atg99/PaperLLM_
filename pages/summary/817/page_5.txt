The paper presents a methodology for generating knockoff features in deep neural networks, specifically focusing on the application of these features for filter pruning. Proposition 1 asserts that the knockoff features derived from a generative model of the input data can be treated as counterparts to the actual features produced by the network. This allows for the simplification of the knockoff generation process, as it only needs to be performed once for a given dataset.

In the filter pruning section, the authors propose using the generated knockoff features as a control group alongside the real features during the selection of relevant features for subsequent layers. They formulate an optimization problem that minimizes a loss function while adhering to sparsity constraints. The real features serve as the treatment group, while the knockoff features help mitigate the influence of irrelevant factors.

To implement this, an adversarial selection layer is introduced after each convolutional layer, allowing both real and knockoff features to compete for influence in the network's output. The scaling factors for these features are optimized based on ground-truth labels, enabling the identification of redundant filters.

The importance of each filter is assessed based on the scaling factors obtained after optimization. A filter is deemed less important if its corresponding real feature cannot effectively suppress its knockoff counterpart. Consequently, a statistic is defined to quantify the importance of each filter, guiding the pruning process. The methodology aims to enhance model efficiency by eliminating unnecessary filters while preserving essential features.
