The paper discusses key performance metrics in a Cloud-Fog computing environment, focusing on Makespan and cost calculations for task execution. Makespan, defined as the total time to complete all tasks, is calculated using the maximum execution time across nodes. The ideal scenario, or MinMakespan, represents the shortest completion time when all nodes finish simultaneously, determined by the total task lengths divided by the CPU rates of the nodes.

Cost analysis for task processing includes three components: processing cost, memory usage cost, and bandwidth usage cost. Each cost is calculated based on respective parameters such as CPU usage, memory requirements, and bandwidth needs. The total cost for executing all tasks in the system is the sum of the costs for each individual task.

MinTotalCost represents the lowest cost for completing a set of tasks, achieved by assigning each task to the node with the lowest processing cost. The utility function presented in the paper captures the trade-off between Makespan and total cost, allowing for optimization based on a weighting factor. This framework provides a systematic approach for managing task execution in a Cloud-Fog system, balancing efficiency and cost-effectiveness.
