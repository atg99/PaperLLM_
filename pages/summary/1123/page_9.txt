The paper discusses a task scheduling mechanism in a Cloud-Fog computing environment, focusing on optimizing execution time and processing cost. It introduces a balance coefficient, denoted as 'a', which determines the priority between makespan and total cost during optimization. When 'a' equals 0.5, both factors are equally prioritized. If 'a' is greater than 0.5, the emphasis is on minimizing makespan, indicating a user’s willingness to incur higher costs for better performance. Conversely, when 'a' is less than 0.5, cost is prioritized, suggesting budget constraints for the user.

The goal is to minimize both makespan and total cost while ensuring that the utility function F approaches 1 for optimal solutions. The task scheduling problem is framed with independent tasks and processing nodes, resulting in an assignment of tasks to these nodes. The utility function F is defined as a weighted sum of the minimum makespan and minimum total cost.

The paper proposes using Modified Particle Swarm Optimization (MPSO) as an evolutionary algorithm for this scheduling problem. The MPSO adapts the traditional Particle Swarm Optimization (PSO) approach by removing the service layer typical in grid computing. It employs a binary representation for the particle's position matrix, where each task is assigned to one processing node. The velocity of each particle, which determines its movement in the solution space, is also defined in a similar matrix format. This design ensures that each task is executed on only one node, facilitating an efficient task scheduling process in the Cloud-Fog framework.
