In this paper, a novel approach for recognizing 3D objects using a view-based Graph Convolutional Network (view-GCN) is proposed. The method consists of three main components: view-graph construction, the view-GCN itself, and the training loss. The view-GCN operates on a hierarchical structure derived from gradually coarsened view-graphs, allowing for effective multi-view feature aggregation.

The motivation behind this approach stems from the observation that neighboring views of an object, such as a chair, exhibit smooth variations in pose and appearance, providing distinct recognition cues. In contrast, views of objects like cups appear nearly identical. Additionally, symmetric relationships can be identified between paired views, encoding the latent geometry of objects. These insights drive the design of a graph convolutional network that can automatically explore the relationships among views while aggregating features.

The general pipeline begins with feature extraction from multiple views of a 3D object, followed by the construction of a view-graph where each node represents view features. A graph convolutional network is then employed to hierarchically aggregate these features, resulting in a global shape descriptor used for shape recognition.

To construct the view-graph for a 3D shape, a directed graph is created, with each node corresponding to a view defined by its camera coordinates. The adjacency matrix of the view-graph is constructed based on spatial relations between views, which are computed through a non-linear embedding function. A k-nearest neighbor approach is utilized to maintain edges only between neighboring nodes, allowing for diverse view configurations.

The view-GCN itself is structured across multiple levels of coarsened view-graphs, where node features are iteratively updated through local graph convolution and non-local message passing. This hierarchical aggregation enables the model to effectively capture and utilize the rich information contained in multi-view images for 3D object recognition.
