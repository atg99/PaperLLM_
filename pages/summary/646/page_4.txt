This paper presents a novel selective view-sampling strategy aimed at enhancing the construction of a view-graph for improved semantic feature learning in 3D object classification. The approach involves the following key components:

1. **View-Graph Construction**: The proposed method builds a hierarchical view-graph, Gl+1, by utilizing a selective view-sampling strategy that increases the receptive field, enabling better semantic feature learning. Unlike traditional max-pooling techniques that combine multi-view features in a single step, the method merges these features gradually, considering the relationships among views.

2. **Initial Feature Extraction**: Features are extracted from multiple views using a fine-tuned ResNet-18 network, which is pre-trained on ImageNet. The features are collected before the fully connected layer and serve as the initial node features for the first level of the view-graph.

3. **Local Graph Convolution**: A local graph convolution layer updates node features by leveraging the relationships between neighboring nodes defined by k-nearest neighbors based on camera coordinates. This process involves a learnable adjacency matrix and a non-linear transformation to enhance the node features.

4. **Non-local Message Passing**: After local updates, features undergo a non-local message passing operation to capture long-range relationships among nodes in the view-graph. Messages are computed based on pairwise relations between nodes, allowing for the incorporation of information from distant views.

5. **Selective View-Sampling for Graph Coarsening**: The graph is coarsened to form Gl+1, utilizing a selective view-sampling strategy that combines Farthest Point Sampling (FPS) with a view-selector. This method aims to maintain the diversity of sampled views while also ensuring they are representative for the downstream discriminative learning tasks.

In summary, the proposed method enhances multi-view feature learning by integrating selective view-sampling and hierarchical graph convolution techniques, which collectively improve the representation of 3D objects in classification tasks.
