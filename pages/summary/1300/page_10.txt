The paper discusses the evaluation metrics used to assess the performance of an Intrusion Detection System (IDS) using an autoencoder model. Key performance metrics include True Positive Rate (TPR), False Positive Rate (FPR), Accuracy, and F1 Score, with the Matthews Correlation Coefficient (MCC) highlighted as the primary metric. MCC is valued for providing a balanced measure of model performance across all classes, especially in imbalanced datasets common in IDS applications.

The authors conducted experiments to determine how different model structures and latent sizes affect the performance of the autoencoder in network intrusion detection. They utilized various configurations of fully connected hidden layers with ReLU activation in the encoder and Sigmoid activation in the output layer. Each model configuration is represented by the format (Depth, Size), where Depth indicates the number of hidden layers and Size denotes the number of nodes in the first hidden layer. The configurations tested include variations in both the number of nodes and hidden layers to analyze their impact on performance.

The results are derived from multiple test runs using different random seeds to account for performance variability. The paper specifically compares the (5,32) and (5,64) models to assess the effect of model capacity, as well as the (5,64) and (7,64) models to evaluate the impact of model complexity. These comparisons aim to understand how structural differences influence the effectiveness of the IDS model.
