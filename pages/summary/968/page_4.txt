The paper presents a novel stochastic model with discrete latent variables designed for reinforcement learning in environments modeled as Markov decision processes (MDPs). The model architecture consists of two main components: a skip-connected convolutional encoder-decoder and a convolutional inference network. The input to the model includes four stacked frames along with the selected action, which are embedded through fully connected layers. The output is the predicted next frame and expected reward, utilizing a per-pixel softmax with 256 colors.

To condition the output on agent actions, the decoder's outputs are multiplied by the learned action embeddings. During training, latent values sampled from the posterior are discretized into bits, with backpropagation bypassing the discretization to maintain differentiability. An LSTM-based network is trained to predict latent bits auto-regressively during inference.

Reinforcement learning is formalized through MDPs, where the agent interacts with the environment using a policy that maps states to action distributions. The quality of the policy is evaluated using the value function, which estimates the total discounted reward over time. The proposed algorithm, SimPLe, iteratively collects observations from the real environment, updates the simulated environment model, and trains the policy to maximize rewards using minimal interactions with the actual environment.

In summary, the paper emphasizes the importance of using a simulated environment to efficiently learn policies that perform well in real environments, particularly in complex settings like Atari 2600 games. The approach seeks to optimize learning by minimizing the need for extensive interactions with the actual environment, leveraging the capabilities of the world model to enhance policy training.
