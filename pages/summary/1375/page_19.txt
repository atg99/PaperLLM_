The paper discusses two programming languages for autonomous agents: 3APL and 2APL, focusing on their structures, functionalities, and perspectives.

From a Multi-Agent Systems (MAS) perspective, 3APL is designed with programming constructs that allow for the implementation of agents based on beliefs, goals, plans, actions, and practical reasoning rules. The core elements include declarative goals that define desired states, procedural plans for achieving these goals, and rules for plan generation. 2APL, an extension of 3APL, incorporates events into the BDI (Belief-Desire-Intention) framework, facilitating the generation and execution of plans based on beliefs, goals, and events. It features an execution platform with a graphical interface for loading, executing, and debugging multi-agent programs, and can operate in standalone or distributed modes using JADE.

From a logical perspective, 3APL combines logic programming and rule-based systems, allowing agents to express beliefs and goals in a declarative manner. In contrast, 2APL utilizes logical facts and rules, with goals represented as logical formulae that guide the execution of plans.

Technologically, both 3APL and 2APL remain accessible online, although they are no longer maintained. The source code is unavailable, but pre-compiled binaries exist. While 2APL operates on Java Virtual Machines (JVM) 6 to 8, 3APL encounters runtime errors across various JVM versions.

Additionally, the paper briefly introduces jDALMAS, a Prolog implementation of the DALMAS architecture, which allows agents to specify permissible actions based on a normative system. During deliberation, agents can select actions from feasible options, potentially leading to new system states.
