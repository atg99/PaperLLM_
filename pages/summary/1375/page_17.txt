The paper discusses two technologies, DRAGO and Jadex, within the context of Autonomous Agents and Multi-Agent Systems. 

DRAGO, or Distributed Reasoning Architecture for a Galaxy of Ontologies, addresses the challenge of reasoning across multiple ontologies linked by semantic mappings. It utilizes description logic and is grounded in distributed description logics, which enhance standard description logic with semantic mappings, facilitating the representation of interconnected ontologies. The reasoning process follows the distributed contextual reasoning paradigm, employing distributed tableau techniques. DRAGO technology is available as pre-compiled jars for the JVM platform, though it is unmaintained. It has been tested successfully with newer JVM versions.

Jadex, on the other hand, is a software framework designed for creating goal-oriented agents based on the Belief-Desire-Intention (BDI) model. It aims to build a rational agent layer atop the JADE infrastructure, leveraging sound software engineering principles. Jadex allows for the definition of beliefs, intentions, desires, and plans using both Java and XML. It enhances traditional BDI systems by introducing explicit goals and employs a combination of declarative and procedural approaches for agent components. Beliefs can be represented not only in logic but also through ordinary Java objects, facilitating the reuse of existing classes. A query language similar to OQL allows for a more declarative interaction with beliefs, which the reasoning engine uses to monitor changes and adjust goals and plans accordingly.
