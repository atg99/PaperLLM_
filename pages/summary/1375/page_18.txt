The paper discusses various technologies related to autonomous agents, focusing on the Jadex and JIAC frameworks, along with the JADL (JIAC Agent Description Language). Jadex is an open-source technology that requires JVM 8 and is actively developed, as evidenced by ongoing activity on its GitHub repository. Despite encountering issues with its build automation system due to missing dependencies, the project demonstrates maturity and is available as a Maven artifact.

JIAC, an extensive agent framework, incorporates JADL as its core component. JADL, originally proposed by Sesseler, offers a declarative language for agent specification, supporting a variety of tools for agent creation and web-service connectivity. The framework includes a Java-based runtime environment and facilitates the development of multi-agent systems (MAS) through platforms that feature their own agent management systems. Agents in JIAC are defined using JADL, which encompasses ontologies, rules, and plans, allowing interaction with real-world applications through AgentBeans.

From a logical perspective, JIAC employs various logic concepts, such as first-order logic and situation calculus, with JADL based on three-valued predicate logic to handle uncertainty. This allows agents to explicitly evaluate predicates as unknown when information is insufficient. JADL's planning mechanism is distinct from other frameworks, as it relies on first-principles planning without pre-compiled plans.

The paper also mentions that JADL and JIAC are accessible through Maven repositories, with the latest version released in 2018, indicating ongoing maintenance. The availability of documentation and examples facilitated successful testing of JIAC, affirming its operational status as a mature Java project. Additionally, the paper references the 2APL and 3APL frameworks as part of the broader discourse on agent programming technologies.
