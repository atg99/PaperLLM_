The paper discusses two key technologies related to multi-agent systems: 2CL and AORTA. 

2CL is a tool that extends the enhanced commitment machine, allowing for the exploration of all possible executions of a business protocol and identifying violations. It is implemented in tuProlog and uses a Java parser for interpreting specifications. While the 2CL technology is not actively maintained, it stands out as the only commitment-based model with runnable technology available. The implementation requires the JVM 7+ platform.

AORTA, or Adding Organisational Reasoning to Agents, enhances agents with organizational reasoning capabilities. It operates independently of the agent's architecture and utilizes tuProlog for translating the agent's knowledge into Java objects. This integration of logic programming and object-oriented paradigms allows for a flexible reasoning framework. AORTA is also available as an unmaintained Java project on GitHub, requiring the JVM 7+ platform for its pre-compiled jars.

In summary, both 2CL and AORTA offer valuable tools for enhancing commitment and organizational reasoning in multi-agent systems, albeit with limitations regarding maintenance and licensing.
