The paper discusses the Jason interpreter, an extended version of the AgentSpeak(L) programming language, which is grounded in the Beliefs-Desires-Intentions (BDI) architecture. Jason enables developers to create autonomous agents that respond to various events in a multi-agent system (MAS) by modeling their goals and actions through a Prolog-like syntax. The functionality of Jason agents encompasses perception, belief updates, message-passing, and goal management. 

From a logical perspective, Jason operates on BDI logic, defining agents through their beliefs (knowledge of the world), desires (desired states), and intentions (planned actions). It is important to note that while BDI logic serves as a programming framework for agent-oriented programming (AOP), it is not designed for formal analysis of MAS properties.

Technologically, Jason is an open-source tool requiring Java Virtual Machine (JVM) 8 or higher, available under the GNU Lesser General Public License. Its active development is evidenced by a robust GitHub repository and numerous resources on its website. Jason has been tested with various examples, confirming compatibility with recent JVM versions.

The paper also introduces Golog and its successors—ConGolog and IndiGolog—programming languages that model agent dynamics through explicit representations of the initial state and the effects of actions. Golog-like languages allow for the programming of autonomous agents that perceive and plan in their environments. ConGolog supports concurrent programming, while IndiGolog focuses on agents' sensory capabilities and planning.

Golog and its derivatives are implemented in Prolog and are based on the Situation Calculus, utilizing Prolog-based meta-interpreters to define custom action languages through operator overriding.
