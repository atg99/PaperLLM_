The paper discusses two technologies in the realm of argumentation within multi-agent systems: Defeasible Logic Programming (DeLP) and Aspartix.

From a MAS perspective, DeLP integrates logic programming with defeasible argumentation, drawing on Nute's defeasible model. It allows agents to derive tentative conclusions that can be retracted with new evidence, making it suitable for handling uncertainty. DeLP enables the representation of information as weak rules and employs a defeasible argumentation inference mechanism to validate conclusions. In cases of conflict, it facilitates a dialectical process where arguments for and against a conclusion are evaluated, leading to the endorsement of undefeated arguments.

Logically, DeLP is grounded in deontic and defeasible logic, representing a structured argumentation approach. Technologically, it is part of the Tweety Project, offering Java libraries for various AI applications and a web service for in-browser use, although the service was offline during the evaluation. DeLP requires JVM 12+ and is distributed under the GNU Lesser General Public License.

Aspartix, on the other hand, is an agent argumentation framework that formalizes statements and their rebuttals. It provides a means to resolve conflicts by selecting admissible subsets of statements, supporting agent decision-making in a modular architecture. Logically, Aspartix uses Answer Set Programming (ASP) to identify justified arguments based on Dung's argumentation framework, processing input through a disjunctive datalog program with an answer-set solver.

Technologically, Aspartix is available as a web service under the MIT License, with its last update noted in 2018. It can be utilized across platforms and includes predefined examples for testing purposes.

Overall, the paper highlights the capabilities and frameworks of DeLP and Aspartix in enhancing argumentation within multi-agent systems.
