This section discusses several technologies related to multi-agent systems, focusing on their logical and technological aspects.

The DALMAS architecture is highlighted, which integrates a preference and deontic structure influenced by norms expressed through an algebraic notation based on the Kanger-Lindahl theory. This theory blends action logic and deontic logic, allowing for a structured approach to decision-making within the architecture. However, the jDALMAS technology, which implements this architecture, is currently unmaintained and lacks comprehensive documentation, limiting further assessments.

RASP, or Resourced Answer Set Programming, builds upon traditional Answer Set Programming by incorporating resource management into its reasoning capabilities. Although not originally designed for agent-oriented paradigms, it has been utilized to enhance logic agents' reasoning in resource-centric scenarios. RASP integrates answer set semantics with quantitative reasoning and resource usage preferences. The Raspberry implementation serves as a translator from ground RASP to ASP, allowing for the execution of RASP rules. While Raspberry is available but unmaintained, it functions effectively with the Clingo ASP solver.

TeleoR expands on the Teleo-Reactive programming paradigm for robotic agents, allowing for the creation of Guard-Action rules organized into procedures. These rules enable agents to respond to sensory input and perform both primitive actions and complex behaviors, including task management and error recovery. TeleoR aims to enhance the reactive and multi-tasking capabilities of robotic agents, making it a versatile tool in the field of autonomous systems.

Overall, these technologies illustrate advancements in decision-making frameworks and programming languages designed for multi-agent systems and robotics, though some face challenges related to maintenance and documentation.
