The paper discusses various multi-agent system (MAS) programming languages, focusing on JACK MAS and Agent Factory Agent Programming Language (AFAPL). JACK MAS is implemented in an extended version of Java, integrating object-oriented programming with BDI (Belief-Desire-Intention) logic, facilitating the manipulation of agents' plans, beliefs, and interactions. Its design aims to support developers, particularly with AI backgrounds, by incorporating logical variables and cursors for complex queries on the agent belief base. The semantics of JACK is described as a blend of logic programming and embedded SQL, although its closed-source nature limits technological inspection.

AFAPL, introduced in 2002, is another BDI-based language designed for creating intentional agents. It operates through the Agent Factory tool, which supports various MAS development aspects, including distribution via the JADE platform. A key feature of AFAPL is its commitment concept, where agent behavior is guided by the goals they commit to, allowing explicit planning of agent behavior based on commitment conditions. While AFAPL supports heterogeneous logic-based agent architectures, it also draws inspiration from the AgentSpeak(L) model for agent execution semantics. However, AFAPL is an unmaintained Java project lacking documentation, which hinders further technological assessment.

The paper highlights the significance of combining logical frameworks with programming paradigms in developing robust and flexible agent systems, although both JACK and AFAPL present limitations in terms of accessibility and documentation.
