The paper discusses various declarative programming languages and systems for autonomous agents and multi-agent systems, focusing on TeleoR, ASTRA, AgentSpeak(ER), and Jason-ER.

From a logical perspective, TeleoR utilizes logical rules for representing information, with each TR node embodying both percepts and beliefs. It builds on the Qu-Prolog system, enhancing Prolog with a flexible type system for belief storage, inference, and deliberation. However, the evaluation of TeleoR was hindered by difficulties in compiling Qu-Prolog, as the technology is only available as source code without pre-compiled binaries.

Astra allows for declarative agent plan definitions, integrating closely with Java, enabling the use of Java objects and types directly in scripts. It implements BDI logic through AgentSpeak(TR) and is available as an Eclipse IDE plug-in. The installation was successful, and tests were performed using the official documentation.

AgentSpeak(ER) extends AgentSpeak(L) by introducing plan encapsulation, allowing for the definition of plans that integrate proactive and reactive behaviors. It includes prototype implementations based on ASTRA and Jason, with Jason-ER providing necessary syntactical and semantic enhancements to support AgentSpeak(ER). 

In summary, the paper highlights the advancements in agent programming languages, emphasizing the logical frameworks and technological aspects that enhance agent functionality and integration with existing programming environments.
