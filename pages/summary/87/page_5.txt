The paper discusses an enhancement to the Long Short-Term Memory (LSTM) architecture through the introduction of Working Memory Connections. This modification aims to improve the mapping between the internal state of the cell and the gate values. The authors propose using recurrent weights and a nonlinear activation function to establish a connection between the memory cell and the gates.

The equations for the input, forget, and output gates are reformulated to include a protection mechanism for the cell state. Specifically, the input gate equation incorporates the previous cell state, highlighting the importance of non-linear transformation in managing the interactions of the cell state with the gate mechanisms. The authors argue that while these connections may appear redundant, they introduce significant innovations, particularly by allowing the output gate to depend on the current cell state rather than the previous one, thus enhancing the responsiveness of the LSTM block.

The paper also provides a formal analysis of the impact of Working Memory Connections by examining the local gradients of the input gate. This analysis reveals that the inclusion of the cell state interaction in the gate calculations can lead to improved performance, as supported by previous research indicating that the absence of such non-linearities can negatively affect LSTM performance.
