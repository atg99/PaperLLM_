This paper discusses various methods for measuring the influence, relevance, or importance of features in machine learning model predictions, highlighting several contributions within this domain. A notable method is SHAP (SHapley Additive exPlanations), which calculates additive feature importance scores while ensuring properties like local accuracy, missingness, and consistency. Other approaches include coalitional Game Theory and local gradients, which analyze how changes in features affect model outputs. 

The Quantitative Input Influence (QII) measures proposed in one study account for correlated inputs, while another study extends Sensitivity Analysis to a Global SA, allowing broader application. The Automatic Structure Identification (ASTRID) method identifies the most significant subset of features that maintains classification accuracy. Influence functions are discussed as a means to trace model predictions back to training data, and heuristics for creating counterfactual examples contribute to model explainability.

The paper also covers visual explanation techniques that aim for model-agnostic explanations. These include a variety of visualization techniques that aid in understanding black-box models, such as Individual Conditional Expectation (ICE) plots. However, creating effective visualizations poses challenges due to the need for methods to work with opaque models.

Overall, the literature reveals trends in rule extraction techniques and a growing interest in feature relevance methods, especially in deep learning contexts. Visualization techniques are also emerging as significant tools for enhancing model interpretability, often working in conjunction with feature relevance methods to convey information effectively to users.
