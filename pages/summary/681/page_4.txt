Support Vector Machine (SVM): SVM is a powerful classifier that works well for high-dimensional spaces. It constructs a hyperplane or set of hyperplanes in a high-dimensional space to separate different classes. The parameters for SVM included in our study are kernel type as radial basis function (RBF), C set to 1, and gamma set to auto.

In summary, the proposed MSALSTM-CNN algorithm leverages a combination of convolutional neural networks and long short-term memory networks to enhance anomaly detection through effective feature extraction and sequence learning. The attention mechanism plays a critical role in improving the model's performance by assigning significance scores to data sequences. Additionally, the ensemble learning approach, which combines the outputs of multiple classifiers through majority voting, further enhances detection accuracy. The methodologies employed, including parameter tuning, regularization techniques, and advanced optimization methods, collectively contribute to achieving high detection rates while minimizing overfitting.
