The study identifies four key types of anomalies: instant, constant, gradual drift, and bias anomalies. These anomalies can arise from faults or cyberattacks and can severely impact vehicular services. The dataset used for analysis includes both single and mixed anomaly types, with anomalies injected at different frequencies, reflecting potential real-world scenarios.

The proposed methodology integrates multiple machine learning classifiers, including Convolutional Neural Networks (CNNs), Long Short-Term Memory networks (LSTMs), Random Forest, AdaBoost, and Support Vector Machines (SVMs), chosen for their ability to handle diverse data characteristics and improve detection rates of weak classifiers.

A notable aspect of the methodology is the employment of a multistage attention mechanism within the LSTM-based CNN architecture. This approach enhances the model's ability to focus on significant features in the data while processing sequences, thereby improving the accuracy of anomaly detection. The architecture involves several preprocessing steps, including one-hot encoding of target labels and scaling of sensor data, followed by reshaping the data into a three-dimensional format suitable for CNN input.

The overall design aims to create a robust framework for anomaly detection in CAVs, which can adapt to various data types and improve the safety and reliability of automated vehicular systems.
