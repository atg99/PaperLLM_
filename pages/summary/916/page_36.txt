This paper discusses advanced sampling techniques in metric learning, focusing on distance-weighted sampling, Bayesian updating, hard negative sampling, and deep discriminant analysis methods.

1. **Distance-Weighted Sampling**: The approach involves minimizing a loss function that accounts for distances between embeddings of anchor, positive, and negative samples. This method ensures that all candidates have a chance to be selected for each mini-batch.

2. **Bayesian Updating Sampling**: This technique employs the Bayesian theorem to sample triplets from class distributions. It assumes a Gaussian distribution for each class, which is updated as new data is introduced. The updated mean and covariance are used to sample positive and negative points, forming triplets for loss functions like triplet loss and normalized cut adjacency loss.

3. **Hard Negative Sampling**: This method defines distributions for negative and positive points and uses these to compute a loss function that emphasizes learning from difficult examples. The sampling is stochastic, and expectations are estimated using Monte Carlo approximation.

4. **Deep Discriminant Analysis**: This section explores methods inspired by Fisher discriminant analysis, focusing on creating an embedding space that separates classes effectively. Techniques include deep probabilistic discriminant analysis, which minimizes the inverse Fisher criterion to enhance class separation.

Overall, the paper outlines various modern techniques for sampling in metric learning, emphasizing their mathematical foundations and practical implications in creating effective embedding spaces.
