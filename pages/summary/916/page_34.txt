The paper discusses various methodologies in deep adversarial metric learning, specifically focusing on loss functions used within Siamese networks and triplet mining techniques. The total loss function for deep adversarial metric learning is represented as minimizing the combination of a general loss function and a regularization term, emphasizing the role of the triplet loss.

Triplet mining is a critical process that involves selecting triplets of data points within each mini-batch, which can be done in several ways:

1. **Batch-all**: This method considers every point in the mini-batch as an anchor and utilizes all points in the same class as positive points, while all other classes serve as negative points. This approach maximizes the use of available data.

2. **Batch-hard**: Here, the hardest positive (the farthest point from the anchor in the same class) and the hardest negative (the closest point from another class) are selected to enhance learning by focusing on the most challenging cases.

3. **Batch-semi-hard**: This method selects the hardest negative that is farther than the positive point while still using all points in the same class as positives. This balances the difficulty of the negative with the positive point's proximity.

4. **Easy-positive**: In this approach, the easiest positive (closest point in the same class) is chosen, with all other classes serving as negatives. This method simplifies the positive selection to aid in learning.

Additionally, the paper references the use of these triplet mining strategies in other loss functions, such as the Neighborhood Component Analysis (NCA) loss, and introduces the lifted embedding loss, which focuses on the distances between anchor-positive and anchor-negative pairs. The methodologies discussed are significant for enhancing the performance of metric learning systems in various applications, including person re-identification.
