This paper presents the MuRel network, a novel approach to Visual Question Answering (VQA) that enhances the interaction between visual content and questions by utilizing more expressive representations than traditional scalar attention maps. The method incorporates both spatial and semantic context by examining all possible pairs of image regions, rather than relying on a locally connected graph structure.

The MuRel network draws inspiration from synthetic reasoning models like MAC and FiLM, adapting them for real data VQA applications. The network employs a bilinear fusion mechanism to improve interactions between image regions and questions, allowing for richer contextual understanding.

The architecture operates by processing an image and a corresponding question to predict an answer. It represents the image with a set of vectors corresponding to detected objects and their spatial coordinates, while the question is encoded using a gated recurrent unit network. The core component, the MuRel cell, performs elementary reasoning through a residual function that combines bilinear fusion for multimodal embedding with a pairwise modeling component to update representations based on spatial and visual context.

The bilinear fusion module effectively merges question and region feature vectors, capturing intricate interactions while maintaining a compact parameterization. Unlike classical attention models, which only assess relevance, the MuRel cell generates a richer vector representation that encodes complex correlations between modalities.

To address reasoning over multiple interacting objects, the network employs pairwise relationship modeling, ensuring that each region's representation is informed by its neighbors. This holistic approach enables the MuRel network to better understand the spatial and semantic dynamics of visual scenes in relation to posed questions, ultimately improving VQA performance.
