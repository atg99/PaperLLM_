The paper discusses a method for integrating visual and textual information in a navigation task using a cross-modal approach. It outlines the process of obtaining visual attention scores and weights, followed by a weighted sum of input textual and visual tokens to derive raw features. A cross-modal matching is then enforced through an element-wise product, which is incorporated into the agent's state representation. Unlike prior models, which only utilized visual features, this approach leverages both modalities to enhance navigation capabilities.

The decision-making process employs inner product scoring between state representations and visual features to determine the best navigation direction. The authors highlight the effectiveness of the BERT network in scoring, utilizing mean attention weights from visual tokens to derive action probabilities and object selection probabilities.

Training combines reinforcement learning and imitation learning, using the A2C algorithm to sample actions and measure advantages, while also minimizing a navigation loss function based on teacher actions. The model is initially adapted from a pre-trained version of OSCAR, showing compatibility with various feature representations.

Experiments are conducted on NVIDIA 2080Ti GPUs, detailing implementation specifics such as learning rates, batch sizes, and training iterations. Evaluation metrics include trajectory length, navigation error, success rate, and success weighted by path length, ensuring comprehensive performance assessment against established benchmarks.
