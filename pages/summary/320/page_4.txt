The paper discusses the architecture and functionality of a model called VLN-BERT, which adapts the principles of BERT for visual navigation tasks. It begins with a foundational overview of the mathematical formulations used in its layers, including the integration of language and visual tokens, and the application of layer normalization and ReLU activation functions.

The model extends BERT to create V&L BERT, which processes concatenated language and visual tokens to learn representations from image-text corpuses. The authors propose modifications to the OSCAR model, allowing VLN-BERT to learn navigation and referring expression (REF) tasks by processing four sets of tokens at each time step: previous state tokens, language tokens, visual tokens for scenes, and visual tokens for objects.

The language processing aspect initializes the model with a sequence of tokens that includes a classification token, which is crucial for aggregating visiolinguistic clues. During navigation, while visual tokens are updated with each observation, language tokens serve as fixed keys and values to preserve computational efficiency.

The vision processing component involves projecting image features into the same space as BERT tokens, allowing the model to use visual clues for navigation. For the REF task, object features are also included as additional visual tokens.

State representation is central to the model, summarizing all textual and visual information collected by the agent. Rather than using an external memory buffer, VLN-BERT relies on BERT's architecture to update the state recursively. The state representation evolves over time and is used as the leading input for subsequent navigation steps.

To refine the state representation, the model incorporates attention mechanisms that match raw textual and visual tokens, ensuring the state captures significant features. Overall, the paper outlines a systematic approach to enhancing visual navigation through a sophisticated integration of language and visual inputs within a BERT-like framework.
