The referenced works focus on advancements in object detection and action recognition within computer vision. Lin et al. introduced focal loss for dense object detection, addressing class imbalance in the detection process. They also presented feature pyramid networks, enhancing multi-scale feature representation for improved object detection performance. Carreira and Zisserman proposed a new action recognition model alongside the Kinetics dataset, contributing significantly to the field. Szegedy et al. re-evaluated the Inception architecture, optimizing it for better performance in computer vision tasks. Additionally, Deng et al. discussed the ImageNet database, a crucial resource for training deep learning models. Chihara and Hesterberg provided insights into mathematical statistics with a focus on resampling techniques using R. These contributions collectively advance the methodologies and datasets essential for progress in machine learning and computer vision.
