The proposed ranked list loss (RLL) framework iteratively treats each image in a mini-batch as a query, generating a ranked list of images based on similarity scores. The framework focuses on mining non-trivial data points and applying weights to negative examples according to their pairwise margin losses relative to the query. The loss is computed for each query without weighting positive examples due to their scarcity. 

RLL balances two minimization objectives: the positive loss and a weighted negative loss, with a fixed parameter λ set to 1. This results in the overall loss being influenced primarily by the query image, while the features of other images are treated as constants. The learning process is implemented using mini-batch stochastic gradient descent, with each mini-batch representing a simplified ranking problem. 

The computational complexity of RLL is O(N^2), similar to existing structured loss functions. The implementation involves sampling classes and images per class to create a mini-batch, with specific preprocessing and augmentation techniques applied to the input images. The backbone network utilized for this framework is GoogLeNet V2, ensuring consistency with prior studies. The embedding size is standardized to 512 across datasets, and L2 normalization of features is performed during training and testing.
