The paper concludes that the system design is effectively implemented using Unified Modeling Language (UML) diagrams, which include use case diagrams, activity diagrams, and class diagrams. The system is developed using Python, requiring users to operate through the Anaconda prompt and utilize Jupyter Notebook. The focus of the study is on detecting objects in the researcher’s environment, with the system capable of recognizing both stationary and moving objects. The output consists of the object's name, a bounding box, and an accuracy percentage. This indicates a robust approach to object detection, emphasizing the system's versatility in real-time applications.
