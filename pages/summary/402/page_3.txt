The paper discusses a system designed for object detection using the YOLOv3 algorithm, as illustrated in Figure 1, which outlines the monitoring and identification process. The camera captures surrounding objects, and upon detection, a bounding box is displayed along with the object's identification details and accuracy. If the system fails to identify an object, it re-initiates the monitoring process.

The Results and Discussion section highlights common challenges in machine learning for object detection, particularly the variability in object shapes, colors, and sizes, which complicates the detection of both objects and non-objects.

In the System Design subsection, the paper describes the use of Unified Modeling Language (UML) diagrams, including use case, activity, and class diagrams. The use case diagram outlines three key features: 

1. **Scan Object**: Users can point a random object at the camera for detection.
2. **Detecting Object**: The system recognizes the captured object and provides its name and accuracy.
3. **Viewing Object Detection Results**: Users can view the detection results, including object names and accuracy percentages.
