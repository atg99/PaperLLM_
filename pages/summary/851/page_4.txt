This paper discusses a white-box membership inference attack aimed at determining whether a specific data point belongs to the training set of a target model. The attack involves running the target model on input data to compute hidden layers, model output, and the loss function during a forward pass, followed by calculating gradients of the loss with respect to model parameters in a backward pass. These computations, along with the one-hot encoding of the true label, serve as features for the inference attack model, which comprises convolutional neural network (CNN) and fully connected network (FCN) components.

In a white-box scenario, the attacker has access to the model's parameters, enabling them to compute any function related to the model and input. This includes the outputs of hidden layers, which can provide valuable insights for membership inference. The paper highlights that the generalization of model outputs and activation functions can limit the effectiveness of inference attacks, as these outputs might not significantly differ between training and unseen data.

The authors propose leveraging the stochastic gradient descent (SGD) algorithm used in model training. They argue that by observing the gradients of the loss function, which become minimized for data points in the training set, an attacker can distinguish between members and non-members of the training data. Given the high dimensionality of model parameters, the gradients' distribution can reveal membership information.

The inference attack's architecture includes an encoder that processes the outputs from CNN and FCN components, producing a single value that represents the membership information. In a supervised setting, this value is trained to reflect the probability of membership. In an unsupervised setting, a decoder reconstructs important features from the attack output, akin to a deep autoencoder.

Overall, the paper emphasizes the significance of gradient and activation computations across different layers of the neural network, suggesting that earlier layers contain less specific information about training data, while gradients can be more informative for distinguishing membership status.
