The paper discusses active attacks in the context of federated learning, where an adversary, participating in the training process, can manipulate the target model to extract sensitive information about its training set. The adversary can craft parameter updates that exploit the Stochastic Gradient Descent (SGD) algorithm to execute membership inference attacks. By focusing on data points that contribute significantly to the loss, the adversary can adjust model parameters to increase the loss on these points, thus distinguishing between members and non-members of the training set.

In this scenario, the adversary utilizes a gradient ascent approach on a targeted data record to update local model parameters, which are then uploaded to a central server for aggregation. If the targeted record is part of the training set, the local SGD reduces the loss gradient, which can be detected by the inference model, facilitating high-confidence inference attacks.

To construct the inference attack model, the adversary seeks a mapping between the model's responses and data membership. This can be achieved through supervised learning using known members and non-members from overlapping datasets. Alternatively, if the adversary lacks known samples from the target set, they can employ shadow models—models with the same architecture trained on similar but distinct datasets—or unsupervised training on the target model. 

In the unsupervised setting, the adversary utilizes an encoder-decoder architecture to derive embeddings for data points, which helps in distinguishing members from non-members using clustering techniques. The decoder reconstructs important features such as loss values, model predictions, and gradient norms, which are critical for effective membership inference. Ultimately, the attack outputs embeddings that represent each data point's membership likelihood, enabling a batch attack on a large set of data records.
