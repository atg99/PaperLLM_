The paper presents a methodology tested on validation sets from a 5-fold cross-validation, focusing on hyperparameter selection to achieve the highest combined score across all folds. A grid search method was employed to determine the optimal threshold value within the range of 0.3 to 0.7, and the number of voxels was also optimized within the range of 0 to 100 based on maximizing scores in cross-validation.

The solution is implemented in PyTorch, extending NVIDIA's nnU-Net, and is publicly available on the NVIDIA Deep Learning Examples GitHub repository. The implementation utilizes the NVIDIA NGC PyTorch 21.07 Docker container for dependency management and reproducibility. Mixed Precision was employed to enhance performance and reduce GPU memory usage during training and inference on an NVIDIA DGX A100 system.

The training schedule involved 1,000 epochs using the Adam optimizer with varying learning rates and a weight decay of 0.0001. A linear warm-up of the learning rate was applied in the first 1,000 steps, followed by a cosine annealing schedule. Model evaluation was conducted using 5-fold cross-validation, focusing on the highest Dice scores, with checkpoints saved for the best-performing models.

Three U-Net variants were tested to select the model architecture: a baseline U-Net following nnU-Net heuristics, UNETR which integrates a Vision Transformer for 3D convolutions, and a U-Net with an autoencoder structure. The evaluation metrics and methodologies aim to ensure robust model performance in segmentation tasks.
