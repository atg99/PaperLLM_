This paper presents a framework for 3D point cloud oversegmentation, particularly in challenging scenarios where object boundaries are not clearly defined, such as a whiteboard on a white wall. The framework consists of several key steps: first, a colored point cloud is inputted, and an embedding for each point is computed. This embedding facilitates the application of a clustering technique to achieve oversegmentation that closely aligns with the true objects.

The related work section discusses existing methods for superpixel and supervoxel segmentation, emphasizing the differences in handling 2D images and 3D point clouds. While traditional methods are effective for images, they struggle with the unordered and irregular nature of point clouds. Various graph-based and cluster-based approaches have been proposed for 3D oversegmentation, but many rely on hand-crafted features and can be sensitive to initialization.

Deep learning methods have been explored for 3D point cloud tasks, primarily for semantic segmentation and object detection, but no supervised oversegmentation techniques utilizing deep learning embeddings have been identified. The paper highlights the relevance of metric learning, which aims to create a similarity function for data points, and discusses its application in enhancing features for semantic segmentation.

The proposed method aims to achieve high-quality oversegmentation with three main properties: object-purity, ensuring superpoints do not overlap different objects; border recall, aligning superpoint interfaces with object borders; and regularity, maintaining simple shapes for superpoints. The methodology is divided into two parts: the local cloud embedder, a neural network that generates embeddings capturing local geometry and radiometry, and the subsequent computation of oversegmentation using graph or cluster-based algorithms.
