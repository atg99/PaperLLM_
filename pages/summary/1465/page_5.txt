The paper introduces CERT, a method that enhances language understanding through contrastive self-supervised learning (CSSL) using pretrained language models like BERT. The process begins with pretraining the BERT model on large-scale unlabeled text from source tasks. Following this, the model undergoes further training with CSSL on unlabeled input texts specific to a target task, resulting in a pretrained CERT model.

CERT employs a technique where original sentences are augmented through back-translation, creating pairs of sentences. These pairs are classified as positive if they derive from the same original sentence and negative otherwise. The BERT model encodes these augmented sentences, and a similarity score is computed based on their encodings. The contrastive loss is then defined using these similarity scores and binary labels to train the model.

To address the computational challenges of requiring large minibatch sizes, CERT utilizes the MoCo framework, which employs a dynamic queue of augmented examples that decouples the training process from the minibatch size. This allows for efficient training while maintaining performance. Ultimately, the CERT model is fine-tuned with labeled data from the target task to produce a model optimized for that task.
