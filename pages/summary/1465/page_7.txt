The paper presents CERT, a method for contrastive self-supervised learning (CSSL) aimed at enhancing language understanding. The authors implement CSSL using the MoCo framework, where augmented sentences are categorized into positive pairs (from the same original sentence) and negative pairs (from different sentences). A queue maintains augmented sentences, allowing a query sentence to be compared with these keys. The query and keys are encoded using a pretrained BERT model, with the key weights updated through a momentum mechanism. The contrastive loss is defined to optimize the model by minimizing the difference between the query and its corresponding positive key while contrasting it with negative keys.

The evaluation of CERT is conducted across eleven tasks from the General Language Understanding Evaluation (GLUE) benchmark, which includes a variety of tasks focused on sentence classification, similarity, and inference. Performance is assessed primarily through accuracy, with specific metrics like the Matthews correlation coefficient for grammaticality judgments in the CoLA task, and accuracy and F1 scores for paraphrasing tasks like MRPC. The authors note that while the validation labels are publicly available, test set labels are not, and performance is derived by submitting results to the GLUE evaluation server. Overall, CERT is positioned as a competitive approach to language understanding, particularly when compared to the established BERT model.
