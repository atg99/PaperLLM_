The paper introduces CERT, a method for contrastive self-supervised learning aimed at enhancing language understanding. The process begins with a BERT model pretrained on large-scale unlabeled texts from source tasks. This model is then further trained using Contrastive Self-Supervised Learning (CSSL) on unlabeled input texts from a target task, resulting in a pretrained CERT model. Following this, the CERT model is fine-tuned with labeled data specific to the target task to produce a final model capable of performing that task effectively.

Additionally, the paper discusses a data augmentation technique utilizing back-translation. For each input sentence in the target task, the original English sentence is first translated into German and then back into English, generating an augmented sentence. A similar process is applied using Chinese, creating another augmented version. This method leverages machine translation models to enhance the dataset without losing the original meaning, ultimately improving the performance of the model on the target task.
