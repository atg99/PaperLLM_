Contrastive self-supervised learning (SSL) is a learning paradigm that derives patterns and properties from input data without requiring human-provided labels. The core concept involves constructing auxiliary tasks from the data itself, compelling the network to learn meaningful representations through these tasks. Common auxiliary tasks include rotation prediction, image inpainting, automatic colorization, and context prediction.

Recent research has highlighted the effectiveness of contrastive mechanisms in SSL. The fundamental approach in contrastive SSL is to generate augmented examples from original data and create a predictive task to determine if two augmented examples originate from the same original data. This method emphasizes learning representations by solving the similarity task between augmented data pairs.

In the contrastive framework, a momentum encoder is utilized to encode keys from a queue. When a query (an augmented example from the current minibatch) is compared to a key, they are considered a positive pair if they stem from the same original example and a negative pair otherwise. The similarity score between the query and each key is computed, and contrastive losses are defined based on these scores and their corresponding binary labels.

Different implementations of contrastive SSL exist, such as SimCLR, which applies random data augmentation to images. Augmented images derived from the same original image are labeled as similar, while those from different images are labeled as dissimilar. This process aids in the representation learning of the network.
