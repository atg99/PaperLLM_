The paper presents a bidirectional shape matching framework for matting and style transfer, divided into two main stages: input preprocessing and forward style transfer. 

In Stage I, called backward structure transfer, the framework preprocesses a structure map obtained from the style subject image using tools like Photoshop. This creates training pairs that consist of a coarse version of the structure map and the original structure. The parameter controlling the level of detail is denoted as ℓ. 

Stage II focuses on forward style transfer, where a Glyph Network (GS) learns to apply the stylized structure to a target text image, producing a result denoted as IXℓ. A Texture Network (GT) then renders the texture from the style image onto the transferred structure to create the final artistic text output, IYℓ. 

The framework employs adversarial learning with discriminators DS and DT to enhance the quality of the generated images. The paper details the backward structure transfer process using a sketch module (GB) that incorporates a smoothness block to simplify images at various scales and a transformation block to map smoothed images back to the text domain. This method allows for parameterization of deformation levels and facilitates training with easily accessible text images, enabling the application of the trained model to various input styles.
