In this paper, we introduce PestNet, an innovative end-to-end architecture tailored for large-scale multi-class pest detection that not only focuses on recognizing pests but also localizing and counting them. PestNet utilizes a deep learning approach where images are processed through a CNN backbone to extract features automatically, eliminating the need for manual preprocessing. The architecture includes a Channel-Spatial Attention (CSA) module to enhance feature representation, and a Region Proposal Network (RPN) to generate region proposals that help distinguish between pest and non-pest areas.

The model further refines pest classification and bounding box regression by incorporating Contextual Regions of Interest (Contextual RoIs) and replacing traditional Fully Connected (FC) layers with a Position-Sensitive Score Map (PSSM) to improve spatial sensitivity and reduce computational costs. The training process is optimized using Online Hard Example Mining (OHEM) to enhance model effectiveness.

A significant contribution of this work is the creation of the Multi-class Pest Dataset 2018 (MPD2018), a comprehensive dataset comprising over 80,000 images and 580,000 labeled pests across 16 categories, captured using custom-designed imaging equipment. 

In summary, PestNet represents a significant advancement in automated pest detection, combining innovative architectural features with a robust dataset to improve accuracy in pest recognition and localization in agricultural practices.
