This paper focuses on the use of a DenseNet-121 architecture-based convolutional neural network (CNN) for identifying COVID-19 through CT images. It utilizes a dataset from a hospital in Sao Paulo, Brazil, containing 2482 images, with 1252 images confirmed as COVID-19 positive and 1230 images representing other pulmonary diseases. The images are categorized into two classes: COVID and non-COVID.

In the pre-processing stage, the images undergo several techniques to enhance their quality for model training. The images are resized to 64 × 64 pixels using the Pillow library, and pixel intensities are normalized to a range between 0 and 1 to reduce computational complexity during model training. The normalization process employs a specific formula to ensure consistency in pixel values.

The experimental setup includes the implementation of the COVID-19 classification model using Python 3.7 on an Intel Core i5 processor. The study aims to improve the accuracy of COVID-19 detection through advanced image processing and machine learning techniques.
