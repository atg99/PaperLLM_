The paper presents a unified language model (U NILM) that integrates various language modeling objectives, including bidirectional, unidirectional, and sequence-to-sequence tasks, while sharing parameters across these tasks. This model employs different self-attention masks to manage the context each token can attend to, thereby allowing flexible information access during training.

The input to the model consists of a word sequence, which may be a single text segment for unidirectional language models or a pair of segments for bidirectional and sequence-to-sequence models. Each input sequence begins with a special start-of-sequence token and concludes with an end-of-sequence token, essential for marking sentence boundaries and guiding the decoding process. The input representation mirrors that of BERT, using WordPiece tokenization to convert text into subword units. Each token's vector representation is generated by summing its token, position, and segment embeddings, with segment embeddings also serving to identify the specific language modeling task.

The backbone of the model is a multi-layer Transformer architecture, where input vectors are encoded into contextual representations through multiple layers. Each layer utilizes multiple self-attention heads to combine outputs from the previous layer, facilitating the aggregation of information across the sequence. The architecture allows for effective training and fine-tuning on downstream tasks using task-specific data once pretraining is complete.
