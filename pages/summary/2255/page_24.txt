The paper presents various models and training procedures used in synthetic experiments, sentiment analysis, and benchmarks like GLUE and ChestX-ray14. 

In synthetic settings, linear regression, logistic regression, and a one-layer neural network with ReLU activation are employed. For sentiment analysis, the authors utilize three models: a multi-layer perceptron (MLP) that averages word embeddings, a one-layer LSTM, and a CNN based on Kim's architecture with specified filter sizes. Pre-trained GLoVe embeddings are fine-tuned in these experiments, which also adopt a multi-task learning approach with shared embedding and feature extraction layers.

For the GLUE benchmark, the BERT model is applied with a classification/regression layer added for each task, using the BERT LARGE uncased version. In the ChestX-ray14 experiments, the DenseNet model serves as the shared module with separate classification layers for each task.

Training procedures involve mini-batch stochastic gradient descent (SGD) with different strategies for tasks with varying features, and a grid search for optimal learning rates and epochs in synthetic settings. The sentiment analysis data is split into training, development, and test sets, with accuracy reported as the performance metric.
