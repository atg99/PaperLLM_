The paper discusses various example-based explainable artificial intelligence (XAI) techniques and their corresponding programming libraries. It presents a comparison of different libraries such as Keras, TensorFlow, and PyTorch, alongside specific XAI methods including Anchors, Counterfactuals, and Integrated Gradients. Each method's availability across these libraries is summarized in a table, highlighting which libraries support which techniques.

DiCE is highlighted for its ability to allow users to input relative difficulty in changing features, thus enhancing its utility in generating counterfactuals. Alibi is introduced as an open-source Python library focused on machine learning model inspection and local interpretation, offering a range of algorithms suitable for black box models.

The paper also outlines software toolkits available for building XAI applications, emphasizing the need for a comprehensive toolkit that encompasses various tools and techniques for visualization, debugging, and evaluating machine learning models. This section aims to provide insights into both commercial and open-source options for developers in the field of XAI.
