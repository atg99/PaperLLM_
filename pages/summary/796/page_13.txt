In this paper, it is demonstrated that using a JPEG compressed version of an image as input to a deep neural network (DNN) can significantly enhance classification performance, even when the ground truth (GT) label of the original image is unknown. This finding challenges the conventional belief that compression negatively impacts deep learning tasks. 

To address scenarios where the GT label is not accessible, the authors propose a new convolutional neural network (CNN) topology. This architecture incorporates the original image along with ten JPEG compressed versions, processed in parallel. The design consists of eleven parallel instances of the underlying DNN, each handling one version of the image, culminating in a concatenation of outputs before the final prediction layer.

The proposed network is trained on the ILSVRC 2012 dataset and evaluated on the ImageNet validation dataset, showcasing its ability to leverage compressed inputs for improved image classification outcomes. This innovative approach underscores the potential benefits of JPEG compression in deep learning applications.
