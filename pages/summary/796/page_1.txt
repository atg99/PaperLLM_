The article "Compression Helps Deep Learning in Image Classification" by En-Hui Yang, Hossam Amer, and Yanbing Jiang explores the impact of JPEG compression on deep learning models used for image classification. Contrary to the common belief that JPEG compression degrades classification accuracy, the authors demonstrate that selecting an optimal JPEG compressed version of an image can significantly enhance the accuracy of deep neural networks (DNNs) while also reducing the file size of the input images.

The study introduces the Highest Rank Selector (HRS), which identifies the best compressed version of an image among ten JPEG versions with varying quality factors. HRS achieves notable improvements in classification accuracy, specifically a 5.6% increase in Top 1 accuracy and a 1.9% increase in Top 5 accuracy on the ImageNet validation dataset, alongside an average compression ratio of 8. This means the input size is substantially reduced compared to the original images.

When the ground truth label of the original image is unknown, the authors propose a new convolutional neural network (CNN) architecture that processes both the original image and its compressed versions in parallel. This architecture also shows improvements in accuracy, albeit smaller, with a consistent enhancement in classification performance for the tested DNNs.

The paper concludes by highlighting the potential of image compression techniques to improve deep learning performance in image classification tasks, providing insights into the effective utilization of JPEG compression within DNN frameworks.
