This paper discusses the analysis of Twitter data in the context of understanding communication dynamics during critical events, specifically focusing on the 2017 Catalan independence referendum. It highlights the limitations of studying Twitter data, particularly concerning the representativeness and validity of samples obtained through various APIs provided by Twitter. 

The authors identify two primary questions regarding Twitter data: whether Twitter users represent the general population and whether Twitter samples accurately reflect overall communication on the platform. They concentrate on the latter, acknowledging that different methods for accessing Twitter data exist, with the most common being the Application Programming Interface (API) which includes both the Filter API and Sample API. The Filter API allows searches based on parameters, while the Sample API provides a random 1% of all tweets.

The paper raises critical methodological concerns about the validity of the 1% Sample API data as a representation of Twitter communication, noting that previous research has identified sample bias when comparing different API sources. It points out that while the Sample API may work well for larger datasets, it can show negative correlations in low-coverage scenarios, unlike the Firehose, which provides a more comprehensive dataset. 

The authors also discuss the impact of hashtag usage, which can create confirmation bias and bubble effects in data interpretation. They emphasize that even the Sample API can be biased, whether by design or purpose, influencing the representation of various sociodemographic groups. The paper concludes that while the Sample API can offer a more realistic depiction of Twitter activity, researchers must be cautious of inherent biases and the influence of external factors on sentiment analysis and data interpretation.
