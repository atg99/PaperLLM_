The paper discusses the numerical evaluation of nonlinear first-order non-homogeneous delay differential equations (DDEs), specifically focusing on Equations 11, 12, and 14. The standard numerical technique involves discretizing the equations in time, allowing for the computation of input and state signals at discrete time samples. 

Using the backward Euler discretization method, the paper derives a set of equations. It first defines the time sample index and introduces the concept of storing readout signals in memory for use in subsequent calculations. By setting the delay equal to the sampling time step, the equations are reformulated to express the relationship between the state signals and the input signals at each time step.

The discretization leads to a transformation of the continuous equations into a nonlinear first-order non-homogeneous difference equation. The final form of the difference equation is presented, which relates the state at the next time step to the current state and the input signals, while incorporating matrix coefficients that represent the dynamics of the system.

The paper concludes by defining a matrix \( W_s \) to facilitate the calculation of state signals, ultimately yielding a recursive relationship that can be used to compute future states based on past information. This approach allows for a systematic method to handle the complexities of the nonlinear DDEs in a numerical framework.
