This section discusses the reduction of complex equations to a standard recurrent neural network (RNN) form, specifically unrolled for Km steps across multiple segments indexed by m, where m ranges from 0 to M-1. The initial state signal for each segment is defined as zero, and the subsequent state and readout signals are derived from the previous state, the input signal, and a bias term. 

Key equations illustrate that for each segment, the state signal, readout signal, and input signal are non-zero only within the specified range of n, which spans from 0 to Km-1. The input signal varies for each segment, allowing the RNN computations to remain independent across different segments. This independence leads to a generic computational model for all segments, with the input being the only variable dependent on the segment index.

The prototype formulation of the RNN retains this structure, allowing for systematic processing of segments one at a time. After initializing the state signal and selecting input samples for a segment, the RNN can compute the state and readout signals for Km steps. This process can be repeated for each segment, leveraging the independence of segments to facilitate parallel computations, thereby enhancing efficiency in processing multiple segments concurrently.
