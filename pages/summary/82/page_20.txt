The paper discusses the derivation of a standard Recurrent Neural Network (RNN) system, particularly focusing on the use of gate functions to enhance stability and manage the vanishing/exploding gradient problem. It starts by establishing that the diagonal matrix W_s in Equation 96 consists of positive fractions, allowing for the simplification of the state update equation. By setting W_s to the identity matrix, the state update retains fractional contributions from the previous state, ensuring system stability.

The paper introduces control gates, specifically the control readout gate g_cr[n], which regulates the amount of the readout signal that influences the cell's observable value. This allows the update candidate signal to be adjusted, thus mitigating the risk of gradient issues associated with direct connections between state signals. Furthermore, the introduction of a control input gate g_cx[n] facilitates a more flexible interaction with external inputs.

The final form of the state update equation incorporates a saturating warping nonlinearity G_d(z), which preserves the dynamic range of the cell's value signal while integrating contributions from both the readout and external input signals. Overall, the adjustments made through these gates enhance the RNN's adaptability and stability, paving the way for improved performance in sequential data tasks.
