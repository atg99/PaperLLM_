The paper discusses an enhancement to recurrent neural networks (RNNs) by introducing two gate signals: control state (gcs) and control update (gcu). These gates allow for fine-grained control over the contributions to the state signal at each step. The first part of the state signal (Fs) carries information from the previous step, while the second part (Fu) combines the previous readout signal with the current input signal. The state signal is formulated as a blend of these contributions, with the proportions adjustable via the gate signals. Both gate signals are non-negative fractions, ensuring that their values lie between 0 and 1. This setup enables the model to selectively retain information from past states and regulate the updates based on current inputs, enhancing the RNN's ability to process information over time.

The paper also highlights the flexibility of RNNs in terms of time representation, suggesting that terms like "previous" and "current" are used for convenience, as RNNs can be processed in both forward and backward directions. The potential for non-causal processing is discussed, where future input data can be utilized to improve decision-making at the current step, particularly beneficial in applications like audio, speech, and text analysis. The significance of the gate-controlled content signals has been recognized in related research, indicating the importance of this approach in advancing RNN capabilities.
