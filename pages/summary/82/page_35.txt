The paper introduces modifications to the Vanilla LSTM cell, focusing on the Recurrent Projection Layer and a new control input gate. The Recurrent Projection Layer redefines the cell's value signal by incorporating an additional weight matrix, transforming the original value signal into a "qualifier" signal. This adjustment allows for dimensionality reduction of the cell's value signal, enhancing training speed by allowing fewer columns in the matrix multipliers. The flexibility introduced by this layer enables a trade-off between the cell's representational capacity and computational costs.

Furthermore, the paper critiques the treatment of external inputs in the Vanilla LSTM cell, emphasizing that the external input is always fully injected without control. This can limit the cell's adaptability to training data fluctuations. To address this, a control input gate is introduced, allowing the system to regulate the contribution of the external input signal. This gate, computed from the accumulation signal, applies element-wise multiplication to the external input, providing finer control over its influence in the data update accumulation node. The proposed equations illustrate how the new control gate integrates into the LSTM design, enhancing the cell's ability to manage noisy input and improve learning efficiency.
