The paper presents an architecture for a sparse matrix-matrix multiplication (SpMM) engine designed to efficiently handle ultra-sparse inputs in a graph convolutional network (GCN) context. The proposed system addresses read-after-write (RaW) hazards by implementing a stall buffer that temporarily holds jobs targeting the same row until the hazard is resolved. This is crucial for maintaining processing integrity while allowing the engine to accept new tasks.

The architecture incorporates two task distribution queues (TDQ). TDQ-1 is employed for sparse matrices stored in dense format, while TDQ-2 is tailored for ultra-sparse matrices in compressed sparse column (CSC) format. The Omega-network routing mechanism is utilized to efficiently direct non-zero elements to processing elements (PEs), minimizing hardware complexity and improving scalability compared to a global crossbar network.

Each PE performs a sequence of operations upon receiving non-zero data, including multiplication, fetching partial results from accumulation buffers, and updating these buffers. The design allows for the dense output of one layer to be immediately used as input for subsequent layers, facilitating pipelining. This intra-layer pipelining enhances parallelism and reduces latency by allowing multiplications to proceed without waiting for entire matrices to be computed.

Moreover, inter-layer pipelining is introduced to optimize resource allocation and balance workloads across different layers. This approach reduces off-chip storage needs by reusing the adjacency matrix across layers, thus minimizing data access requirements.

Overall, the proposed architecture enhances the efficiency of SpMM operations within GCNs by leveraging hardware design and pipelining strategies, ultimately aiming to improve computational performance in graph-based tasks.
