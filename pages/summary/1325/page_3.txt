The paper investigates the memory capacity of a system that transforms a sequence of inputs using a complete orthonormal set of basis functions within a constructed Hilbert space. The inputs are indexed to represent time steps, and the transformations are assessed through chosen basis functions, specifically normalized Legendre polynomials. Two transformation examples are considered: recalling an input from five steps back and performing a nonlinear transformation that combines inputs from different past steps.

The memory capacity, defined as C=1-NRMSE², quantifies the system's ability to approximate these transformations, where a value of 1 indicates perfect capability and 0 indicates none. An alternative method for calculating capacity, proposed by Dambre et al., is also utilized. The basis of the transformation tasks is built using finite products of Legendre polynomials, with the inputs uniformly distributed random numbers drawn from the interval [-1, 1].

The total memory capacity is computed by aggregating contributions from all possible transformation tasks across different polynomial degrees. The simulations were executed in C++, employing the Armadillo library for linear algebra calculations, and involved a Runge-Kutta method for numerical integration of the delay-differential equations. The analysis focuses on the total memory capacity, contributions from different degrees, and the normalized root mean square error (NRMSE) of the NARMA10 benchmark task, which combines memory and nonlinear transformations.

The focus is on a Stuart-Landau oscillator, which serves as the reservoir for the analysis. This model is relevant for systems operating near a Hopf bifurcation, such as lasers just above their threshold. The paper concludes by characterizing the performance of the nonlinear oscillator with respect to its memory capacity and transformation capabilities.
