The paper discusses a complex dynamical system represented by a differential equation that models the behavior of a laser. Key parameters include the pump rate, input strength, frequency, nonlinearity, feedback strength, feedback phase, and delay time, which collectively influence the system's ability to recall input sequences. 

The results section presents the linear recall capacities for different delay times, illustrating how the system can retrieve inputs over time. It shows that for a specific input period time, high recall capacity is achieved initially but declines significantly after several steps. When the input period time is adjusted to resonate with the delay time, the recall capacity exhibits oscillatory behavior, indicating a complex relationship between these variables.

A comprehensive analysis of both linear and quadratic capacities is provided through heatmaps, revealing that while the system can remember specific steps, it struggles with gaps in recall, limiting overall memory capacity. The quadratic capacities show a similar trend but with less effective recall, highlighting the system's nonlinear transformation limitations compared to linear recall. Overall, the findings underscore the intricate dynamics of the system and its memory capabilities.
