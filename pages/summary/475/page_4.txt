This paper discusses two approaches to training Deep Belief Networks (DBNs) using Restricted Boltzmann Machines (RBMs): the classical greedy method and a novel iterative learning algorithm (iDBN). 

In the classical approach, each RBM layer is trained sequentially. The first layer is trained with input data, and its weights are then frozen. The data is projected into the hidden neurons, creating a new training set for the subsequent layer, and this process continues for all layers. This method relies on the conditional probability distribution of the hidden neurons based on the layer below.

The iDBN algorithm, in contrast, updates all parameters of the DBN simultaneously, allowing for a more integrated learning process. It mimics the rapid feed-forward processing seen in cortical circuits, where sensory input is quickly propagated through the network. This method faces challenges during initial learning due to the non-stationary nature of hidden unit activations, as weights are randomly initialized. Despite this, it aims to reconstruct data representations at each hierarchical level using top-down generative connections.

Additionally, the paper presents a full-stack joint learning approach, which propagates input through the hierarchy before producing reconstructions. While simpler, this method encounters the vanishing gradient problem common in deep learning.

The authors conducted simulations using the MNIST dataset, maintaining a consistent DBN structure for both greedy and iterative learning approaches. They explored different weight initialization strategies, including the Glorot initialization, to assess convergence in learning.

Overall, the paper highlights the advantages of the iDBN method over traditional greedy approaches and provides insights into the complexities of training deep generative models.
