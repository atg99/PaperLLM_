The paper presents Proposition 4, which establishes a relationship between the value function and the rewards received in a reinforcement learning context, assuming Condition A.2 is met. The value function is expressed as a combination of immediate rewards and expected future values, represented by a summation over possible states and actions.

The proof unfolds by substituting previously established equations and simplifying them using properties of expectations. It shows how the value function can be reformulated to include both immediate rewards and a term that captures the expected future rewards, adjusted by a coefficient related to the given conditions.

The proof of Theorem 2 builds upon the Policy Gradient Theorem, utilizing Propositions 3 and 4. It derives the gradient of the value function with respect to policy parameters. This involves differentiating the value function in relation to the policy and incorporating the expected future value calculations. The result illustrates how policy changes can impact the expected rewards through state transitions, reinforcing the connection between policy optimization and value function updates in reinforcement learning frameworks.
