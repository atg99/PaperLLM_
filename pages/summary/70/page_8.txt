The paper discusses the architecture and functioning of Long Short-Term Memory (LSTM) networks, which are designed to address the long-term dependency problem in sequential data processing. LSTM networks consist of memory blocks called cells that transfer two states: the cell state and the hidden state. The cell state serves as the main data flow, remaining largely unchanged except for linear transformations. Sigmoid gates control the information flow into and out of the cell state, allowing for the selective retention or exclusion of data.

The construction of an LSTM network begins with identifying unnecessary information to be omitted from the cell state, facilitated by the forget gate. This gate, represented by a sigmoid function, determines which information from the previous cell state should be discarded. Next, the network updates the cell state by deciding which new information to store, using both a sigmoid layer for selection and a tanh layer for weighting the importance of the incoming data. The updated cell state is a combination of the previous state and the newly integrated information.

The output of the LSTM is derived from the output cell state, filtered through another sigmoid gate that decides which parts of the cell state to pass on. This output is then combined with the new values from the tanh layer to produce the final hidden state.

For model evaluation, the paper highlights the use of the Nash-Sutcliffe Efficiency (NSE) and Root Mean Square Error (RMSE) as statistical methods to assess the performance of forecasting models in hydrology. The NSE quantifies how well the model predicts variability relative to the observed data, while RMSE measures the closeness of predicted values to actual observations.
