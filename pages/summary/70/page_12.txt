The paper presents a validation phase for a one-day flow forecasting model, detailing results from various scenarios as outlined in Table 4. The study compares two forecasting scenarios over different timeframes: one-day, two-day, and three-day forecasts. The first scenario incorporates twelve input variables, combining rainfall and flow rate data, while the second scenario relies on only five input variables, using flow rate data alone. 

The results indicate that both scenarios yield comparable forecasting performance, with the first scenario showing a slightly higher trend in accuracy, although the difference is minimal (about 1%). The Root Mean Square Error (RMSE) and Nash-Sutcliffe Efficiency (NSE) values are provided for each case, demonstrating high accuracy across all scenarios. Specifically, the one-day forecasts achieved RMSE values between 149.0 and 151.3 m³/s and NSE values above 99%. The two-day forecasts showed a decrease in accuracy, with RMSE values ranging from 366.1 to 374.2 m³/s and NSE values around 94%. The three-day forecasts had further reduced accuracy, with RMSE values from 2296 to 3655 m³/s and NSE values between 86.8 and 87.8%.

Figures accompanying the results illustrate the agreement between observed and predicted flow values, reinforcing the model's effectiveness in accurately forecasting discharge one day in advance. Overall, the findings suggest that both forecasting scenarios are robust, providing reliable predictions for water flow management.
