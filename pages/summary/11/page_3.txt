The paper introduces new calibration metrics for evaluating the performance of multiclass classification models, focusing on Static Calibration Error (SCE), Adaptive Calibration Error (ACE), and Thresholded Adaptive Calibration Error (TACE).

SCE is an extension of Expected Calibration Error tailored for multiclass settings. It calculates calibration error by binning predictions for each class, measuring accuracy and confidence within each bin, and averaging these values across all bins.

ACE addresses the bias-variance tradeoff by adapting bin intervals to ensure equal numbers of predictions in each bin, allowing for a more accurate assessment of calibration error in regions where predictions are concentrated. It uses sorted predictions to define calibration ranges.

TACE responds to the issue of softmax predictions becoming very small, which can dilute calibration scores. By applying a threshold to exclude these minuscule predictions, TACE ensures that only significant values are evaluated, similar to ECE but focusing on more impactful predictions.

Tables presented in the paper compare the effectiveness of various calibration methods using these metrics. Results indicate that the best recalibration method varies depending on the metric used, underscoring the importance of studying multiple calibration metrics to obtain a comprehensive evaluation of model performance.
