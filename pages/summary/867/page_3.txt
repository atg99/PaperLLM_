The paper introduces a novel neural architecture called DySAT, designed to efficiently model dynamic graph evolution through a modular approach. It consists of three main components: a structural attention block, a temporal attention block, and graph context prediction. The key innovation is the decoupling of graph evolution into these two modular blocks, allowing for efficient computations of dynamic node representations.

The structural self-attention layer processes a graph snapshot and a set of input node representations, transforming them to capture local structural properties. It computes attention weights based on the immediate neighbors of each node, utilizing a shared weight transformation and a feed-forward layer to derive new node embeddings.

The temporal self-attention layer focuses on capturing temporal variations in graph structure across multiple time steps. It takes a sequence of representations for each node and allows the current representation to attend to its historical representations. This layer enhances efficiency by decoupling local neighborhood interactions from the temporal history of each node.

To address the complexity of real-world dynamic graphs that evolve along multiple facets, the model incorporates multi-head attention. This approach enables the model to capture diverse attention mechanisms by creating multiple independent attention heads that operate on different portions of the input embedding, thereby improving model capacity and stability.

Overall, the DySAT architecture effectively combines structural and temporal self-attention mechanisms to model dynamic graphs, providing a robust framework for understanding complex graph evolutions over time.
