The paper discusses the optimization process for Gradient Boosted Decision Trees for Multiple Outputs (GBDT-MO), focusing on the derivation of optimal leaf values and objectives. It begins by defining the prediction for the first t trees and examining the objective for the (t+1)-th tree, which is separable concerning each leaf. The loss function is approximated using a second-order Taylor expansion, leading to expressions for optimal leaf values and objectives.

The authors derive optimal leaf values and objectives for multiple outputs, noting that when the loss function is separable, the optimal values can be calculated similarly to the single output case. However, complications arise when the loss function is not separable, as storing the Hessian matrix becomes impractical with large output dimensions and computing the inverse of a large matrix is time-consuming. The authors propose approximations for optimal values and objectives based on diagonal dominance of the Hessian.

The paper also introduces a sparse objective, addressing the fact that only a subset of output variables is typically correlated. By applying an L0 constraint to the non-sparse objective, the authors aim to minimize the number of parameters while retaining effectiveness. They derive optimal sparse leaf values and objectives, emphasizing that while only a subset of variables is covered in a leaf, all variables are considered across multiple leaves.

In conclusion, the proposed approach allows for effective handling of multiple outputs in GBDT while addressing the challenges associated with non-separable loss functions and enhancing model sparsity. Future work is suggested for improving approximations for specific loss functions.
