In this paper, the authors introduce ShelfNet, a novel multi-column convolutional neural network designed for semantic segmentation. Unlike traditional single encoder-decoder architectures, ShelfNet employs a shelf-structured network that enhances information flow through multiple paths. The network utilizes various CNN backbones such as ResNet, Xception, and DenseNet, generating feature maps at different spatial scales. 

The architecture comprises a segmentation shelf with four columns, where column 3 serves as an encoder branch and columns 2 and 4 function as decoder branches. Skip connections at various spatial scales facilitate the integration of features between these branches. The Shared-weight blocks (S-blocks) in the decoder columns combine features from both vertical and lateral directions, enhancing the network's efficiency.

To optimize inference speed, the authors implement channel reduction techniques using 1x1 convolutions, batch normalization, and ReLU activations, significantly lowering the computational burden associated with high channel counts in backbone feature maps. This reduction enables faster processing while maintaining performance.

Furthermore, ShelfNet is conceptualized as an ensemble of fully convolutional networks (FCNs), leveraging the residual connections to support multiple information flow paths. This ensemble approach contributes to the model's segmentation accuracy and efficiency, demonstrating superior performance compared to previous methods in both speed and accuracy.
