This paper discusses the limitations of existing neural network pruning methods, particularly their inability to maintain accuracy and achieve significant speedups on CPU-based platforms. The authors propose a new pruning pattern called 1×N pruning, which aims to enhance model inference efficiency while preserving accuracy.

The methodology begins with defining the notation for a pre-trained convolutional neural network (CNN) model, where the filter set is represented as W. Pruning can be implemented by applying a binary mask T to the weights, indicating which weights are retained or removed. The objective is to maximize the importance of the remaining weights while adhering to a specified pruning rate.

The paper distinguishes between weight pruning, which removes individual weights, and filter pruning, which eliminates entire filters. The proposed 1×N pruning pattern is a hybrid approach that allows for pruning consecutive N output kernels with the same input channel index. This method introduces a new level of granularity, offering a balance between fine-grained weight pruning and coarse-grained filter pruning.

The authors argue that the 1×N pruning pattern provides advantages in terms of memory storage and computational efficiency, as consecutive kernels can be stored together in memory, facilitating parallelized operations during convolution. This approach is expected to yield better performance and speed compared to traditional pruning methods. Overall, the study presents a promising direction for improving neural network pruning techniques on CPU platforms while maintaining accuracy.
