The paper presents the classification results of an LSTM-RNN classifier using a feature space of 122 dimensions for both binary and multi-class classification tasks. In binary classification, the highest testing accuracy achieved was 96.51% with a training accuracy of 99.88%, both using five neurons in the hidden layers. Various configurations with different neuron counts were evaluated, showing consistent high training accuracy but slightly varied testing accuracy.

For multi-class classification, the highest testing accuracy recorded was 82.68%, with a training accuracy of 99.87% using 60 neurons in the hidden layers. The results indicate that while the model performs well in training accuracy across different configurations, the testing accuracy varies more significantly, particularly in the multi-class scenario.

Further analysis was conducted using an optimal feature set derived from a genetic algorithm, reducing the feature set to 99 prominent features. In this case, the binary classification achieved a remarkable testing accuracy of 99.91% and a training accuracy of 99.99%, utilizing 40 neurons in the hidden layers. This demonstrates the effectiveness of feature selection in enhancing model performance.
