The paper discusses the architecture of YOLO (You Only Look Once), specifically version 1, which is inspired by GoogLeNet. YOLO was tested on the VOC Pascal Dataset for object detection tasks, utilizing the Darknet framework for model training. The architecture comprises 24 convolutional layers, where inception modules from GoogLeNet are replaced by a sequence of (1 × 1) convolution followed by (3 × 3) convolutional filters. The first convolutional layer uses a (7 × 7) filter, and only four of the convolutional layers are followed by max-pooling layers.

Key features of YOLO include the use of (1 × 1) convolution and global average pooling. The authors initially trained the model using the first twenty layers on the ImageNet 2012 dataset for about a week, then fine-tuned it for object detection by adding four additional convolutional layers and two fully connected layers with randomly initialized weights. The activation function used throughout the convolutional and dense layers is Leaky Rectified Linear Unit (LReLU), except for the final layer, which employs a linear activation function to predict class probabilities and bounding boxes.

The paper includes figures illustrating the effect of Non-Max Suppression in object detection and the computational schematic of Intersection over Union (IoU), highlighting key concepts in the YOLO architecture and its functionality in object detection tasks.
