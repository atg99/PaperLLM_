The paper discusses an object detection framework that utilizes a grid-based approach for identifying objects within an image. The core idea is that each grid cell is responsible for detecting an object if its center falls within that cell. For each grid cell, parameters are predicted for a single bounding box, including the probability of the grid containing an object, the coordinates of the bounding box center, its dimensions, and the conditional probabilities for each class the object may belong to.

Specifically, the parameters are represented as follows: pc (probability of an object), (bx, by) (bounding box center), (bh, bw) (bounding box dimensions), and p(ci) for each class i. The overall prediction for a grid cell consists of B bounding boxes, leading to an output tensor shape of S×S×(B×5+n), where S is the number of grid cells and n is the number of classes.

The confidence score for each bounding box is calculated by multiplying the probability of containing an object (pc) with the Intersection over Union (IoU) between the predicted box and the ground truth. If no object is present in the grid cell, the confidence score is zero. The paper includes a schematic representation of the output tensor when an image is divided into a 19×19 grid, predicting four bounding boxes per cell, with class probabilities shared across them.
