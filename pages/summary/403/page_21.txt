The paper discusses key limitations of the YOLO object detection model, particularly its large localization error and lower recall compared to two-stage object detectors. To address these issues, variants of YOLO have been proposed. Fast YOLO is introduced as a simpler model featuring nine convolutional layers with fewer filters, enabling faster detection. Another variant, Yolo-lite, is designed for real-time object detection on standard non-GPU systems, showcasing the effectiveness of shallower networks without the need for accelerators. The authors highlight that batch normalization can hinder the performance of these shallow networks in object detection.

The paper also details the loss function used in the YOLO framework, which is based on sum squared error and consists of five terms. These terms account for the differences between the predicted and ground truth bounding box coordinates, emphasizing that errors in smaller bounding boxes significantly affect Intersection over Union (IoU). To mitigate this, the model uses the square root of the bounding box dimensions in the loss calculation. The remaining terms address the prediction confidence scores for bounding boxes, incorporating an indicator function to manage cases where objects might be misidentified or missed entirely within grid cells. This comprehensive approach aims to improve the accuracy and reliability of object detection in various scenarios.
