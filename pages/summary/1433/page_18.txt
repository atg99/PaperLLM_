The section discusses the issue of delay in the context of attention mechanisms in sequence processing, particularly in automatic speech recognition (ASR) systems. Two primary sources of delay are identified: the length of the encoder's output sequence and the requirement for the attention mechanism to wait until the entire sequence is generated before functioning. 

To address these delays, researchers have explored various solutions. One approach involves using a uni-directional Recurrent Neural Network (RNN) for the encoder combined with a window mechanism that allows the attention to operate on a subset of the encoding results, rather than the entire sequence. This window mechanism enables the attention process to begin as soon as sufficient information is available, effectively controlling delay within a specified window size.

The paper presents specific equations that detail how the window is defined and how attention is calculated within this framework. It mentions that when attention is applied at position u, a median is computed to establish the window limits. This allows the model to focus only on the relevant portion of the sequence as defined by the window.

Additionally, another study proposed a more adaptive window size using a Gaussian prediction method, which calculates the window size and slide step based on the system's state at a given time. This approach allows for dynamic adjustments to accommodate variations in processing speed, enhancing the system's flexibility.

Overall, the exploration of these mechanisms aims to reduce latency in ASR systems while maintaining performance efficacy.
