The paper discusses the limitations of the Connectionist Temporal Classification (CTC) model in speech recognition, highlighting two major deficiencies: the inability to model interdependencies within the output sequence and the restriction of mapping input sequences to shorter output sequences. CTC primarily functions as an acoustic model, lacking the capability to learn language models effectively.

To address these shortcomings, the RNN-Transducer model was introduced, which can theoretically map any input to any finite output sequence while jointly modeling interdependencies between input and output. The RNN-Transducer comprises three subnetworks: the Transcription network (F(x)), which acts as the acoustic model; the Prediction network (P(y,g)), which serves as the language model; and the Joint network (J(f,g)), which integrates outputs from the first two networks.

The Transcription network encodes the acoustic input into a feature sequence, while the Prediction network uses an RNN structure to capture the dependencies within the output label sequence. The interaction between these networks allows for more effective modeling of speech recognition tasks compared to CTC, as it incorporates both acoustic and language modeling aspects, thus overcoming the limitations associated with forced segmentation alignment.
