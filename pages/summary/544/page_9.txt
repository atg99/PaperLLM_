The paper provides an overview of Neural Architecture Search (NAS), with a focus on various search spaces developed for architecture optimization. It discusses the search space proposed by Liu et al. (2018b), which features an architecture template that outlines a sequence of cells and operations. This template allows for the use of fixed max-pooling layers instead of reduction cells to manage feature dimensions. Notably, the proposed search space permits arbitrary connections between nodes, granting a higher degree of freedom compared to traditional NASNet structures, where the number of operations within cells is predetermined.

The search space is structured hierarchically, with the first level defining a set number of meta-operations, leading to diverse cell configurations. Importantly, this formulation restricts skip connections between different cells, which influences the architecture's connectivity. The paper illustrates these concepts with visual examples, including a discovered architecture. Overall, the work emphasizes the flexibility and complexity of the search spaces in NAS, highlighting advancements in the design of neural architectures through meta-operations.
