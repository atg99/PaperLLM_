This paper discusses various approaches to automating the fine-tuning of neural architectures across different tasks, focusing on the utilization of meta-features, which are properties of datasets that inform model design and optimization.

Wong et al. (2018) introduce a transfer learning framework that enhances the controller from Zoph and Le (2017) by incorporating task-specific embeddings. This controller generates discrete actions that dictate design choices for fine-tuning network architectures, including embedding selection, classifier structure, and hyperparameter tuning. The controller's parameters are optimized using the REINFORCE algorithm, and the study explores applications in both image classification and natural language processing.

Istrate et al. (2019) propose a surrogate model that predicts the performance of neural architectures on new datasets based on prior performance observations from other datasets. Their approach uses a computationally inexpensive CNN model's accuracy as a single meta-feature to identify similar datasets. This information, along with architecture encoding, informs the surrogate model, which is trained using observations from datasets with similar validation accuracies. An evolutionary algorithm is employed to search for the architecture that maximizes the surrogate model's predictions, with the final architecture trained from scratch.

Kokiopoulou et al. (2019) focus on automating fine-tuning for text classification tasks by using a surrogate model that learns meta-features directly from raw data, rather than relying on manually engineered features. Their model consists of two components: one that computes predictive meta-features and another that predicts validation accuracy based on architecture and meta-features. This model is trained across multiple datasets and employs gradient ascent for architecture optimization using a continuous parameterization approach.

Xue et al. (2019) present a lifelong neural architecture search strategy that utilizes a set of landmarkers to represent datasets. When a new dataset arrives, the method determines if it is similar to previously encountered datasets. If it is, the existing solution is reused; if not, a new search is initiated using any chosen optimizer.

Overall, these studies collectively highlight the importance of meta-features and surrogate modeling in optimizing neural architectures for diverse tasks, contributing to the field of automated machine learning.
