This section outlines the framework for few-shot image classification, providing definitions and notation essential for understanding the task. Few-shot classification involves two datasets: the base dataset, which aids in classifier training, and the novel dataset, where classification tasks occur. The base dataset is denoted as Dbase, while the novel dataset is represented as Dnovel, with the crucial point that they do not share any class labels.

The classification task is structured around a support set (DS) and a query set (DQ). The aim is to develop a classifier capable of accurately classifying instances from the query set based on the limited examples available in the support set. Specifically, if DS includes C classes with K labeled examples each, it is termed C-way K-shot classification, with one-shot classification being a special case where K equals one.

The section also introduces the concept of domains, defining a cross-domain few-shot classification task as one where the base and novel datasets originate from different domains, indicated by differing feature spaces or marginal distributions.

Lastly, an evaluation procedure for the few-shot classification performance is proposed, involving multiple episodes where C classes are randomly selected from the novel label set, and samples are chosen to form the support and query sets. The classifier's performance is assessed based on the average classification accuracy across these episodes.
