This section presents a lemma that quantifies the linearization error between a two-layer neural network and its linear approximation. The neural network is defined by the feature mapping φθ, while φ0 represents the feature mapping at the initial parameter Winit. A function class is introduced to describe these linearizations, which are linear in the parameters W but nonlinear in the inputs (s,a). 

The lemma establishes that the linearization error decreases as the width of the network m increases, under the condition that the differences between the parameters W and Winit are bounded. Specifically, as m grows large, the probabilities that the conditions for the parameters hold become high, leading to a close approximation of the neural network by its linearization.

The formal statement of the lemma indicates that, for parameters within a bounded set B, the expected squared difference between the gradients of the linearized function and the original function, evaluated at any two points in B, scales as O(R^3·m^(-1/2)). This result underlines the effectiveness of the linear approximation in capturing the behavior of the neural network when the width is sufficiently large.
