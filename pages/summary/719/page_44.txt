In this section, the paper examines the convergence of a neural policy gradient approach that eliminates the need for projection during actor updates. The projection-free actor update is expressed as:

θi+1 ← θi + η · 𝜏i ∑ℓ=1B 𝑄ωi(sℓ, aℓ) · ∇θ log πθi(aℓ | sℓ).

Here, 𝜏i represents the temperature parameter for the policy πθi, and the state-action pairs {(sℓ, aℓ)}ℓ∈[B] are drawn from the visitation measure σi corresponding to the current policy. The batch size is denoted as B, and 𝑄ωi is a modified critic that adjusts the value function based on thresholds defined by Qmax.

The algorithm for the projection-free neural policy gradient is outlined in Algorithm 3. It requires parameters such as the number of iterations T, the number of temporal difference (TD) iterations TTD, learning rates η and ηTD, temperature parameters {𝜏i}, and batch size B. 

The process begins with initialization of weights and parameters, followed by a loop for T iterations. Within each iteration, the critic is updated with the current policy, a batch of state-action pairs is sampled, and the policy gradient is estimated using the modified critic. The actor's parameters are then updated based on this gradient. The output of the algorithm is the sequence of policies {πθi} over T+1 iterations. 

This approach aims to enhance the efficiency of policy updates in reinforcement learning without the constraints imposed by projection methods.
