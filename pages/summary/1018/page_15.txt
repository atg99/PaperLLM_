The paper discusses the back-propagation algorithm used to calculate the error signals for hidden and output units in a neural network. It starts by explaining the straightforward evaluation of the error for output units using the derivative of the error function with respect to the output. Specifically, it references the sum-of-squares error function and cross-entropy error function, leading to a formula that expresses the error as the difference between actual and desired outputs.

For hidden units, the paper employs the chain rule to derive the error signal, which involves summing the contributions from all connected units. The derived back-propagation formula for hidden units shows how to calculate their error signals based on the error signals from subsequent units in the network. The paper emphasizes the interconnections between units and how variations in one unit affect the overall error through its connections, illustrating the process with a diagram.

The key takeaway is that the back-propagation algorithm allows for the efficient computation of error signals in neural networks, which is crucial for the training process.
