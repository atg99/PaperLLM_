The paper discusses the adjustment of prior probabilities in neural networks without the need for retraining. By dividing posterior probabilities by prior probabilities from a training set, multiplying by new prior probabilities, and normalizing the results, changes in prior probabilities can be accommodated. Prior probabilities for the training set can be estimated from the fraction of data points in each class, while those for the operating environment can often be obtained easily using class labels without requiring input data.

An example provided involves classifying medical images into 'normal' and 'tumor' categories. In a screening context, the prior probability of 'tumor' is expected to be very low, necessitating a large number of training examples to obtain a representative set of tumor images. One alternative is to artificially increase the proportion of tumor images in the training set and then adjust the outputs based on the actual prior probabilities in the test data. The necessary prior probabilities can be sourced from medical statistics, which simplifies the output correction process to basic multiplication and division.

The paper also describes a common approach in neural network classification where the network directly produces classification decisions. However, it emphasizes that knowledge of posterior probabilities is significantly more powerful. 

In the latter part, it addresses the determination of suitable weight parameters in a network using training data consisting of input-output pairs. It introduces the concept of maximum likelihood for devising an error function, stating that the likelihood for a set of training data can be expressed as the product of probabilities for each data point. Instead of maximizing the likelihood, it is often more convenient to minimize the negative logarithm of the likelihood, leading to the formulation of an error function. Further assumptions allow for the derivation of error functions for regression and classification problems based on the conditional probability density of the target data given the input data.
