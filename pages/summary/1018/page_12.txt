The paper discusses the interpretation of neural network outputs as posterior probabilities in a classification context. It begins by outlining the generation of a training dataset from class-conditional densities represented by Gaussian mixtures. The network consists of a feedforward architecture with five hidden units utilizing logistic sigmoid activation functions and one output unit also using a logistic sigmoid function. The model is trained using a cross-entropy error minimization approach.

Key findings highlight that the output of the network can be interpreted as probabilities of class membership given inputs. This is formalized through the use of Bayes' theorem. For multi-class problems, the network is configured to have one output for each class, employing a one-of-c coding scheme for target values. The likelihood of observing these target values, given an input vector, aligns with the corresponding network output.

An error function is derived from the likelihood function, emphasizing the relationship between the network's outputs and the conditional distributions of the target values. The paper demonstrates how the architecture and training process effectively map inputs to posterior probabilities, thus illustrating the neural network's capability in probabilistic classification tasks.
