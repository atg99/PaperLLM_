The paper discusses error functions for classification problems, specifically focusing on approximating posterior probabilities of class membership given an input pattern. It begins by examining a binary classification scenario with two classes, C1 and C2, where a neural network's output, y, represents the posterior probability P(C1|x). Consequently, the probability for class C2 is derived as P(C2|x) = 1 - y. A target coding scheme is proposed where t = 1 denotes class C1 and t = 0 denotes class C2. The probability of observing either target value follows a Bernoulli distribution.

The likelihood of the training data, assuming independent data points, is expressed in a specific form, which leads to the cross-entropy error function. This function is convenient for optimization as it minimizes the negative logarithm of the likelihood. The paper highlights that while previous models used linear functions for outputs in regression, classification requires appropriate output activation functions.

The authors assume that the outputs of hidden units are described by a member of the exponential family of distributions. This approach allows for different parameters controlling the distribution's form. The paper also illustrates the use of Bayes' theorem to express the posterior probability for class C1 in terms of the hidden unit outputs, resulting in a logistic sigmoid function representation. This relationship emphasizes the linearity of decision boundaries in the transformed space of hidden unit outputs while maintaining non-linearity concerning the original input variables.
