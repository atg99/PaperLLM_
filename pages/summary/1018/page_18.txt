The paper presents two figures illustrating the approximation of a function h(x) using polynomial fitting techniques. Figure 7 displays data points sampled from the function h(x) at equal intervals, with added random noise. It shows a poor approximation using a linear polynomial (M=1), represented by a solid curve, while the dashed curve represents the actual function h(x). Figure 8, on the other hand, demonstrates the same data set fitted with a cubic polynomial (M=3), resulting in a significantly improved approximation of h(x). The comparison highlights the advantage of using a more flexible polynomial model for better data representation.
