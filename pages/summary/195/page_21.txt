The paper discusses two reinforcement learning algorithms: REINFORCE with baseline and Actor-Critic, both adapted from Sutton and Barto. 

In the REINFORCE algorithm, the policy and state-value weights are updated iteratively through episodes. Each episode generates states, actions, and rewards, where the return from each step is calculated. The updates for the value weights and policy parameters are performed using step sizes and gradients of the log probability of actions taken, adjusted by the return.

The Actor-Critic algorithm combines aspects of both policy-based and value-based methods. It operates by initializing the first state and continuously updating the action based on the policy. The algorithm observes the next state and reward, then updates the value weights and policy parameters similarly to REINFORCE, with the added feature of using current state values to compute returns.

The paper also introduces deep reinforcement learning (deep RL), which utilizes deep neural networks to represent various components of reinforcement learning, such as the value function, policy, and model. The distinction between deep RL and shallow RL lies in the function approximators used, with deep models offering more complex representations. The paper notes that while deep RL can lead to instability when combining non-linear function approximations and bootstrapping, recent advancements like deep Q-networks and AlphaGo have successfully stabilized learning processes. Efforts are ongoing to provide convergence proofs for control using non-linear function approximations.
