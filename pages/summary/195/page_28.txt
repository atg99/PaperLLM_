The paper discusses the computation of the Bellman update for each atom in a distributional reinforcement learning framework, specifically focusing on the sampling Bellman operator and its projection for distributing probabilities among immediate neighbors. The sample loss function is defined as the cross-entropy term of the KL divergence, which can be optimized using gradient descent. 

Algorithm 9 outlines the categorical algorithm for computing the sampling Bellman operator based on a single transition sample. The algorithm takes as input a transition consisting of the state, action, reward, and next state, and outputs the cross-entropy loss. The process includes computing the distribution of the updated value, projecting it onto the support of defined atoms, and distributing probabilities accordingly.

The paper also references several studies related to distributional reinforcement learning, including risk-sensitive algorithms and the use of quantile regression for state-action return distribution. 

In addition, it introduces the concept of the General Value Function Horde, proposed by Sutton et al., which emphasizes the learning of value functions that can represent predictive and goal-oriented knowledge. Horde is designed to learn in real-time from unsupervised interactions and can handle multiple sub-agent policies, demonstrating off-policy learning with efficient temporal difference methods.
