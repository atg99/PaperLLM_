The paper presents the training algorithm for AlphaGo Zero, which employs a neural network to play the game of Go. The algorithm initializes with the raw board representation, game history, and the color to play. It utilizes a generalized policy iteration procedure through iterations, where the termination conditions include both players passing, a search value falling below a resignation threshold, or exceeding a maximum game length.

During each iteration, the algorithm employs an asynchronous policy and value Monte Carlo Tree Search (APV-MCTS) to improve the policy. The search tree is traversed by selecting edges based on their upper confidence bound, and evaluations of leaf nodes are conducted using the neural network, which generates prior probabilities and value estimates.

Self-play is integral to the training, where moves are selected based on the improved MCTS policy, and the game outcome is used to inform value assessments. Data from each game is stored for training, where the neural network weights are adjusted by minimizing the error between predicted values and actual game outcomes while maximizing the alignment of predicted move probabilities with the search probabilities.

The algorithm incorporates a loss function that combines mean-squared error and cross-entropy losses, with L2 weight regularization to mitigate overfitting. The performance of the neural network is evaluated periodically to determine if it should replace the current best player in generating subsequent self-play games. This iterative process enables AlphaGo Zero to improve its gameplay through self-generated data and reinforcement learning.
