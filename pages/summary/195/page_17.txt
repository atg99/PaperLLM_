The paper discusses various reinforcement learning algorithms, focusing on SARSA and Q-learning, which are methods to find an optimal policy through action value functions. SARSA, an on-policy control method, updates its action value function using the rule Q(s;a) = Q(s;a) + α[r + Q(s0;a0) - Q(s;a)], while Q-learning, an off-policy method, employs the update Q(s;a) = Q(s;a) + α[r + max_a0 Q(s0;a0) - Q(s;a)]. Both algorithms converge under specific conditions and are designed to derive optimal policies from action value functions.

The paper also introduces multi-step bootstrapping methods for these algorithms, distinguishing between one-step returns (TD(0), Q(0), SARSA(0)) and n-step returns. The n-step update is defined as the accumulation of rewards over n steps plus the value of the state at the n-th step. The eligibility trace mechanism is discussed as a way to enhance learning by providing a short-term memory that aids in addressing the challenges of long-delayed rewards and non-Markov tasks.

Furthermore, the paper compares dynamic programming (DP), Monte Carlo (MC), and temporal difference (TD) learning. Key distinctions include that DP requires a model while TD and MC are model-free. DP and TD utilize bootstrapping techniques, whereas MC does not, and different backup strategies are employed across these methods, with DP using one-step backups, TD using one or multi-step backups, and MC employing deep backups until episode termination.
