The paper discusses optimal state and action value functions in the context of reinforcement learning (RL) and their decomposition into Bellman equations. An optimal state value function, denoted as v*(s), represents the maximum achievable value for any policy at state s. This is expressed through the Bellman equation, which incorporates potential future rewards and values from subsequent states.

Similarly, the action value function q*(s;a) reflects the maximum action value for a given state and action, also decomposed into a Bellman equation. The text uses the single-source shortest path problem as an example to illustrate these concepts. In this scenario, states correspond to nodes in a graph, actions to links between nodes, and rewards are defined as the negative of link weights, with the objective of minimizing total distance to a destination. While Dijkstra’s algorithm is highlighted for its efficiency with complete graph information, RL can be applied in a model-free manner, allowing agents to learn optimal policies through exploration.

The paper also addresses the exploration versus exploitation dilemma inherent in RL, introducing the ε-greedy strategy as a means for agents to balance the two. Here, agents exploit the best-known actions with a high probability while occasionally exploring random actions. The discussion previews further examination of exploration strategies in subsequent chapters, including methods like optimistic initialization and upper confidence bounds.

Lastly, the concept of dynamic programming (DP) is introduced as a method applicable to problems with optimal substructure, such as Markov Decision Processes (MDPs). DP relies on the Bellman equation for recursive problem-solving while presuming complete knowledge of the transition and reward models. The paper distinguishes between the prediction problem, which evaluates the value function for a given policy, and the control problem, which aims to determine optimal value functions and policies.
