This paper explores enhancements to the 3D U-Net architecture by introducing a residual variant. The original 3D U-Net employs a structure where the number of feature maps doubles with each downsampling and halves with each transposed convolution, maintaining a maximum of 320 feature maps. Downsampling continues until the spatial feature map size is less than 4.

The plain 3D U-Net consists of two convolution-instant normalization-Leaky ReLU blocks between pooling and upsampling layers, starting with 30 feature maps at the highest resolution. In contrast, the residual 3D U-Net incorporates residual blocks in the encoder, following a specific pattern of convolution, normalization, and activation, with the residual addition occurring before the final ReLU. This architecture begins with one residual block at the highest resolution, gradually increasing the number of blocks after each downsampling step. The decoder is simplified to one convolution-instant normalization-ReLU per resolution, and to manage the increased memory demand of the residual design, the initial number of feature maps is reduced from 30 to 24.
