The paper describes various robotic tasks that involve cooperative actions among multiple agents, highlighting the use of macro-actions to improve performance in different scenarios. 

In the Box Pushing domain, each robot can perform three one-step macro-actions: Turn-left, Turn-right, and Stay, as well as multi-step actions like Move-to-small-box(i) and Move-to-big-box(i) to navigate to specific locations. A unique aspect of this task is that the big box can only be moved when both robots collaborate. Robots can only observe the status of the cell directly in front of them, and penalties are incurred for hitting boundaries or pushing the big box alone.

The Overcooked task requires three agents to cooperatively prepare a salad with unknown recipes. Agents can move and perform actions like picking, placing, chopping, and delivering items by using a set of macro-actions that include one-step actions and specific long-term navigation actions. Each agent observes a limited area around them, which adds complexity to the coordination required.

In the Warehouse Tool Delivery scenario, a robot arm is responsible for retrieving tools needed by humans working on assembly tasks. The mobile robots must learn which tools to deliver, and they have specific macro-actions to navigate to waypoints and interact with the robot arm. The arm also has its own set of macro-actions for finding and passing tools.

The results section evaluates the performance of macro-action-based methods compared to primitive-action-based methods across different scenarios. The study indicates that the use of macro-actions significantly enhances performance in both decentralized and centralized settings, especially in various grid sizes of the Box Pushing domain and in Overcooked scenarios. The paper provides detailed training methodologies and performance metrics, emphasizing the effectiveness of macro-actions in improving robotic cooperation and task execution.
