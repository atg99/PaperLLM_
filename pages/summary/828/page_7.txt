The paper discusses various approaches to quantization in neural networks, focusing on the calibration of activation ranges and the granularity of quantization. 

To compute typical activation ranges, multiple metrics have been proposed, with Mean Squared Error (MSE) being the most common method. Other metrics like entropy have been considered, and some methods learn the clipping range during neural network training. Notable techniques include LQNets, PACT, LSQ, and LSQ+, which optimize both clipping ranges and weights during training.

The paper differentiates between dynamic and static quantization. Dynamic quantization computes clipping ranges on-the-fly, leading to higher accuracy, but is computationally expensive. Static quantization, which uses fixed clipping ranges, is more commonly employed.

Quantization granularity is categorized into four types:
1. Layerwise Quantization: Uses a single clipping range for all weights in a layer, which can lead to sub-optimal accuracy due to variability in filter ranges.
2. Groupwise Quantization: Groups channels to determine clipping ranges, useful for varied parameter distributions, but adds complexity.
3. Channelwise Quantization: Assigns a unique clipping range to each convolutional filter, improving accuracy while maintaining low overhead, making it the standard approach.
4. Sub-channelwise Quantization: Determines clipping ranges for smaller groups of parameters but incurs significant computational overhead.

Lastly, the paper touches on non-uniform quantization, which allows for non-uniformly spaced quantization levels and steps. This method can enhance accuracy for a given bit-width by better capturing important value regions in weight and activation distributions, particularly useful for bell-shaped distributions.
