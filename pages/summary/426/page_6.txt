In this section, the authors present the Prototypical Calibration Block (PCB), a novel metric-based score refinement module designed to separate classification and localization tasks during inference. Traditional detectors often utilize a shared backbone for both tasks, which can lead to conflicts since classification requires translation invariant features while localization requires translation covariant features. This tension can degrade classification performance, especially in scenarios with limited annotated samples.

The PCB aims to address this issue by refining scores generated from a few-shot classification branch that tends to produce low-quality outputs. The PCB consists of a strong classifier pretrained on ImageNet, a RoIAlign layer, and a prototype bank. For a given M-way K-shot task, it extracts features from the image and uses RoIAlign with ground-truth boxes to create instance representations. It then reduces the support set to a prototype bank through averaging, allowing the PCB to calculate the cosine similarity between predicted features and prototypes.

The final classification score is obtained through a weighted aggregation of the scores from the few-shot detector and the PCB. Notably, the PCB operates independently of the few-shot detector without shared parameters, ensuring that it maintains the quality of classification-focused features while effectively decoupling the tasks. This modular design allows the PCB to be easily integrated into various architectures, enhancing few-shot detection capabilities.

The subsequent section details experimental settings, including benchmark datasets and evaluation protocols, comparing the proposed method against state-of-the-art approaches. Results indicate that the PCB significantly improves detection performance on PASCAL VOC and COCO datasets, validating its effectiveness in both few-shot and generalized few-shot object detection scenarios.
