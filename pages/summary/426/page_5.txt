In this section, the concept of the Gradient Decoupled Layer (GDL) is introduced, focusing on its innovative approach to managing the relationship between upstream and downstream modules in a neural network. The GDL operates through an affine transformation layer during forward propagation, enhancing feature representations using learnable channel-wise weights and bias. In backward propagation, it modifies the gradient from the subsequent layer by multiplying it with a constant decoupling coefficient, λ, which ranges from 0 to 1. This results in a scaled gradient being passed to the preceding layer.

The GDL can be mathematically expressed as a pseudo-function, with distinct equations for its forward and backward behaviors. The implementation of GDL within existing deep learning frameworks is straightforward due to the simplicity of defining forward and backward procedures. The paper demonstrates how GDL can be integrated into a standard Faster R-CNN architecture by placing GDLs between the shared backbone and both the Region Proposal Network (RPN) and the RCNN. This configuration allows for the adjustment of the decoupling degree of the modules during the backward propagation.

The loss function for the model is defined with respect to the two GDLs, allowing for the optimization of the model parameters through a gradient descent approach. The paper outlines three scenarios for the decoupling coefficients that affect the parameter updates of the shared backbone, RPN, and RCNN, illustrating how GDL influences the learning process. The accompanying algorithm provides a PyTorch-like implementation of the GDL, detailing both the forward and backward passes.

Overall, the GDL presents a novel mechanism for decoupling gradients, enabling more flexible and controlled training dynamics within neural network architectures.
