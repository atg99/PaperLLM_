The Convolutional Block Attention Module (CBAM) consists of two sequential attention modules: channel attention and spatial attention. The channel attention module generates feature maps through average and maximum pooling, which are then processed by a shared multilayer perceptron (MLP) and normalized using a sigmoid function. This output is multiplied with the convolutional layer's features, which are then passed to the spatial attention module to identify critical feature positions within the image.

The Squeeze-and-Excitation (SE) Attention Module compresses the input feature map to a lower dimension using global pooling, followed by two fully connected layers with ReLU and sigmoid activations to form an excitation block. The output of this block is multiplied with the input feature maps for enhanced representation.

These attention modules aim to improve the model's ability to focus on important features, thereby optimizing performance in tasks such as image classification within agricultural contexts.
