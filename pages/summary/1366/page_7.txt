This paper emphasizes the importance of interdisciplinary information sharing and teamwork in understanding human-robot interactions, particularly in industrial applications. It discusses the "user understanding" phase of design, which focuses on thorough user analysis through techniques like observation, focus groups, and interviews. These methods facilitate context research and help define user personas and usage scenarios.

The paper outlines various UX tools such as task analysis, empathy maps, journey maps, and service blueprints to analyze user interactions and improve design processes. These tools enable designers to visualize user experiences and identify pain points in the user journey.

The research proposes a UX-based design workflow comprising four steps: requirement gathering, interface design, prototyping, and UX assessment. The requirement gathering phase includes forming a multidisciplinary team, conducting user analysis, performing activity analysis, and visualizing interactions using new tools like the User/Task Matrix and Experience Maps. These tools help synthesize user data and operational conditions to guide interface design.

The User/Task Matrix organizes information about tasks, actors, and working conditions, allowing for a structured approach to interface selection. The overall goal is to ensure effective human-robot collaboration by focusing on user-centered design principles, ultimately enhancing user experience and operational efficiency in manufacturing settings.
