The paper presents a methodology for optimizing classification of Diabetic Retinopathy datasets using a combination of algorithms. The core concept revolves around the Firefly Algorithm, which is inspired by the behavior of fireflies, where the brightness of their light serves as the objective function to be optimized. The algorithm follows a structured approach that includes generating machines and job sequences, evaluating makespan, and iterating through generations to enhance job sequences and lot sizes.

To address potential bias in the dataset, which contains 19 attributes with varying ranges, a StandardScaler method is employed to normalize the data. This step ensures that all attribute values are on a common scale, thus preventing skewed predictions. Subsequently, Principal Component Analysis (PCA) is applied to eliminate insignificant attributes, refining the data for training a Deep Neural Network (DNN).

The Firefly Optimization Algorithm plays a crucial role in feature engineering by selecting optimal parameters that enhance classification performance while minimizing training time. The DNN is set up with the Adam optimizer and Softsign activation function for all layers except the output layer, which uses a sigmoid activation function for binary classification. The training process employs Root Mean Square Propagation (RMSprop) for backpropagation and utilizes a batch training method, where each epoch processes a subset of the data to improve model accuracy.

In summary, the proposed model effectively transforms the Diabetic Retinopathy dataset, reduces dimensionality, and optimizes parameters using the Firefly Algorithm, ultimately leading to improved classification outcomes.
