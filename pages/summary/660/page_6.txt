The paper discusses an efficient architecture for implementing deep learning operations on FPGA, focusing on the communication and data management between the CPU and FPGA during the forward and backward passes of a multi-layer perceptron (MLP) and graph convolutional network (GCN). It outlines the data that needs to be communicated to and from the FPGA, including node features, subgraph topological data, pre-computed vector sums, model weights, and gradient information. The architecture utilizes on-chip Block RAM (BRAM) to store essential data, ensuring that gradients are only stored for consecutive layers, which optimizes memory usage.

The processing pipeline consists of two primary computation modules: the Feature Aggregation module and the Weight Transformation module. The Feature Aggregation module aggregates features through a three-step process, emphasizing parallelism in the computation of node pairs and their respective features. It utilizes a 1D accumulator array for efficient data processing. The Weight Transformation module focuses on matrix multiplication using a 2D systolic array to enhance computational efficiency. It details the data access patterns and the operations required for both GCN and MLP layers, including ReLU activation.

The paper highlights the importance of optimizing data management and computation on FPGA to enhance performance in deep learning tasks. It discusses potential improvements in parallelism and storage efficiency, indicating that the architecture is designed to handle complex operations while minimizing external memory access. Overall, the architecture aims to provide a high-performance solution for deep learning applications on FPGA platforms.
