The paper presents an improved baseline algorithm for class-level mining, utilizing a two-step process that enhances computational efficiency and diversifies training examples. The key components of the algorithm include sampling anchor classes, identifying nearest neighbor classes, and refining instance-level searches based on selected classes. 

Algorithm 1 outlines the procedure, where an anchor class is randomly selected, and instances are sampled from this class. The search for nearest neighbor classes is formalized through a similarity measure, leading to the selection of negative class signatures that guide the instance sampling process. This results in a minibatch composed of instances from the anchor class and selected negative classes, which is then used for training to minimize a defined loss function.

Algorithm 2 summarizes the overall training process, emphasizing stochastic hard example mining, which facilitates the identification of diverse negative classes across iterations. This method is shown to improve model learning efficiency compared to traditional approaches.

The paper also discusses computational efficiency, noting that the naive approach would require extensive computations for feature extraction across all classes. In contrast, the proposed method reduces this cost by focusing only on a small subset of nearest classes, thus optimizing feature extraction during training.

Finally, the loss function is defined to jointly minimize both triplet loss and class signature loss, with the expectation that this combined learning approach will enhance the accuracy of the model's outputs.
