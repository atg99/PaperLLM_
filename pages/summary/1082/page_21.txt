The paper discusses the function of the "control readout" gate in the Vanilla LSTM network, denoted as gcr[n], which regulates the proportion of the readout signal that contributes to the observable value signal at each time step. This is integral to the formulas defining the LSTM cell. According to the equations presented, the current state signal of the cell is a combination of the previous state signal and the new information available at the current time step.

An example illustrates the LSTM's capability to propagate the error gradient without attenuation by setting specific gate values. This mode, referred to as the "Constant Error Carousel" (CEC), allows for continuous error gradient flow and refreshes the state signal at each step. The paper notes that while the error gradient influences parameter updates in standard RNNs via Gradient Descent, LSTM networks are better suited to accommodate this due to their gating mechanisms.

Furthermore, it is indicated that under certain parameter conditions, the LSTM can operate in CEC mode, which enables effective back-propagation of the error gradient over many time steps, thereby enhancing sensitivity to long-range dependencies during training. If the model parameters lead to a specific condition where gcs[n] equals 1, the LSTM can effectively avoid the vanishing gradient problem, although the design does not explicitly address the exploding gradient issue. To mitigate this, the paper mentions that derivatives are renormalized to remain within a specific range during training. The LSTM cell is also likened to a differentiable version of a digital static random access memory cell due to its access control capabilities.
