The paper introduces modifications to the Vanilla LSTM cell by integrating a Recurrent Projection Layer and a new control input gate. The Recurrent Projection Layer alters the cell's value signal, denoted as ⃗ v[n], by introducing a qualifier signal ⃗ q[n] through matrix multiplication with a weight matrix Wqdr. This adjustment allows for dimensionality reduction of the cell's value signal, enabling faster training by reducing computational load. In contrast to the Vanilla LSTM, where the dimensionality of the value signal must match that of the state signal, this new layer provides flexibility to balance representational capacity and computational efficiency.

Additionally, the paper critiques the treatment of the external input in the Vanilla LSTM cell, where it is always fully injected without regulation. To enhance adaptability to training data variations, the authors propose the introduction of a control input gate, ⃗ gcx[n], which modulates the contribution of the external input to the data update accumulation node ⃗ adu[n]. This new gate allows for finer control, enabling the LSTM cell to adjust the impact of both the readout and external input signals on the state signal, thereby improving performance in the presence of noisy or spurious inputs.

Equations are provided to illustrate the implementation of the new control input gate and its integration into the LSTM cell design, highlighting the element-wise multiplication that governs the contribution of the external input. Overall, these modifications aim to enhance the efficiency and adaptability of LSTM cells in processing complex data.
