The paper defines two additional weight matrices, Wr and Wx, along with a bias vector θs, which transforms the system into the canonical form of a Recurrent Neural Network (RNN). The equations presented illustrate the relationship between the current state s[n], the previous state s[n-1], the previous output r[n-1], and the input x[n]. Specifically, the RNN state update is represented by the equation s[n] = Ws s[n-1] + Wr r[n-1] + Wx x[n] + θs, where Wr and Wx are scaled by a factor ΔT and the weight matrix Ws. The output r[n] is then derived from the state s[n] using a function G. 

The figure accompanying the text depicts the canonical RNN cell, noting that the bias vector θs can be incorporated into the input signal by modifying the input vector x[n]. The paper hints at a future transition from this RNN formulation to a Long Short-Term Memory (LSTM) system. Additionally, it mentions the concept of "unrolling" or "unfolding" RNNs, which will be further clarified using the standard RNN definition based on stability considerations.
