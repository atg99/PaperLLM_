The paper discusses the derivation and modification of a standard Recurrent Neural Network (RNN) system, focusing on the stability and gradient issues associated with it. It begins by noting that the matrix W_s in the RNN is a diagonal matrix with positive fractions, allowing the simplification of the state update equation. By setting W_s to the identity matrix, the contribution from the previous state remains fractional, ensuring system stability.

The paper introduces a control readout gate, g_cr[n], to manage the readout signal, which prevents the vanishing and exploding gradients problem by controlling the feedback path. The revised update term incorporates both the readout signal and the input signal, allowing for a flexible system where the contributions can be modulated. The control input gate, g_cx[n], further enhances flexibility by allowing the external input to be scaled.

The dynamics of the value signal, v[n], are determined by the readout signal, which is bounded by a warping nonlinearity, G_d(z). This nonlinearity is crucial for maintaining the dynamic range when incorporating the input signal. Ultimately, the paper presents an updated state equation that integrates these modifications, emphasizing the role of the control gates in improving the RNN's performance while addressing stability concerns.
