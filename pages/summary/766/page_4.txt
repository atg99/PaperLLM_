The paper discusses an experimental setup utilizing a lens-free Mach-Zehnder interferometer for holographic imaging. The setup includes standard interferometer components and two linear motion controllers for precise object positioning. The system generates interference patterns between reference and object beams, recorded at the hologram plane without an objective lens, resulting in unit magnification.

Three types of objects were used for imaging: an amplitude object (a negative USAF 1951 test target), a phase-only object (a lithographically created groove on an optical wafer), and a two-sectional transparent object (a triangle and rectangle). Holograms were acquired by adjusting the position of the target or the incident angle of the beams, resulting in over 10,000 holograms collected for the dataset.

The proposed HRNet model employs a train-validate-test scheme, with data split into 80% for training, 10% for validation, and 10% for testing. Weights and biases are initialized using truncated normalization, with a minibatch size of 10 holograms for each training iteration. The loss function is minimized using the Adam optimizer with a learning rate of 0.01, which decays exponentially during training. The experiments were performed in a specified computing environment.

The amplitude object imaging process involved careful adjustments to ensure optimal pattern contrast, with ground-truth images obtained through numerical backpropagation and manual artifact removal. The paper provides detailed experimental results and comparisons, highlighting the effectiveness of the proposed deep learning framework in holographic imaging.
