The paper discusses the element-wise multiplication of an input sequence by a sampling window to extract segment-level input sequences. Specifically, the input sequence \( \vec{x}[n] \) is multiplied by a window \( \vec{w}_m[n] \) to create a segment-level input sequence \( \vec{x}_m[n] \), which retains non-zero values only within a specific range defined by the segment index \( m \). The recursive nature of Recurrent Neural Networks (RNNs) implies that the state signal sequences depend on the entire input sequence. However, the paper asserts that state signal subsequences from different segments remain independent, necessitating that the state signal \( \vec{s}_m[n] \) only depends on its corresponding input sequence \( \vec{x}_m[n] \).

A mapping function \( F \) transforms the segment-level input sequence into its corresponding state signal sequence. The independence of state signal subsequences requires that certain conditions be met, which the paper simplifies by setting specific state signals to zero. The equations governing the RNN system for individual segments are derived, showing how the segment-level state and input sequences are updated based on previous states and inputs.

Furthermore, the paper introduces an index substitution that shifts the segment-level subsequences, effectively adjusting the indices for clarity and ensuring that the equations reflect the segment structure. Overall, the work provides a framework for understanding how RNNs can operate on segmented input data while maintaining the independence of state signals across different segments.
