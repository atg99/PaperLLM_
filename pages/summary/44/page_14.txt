The equations presented outline a standard recurrent neural network (RNN) system that is unrolled for Km steps across multiple segments indexed by m, where m ranges from 0 to M-1. The initial state signal for each segment is defined as a zero vector for n equal to -1. For n within the range of 0 to Km-1, the state signal is calculated using a combination of the previous state, the input signal, and a bias term. The readout signal is generated from the state signal using a function G.

Each segment's input subsequence consists of values from the overall input sequence, effectively making the input signal the only independent variable of the RNN system. The mutual independence of the state signals across different segments allows for generic computations for all segments. The dependency on the segment index is retained only in the input signal.

The prototype formulation simplifies the representation by dropping the segment subscript for state and readout signals. This approach allows for processing each segment sequentially while maintaining the ability to evaluate all segments in parallel due to their independence. The process involves initializing the state signal, selecting input samples, and then running the RNN computations for each segment, which can be executed concurrently for efficiency.
