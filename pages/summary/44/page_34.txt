The paper discusses extensions to the Vanilla LSTM network, focusing on enhancing its architecture through three main improvements. First, it proposes expanding the input from a single sample to multiple samples within a context window. This adjustment allows the model to leverage a richer input signal, which is managed by introducing a new gate as outlined previously. Second, the paper incorporates a "recurrent projection layer" into the enhanced model, which has shown advantages in specific sequence modeling tasks.

In detail, the external input context windows are represented by linear filters with matrix-valued coefficients that operate on the sequence of input samples. This involves replacing single input sample computations with convolutions of context window filters, thus allowing the model to utilize input samples from both past and future steps in the sequence. The filters are designed to be non-causal, enabling the model to access future input samples without significantly increasing the number of parameters.

The convolutional approach allows the model to discern the context surrounding each sequence step, akin to how humans read ahead for better comprehension. The paper suggests exploring the trade-offs between the additional parameters required for context windows and the training complexity of a bi-directional LSTM network, advocating for comparative performance analysis across various datasets.
