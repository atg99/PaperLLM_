The Vanilla LSTM network processes its state signal at the current step as a weighted combination of the previous cell's state and the aggregate of historical and novel updates. Similar to standard RNNs, it can learn short-range dependencies within subsequences of training data. However, when model parameters lead to a condition where the error gradient signal declines (∥⃗ gcs[n]∥<1), the gradient may vanish over time, despite the presence of update signals (∥⃗ gcu[n]∥>0 and ∥⃗ gcr[n]∥>0). This phenomenon will be further discussed in Section VI-J.

To define the gate signals (⃗ gcs[n], ⃗ gcr[n], and ⃗ gcu[n]), it is essential that all functions within the system are differentiable, particularly when trained using Backpropagation Through Time (BPTT). The logistic function serves as a suitable mapping function, defined as Gc(z) = σ(z) = 1 / (1 + e^(-z)), which translates inputs from the real line into the range (0,1). This function is continuous, differentiable, and monotonically increasing. The same principles apply when calculating Gc(⃗ z) and Gd(⃗ z) for vector inputs, using the logistic function's properties.
