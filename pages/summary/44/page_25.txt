The paper discusses warping functions and the parameters of the Vanilla Long Short-Term Memory (LSTM) cell model. Warping functions are crucial for controlling values within a specified range, specifically between 0 and 1. The sigmoidal function is chosen for its properties of monotonicity, continuity, and differentiability, making it suitable for control applications. It is defined as Gc(z) = σ(z) = 1 / (1 + e^(-z)). The hyperbolic tangent function is utilized for data bounding, defined as Gd(z) = tanh(z), which effectively supports both negative and positive standardized values.

The paper also details the fifteen parameters associated with the Vanilla LSTM cell model, categorized into three main accumulation nodes: the control update node (acu), the control state node (acs), and the control readout node (acr). Each node has specific weight matrices (Wx, Ws, Wv) and bias vectors (b) that connect input signals, previous state signals, and observable value signals to manage the cell's state and outputs at each time step. This structured parameterization is essential for the operation of LSTM networks in processing sequential data.
