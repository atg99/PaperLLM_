The paper outlines the fundamental equations governing the forward pass of a Vanilla Long Short-Term Memory (LSTM) cell, emphasizing the sequential dependency of cell states. Each state at index n relies on the previous state at index n-1. The equations that define the computations for the LSTM cell are presented as follows:

1. The update gate (acu) is calculated using inputs and previous states.
2. The cell state (acs) incorporates similar dependencies.
3. The candidate state (acr) also uses both current and previous states.
4. The activation (adu) considers only the current input and previous outputs.
5. The output (u) is generated through a non-linear function applied to adu.
6. The gates (gcu, gcs, gcr) are derived from the activation functions of their respective states.
7. The new cell state (s) is updated by combining the previous cell state with the contributions from the update gate.
8. The reset gate (r) is derived from the current cell state.
9. The final output (v) is computed based on the reset gate and the current state.

Figures included in the paper illustrate the LSTM cell's architecture and its unrolled representation over several steps, providing clarity on the function of each component within the cell. The discussion notes that for bi-directional LSTM, evaluations take place in both forward and backward directions, although the focus here is solely on the forward direction.
