The paper presents a Visual Question Answering (VQA) model that integrates visual and language features to determine answers to questions about images. The model consists of two main components: the visual part, which utilizes a CNN architecture (ResNet-152) to extract image features, and the language part, which employs a skip-thoughts model to generate semantic vectors from the input questions.

The visual features are transformed into a 1200-dimensional vector, while the language features are also reduced to the same dimension through a fully connected layer. The fusion of these two vectors is achieved via point-wise multiplication after applying the hyperbolic tangent function, ensuring comparability during end-to-end training.

For prediction, the model utilizes a multi-layer perceptron (MLP) to project the fused vector into an answer space, treating the task as a classification problem where each potential answer corresponds to a class. The training process employs the Adam optimizer and includes dropout to mitigate overfitting, with variations in batch size according to the dataset's image dimensions.

The results indicate that the model achieves an overall accuracy of 79% across both low-resolution (LR) and high-resolution (HR) datasets, with detailed performance metrics provided for different question types. The paper includes qualitative assessments of model predictions and confusion matrices to illustrate the results further.
