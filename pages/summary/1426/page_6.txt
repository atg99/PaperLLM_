The paper presents a model for Visual Question Answering (VQA) that incorporates semantic, spatial, and implicit relations to enhance prediction accuracy. The model was evaluated on the VQA 2.0 and VQA-CP v2 datasets, using Visual Genome for pre-training the semantic relation classifier. The evaluation metric employed is accuracy, which is calculated based on the number of human-provided answers.

The VQA 2.0 dataset consists of real images from MSCOCO, with questions categorized into Yes/No, Number, and Other types. Each image-question pair is associated with multiple answers collected from human annotators. The VQA-CP v2 dataset aims to address question-oriented bias in VQA models by altering the distribution of answers across training and testing splits.

Implementation details include the tokenization of questions and the use of 600-dimensional word embeddings, with a GRU network processing the embedded sequences. Multi-head attention is applied, and the model features a semantic relation classifier trained on selected object and attribute classes from a Faster R-CNN model.

The experiments demonstrate that the proposed relation encoder can be integrated into existing VQA architectures, such as Bottom-up Top-down, Multimodal Tucker Fusion, and Bilinear Attention Network. Results indicate that incorporating the proposed relation encoder consistently improves model performance across all architectures, with the best results achieved when utilizing all three relation types. This evidence supports the effectiveness of the ReGAT model as a versatile enhancement for state-of-the-art VQA models.
