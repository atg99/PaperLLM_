The paper discusses the implementation of various models for generating and inferring 3D human motion data using deep learning architectures. 

1. **DVAE Implementation**: It employs a Multi-Layer Perceptron (MLP) for both the latent variable representation and the function \( e_z(g_t) \), where \( z_{t-1} \) is transformed using an MLP with 16 units and Tanh activation, and \( g_t \) is processed with an MLP featuring 32 units and Tanh.

2. **STORN Model**: For generation, the function \( d_h(x_{t-1}, z_t, h_{t-1}) \) utilizes a concatenation of two MLPs followed by a forward LSTM network. The MLPs have 64 and 32 units respectively. The output layer for \( x_t \) is determined by the function \( d_x(h_t) \). Inference is managed through an MLP for \( e_g(x_t, g_{t-1}) \) and \( e_z(g_t) \).

3. **VRNN Model**: Feature extraction uses MLPs for both \( \phi_x(x_t) \) and \( \phi_z(z_t) \). Generation is executed via an LSTM network that takes the concatenated feature representations as input. The functions \( d_z(h_t) \) and \( d_x(\phi_z(z_t), h_t) \) are implemented as output layers mapping to the latent space. Inference for \( e_z(\phi_x(x_t), h_t) \) concatenates inputs for processing.

4. **SRNN Model**: Generation functions are implemented using LSTM networks and MLPs. Specifically, \( d_h(x_{t-1}, h_{t-1}) \) is processed through an LSTM and \( d_z(z_{t-1}, h_t) \) utilizes an MLP with 32 units. The function \( d_x(z_t, h_t) \) is also implemented with an MLP containing 64 units.

Overall, the implementations leverage MLPs and LSTM networks to manage both generation and inference tasks effectively within the context of 3D human motion data.
