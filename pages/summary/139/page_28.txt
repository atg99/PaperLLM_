This section discusses the application of variational inference in learning, specifically focusing on maximizing the total variational lower bound (VLB) with respect to generative model parameters. The gradient of the total VLB is derived from local VLBs associated with each data sample. For large datasets, directly computing these gradients can be inefficient, prompting the use of stochastic variational inference. This method employs a noisy estimate of the gradient from either a single sample or a mini-batch, mirroring techniques from stochastic gradient descent and benefiting from similar convergence properties.

Nevertheless, estimating the complete set of variational parameters can still be costly for large datasets. To address this, amortized variational inference introduces an inference model that maps observations to local variational parameters, thereby sharing parameters across all variational distributions. This approach defines a variational family that is more constrained than non-amortized methods, potentially resulting in a larger Kullback-Leibler divergence between the exact posterior and its approximation.

The total VLB for the entire dataset is then reformulated as a function of the shared parameters, shifting the focus from optimizing individual local variational parameters to optimizing these shared parameters. This transition signifies a significant change in how variational inference is approached, especially in the context of large datasets.
