In this section, the paper details the implementation of the Deep Variational Autoencoder (DVAE) models specifically designed for 3D human motion data. The architecture remains consistent with that used for speech data, as both inputs consist of sequences of 1D vectors. However, due to the smaller dimensionality of human pose vectors (96) compared to speech vectors (513), the latent variable dimension zt is reduced to 10, and lighter Long Short-Term Memory (LSTM) networks with a hidden state dimension of 64 are employed.

For the DKF (Dynamic Keyframe) generation, the gated transition function mirrors that of the speech data, with the hidden dimension for all Multi-Layer Perceptrons (MLP) adjusted to 10. The generation function dx(zt) is implemented with an MLP configured as (zt, 32, Tanh, 64, Tanh).

In the inference process, similar to the speech data implementation, the function for encoding is executed using a backward LSTM, which is fed by an MLP structured as (xt, 64, Tanh). The affine function of the latent variable zin is modified to utilize a one-layer architecture. This adaptation allows the DVAE model to effectively handle the specific characteristics of 3D human motion data while maintaining performance efficiency.
