The Stochastic Recurrent Neural Network (SRNN) model, introduced by Fraccaro et al. in 2016, integrates a deterministic recurrent neural network with a state space model to create a stochastic generative model for sequential data. In the paper, the authors denote the hidden state as dt, but this summary uses ht for consistency with comparisons to other models like the Variational RNN (VRNN) and Stochastic Time-Dependent Recurrent Neural Network (STORN).

The generative model of the SRNN is structured as follows: the hidden state at time t, ht, is determined by the function dh, which takes the previous observation xt-1 and the previous hidden state ht-1 as inputs. The model then generates parameters for a normal distribution, specifically the mean µθx and standard deviation σθx, based on the current hidden state ht and a latent variable zt. The observation xt is modeled as a normal distribution centered around µθx with a diagonal covariance defined by σ2θx.

This formulation highlights that the first equation mirrors the deterministic RNN structure, while the subsequent equations introduce stochasticity into the model, enabling it to capture complex temporal dependencies in sequential data.
