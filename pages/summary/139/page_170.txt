The paper describes a deep learning architecture involving a forward LSTM network for the generation function dh(zt−1,ht−1), which has a hidden layer with a dimension of 128. The projection of the hidden state ht to zt is accomplished through a one-layer linear network. The function dx(zt,v) is implemented as a multi-layer perceptron (MLP) with a specific architecture comprising several layers and activation functions.

For inference, the process for estimating the variable v uses a bidirectional many-to-one LSTM with input xt and output gv, followed by a single output layer. The estimation of zt is carried out using a bidirectional LSTM that takes both v and xt as inputs. Additionally, the function ez(gz_t) is implemented as an RNN with a hidden layer of dimension 128.

The paper notes a design choice regarding MLP blocks in the architecture. While MLP blocks were initially included in the design for outputting gz_t, they were ultimately not used in the implementation due to improved performance without them, although the option to include such layers remains in the open-source code.
