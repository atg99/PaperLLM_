The paper presents a framework for transferable contrastive learning, focusing on zero-shot learning (ZSL). It introduces an information fusion module that integrates image features with class semantic information and a contrastive learning module that evaluates the consistency of this fusion. The core idea is to achieve both discriminative and transferable properties in the model.

Discriminative property ensures the model can classify different classes effectively, while transferable property allows the model to generalize to target classes. The loss functions are formulated to maximize contrastive values for consistent fusions and minimize them for inconsistent ones. The overall loss function combines discriminative and transferable components, controlled by a parameter.

To address the lack of labeled target images, the method leverages class similarities by using source images to learn about similar target classes. The similarities are computed through a reconstruction approach inspired by sparse coding, which helps in understanding the relationship between source and target classes.

In summary, the framework aims to enhance ZSL by effectively transferring knowledge from source to target classes through contrastive learning, utilizing both semantic information and class similarities.
