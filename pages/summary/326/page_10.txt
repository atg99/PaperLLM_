The paper presents a comprehensive classification framework for the use of GPT in research data, focusing on two primary areas: data generation and augmentation, and natural language processing (NLP) and text analysis.

In the section on data generation and augmentation, the paper discusses synthetic data creation, which involves using GPT models to generate artificial data that resembles real-world data, especially in situations where data privacy is important or actual data is scarce. This aspect is supported by literature references [31,35,51,52,56,57]. Additionally, text data expansion and enhancement is highlighted, wherein GPT is utilized to create new textual content and improve existing datasets, thus enhancing the performance of machine learning models and mitigating data scarcity challenges [12,26,37,39,41,48,53,54,65].

The NLP and text analysis section covers feature extraction and named entity recognition (NER), emphasizing GPT's capability to identify key features in unstructured data and improve NER functionalities [33,38,43]. The paper illustrates how, before GPT, various NLP techniques were employed for feature extraction from textual data, but GPT allows for a more straightforward approach using simple prompts. Furthermore, text simplification and classification are discussed, showcasing GPT's effectiveness in making complex texts more understandable, particularly in specialized fields like finance [10,62,64,67]. Lastly, text augmentation and linguistic feature detection are examined, where GPT generates text that aids in identifying specific linguistic features, including similes and event relations, as noted in works [44,63,53].

Overall, the paper provides a structured overview of GPT's applications in enhancing research data handling through data generation, NLP, and text analysis techniques.
