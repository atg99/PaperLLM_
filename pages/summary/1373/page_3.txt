This paper discusses the Belief-Desire-Intention (BDI) model, a prominent framework in agent-based programming that facilitates the decision-making process of agents. The workflow of a generic BDI system involves a belief revision function that updates the belief base using input from the environment, which generates potential desires. A filtering mechanism updates the intentions base, leading to the selection of an intention for action execution. The AgentSpeak(L) language is highlighted as an abstraction for interpreting BDI systems, which has influenced various agent programming languages (APLs).

Additionally, the paper introduces Situation Calculus, a first-order language that models changes in dynamic environments through a sequence of actions. This model is essential for understanding how agents interact with their environment, particularly in dynamic contexts.

The authors note that while there are many models influencing APLs, BDI and Situation Calculus are historically significant. They also mention that APLs may incorporate concepts from various programming paradigms, although a detailed comparison of these paradigms is beyond the scope of the review.

The paper further emphasizes the practical applications of agent-based programming, which include distributed control systems, resource allocation, automated machine interactions, and privacy violation detection. Lastly, the authors outline their systematic review methodology, which analyzed literature on agent programming languages published between 2015 and 2020, focusing on the first 100 entries from Google Scholar for each search term.
