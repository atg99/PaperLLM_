The paper discusses the implementation of various agent programming languages (APLs) used for developing domain-independent multi-agent systems (MASs). It highlights that Java is the predominant language due to its cross-platform capabilities via the Java Virtual Machine. The authors provide a table listing recent APLs, detailing their models, implementations, and last updates. Notable languages include ASTRA, Chromar, GOAL, Gwendolen, JaCaMo, and Jason, among others. 

The paper also addresses the cognitive challenges faced by APL developers when bridging the gap between traditional programming concepts and those specific to agent-oriented programming (AOP). It references studies aimed at understanding the connection between AgentSpeak and object-oriented programming (OOP) to alleviate this cognitive disparity. Additionally, Chromar is introduced as a rule-based language with stochastic semantics, demonstrating the diversity of approaches within agent programming research. The discussion emphasizes the ongoing development and updating of these languages to enhance their applicability in agent-based systems.
