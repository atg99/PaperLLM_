This section discusses notable extensions to existing Agent Programming Languages (APLs) that have emerged between 2015 and 2020. These extensions involve modifications that enhance the functionality of APLs by adding features or adapting them for specific applications.

One significant extension is the enhanced version of the Multi-Agent System for Competitive Electricity Markets (MASCEM), which supports the integration of new models and tools, particularly through the use of ontologies to facilitate communication among market players. Another extension, TABSAOND, builds upon the PEABS language, focusing on decision-making in non-deterministic scenarios and enabling the deployment of simulators as mobile applications and online tools.

A conservative synchronization model for the SARL language and its runtime platform Janus is introduced to address the lack of event ordering assumptions in Janus, allowing for time-based agent simulations. Additionally, new programming constructs for integrating an advanced rule-based emotion model, EMIA, with the 2APL agent language have been proposed, enhancing the believability of agent emotions in response to real-life scenarios.

ARGO represents a customized architecture for programming embedded robotic agents using the Javino middleware. Procedural reflection in the meta-APL language allows for a more straightforward implementation of BDI agent deliberation cycles. Other extensions enable communication between Jason and ROS, facilitating the programming of autonomous agents in robotic applications without requiring modifications to either platform. A framework for embedded systems using Jason with ROS is also introduced, enhancing low-level interactions.

Lastly, a model integrating reinforcement learning within a BDI agent programming framework based on the Jason language is presented, allowing for a combination of explicitly programmed and learned plans during agent development.
