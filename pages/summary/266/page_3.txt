This paper discusses a capsule network architecture designed for hierarchical multi-label classification (HMC). The architecture employs a dynamic routing algorithm to enhance the classification process by effectively clustering features from primary capsules into classification capsules. The prediction vector for each classification capsule is generated by multiplying the output of primary capsules by a weight matrix, followed by a squashing function to interpret the vector's length as a probability for the corresponding category.

The dynamic routing heuristic iteratively adjusts coupling coefficients based on the similarity between primary capsule outputs and classification capsule predictions, ensuring convergence and allowing for better generalization and combination of features compared to traditional routing methods like max-pooling. This is particularly beneficial in distinguishing classes with similar features, which is critical in HMC where label hierarchies exist.

The capsule network architecture consists of four layers, with primary capsules receiving input from a convolutional layer. The routing algorithm clusters outputs from these primary capsules to create pseudo-probabilities assigned to each classification capsule. Additionally, the network leverages label co-occurrences by initializing weights based on the relationships between classes, which enhances the learning process.

To address potential inconsistencies in label assignments that may violate the hierarchical structure, a post-processing step is implemented to correct these discrepancies. The paper emphasizes the advantages of using capsules and dynamic routing in achieving a robust classification framework for hierarchical data.
