This paper discusses various techniques for dimensionality reduction in the context of graph learning. It begins with linear methods, notably Principal Component Analysis (PCA), which identifies principal components that capture significant variance while discarding noise. Linear Discriminant Analysis (LDA) focuses on enhancing class separability through a linear projection that maximizes the ratio of inter-class to intra-class variance. Multi-Dimensional Scaling (MDS) is highlighted as a method that preserves distances during dimensionality reduction.

The paper then transitions to nonlinear dimensionality reduction techniques, emphasizing methods like Isomap, which constructs neighborhood graphs to find shortest paths, and Locally Linear Embedding (LLE), which focuses on local linear reconstructions for low-dimensional embeddings.

Matrix factorization approaches, inspired by dimensionality reduction principles, are also examined. These models aim to reconstruct adjacency matrices while preserving structural information. Techniques such as Graph Laplacian eigenmaps and Node proximity matrix factorization are discussed for their ability to maintain local distances and approximate node proximities through specific constraints.

The paper further explores GraRep and HOPE, which focus on preserving high-order proximity in graph embeddings. GraRep computes a k-th order transition matrix for high-order relationships, while HOPE minimizes a loss function to capture asymmetric transitivity, utilizing low-rank singular value decomposition for matrix reconstruction.

Lastly, the paper addresses graph kernels, which are essential in machine learning for mapping graph data to high-dimensional spaces. It distinguishes between two types of kernel methods: those that convert graph data into vector form, often losing important structural information, and those that utilize graph kernel functions to maintain the original structure in high-dimensional representations. The paper concludes by noting the diversity and evolution of these methods, reflecting ongoing advancements in graph learning techniques.
