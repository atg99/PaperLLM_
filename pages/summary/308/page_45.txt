Semi-supervised GL combines both labeled and unlabeled data, leveraging the labeled instances to guide the learning process. Lastly, self-supervised GL utilizes pretext tasks to generate labels from the data itself, allowing the model to learn representations without requiring external labels.

Learning Mode The learning modes in graph learning can further influence the model's performance. They can be categorized into transductive and inductive learning. Transductive learning focuses on making predictions for a fixed set of nodes in the graph, leveraging the entire graph structure during training. In contrast, inductive learning aims to generalize to unseen nodes or even new graphs, requiring the model to learn representations that can apply beyond the training data.
