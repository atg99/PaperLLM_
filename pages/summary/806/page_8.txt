The paper discusses a quantization scheme for mapping floating-point values to fixed-point representations, focusing on reducing the number of bits required for storage. The minimum weight value (xmin) is set to 0, and the maximum value (xmax) is set to 2^b - 1, with b representing the number of bits of precision (where b is less than 32). This allows for linear extrapolation of floating-point values into a discrete range of [0, 2^b - 1], effectively converting them into fixed-point values.

The process can also accommodate signed b-bit fixed-point integers, resulting in values ranging from [-2^(b-1), 2^(b-1)-1]. A common choice for b is 8, leading to a significant reduction in space due to the smaller representation size of uint8_t and int8_t datatypes.

During inference, the paper describes a dequantization process that provides a lossy estimate of the original floating-point value using xmin and xmax, acknowledging a loss of information due to rounding. The quantization process must adhere to two main constraints: it should be linear, ensuring precision bits are evenly distributed, and it must accurately map 0.0 to a fixed-point value that preserves the interpretation of zero as a padding indicator for missing tensor elements.

To implement this quantization, the paper outlines a piece-wise linear transformation defined by the equation quantize(x) = xq = round(x/s) + z, where s is the scale value derived from xmin and xmax, and z is the zero-point value assigned to x = 0.0. This method ensures that the quantized representation maintains the necessary properties for effective utilization in computational tasks.
