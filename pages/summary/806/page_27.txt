The paper discusses various strategies for optimizing deep learning models to make them smaller, faster, and more efficient, particularly focusing on embedding table compression and the use of random projection methods. Embedding tables can consume significant memory, especially with large vocabularies, necessitating alternative approaches when model size is a constraint. 

Random projection methods replace traditional embedding tables by mapping input features into a lower-dimensional space using random projection operators. This approach leverages Locality Sensitive Hashing (LSH) to preserve the similarity between data points in the reduced space, allowing the model to learn meaningful features while significantly reducing space requirements from O(V.d) to O(T) with T representing the number of hash functions.

Despite the increased computational complexity of random projection operations compared to embedding lookups, the space efficiency makes them attractive for model optimization. The paper highlights notable models in this category, such as PRADO and PQRNN, which have shown competitive performance on natural language understanding tasks. For instance, PRADO achieves comparable accuracy to LSTM models while being 100 times smaller and ensuring fast inference times. Overall, the survey underscores the potential of random projection methods as a viable solution for efficient deep learning model design.
