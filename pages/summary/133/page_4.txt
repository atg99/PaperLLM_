Denoising autoencoders are a type of neural network architecture that serves as both a regularization technique and a robust method for error correction. In this framework, the input data is intentionally corrupted by noise, such as additive white Gaussian noise or through dropout, and the autoencoder's task is to reconstruct the original, clean input. This process is illustrated in the accompanying figure, which demonstrates how a disrupted input image is transformed into a representation before being decoded back to the original form.

The corrupted input is represented as a random variable with its distribution defined by specific conditions. Two common formulations for these conditions are presented: the first option involves a Gaussian distribution where the variance parameter controls the noise's effect, while the second option employs a probability parameter that determines the likelihood of preserving values in the input. The relationship between denoising autoencoders using dropout and analog coding with erasures has been explored in previous research.
