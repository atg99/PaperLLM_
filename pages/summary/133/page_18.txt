The paper discusses a method for conditional image generation using PixelCNN decoders, which combines elements of autoencoders and PixelCNN. In PixelCNN, pixels are generated sequentially based on a defined order, such as top to bottom or left to right, with each pixel's value influenced by previously generated pixels and the input data. This approach effectively utilizes local spatial statistics, enhancing the probability of generating coherent image features, like maintaining background continuity. An advancement in this technique involved replacing local statistics with a recurrent neural network (RNN), while still preserving the core pixel generation concept. The integration of PixelCNN into autoencoders allows the decoder to function as a PixelCNN network, producing images in a structured, sequential manner. The paper illustrates this framework with a diagram showing how pixels are generated in relation to one another.
