This allows us to differentiate between pixels belonging to the same object class and those belonging to different classes, enhancing the contextual representation for semantic segmentation tasks.

Our proposed OCR (Object-Contextual Representation) method operates through three key steps. First, we create soft object regions from contextual pixels using a deep learning model, guided by ground-truth segmentation. Second, we compute the representation of each object region by aggregating the pixel representations within that region. Lastly, we enhance each pixel's representation with the OCR, which is a weighted sum of all object region representations, with weights determined by the relationships between the pixels and the object regions.

This approach distinguishes itself from traditional multi-scale context methods that do not consider object class relationships, as well as from previous relational context methods that analyze pixels independently without structuring them into regions. Our evaluation on several challenging semantic segmentation benchmarks shows that our method outperforms existing multi-scale and relational context approaches, achieving competitive results across multiple datasets.

In summary, the segmentation transformer framework integrates object-contextual representations that lead to improved segmentation accuracy and efficiency, demonstrating its effectiveness in both semantic and panoptic segmentation tasks.
