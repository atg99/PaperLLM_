The paper discusses the Segmentation Transformer, which is designed for Optical Character Recognition (OCR) in the context of semantic segmentation. The core concept involves computing an object contextual representation for each pixel, utilizing transformation functions implemented through a sequence of convolution, batch normalization, and ReLU activation. This representation is then updated by aggregating the original pixel representation with the object contextual representation, effectively fusing these two components.

The authors highlight that while recent studies like Double Attention and ACFNet share similarities with their approach, they differ in key aspects, such as the nature of the regions formed and the computations involved. The paper also rephrases the OCR pipeline within the framework of Transformer architecture, emphasizing the roles of the encoder and decoder cross-attention modules.

Attention mechanisms are central to this approach, calculated via scaled dot-product, where attention weights are derived from the relationship between queries and keys. The output of the attention mechanism aggregates values based on these weights. The decoder cross-attention module serves a dual purpose: extracting soft object regions and computing object region representations. This is accomplished by treating image features as keys and values while using category queries to generate soft object regions, thus enhancing the segmentation process.
