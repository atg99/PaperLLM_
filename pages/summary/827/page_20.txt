The paper discusses the implementation of quantization-aware training (QAT) using the Straight-Through Estimator (STE) for gradient backpropagation through quantization blocks. The quantization process is defined by a gradient that allows for the effective flow of information despite the non-differentiable nature of quantization. The forward pass remains consistent with previous models, while the backward pass effectively bypasses the quantization block due to the STE assumption.

In earlier studies, quantization ranges for weights and activations were typically updated using min-max scaling. However, recent works have utilized the STE to compute gradients concerning quantization parameters such as scale factors and zero-points. The scale-factor gradient is derived using the chain rule, allowing for the calculation of how changes in the scale affect the quantized outputs.

To enhance flexibility, the zero-point, originally constrained to integer values, is modified to be a learnable real number. This adjustment necessitates the introduction of a rounding operator in the quantization function, which subsequently alters the gradient calculation for the zero-point using the STE again. The paper outlines these modifications and their implications for improving QAT methodologies.
