2.1.2 Sample Size
The sample size hyperparameter refers to the number of observations drawn for each tree. Adjusting this parameter influences the variance of the predictions. A smaller sample size can lead to higher variability in individual trees, while a larger sample size may result in more stable trees. The choice of sample size should consider the balance between bias and variance in the model.

2.1.3 Node Size
The minimum node size is another crucial hyperparameter that determines the minimum number of observations required to create a terminal node. Smaller node sizes can create more complex trees, which may overfit the training data. Conversely, larger node sizes simplify the trees and can lead to underfitting. The optimal node size must be carefully chosen to maintain a balance between complexity and generalization.

2.1.4 Number of Trees
The number of trees in the forest directly impacts the model's overall performance. Increasing the number of trees generally improves prediction accuracy by reducing variance, but it also increases computational costs. The key is to find a sufficient number of trees that balances performance and resource usage.

2.1.5 Splitting Rule
The splitting rule determines how the data is divided at each node in the tree. Various criteria, such as Gini impurity or p-values, can be employed. The choice of splitting rule can influence the model's interpretability and performance, making it another important hyperparameter to consider.

In summary, the paper reviews the hyperparameters of the random forest algorithm, emphasizing their impact on prediction performance and variable importance. It also discusses various tuning strategies and software packages for optimizing these hyperparameters, ultimately contributing to a better understanding of how to effectively employ random forests in data analysis.
