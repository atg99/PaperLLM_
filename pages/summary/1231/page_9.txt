The paper discusses two R packages, tuneRF and tuneRanger, which automate the tuning of hyperparameters for random forest models. 

The tuneRF function from the randomForest package focuses on optimizing the mtry parameter. It begins by calculating the out-of-bag error using the default mtry value, which is the square root of the number of variables for classification and set to three for regression. The algorithm then tests smaller mtry values, decreasing by a factor of two, and continues this process if a relative improvement of at least 0.05 is observed in the out-of-bag error. Once smaller values are exhausted, it explores larger mtry values until no further improvements are found, ultimately returning the model with the optimal mtry.

The tuneRanger package, created as a result of a literature review, facilitates automatic tuning of random forests using the ranger package with minimal user input. It employs sequential model-based optimization (SMBO) with a default of 30 evaluated random points for initial design and 70 iterative steps for optimization, though these parameters can be adjusted. The package simultaneously tunes three parameters: mtry, sample size, and node size, with specific sampling strategies for each. It uses out-of-bag predictions for evaluation, making it more efficient than methods relying on cross-validation. The default performance measures optimized include the Brier score for classification and mean squared error for regression, with the option to select from 50 different measures available in the mlr package.

The final hyperparameter settings are derived from the best 5 percent of SMBO iterations based on the selected performance measure, averaging the hyperparameters and rounding as necessary. The paper provides an example of how to execute the tuning algorithm using the monks-problem-1 dataset from OpenML, highlighting the execution process with the relevant R libraries.
