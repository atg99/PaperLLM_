This section provides a detailed overview of the process involved in a training run for a single-task model using the Lingvo framework. The training initiates with the launch of a trainer, specifying the model name and log directory path. The model name is then resolved through a model registry, which retrieves the relevant parameters for the model. At this stage, parameters for the top-level model are established, but no layers have been instantiated.

Each job runner, including the Trainer, Evaler, and Decoder, independently instantiates the model and constructs the corresponding TensorFlow graphs and operations. The Trainer focuses on creating a training operation that encompasses both forward propagation (FProp) and backward propagation (BProp), while the Evaler and Decoder concentrate on evaluation metrics that involve only the FProp graph.

The instantiation of the model triggers its initialization method, which constructs parameters for child layers recursively. These parameters can either be exposed as part of the top-level model parameters or created from scratch during the initialization process. Additionally, the initialization method is responsible for creating the necessary variables managed by the layer.

After the graphs are built, the Trainer runner awaits the Controller runner to initialize or restore variables from a checkpoint, while the evaluation runners wait for a new checkpoint to be saved in the log directory. This systematic approach ensures the organization and efficiency of the training process within the Lingvo framework.
