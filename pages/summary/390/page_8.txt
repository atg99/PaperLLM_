The paper discusses various statistical procedures employed in image processing, which are essential in fields such as digital photography, satellite imagery, and medical imaging. Key techniques highlighted include contrast enhancement, image resizing, noise reduction, segmentation, color correction, and feature extraction. The dataset preprocessing involved steps like feature-wise centering and standard deviation normalization, along with horizontal flipping and adjustments for width and height shifts, as well as rotation.

The dataset is divided into training, validation, and test sets, each serving distinct purposes: the training set develops the model, the validation set evaluates the training process, and the test set measures the model's performance. The distribution of these sets is illustrated in Figure 5.

Two activation functions are utilized in the study: Softmax and ReLU (Rectified Linear Unit). The Softmax function transforms neural network outputs into probabilities, while ReLU introduces non-linearity by converting negative inputs to zero, helping mitigate the vanishing gradient problem. The mathematical representations of these functions are provided, emphasizing their roles in deep learning.
