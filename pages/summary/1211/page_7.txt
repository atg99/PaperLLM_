In this random features approach, we define a new measure of inlierness that utilizes the characteristics of the feature map. Specifically, we consider the contributions of individual features in this transformed space, allowing for a more nuanced attribution of relevance scores. By analyzing the feature map, we can achieve a better understanding of how specific input features influence the inlierness prediction made by the KDE model.

The proposed method involves calculating relevance scores based on the activations from the random features, which provides a mechanism to identify which input features are most influential. This results in a richer explanation that varies depending on the data point being analyzed, rather than an overly simplistic uniform attribution. By comparing the contributions from different features, we can derive insights into the underlying structure of the data and the reasons why certain examples are classified as inliers.

In summary, this paper discusses two approaches to explaining inlierness in unsupervised learning models. The first approach, while straightforward, leads to uniform attributions that lack informative detail. The second, more advanced method employs a feature map representation, enabling a more precise understanding of the contributions of individual input features to the inlierness prediction.
