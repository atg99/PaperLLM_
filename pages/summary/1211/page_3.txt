The paper discusses the challenge of attributing the predictions of unsupervised and supervised learning models to individual input features, a key area in explainable artificial intelligence (XAI). It defines the input space formed by concatenating multiple input features and introduces a function mapping these inputs to a real-valued score that indicates the evidence for a class or predicted quantity. The attribution problem involves creating a mapping that assigns a vector of scores to each input example, reflecting the contribution of each feature while ensuring that the total score matches the function value for each data point.

Three main approaches to attribution are explored:

1. **Occlusion-based methods**: These methods involve testing the function against various occlusions of input features. The Shapley value, a notable method in this category, provides a unique attribution that adheres to certain axioms, including the conservation property. However, its computational demand is high due to the need for exponential function evaluations for each subset of input features, making it impractical for models with many input dimensions.

2. **Gradient-based methods**: These leverage the gradient of the function to create a mapping of function values onto input dimensions. The integrated gradients method, for instance, attributes predictions by integrating the gradient along a path from a reference point to the data point. This approach requires significantly fewer evaluations (between ten and a hundred) and satisfies the conservation property, streamlining the explanation process by avoiding individual feature perturbations.

3. **Surrogate-based methods**: This approach involves creating a simple local surrogate model that approximates the function accurately, facilitating fast and clear explanations. For example, using a linear model allows for easy decomposition of outputs into contributions from input features. However, there are costs associated with training the surrogate model, and it is crucial to ensure that it reflects the same decision-making strategy as the original model.

Overall, the paper highlights the varying strengths and limitations of different attribution techniques in the context of XAI, emphasizing the importance of balancing computational efficiency with explanatory power.
