The paper discusses the approximation of the Gaussian kernel using random features, particularly in the context of a two-layer neural network architecture. The Gaussian kernel is defined as K(x,x') = ⟨Φ(x), Φ(x')⟩, and the inlierness score can be expressed in terms of the dataset mean. The authors introduce a random feature approximation for the Gaussian kernel, where features are sampled based on a specified distribution. This leads to a two-layer architecture where the first layer applies a cosine nonlinearity, and the second layer performs average pooling.

As the number of features, H, increases, the approximation of the true inlierness score becomes more accurate. The first layer acts as a detection layer, while the second layer aggregates the results. This neural network structure not only approximates kernel density estimation but also allows for feature-wise explanations of the computations involved. The paper emphasizes the interpretability of the inlierness computation, as contributions from individual features can be analyzed in the pooling operation.
