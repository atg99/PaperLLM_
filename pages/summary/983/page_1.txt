The paper presents Sta n z a, an open-source Python natural language processing (NLP) toolkit that supports 66 languages. It offers a fully neural, language-agnostic pipeline for text analysis, encompassing various tasks such as tokenization, multi-word token expansion, lemmatization, part-of-speech tagging, morphological feature tagging, dependency parsing, and named entity recognition. Sta n z a has been trained on 112 datasets, including Universal Dependencies treebanks, demonstrating strong performance across multiple languages.

Key advantages of Sta n z a include its ability to process raw text directly, without requiring prior tokenization or annotation, and its multilingual capabilities driven by a unified architecture. Additionally, it features a Python interface to Java's Stanford CoreNLP, extending its functionalities to tasks like coreference resolution and relation extraction. The toolkit aims to address limitations in existing NLP tools, such as restricted language support and under-optimization for accuracy. Source code and pretrained models are available online for users.
