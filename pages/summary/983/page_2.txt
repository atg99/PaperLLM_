The paper presents Sta n z a, a fully neural multilingual natural language processing (NLP) toolkit that supports 66 languages, leveraging training on Universal Dependencies treebanks and other multilingual corpora. It achieves state-of-the-art performance across 112 datasets, demonstrating adaptability to various text genres. Sta n z a offers a Python interface to the Java CoreNLP package, enabling access to features like coreference resolution and relation extraction. As an open-source tool, it provides pretrained models for all supported languages, aiming to advance multilingual NLP research and applications.

The system comprises two main components: a neural multilingual NLP pipeline and a Python client interface for CoreNLP. The neural pipeline includes models for tasks ranging from tokenization to syntactic analysis, designed to handle the complexities of multiple languages. A key innovation is the integration of tokenization and sentence segmentation into a single module, modeled as a tagging problem over character sequences. The pipeline also includes multi-word token expansion, utilizing both a frequency lexicon and a neural sequence-to-sequence model to ensure robust and flexible expansions.

Furthermore, Sta n z a employs a bidirectional long short-term memory network for part-of-speech and universal morphological feature tagging, ensuring consistency in processing. The paper highlights the modular design of Sta n z a, which allows for efficient reuse of model architectures while addressing the unique challenges presented by diverse languages.
