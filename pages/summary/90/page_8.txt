The paper discusses a constrained optimization approach for training a Long Short-Term Memory (LSTM) based anomaly detection algorithm using Support Vector Data Description (SVDD). The optimization procedure is iterative, involving the simultaneous update of LSTM parameters and dual SVDD parameters. Initially, a set of LSTM parameters is fixed, and the optimal dual parameters are found using the Sequential Minimal Optimization (SMO) algorithm. These parameters are then fixed to update the LSTM parameters, continuing this process until convergence is achieved. 

The paper also introduces a quadratic programming-based training algorithm, detailed in Algorithm 3, which iteratively updates parameters until a convergence criterion is met. The algorithm begins with initializing LSTM and dual SVDD parameters, followed by iterations that involve calculating optimal values and detecting anomalies.

In addition to the quadratic programming approach, a gradient-based training algorithm is proposed, which simplifies the optimization of the objective function by employing first-order gradients. The method modifies the objective function to accommodate the non-differentiable aspects of the original function, utilizing the Stochastic Gradient Descent (SGD) algorithm for parameter updates. The gradients for each parameter are computed, and updates are performed until local or global optima are reached.

Overall, the paper presents a comprehensive methodology for training LSTM-based anomaly detection models, combining both quadratic programming and gradient-based techniques to effectively handle optimization constraints.
