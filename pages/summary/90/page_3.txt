In this paper, the authors present a model for detecting anomalies in data sequences using a combination of Long Short-Term Memory (LSTM) networks and One-Class Support Vector Machine (OC-SVM) techniques. The model operates on data sequences represented as column vectors, where each sequence may vary in length. The primary goal is to develop a scoring function that can classify sequences as either normal or anomalous, with +1 indicating normal and -1 indicating anomalous.

The authors highlight an application in host-based intrusion detection, where the sequences represent system calls made by users or programs. The co-occurrence of these calls is essential for identifying anomalies. To achieve fixed-length representations of the variable-length sequences, the authors utilize an LSTM architecture, specifically the standard version without peephole connections. The LSTM processes each sequence and generates output vectors, which are then averaged using mean pooling to create fixed-length representations.

The paper also discusses the implementation of anomaly detection algorithms based on OC-SVM and Support Vector Data Description (SVDD). The OC-SVM aims to find a hyperplane that separates normal sequences from anomalies, while SVDD seeks to create a hypersphere that encloses normal data points. The authors propose joint optimization updates for training both the LSTM and SVM parameters, incorporating gradient-based training methods to enhance convergence to the desired solutions.

Overall, the methodology combines LSTM for sequence representation and OC-SVM for anomaly detection, providing a robust framework for identifying anomalies in variable-length data sequences.
