The paper discusses the Cross Stage Partial (CSP) architecture, which modifies the DenseNet approach by splitting the input feature map into two portions. One portion is processed through the dense block, while the other is sent directly to the next stage without processing. This design allows for repeated learning of gradient information across different dense layers. The CSP concept is integrated into the Darknet-53 architecture used in YOLOv3, where residual blocks are replaced with dense blocks. This integration helps maintain feature propagation, encourages feature reuse, and reduces the number of network parameters, thereby preserving fine-grained features for deeper layers. However, to avoid a decrease in detection speed due to an increase in densely connected layers, only the last convolutional block in the Darknet-53 backbone is converted into a dense block, which enhances the extraction of richer semantic features.
