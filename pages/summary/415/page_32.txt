The PAN architecture introduces a bottom-up augmentation path alongside the existing top-down path in the Feature Pyramid Network (FPN), creating a direct link between fine-grained features from lower layers and higher layers. This shortcut, comprising fewer than 10 layers, facilitates smoother information flow. While the backbone architecture appears similar to the FPN, it consists of numerous layers; the depicted layers represent only those concatenated to multi-scale detectors. 

The bottom-up path mirrors the top-down path of the FPN, with each stage generating feature maps of identical spatial dimensions. In the original PAN architecture, these feature maps are integrated with the lateral architecture using element-wise addition. However, in the modified PAN architecture for YOLOv4, concatenation is employed instead, ensuring that information from both FPN features and the bottom-up path is preserved.
