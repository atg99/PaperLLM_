The paper discusses modifications made to the Spatial Pyramid Pooling (SPP) block in the YOLOv2 algorithm, which has transitioned to a fully convolutional network (FCN) model. This change allows for input images of varying dimensions, eliminating the need to convert two-dimensional feature maps into a fixed-size one-dimensional vector. The new SPP block is positioned adjacent to the backbone of the network and incorporates a 1x1 convolution to reduce the number of input feature maps from 1024 to 512. 

The SPP block pools the input feature maps at different scales while using padding to maintain a constant output size. Consequently, three feature maps are produced, each retaining the dimensions of size_fmap × size_fmap × 512. Unlike the classical SPP block, which converts pooled feature maps into a one-dimensional vector, the modified SPP block concatenates these three pooled feature maps, thereby preserving their spatial dimensions. This approach enhances the model's ability to make accurate predictions and localizations based on the S×S grid cell framework.
