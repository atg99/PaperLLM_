The paper discusses the architecture of the YOLOv3 network, highlighting its advancements over previous versions, particularly YOLOv1 and YOLOv2. In YOLOv1, each grid cell was limited to predicting one object and shared a set of prediction probabilities for C classes. Conversely, YOLOv2 introduced the capability for a grid cell to predict multiple objects, allowing each predicted bounding box to have its own set of prediction probabilities. This innovation allows for greater flexibility and accuracy in object detection.

The output parameters of YOLOv3 are defined as S×S×(B×(5+C)), where S is the grid size, B is the number of bounding boxes per cell, and C is the number of classes. The first detection occurs at the 82nd layer of the network, with a default input image size of 416×416 pixels. After processing through the initial 81 layers, the image is downsampled to a 13×13 feature map, corresponding to 13×13 grid cells. Detection is performed by applying 1×1 detection kernels on these feature maps, with each kernel predicting B bounding boxes for each grid cell. YOLOv3 was trained on the COCO dataset, utilizing B=3 bounding boxes per cell and C=80 classes.
