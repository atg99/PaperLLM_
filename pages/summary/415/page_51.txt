The thesis aims to evaluate the performance of the YOLOv5 algorithm without incorporating additional algorithms or optimization methods. The YOLOv5 architecture is utilized to train on the COCO dataset, which includes 80 defined classes. For the wheat dataset, the number of classes will be adjusted accordingly. The anchor box parameters, which benefit from auto-learning integration, can be set to default values.

The training model is executed using a command line interface, specifically through the compile file train.py, which includes configurable arguments. One key argument is the input image size, where the original size of 1024x1024 pixels is compressed to enhance training speed. This approach is based on extensive experimentation.
