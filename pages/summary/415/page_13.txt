The loss function of YOLO is primarily based on the sum-squared error, which is critical for training stability. YOLO addresses the issue of grid cells without objects overwhelming the gradients by assigning higher penalties to bounding box predictions containing objects (λ_coord = 5) and lower penalties when no object is present (λ_noobj = 0.5). The overall loss function incorporates the loss from all bounding box parameters, including coordinates (x, y), width (w), height (h), confidence score, and class probability.

The loss function is expressed mathematically, with the first component focusing on the difference between predicted and actual bounding box positions based on coordinates. The indicator function l_ij_obj is 1 if an object is present in the j-th predicted bounding box of the i-th cell, and 0 otherwise. The bounding box responsible for predicting an object is determined by the highest Intersection over Union (IOU) with the ground truth.

The second component of the loss function evaluates the error in predicting bounding box dimensions, specifically width and height. To mitigate the effect of size discrepancies, the square root of these dimensions is used, which emphasizes errors in smaller boxes more significantly than in larger ones, as both width and height are normalized between 0 and 1. This approach helps maintain balance in the loss contributions across varying box sizes.
