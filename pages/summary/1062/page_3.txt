The paper discusses a proposed technique called TimeGAN, aimed at handling irregularly sampled time-series data more effectively than existing methods that rely solely on binary adversarial feedback. These existing approaches may not adequately capture the temporal dynamics inherent in the training data. TimeGAN incorporates stochasticity at each time step and utilizes an embedding network to create a lower-dimensional representation, allowing it to learn the stepwise distributions and latent dynamics of the data.

The authors start by formulating the problem in a setting where data instances consist of static features, which remain constant over time, and temporal features that change over time. They define a joint distribution for these features and aim to learn a density that approximates this distribution using training data. The complexity of this task is addressed by decomposing the joint distribution into a series of conditional distributions, allowing for a more manageable optimization process.

TimeGAN employs two objectives: a global objective that focuses on matching the joint distribution and a local objective that targets the conditional distributions at each time step. The global objective relies on the presence of an ideal discriminator in the GAN framework, while the local objective can be supervised using maximum-likelihood training with the original data. This dual-objective approach facilitates an effective training procedure that combines adversarial learning with supervised loss.

The proposed model consists of four components: an embedding function, a recovery function, a sequence generator, and a sequence discriminator. This architecture aims to leverage autoencoding techniques to enhance the generative capabilities of the model while ensuring that it can effectively learn from time-series data.
