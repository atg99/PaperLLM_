This paper discusses generation-based methods for semi-supervised learning (SSL) on graph data, focusing on two main sub-categories: feature generation and structure generation. These methods aim to reconstruct input data, utilizing the input itself as a supervisory signal. The origins of these methods can be traced back to Autoencoders, which compress data into low-dimensional representations and then attempt to reconstruct the original data.

Feature generation approaches focus on recovering feature information from perturbed or original graphs. The methods typically employ a masked feature regression strategy, inspired by image inpainting techniques from computer vision. For example, the Graph Completion method masks certain nodes by removing their features and then predicts these masked features using the features of neighboring nodes through a Graph Convolutional Network (GCN) encoder. Other methods like AttributeMask and AttrMasking aim to reconstruct dense feature matrices and both node and edge attributes, respectively.

On the other hand, structure generation approaches concentrate on recovering the topological structure of graphs, primarily by reconstructing the adjacency matrix. These methods formalize their objectives similarly, employing a decoder dedicated to structure reconstruction. The overall goal is to leverage the relationships between nodes to effectively recover either feature or structural information.

The paper emphasizes the importance of using reconstruction tasks as a means to improve SSL on graph data, highlighting the distinct methodologies and objectives of feature and structure generation approaches.
