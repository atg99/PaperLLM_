The paper discusses various graph augmentation techniques that enhance the performance of graph-based models. Five common types of augmentations are identified: Node Feature Masking (NFM), Node Feature Shuffle (NFS), Edge Modification (EM), Graph Diffusion (GD), and Subgraph Sampling (SS). 

Attributive augmentations focus on node attributes. NFM randomly masks certain features of nodes in a graph, either completely or partially. The operation is formalized using a masking matrix, which can be adaptively calculated based on node importance. NFS, on the other hand, involves shuffling the positions of node features within the feature matrix.

Topological augmentations target the graph's structural aspects, particularly the adjacency matrix. EM modifies the graph by randomly dropping and adding edges, using matrices generated through random masking. GD injects global topological information by connecting nodes to their indirectly connected neighbors, with formulations based on heat kernel and Personalized PageRank methods.

Hybrid augmentations combine both attributive and topological techniques, exemplified by SS, which samples a subset of nodes and their connections, akin to image cropping. Overall, these augmentation strategies aim to improve the robustness and representation of graph data in machine learning applications.
