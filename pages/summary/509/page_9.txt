This paper discusses various approaches in graph self-supervised learning (SSL), particularly focusing on decoder architecture and auxiliary property regression. It introduces a pair-wise node decoder that utilizes a mapping function to create pseudo labels based on the contextual relationships between nodes. The objective function is presented, emphasizing the minimization of a cross-entropy loss over a set of node pairs defined by pretext tasks. 

Several methodologies, such as S2GRL and PairwiseDistance, are examined, which predict distances between nodes or centrality scores. Auxiliary property regression methods are also explored, contrasting them with classification methods by focusing on predicting continuous numerical properties of graphs instead of discrete labels. Examples include NodeProperty, which predicts node degrees, and Distance2Cluster, which assesses distances to cluster centers.

The paper then transitions to contrast-based methods, emphasizing mutual information maximization. This section outlines how these methods leverage graph augmentations to improve model performance by creating diverse instances for learning. It categorizes graph augmentations into three types: attributive-based, topological-based, and hybrid approaches. 

Overall, the paper highlights the need for diverse methodologies in both classification and regression tasks, while suggesting future work could further explore continuous properties in graph SSL.
