In the context of robust Markov Decision Processes (MDPs), the goal is to maximize the worst-case return, defined as the minimum return across all models in the uncertainty set. The robust performance of a policy is given by the expression ρπ_U, which is maximized by the optimal robust policy π*_U. The robust value function vπ_U is defined similarly, representing the minimum value function across models in U.

To ensure efficient computation, the uncertainty set is assumed to be convex and rectangular, which allows for the determination of an optimal robust policy in polynomial time. The specific structure of the uncertainty set, particularly the (s, a)-rectangular form, ensures that the optimal policies are stationary, although they may be stochastic.

Both the robust value function and the optimal robust value function can be computed using a robust Bellman operator. This operator takes the minimum across the uncertainty set, providing a unique fixed point that can be found through robust value iteration. While this method guarantees convergence, the computational demands of evaluating the Bellman operator can be significant. 

To address this, the paper proposes using ball-constrained uncertainty sets that simplify the computation of robust Bellman updates, allowing for more tractable solutions in practical scenarios.
