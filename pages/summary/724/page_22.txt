The paper discusses the computation of Q-values given a robust value function approximation. It starts by establishing the relationship between the Q-value and the robust value function through the equation QπU(s, a) = RπU(s, a) + Σs' PπU(s'|s, a) vπU(s'). An approximation for the Q-value is introduced as Q(s, a) = R0(s, a) + γΣs' P0(s'|s, a) v(s') - ΩU(v, π).

The paper then derives an upper bound for the difference between the exact and approximated Q-values, showing that this difference is influenced by the approximation error ε1 of the robust value function and the properties of the variance function κ. Specifically, it is shown that ∥Q - QπU∥∞ ≤ O(S1q ε1), where S1q is a Lipschitz constant for the variance function.

Several lemmas are presented to support these findings. Lemma F.2 establishes that the variance function κp is Lipschitz, allowing for bounds on the differences between the variances of different value functions. Lemma F.3 states that QπUsap can be approximated to an ε tolerance with the same computational complexity as calculating the corresponding value function.

The complexity of computing the Q-value is addressed in the context of the overall computation effort, indicating that the complexity of calculating the Q-value with ε1 tolerance is Osa p(S−1 q ε1), which is manageable compared to other required computations. The paper concludes that approximating gradients using the defined Q-values and distributions has a complexity that is negligible relative to other computations involved.
