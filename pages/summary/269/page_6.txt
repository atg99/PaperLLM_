The paper discusses the outputs of the DigitCaps layer in a Capsule Network (CapsNet) during inference, focusing on how these outputs can classify input images. Ideally, a CapsNet should produce a single output capsule with a probability close to one for the ground truth (GT) class, while probabilities for other classes should approach zero. The outputs can be analyzed individually for each image or averaged by class.

Figures illustrate the output capsule probabilities for test images from the MNIST and CIFAR10 datasets. For MNIST, the network demonstrates effective training, yielding highly peaked probabilities for the correct digit classes. In contrast, CIFAR10 shows improved class separation with Max-Min normalization, although both normalization methods reveal multiple high peaks in output capsules, indicating difficulty in distinguishing between object classes. This challenge has been previously addressed by incorporating a "none-of-the-above" category in the routing Softmax, which is not present in the current network.

The analysis extends to the concept of capsules as "grandmother cells," assessing their tuning to recognized objects. Class-averaged output capsule probabilities for MNIST reveal that both Softmax and Max-Min normalizations maintain the network's ability to differentiate between digits effectively. However, the tuning curves for CIFAR10 suggest that certain object classes exhibit poorer discriminability compared to MNIST, reflecting in the accuracy results presented in the paper.
