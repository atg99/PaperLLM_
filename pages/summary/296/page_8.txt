The paper discusses a decoder output defined by the function yt=f2(st-1, yt-1, ct), where f2 is a recurrent neural network (RNN) tailored to specific tasks through additional layers, such as a linear layer for series prediction or a softmax layer for translation. The input to this function is formed by concatenating the previous output yt-1 with the context vector ct, which aggregates the hidden states of the input sequence weighted by alignment scores. The context vector is calculated as ct=Σ(ati*hi), where ati represents the attention weights derived from a scoring function that compares the current state st-1 with each hidden state hi.

The scoring function, as detailed, can utilize various alignment models, including feedforward networks and cosine similarity, to generate a matrix of alignment scores that enhances interpretability by indicating which input time-steps are most relevant for generating the output. This attention mechanism effectively transforms the traditional encoder-decoder model into a non-sequential framework, allowing the decoding process to be informed by the encoded states, thereby improving the model's performance and interpretability.
