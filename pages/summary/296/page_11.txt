The paper discusses the implementation of attention mechanisms in non-autonomous dynamical systems, where the current state is influenced by previous states and current inputs across multiple dimensions. It highlights a dual-stage attention architecture consisting of an encoder that focuses on input features and a decoder that emphasizes temporal attention.

The encoder processes an input sequence X, mapping it to a hidden state ht at each time step t. The relevant input features are selected adaptively, replacing the original input xt with a new representation ut, which is a weighted combination of the input features. The attention weights akt, calculated using a score function, determine the importance of each input feature at time t.
