The paper discusses a decoder with temporal attention, which is an extension of the attention decoder outlined in Section 3.2. The decoder's output is defined by the equation yt=f2(st−1, yt−1, ct), where f2 can be any recurrent neural network variant. The input to this decoder is a concatenation of the previous output yt−1 and the context vector ct. The context vector is computed as a weighted sum of the hidden states of the input sequence, determined by alignment scores. The weights for each state are calculated using a similarity function and a softmax application.

The paper highlights that this dual-stage attention mechanism demonstrates superior performance in time series prediction compared to classical models. It references studies that compare LSTMs with attention mechanisms, indicating that LSTMs augmented with attention yield better results for financial time series forecasting. Additionally, the use of a temporal attention layer enhances model interpretability, which is crucial for understanding deep learning models. The interpretability of attention weights is also discussed, suggesting they reflect the influence of input elements on predictions.

The paper further introduces memory networks, which facilitate the learning of long-term dependencies in sequential data through an external memory component. This approach allows the model to utilize not just the most recent states but also the entire list of states. An application of memory networks to complex systems is presented, utilizing a time series of historical data and current inputs as queries in the attention mechanism.
