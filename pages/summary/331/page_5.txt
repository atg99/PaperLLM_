The paper investigates whether Generative Pre-trained Transformers (GPT) can successfully complete assessments in higher education programming courses. It presents data from various coding tasks across multiple projects, detailing prompt and completion token lengths, maximum scores, first submission scores, attempts, and final scores.

The findings reveal that GPT's performance does not significantly differ between introductory and intermediate topics. Instead, the complexity of the coding tasks plays a crucial role in GPT's success. For instance, while it scored 49.5% on control flow tasks, it achieved 88.4% on object-oriented programming (OOP) activities, indicating that foundational concepts are easier for GPT to handle than more intricate coding nuances.

Notably, tasks that require precise output formatting, bug fixing, refactoring, or engagement with real-world data formats presented significant challenges for GPT. These difficulties align with the observed struggles in multiple-choice question (MCQ) exercises, suggesting that the depth of knowledge required for nuanced programming tasks is a critical factor in GPT's effectiveness.

Overall, the results highlight GPT's limitations in handling complex programming challenges while demonstrating reasonable capabilities in foundational programming concepts.
