The paper investigates the capability of Generative Pre-trained Transformers (GPT), specifically the text-davinci-003 model, to successfully pass assessments in higher education programming courses. The study focuses on two courses, PE1 and PE2, which employ a variety of assessments including multiple-choice questions (MCQs) and coding exercises. Data collected from these courses includes 297 questions, of which 179 contain code snippets, highlighting the emphasis on practical coding skills.

The experimental design involves using the OpenAI Python library to submit MCQs to the GPT model, with the performance evaluated against reference answers. The model is configured with specific parameters, such as a temperature setting of 0.0 for MCQs to ensure consistent outputs, while a higher temperature of 0.7 is used for coding tasks to allow for variability in responses.

Results indicate that the text-davinci-003 model is robust in handling both MCQs and coding assessments, demonstrating a comparable performance to the previously used Codex model. The study concludes that GPT models, particularly text-davinci-003, possess the potential to effectively tackle programming course assessments, suggesting implications for their integration into educational contexts.
