This survey paper discusses various methods for compressing deep learning models specifically tailored for text tasks. It presents a comprehensive comparison across different tasks, datasets, and methodologies, focusing on the balance between model size reduction and performance metrics such as perplexity, accuracy, and BLEU scores.

Key findings indicate that parameter sharing techniques, including shared reference vectors and k-means quantization, can significantly decrease model size while maintaining competitive accuracy. For instance, using shared reference vectors, a model can achieve the same perplexity as a traditional word-LSTM with only 1% of the trainable parameters. The survey also highlights various approaches like LightRNN, Slim Embeddings, and Quaternion Attention, applied to diverse tasks ranging from language modeling to machine reading comprehension.

The paper systematically categorizes results by task and dataset, illustrating the performance of different base models and compression methods. Overall, it emphasizes the importance of developing efficient models that preserve accuracy despite reduced complexity, which is crucial for deploying deep learning applications in resource-constrained environments.
