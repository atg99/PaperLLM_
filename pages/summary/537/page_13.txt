The appendix details a simulated dataset used in the research, consisting of time series data generated from three features influenced by hidden states. Each feature's behavior is depicted in Figure A.1, where shaded regions indicate the underlying states. A Hidden Markov Model (HMM) is employed to create latent states, with a 5% probability for state transitions and an 85% probability for remaining in the same state. The features are generated from different signal distributions, as outlined in Table 3. Features 1 and 2 are correlated, reflecting real-world clinical measurements like pulse and heart rate.

In State 1, correlated features are produced using a Gaussian Process (GP) with a periodic kernel, while Feature 3 is generated using a GP with a squared exponential kernel. The dataset also incorporates Non-Linear Auto-Regressive Moving Average (NARMA) time series models, with specific equations provided for the NARMA processes. A white Gaussian noise is added to each signal, resulting in a dataset comprising 500 instances, each with 2000 measurements.
