The paper discusses the implementation details of various baselines used for representation learning in time series data, emphasizing reproducibility and hyper-parameter tuning through cross-validation. 

For Contrastive Predictive Coding (CPC), a sequential signal is processed using an encoder, with a one-directional GRU cell utilized for autoregression. The model is trained for one-step ahead prediction, employing a linear transformation for density ratio estimation. 

The Triplet-Loss (T-Loss) baseline is based on the original code provided by the authors on GitHub. For KNN and K-means clustering, the tslearn library is employed, incorporating distance metrics like Dynamic Time Warping (DTW). Due to the computational demands of DTW, the signal frequency is down-sampled for waveform data.

In the TNC framework, the neighborhood range is defined using the Augmented-Dickey Fuller (ADF) test to determine the stationary region of signals. The range is adjusted from one window size to three, and the p-value from the ADF test helps establish the threshold for stationarity. The implementation of ADF, sourced from the stats model library, is noted to be unoptimized, impacting training speed.

Window size selection is crucial for performance across all methods, including TNC, CPC, and triplet loss. The authors suggest that the window size should effectively capture the underlying state without being too long. For example, a 7-second window is used for ECG signals, balancing stability and informational content. The paper includes performance results across varying window sizes, highlighting performance drops when the window size is either too small or too large.
