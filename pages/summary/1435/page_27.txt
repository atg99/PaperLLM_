Self-organizing maps (SOM), introduced by Teuvo Kohonen in 1982, are a type of artificial neural network that organizes input signals into a lower-dimensional feature space by clustering similar inputs. This unsupervised learning method does not require predefined outputs, but it necessitates a substantial amount of training data to function effectively. The training process involves calculating the similarity between input patterns and output layer neurons using Euclidean distance, followed by updating synaptic weights based on a specific formula that incorporates learning rate and a neighborhood function.

Research has demonstrated various applications of SOM, such as in vowel recognition combined with discrete wavelet transforms (WSOM), achieving 55% accuracy. Another study utilized SOM to convert variable-length feature vectors into fixed-length ones, ensuring compatibility with multi-layer perceptron classification models. Additionally, SOM was employed to identify twelve Hindi words spoken by five speakers, using a modified supervised version of SOM. This approach extracted features like intensity, pitch, MFCC, and LPC, with the intensity features yielding the highest accuracy of 98.17% and 98.54% for mean-SOM and median-SOM, respectively.

Radial basis functions (RBF) are another neural network structure that includes an input layer, hidden layer, and output layer, distinguished by the use of Gaussian functions in the hidden layer. RBF models aim to generate clusters based on input speech signal patterns, establishing relationships among these clusters through Gaussian functions. The output is derived from these relationships, facilitating effective modeling of input data.
