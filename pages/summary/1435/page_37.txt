The paper discusses various open-source speech recognition tools that are publicly available, highlighting their features, programming languages, and supported languages. 

Kaldi is an open-source toolkit developed in C++ that primarily supports English and utilizes deep neural networks for classification tasks. It allows for feature extraction using methods like MFCC and CMVN.

CMU Sphinx, developed in Java, supports multiple languages including English, French, Mandarin, Russian, and German. It employs MFCC for feature extraction and an HMM-based model for classification.

Julius is another open-source tool initially aimed at Japanese recognition, which has since been adapted for English. It is language-independent as long as appropriate acoustic and language models are provided.

The Hidden Markov Model Toolkit (HTK) is a portable toolkit designed for building and manipulating hidden Markov models, originally intended for speech recognition but applicable to other pattern recognition tasks.
