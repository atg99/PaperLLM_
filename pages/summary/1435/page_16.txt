The paper discusses the use of delta and delta-delta features in Mel-frequency cepstral coefficients (MFCC) for audio processing. The delta MFCC incorporates dynamic features, while the delta-delta MFCC includes acceleration features. This results in a feature vector that comprises three types of features: static features, delta features (the differences between static features of successive frames), and delta-delta features (the differences between successive dynamic features). Typically, an MFCC feature vector has thirty-nine dimensions, with thirteen for each feature type: static, dynamic, and acceleration. Additionally, a variation of the MFCC feature vector includes normalized log energy. The paper illustrates the MFCC process through a block diagram, detailing the steps from input sound wave to the final cepstral coefficients.
