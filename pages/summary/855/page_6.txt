The paper presents a framework for Federated Privacy-Preserving Deep Learning (FPPDL) using blockchain technology to enhance modularity, independence, and robustness. It introduces two types of blocks in the blockchain: init blocks and operation blocks. An init block is responsible for benchmarking the usefulness of each party's training data and includes init transactions that contain initial points, contributed samples, and public keys for future transaction authentication. A genesis block serves as the first init block, containing initial points and credibility values for participants based on their contributions.

Operation blocks consist of transactions for UPLOAD and DOWNLOAD operations. Each transaction is signed by the creator using their private key, ensuring authenticity. An UPLOAD operation indicates that a data owner has uploaded local model gradients, while a DOWNLOAD operation signifies a request for local model updates. Miners verify transactions and record them in operation blocks, ensuring that the requested gradients are encrypted and uploaded securely.

The framework employs a three-layer onion-style encryption scheme to protect the privacy of local model gradients. The first layer uses symmetric key-based homomorphic encryption, allowing parties to learn aggregated gradients without revealing individual data. The subsequent layers utilize standard hybrid encryption techniques to further secure the data while minimizing computational costs.

In this private blockchain, only the requester who pays can access plaintext data, while others can verify transactions without reading sensitive information. If a dispute arises, the uploader can reveal the plaintext as evidence, and dishonest requests may incur penalties.

The implementation of FPPDL is designed for a relatively stable set of participants, such as financial institutions, operating under horizontal federated learning. This context allows for the use of a permissioned blockchain, ensuring secure and efficient collaboration among participants. The paper details the structure of both init and operation blocks, emphasizing their role in maintaining consensus and facilitating transactions within the blockchain framework.
