The paper presents the architecture and functionality of the Auto-Keras system, which facilitates neural architecture search. The system consists of several key modules: the API, Searcher, Model Trainer, Graph, and Model Storage. The API serves as the interface for users, initiating searches for optimal neural architectures. The Searcher, utilizing a Bayesian Optimizer and Gaussian Process, generates new architectures on the CPU while the Model Trainer conducts training on GPUs. The Graph module processes computational graphs, and the Model Storage holds trained models, addressing the challenge of large neural network sizes.

A typical workflow involves the user requesting a search, where the API preprocesses data and engages the Searcher to create a new architecture. This architecture is built in RAM and then transferred to the GPU for training. Once trained, the model is stored, and performance feedback is provided back to the Searcher for optimization.

The API is designed with user convenience in mind, offering two levels: task-level for general users and search-level for advanced users who can specify neural network types. Enhancements include the ability to restore interrupted searches and export neural architectures as Keras models.

To optimize resource usage, the system employs CPU and GPU parallelism, allowing simultaneous architecture generation and training, thus reducing idle times. Additionally, a memory adaptation strategy is implemented to prevent GPU crashes due to memory overutilization, with an adjustable upper bound on neural architecture sizes based on memory estimates.

Overall, Auto-Keras provides a user-friendly interface and efficient computational strategies to facilitate deep learning model development.
