The paper discusses the implementation of a Grouping Block within a model called GroupViT, which focuses on segment token assignment and merging for improved visual representation. The Grouping Block utilizes hard assignment to form new segment tokens, leading to more effective grouping compared to soft assignment. This mechanism is akin to the Slot Attention method but operates under weaker text supervision.

To train GroupViT, the authors employ contrastive losses based on image-text pairs. The model consists of a dual-encoder architecture where GroupViT serves as the image encoder and a Transformer as the text encoder. The final image embedding is an average of output segment tokens, while the text embedding is derived from the last output token of the text encoder. The training goal is to optimize the similarity between matched image-text pairs while minimizing it for unmatched pairs.

The paper introduces a Multi-Label Image-Text Contrastive Loss, which enhances visual grouping by generating additional text labels through a "prompting engineering" approach. By extracting nouns from the original text and using sentence templates, the model creates multiple positive text pairs for each image, thus increasing the number of positive instances during training. This approach allows GroupViT to leverage a richer dataset for contrastive learning, ultimately improving its performance in visual grouping tasks.
