The paper presents a DenseNet algorithm for classifying PE binary files into correct matching classes. The process begins by transforming the binaries into two-dimensional grayscale images. The model is trained through several steps, including feature extraction, convolution operations across multiple Dense Conv blocks, and pooling layers to reduce dimensionality. 

The classification layer employs a fully connected softmax function to categorize the images into their respective classes, addressing multi-class classification challenges. The softmax function computes the probability distribution of each class based on input values, allowing the model to classify images effectively.

A significant challenge highlighted is the class imbalance present in malware datasets, such as Malimg and Microsoft BIG 2015, where certain classes dominate in sample size. Traditional methods like data augmentation and reweighting losses often prove ineffective in this context. Instead, the proposed model employs a class-balanced loss approach, using a weighting factor inversely proportional to the number of samples for each class. This method aims to improve classification performance on datasets with high class imbalance, ensuring that minority classes are adequately represented in the training process.
