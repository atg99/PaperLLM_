The paper discusses various malware datasets utilized in experiments to evaluate a proposed deep neural network model for malware classification. Key datasets include the BIG 2015 dataset, which contains 21,741 samples divided into a training set of 10,868 and a test set of 10,873, with each sample identified by a unique hash value and categorized into one of nine malware families. The MaleVis dataset consists of 14,226 RGB byte images across 26 families, while the Malicia dataset includes 9,670 samples classified into eight classes.

Experiments were conducted on a Linux system with specific hardware specifications, utilizing a deep learning framework with defined hyperparameters such as 100 epochs, a learning rate of 0.0001, and a batch size of 32. Different input image sizes were tested, revealing that reshaping images to 64 x 64 dimensions improved predictive accuracy.

Classification performance was evaluated using four metrics: True Positive (TP), True Negative (TN), False Positive (FP), and False Negative (FN). These metrics help assess the accuracy of the model in predicting malware classifications. The distribution of malware samples across different classes for all datasets is illustrated in a figure, highlighting the diversity and complexity of the data.
