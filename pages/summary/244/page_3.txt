The paper presents a novel method for classifying malware variants using a deep learning approach based on the DenseNet model, which is enhanced with a class-balanced loss function to improve the detection and classification of malware images without the need for binary execution or reverse engineering skills. The method leverages transfer learning from pretrained DenseNet models, which allow for efficient preprocessing and training of binary samples while reducing overfitting through dense connections.

Key contributions include: 

1. An effective malware detection system that utilizes raw binary images, eliminating the need for complex feature engineering.
2. The use of DenseNet, which enables feature concatenation and requires fewer parameters compared to traditional CNN models, thereby enhancing detection accuracy.
3. Addressing the data imbalance issue in malware classification by reweighting the categorical cross-entropy loss function.
4. Extensive evaluation on four malware datasets, demonstrating high accuracy rates of up to 98.46% and resilience against evolving malware and evasion tactics.

The paper is structured to include a literature survey, details of the proposed system, descriptions of the datasets used, experimental results, and a conclusion.
