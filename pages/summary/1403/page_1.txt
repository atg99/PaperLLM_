The paper presents FoveaBox, a novel framework for object detection that operates entirely without anchors, addressing limitations associated with traditional anchor-based methods. FoveaBox enhances detection accuracy and flexibility by directly predicting the likelihood of object presence and the corresponding bounding box coordinates. This is achieved through two main strategies: generating category-sensitive semantic maps that indicate object existence and producing category-agnostic bounding boxes for potential object locations. The framework effectively utilizes feature pyramid representations to associate target box scales with various feature levels.

The authors argue that the reliance on predefined anchors in existing object detection frameworks limits performance and generalization, as these anchors must be carefully designed based on dataset statistics, which may not transfer across different applications. FoveaBox circumvents these issues by eliminating anchor-related computations and hyper-parameters, which are often sensitive to model performance. The framework has demonstrated state-of-the-art results on standard benchmarks, including COCO and Pascal VOC, establishing it as a robust baseline for future research in object detection. The code for FoveaBox is publicly available, facilitating further exploration and development in this area.
