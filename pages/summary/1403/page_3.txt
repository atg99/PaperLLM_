The paper introduces FoveaBox, an anchor-free object detection framework that enhances prediction accuracy by directly predicting object boundaries from each foreground position, as opposed to traditional anchor-based methods that rely on predefined anchors. FoveaBox distinguishes itself by utilizing a backbone network for feature extraction and a fovea head network that includes two branches: one for per-pixel classification and another for box prediction.

The authors review existing methods, including RepPoints, FCOS, and CenterNet, highlighting their reliance on anchors or centers for detection. In contrast, FoveaBox simplifies the process by predicting class probabilities without the need for centerness voting or post-processing embedding techniques, making it more straightforward.

FoveaBox incorporates a Feature Pyramid Network (FPN) to create a feature pyramid that aids in detecting objects at various scales. Instead of placing anchors, it directly maps ground-truth boxes to a target feature pyramid and defines positive and negative samples based on these boxes. The model employs a shrunk positive area for training and uses binary masks for class probabilities.

Additionally, FoveaBox addresses scale variations by categorizing object sizes into bins corresponding to different pyramid levels, allowing for more stable boundary predictions. The authors assert that FoveaBox's design leads to improved robustness in object detection by eliminating the anchor dependency prevalent in traditional methods.
