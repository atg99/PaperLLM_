This section of the paper discusses the construction of a score object and the methods for structure learning and sampling in Bayesian networks using the BiDAG package in R. 

To create a score object, the `scoreparameters` function is utilized, which requires a dataset in the form of a data frame or matrix. The function's parameters define the scoring method applicable to different data types, including binary, categorical, continuous, or user-defined data. Additionally, options for incorporating prior information into the structure learning process are available, such as specifying root nodes or defining a graphical prior to influence edge sampling.

The subsequent functions, `learnBN` and `sampleBN`, are implemented for learning and sampling Bayesian networks. `learnBN` employs MCMC schemes to find a Maximum A Posteriori (MAP) Directed Acyclic Graph (DAG), while `sampleBN` samples DAGs from the posterior distribution using various MCMC strategies. Both functions return objects of specific classes depending on the chosen algorithm, facilitating different approaches to structure learning and sampling in Bayesian networks. 

Overall, this section emphasizes the importance of score parameters and MCMC techniques in effectively learning and sampling Bayesian network structures within the BiDAG framework.
