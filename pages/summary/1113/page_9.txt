The paper discusses the implementation of the sampleBN function in the BiDAG package for learning Directed Acyclic Graphs (DAGs) using Markov Chain Monte Carlo (MCMC) methods. It highlights key parameters that define the function's operation, including scorepar and algorithm, which are mandatory, while others are optional with default values. The parameters are categorized into those defining the search space, Markov chain properties, prior information inclusion, and output specifications.

The paper emphasizes the importance of selecting an adequate number of MCMC iterations for convergence, recommending values based on heuristic and simulation studies. Specifically, it suggests default iteration values of 6n²logn for order MCMC, 20n²logn for partition MCMC, and 3.5n²logn for iterative MCMC. The rationale behind these values is rooted in the necessity for sufficient iterations to discover a maximum DAG while also managing runtime.

To enhance efficiency, the algorithm employs a strategy where DAGs are sampled only every stepsave iterations, significantly reducing computation time without compromising convergence quality. The default setting allows for the sampling of 1001 DAGs, a technique referred to as thinning, which minimizes autocorrelation among samples. Overall, the paper provides insights into the flexible design of the sampleBN function, aiming to optimize DAG learning in various statistical applications.
