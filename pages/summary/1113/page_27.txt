The paper discusses the computational efficiency of the order MCMC scheme used in Bayesian network analysis, focusing on the runtime associated with MCMC iterations. By default, the number of iterations is set at 6n^2 log n for a network with n nodes. Each iteration involves calculating the score R(≺′|D), which, when implemented naively, results in exponential complexity, specifically O(nK+1), where K is the maximum number of parents allowed.

To improve efficiency, the authors employ pre-computed score tables based on the methods outlined by Kuipers et al. (2022). This optimization reduces the complexity from O(nKn^2 log n) to O(n^2 log n) by minimizing the impact of the number of MCMC iterations. Although the computation of these score tables remains exponential, it is independent of the iterations since it only needs to occur once.

Furthermore, using a search space H instead of a hard limit for K further decreases the complexity of score table computation to O(K^3 2^K) for order MCMC. For H+, the complexity increases to O(nK^3 2^K) for order MCMC and O(nK^2 3^K) for partition MCMC. When score tables are pre-computed, the overall complexity of the MCMC scheme becomes polynomial in n, enabling the algorithm to handle large networks with hundreds of nodes. However, the exponential nature of score table computations imposes a practical limit on K, as larger values can lead to prohibitive computation times.
