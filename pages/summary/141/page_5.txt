This paper discusses the development and assessment of a Variational Autoencoder (VAE) model using three distinct datasets. The first dataset consists of game maps from the popular tower-defense puzzle game Arknights, which was launched in 2019. The study aims to generate new game maps based on the 180 original maps extracted from the game's official site, providing valuable references for game designers, particularly for enhancing character motion and spatial features. The extraction process utilized Unity Hub, and an example of a game map is presented.

The second dataset is sourced from Konachan, an image board featuring over 60,000 anime and manga wallpapers. This dataset aims to contribute to the model's training by incorporating "humanistic" characters with motion, enhancing its applicability for image processing and data clustering tasks. An example of an anime avatar from this dataset is also provided. Overall, the study outlines the flow from dataset extraction to model optimization and statistical analysis, emphasizing the significance of these datasets in the context of game design and image processing.
