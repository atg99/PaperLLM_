The paper discusses the integration of Genetic Algorithm and Logistic Regression (GA-LR) by Khammassi and Krichen in 2017 for network intrusion detection. The GA optimizes the selection of features, which are then evaluated using Logistic Regression to describe the relationship between dependent and explanatory variables, effectively handling categorical data.

The paper then introduces the Embedded method of feature selection, which differs from pre-processing methods by selecting features during the learning process. This approach enhances computational efficiency and classification accuracy while avoiding the need to retrain the model each time a new feature is introduced. Unlike filter-based methods that do not utilize learning algorithms for feature selection, and wrapper methods that do, the Embedded method simultaneously conducts feature selection and model learning, significantly reducing computational costs.

Further, it highlights the Relevant Sample-Feature Machine (RSFM) algorithm proposed by Mohsenzadeh et al. in 2013, which is based on sparse Bayesian machine learning. RSFM, an extension of the Relevance Vector Machine, employs Gaussian priors and a kernel function for predictions. The subsequent development of the Variational RSFM (VRSFM) by Mirzaei, Mohsenzadeh, and Sheikhzadeh in 2017 builds on this Bayesian model, offering a feature selection method applicable to both classification and regression tasks. VRSFM uses Variational Bayesian approximation to determine hyper-parameters and posterior distributions and is particularly effective for small datasets.
