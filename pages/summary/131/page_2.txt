The paper presents a novel approach to addressing the challenge of long context processing in large language models (LLMs) through context compression, termed the In-context Autoencoder (ICAE). Unlike previous methods, which focused on enhancing performance with long contexts, the ICAE compresses information into fewer memory slots while maintaining response accuracy. 

The ICAE comprises two main components: a learnable encoder, adapted from an LLM using Low-Rank Adaptation (LoRA), and a fixed decoder, which is the LLM itself. This architecture allows the ICAE to encode lengthy contexts into compact memory representations. The authors pretrain the ICAE using autoencoding and language modeling objectives to improve the accuracy of context recovery and continuation. They subsequently fine-tune the model on instruction data to enhance its interaction with various prompts.

Experimental results demonstrate that ICAE can achieve up to 4× context compression, enabling LLMs to convey more information with reduced context lengths, thereby improving latency and memory efficiency during inference. The paper also discusses the implications of self-supervised learning in the pretraining phase, suggesting parallels between LLMs' memorization patterns and human memory encoding processes. This work not only contributes to efficient context management in LLMs but also opens avenues for further research in the relationship between cognitive science and representation learning in artificial intelligence.
