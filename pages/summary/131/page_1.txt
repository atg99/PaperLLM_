The paper introduces the In-context Autoencoder (ICAE), a novel approach that utilizes large language models (LLMs) to compress lengthy contexts into concise memory slots. These memory slots can be effectively conditioned by the LLM for various tasks. ICAE is initially pretrained on extensive text data using both autoencoding and language modeling objectives, which equips it to create memory slots that faithfully represent the original context. Following pretraining, it undergoes fine-tuning on instruction data to enhance its ability to generate appropriate responses to diverse prompts.

Experimental results indicate that ICAE, with only a 1% increase in parameters, achieves a remarkable 4-fold context compression when applied to the Llama model. This improvement leads to reduced latency and lower GPU memory consumption during inference. Additionally, the study provides insights into memorization and scalability, suggesting a significant link between cognitive science's working memory concepts and representation learning in LLMs.

The findings highlight ICAE's potential in addressing challenges associated with long context handling and underscore the need for further exploration into context management within LLMs. The data, code, and models are publicly available for further research.
