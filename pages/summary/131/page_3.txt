The paper presents the In-Context Autoencoder (ICAE), a novel architecture that consists of an encoder and a decoder, similar to traditional autoencoders. The ICAE incorporates in-context processing, utilizing a LoRA-adapted large language model (LLM) as its encoder. The encoding process involves appending a set of memory tokens to the original context, which are then transformed into memory slots. This lightweight approach enhances efficiency by only requiring a LoRA adapter and an embedding lookup for memory tokens.

The pretraining of ICAE includes two main objectives: autoencoding and text continuation. The autoencoding task aims to reconstruct the original input from the memory slots produced by the encoder, utilizing a special token to signal the task within the decoder. This method allows for the use of extensive text data without requiring additional annotations. To improve generalization, the model also incorporates a text continuation task, which is recognized for enhancing the learning of more versatile representations in language models. This dual-objective pretraining strategy is designed to optimize the performance of the ICAE in various applications.
