The paper discusses the application of the SegUnet model for building extraction using the Massachusetts building dataset. To manage computational limitations, the original dataset, which contains 10 test, 4 validation, and 137 training aerial images with dimensions of 1500x1500 pixels, is resized to 384x384 pixels. This results in a total of 1,564 images, including 1,532 for training, 24 for validation, and 8 for testing.

For model performance evaluation, four key metrics are employed: overall accuracy (OA), F1 score, recall, and precision, based on a confusion matrix. OA is defined as the ratio of correctly identified pixels to the total number of pixels. Precision measures the accuracy of identified building pixels as a percentage of all identified pixels, while recall indicates the percentage of correctly predicted building pixels among all actual building pixels. The F1 score integrates both recall and precision. Each metric is calculated using true positive (TP), true negative (TN), false positive (FP), and false negative (FN) values.
