The Segnet architecture is a deep convolutional model designed for pixel-wise classification. It comprises an encoder and decoder, each featuring 13 convolutional layers that correspond to the VGG16 network, which is utilized for feature classification. The architecture is structured such that each encoder layer has a corresponding decoder layer. The final output of the decoder is processed through a Softmax classifier, which generates independent classification probabilities for each pixel, ensuring the outputs are normalized to a range of 0 to 1 and sum to 1.

In the encoder, convolutional filters are applied to create feature maps, followed by ReLU activation functions and max-pooling layers with a kernel size of 2x2, resulting in down-sampling of the output. While max-pooling provides translation invariance to minor spatial changes, it can lead to a loss of spatial resolution in the feature maps. To mitigate this, boundary information is retained in the encoder feature maps before down-sampling.

In the decoder, the model utilizes stored sub-sampling indices from the encoder to up-sample the feature maps. This is done by applying trainable filters and performing batch normalization on the resulting dense feature maps. Unlike the U-Net model, which concatenates features from the encoder to the decoder, Segnet relies on these pooling indices while retaining the complete weights from the pre-trained model. This design allows for effective pixel-wise classification while managing resolution and feature retention throughout the network.
