The paper discusses a convolutional neural network (CNN) architecture designed for audio signal classification, specifically for environmental sound classification (ESC). The architecture incorporates spatially separable convolutions, which utilize different kernel sizes and numbers to effectively process audio features. The input features are structured as (t, f, c), where t represents compressed time, f indicates the number of features, and c denotes the number of feature extraction methods used.

The architecture employs 1×m kernels for feature domain processing and n×1 kernels for time domain aggregation, allowing the model to extract and combine diverse information from various feature sets. This approach not only enhances the network's ability to process audio signals but also significantly reduces the number of parameters compared to standard n×n kernels typically used in image processing.

An attention block is integrated into the architecture to achieve both spatial and channel-wise attention while minimizing parameter count through the use of depthwise convolutions. The attention mechanism normalizes the weights with batch normalization and applies a ReLU activation function, which promotes computational efficiency during matrix operations.

The model is tested on benchmark datasets including UrbanSound8K, ESC-10, and ESC-50, achieving state-of-the-art results. The datasets contain audio files of varying lengths and classes, and k-fold cross-validation is utilized to report average accuracy. The implementation leverages TensorFlow, Keras, and audio processing libraries, running on a high-performance NVIDIA DGX-2 hardware setup.

In summary, the proposed CNN architecture effectively combines separable convolutions and attention mechanisms to enhance audio signal classification while maintaining computational efficiency and reducing model complexity.
