This paper discusses advancements in environmental sound classification (ESC) models, particularly focusing on addressing complexities in existing attention-based systems. Previous models, such as those combining channel and temporal attention mechanisms, have been noted for their increased complexity and parameter count. The authors propose a new ESC model that simplifies this by employing a single depthwise convolutional layer for both spatial and channel attention.

The proposed model integrates multiple feature channels extracted from audio signals, utilizing techniques such as Mel-Frequency Cepstral Coefficients (MFCC), Gammatone Frequency Cepstral Coefficients (GFCC), Constant Q-transform (CQT), and Chromagram. These channels provide complementary information, enhancing the CNN's ability to classify audio effectively. The model architecture incorporates separable convolutions that process time and frequency domain features separately, allowing for more efficient feature aggregation.

The feature extraction process normalizes the data and leverages Principal Component Analysis (PCA) to visualize the distinct information provided by each feature channel. Despite some features, like Chromagram, showing limited contribution to classification performance, they collectively enrich the model's input.

The main block of the proposed Deep CNN architecture consists of multiple layers of convolution, max pooling, and batch normalization, designed to optimize performance for the ESC task. The overall goal of the paper is to achieve state-of-the-art performance while reducing computational complexity and improving feature extraction methods in audio classification tasks.
