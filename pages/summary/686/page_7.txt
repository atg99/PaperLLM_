The paper discusses CDPred, an attention-based neural network architecture designed for predicting inter-chain contact maps in protein dimers. CDPred utilizes the tertiary structures of monomers as input, extracting sequences and intra-chain distance maps. For homodimers, only one monomer's structure is used since both monomers share the same sequence.

The input features for CDPred consist of the monomer's tertiary structure represented as intra-chain distance maps, pairwise co-evolutionary features, and sequential amino acid conservation features. These features are organized into a multi-dimensional tensor. The architecture employs a series of deep residual network blocks enhanced with attention mechanisms to effectively process these inputs. 

The model includes a normalization block, channel attention squeeze-and-excitation blocks, and spatial attention blocks to optimize feature extraction. The output of the network classifies distances between residues into 42 bins, predicting two types of inter-chain residue-residue distances: the distance between the closest heavy atoms and the Cb-Cb distance.

The paper highlights the use of predicted tertiary structures from AlphaFold during testing, which presents a more challenging scenario but allows for a more objective evaluation of the model's performance. Overall, CDPred aims to accurately predict inter-chain contacts, thereby contributing to the understanding of protein interactions.
