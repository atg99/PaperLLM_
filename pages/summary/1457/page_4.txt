This paper discusses various natural language processing tasks that pose challenges for models like BERT, despite being relatively easy for humans. The tasks are categorized into question answering, entailment, word sense disambiguation, and coreference resolution. For a comprehensive understanding, readers are encouraged to refer to the SuperGLUE paper.

Key tasks include:

1. **CommitmentBank (CB)**: A three-class entailment task where models determine if an embedded clause is entailed by the text.
2. **Choice of Plausible Alternatives (COPA)**: A classification task requiring models to identify the cause or effect of a premise from two options.
3. **Winograd Schema Challenge (WSC)**: A commonsense reasoning task where models must identify the correct referent for a pronoun based on context.
4. **Recognizing Textual Entailment (RTE)**: A task focused on textual entailment relationships.
5. **Multi-Sentence Reading Comprehension (MultiRC)**: A multi-hop question answering task where models differentiate between true and false answers from paragraphs.
6. **Word-in-Context (WiC)**: A binary classification task for word sense disambiguation based on context.
7. **BoolQ**: A yes/no question answering task related to passages.
8. **Reading Comprehension with Commonsense Reasoning (ReCoRD)**: A multiple-choice QA task involving news articles and masked entities.
9. **CommonsenseQA and Cosmos QA**: Target tasks that are particularly challenging for high-performing models.

The paper also explores probing tasks, which investigate model capabilities in specific areas. These include Acceptability Judgment Tasks, which assess grammatical acceptability using datasets like AJ-CoLA, and Edge-Probing Tasks that focus on syntactic and semantic relations within sentences.

Overall, the document highlights the complexity of these NLP tasks and the limitations of current models in effectively addressing them.
