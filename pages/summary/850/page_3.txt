The paper introduces the FL-MR framework, which facilitates federated learning (FL) for magnetic resonance (MR) image reconstruction while preserving data privacy. The framework involves multiple rounds of communication between data centers and a central server to collaboratively train a global model parameterized by ΘqG. It builds on existing FL methods like FedProx and Agnostic Federated Learning, which aim to reduce learning bias in global models tailored for local entities. Previous works have explored medical image segmentation and domain shift issues in image classification within the FL context, but there remains a gap in applying these approaches specifically to MR image reconstruction.

The methodology proposed addresses MR image reconstruction by directly learning the mapping from under-sampled data to fully-sampled images. The reconstruction is mathematically formulated using the Fourier transform and its inverse, where the observed under-sampled image is represented as x, the fully-sampled image as y, and noise as ǫ. The framework utilizes data from K different institutions, each with its local dataset of under-sampled and fully-sampled image pairs. Each institution trains a local model by minimizing a specific reconstruction loss function, thereby contributing to the overall goal of estimating the fully-sampled image from the observed under-sampled data.
