Agglomerative Clustering and DBSCAN are two prominent clustering methods used in data analysis. Agglomerative Clustering is a hierarchical approach where the linkage criteria, referred to as 'linkage', defines how distances between clusters are calculated. Options include 'ward', 'complete', 'average', and 'single', each emphasizing different aspects of cluster distance. The primary hyper-parameter is 'n clusters', which indicates the desired number of clusters. However, if a 'distance threshold' is set for merging, 'n clusters' is determined automatically.

DBSCAN, a density-based clustering method, identifies clusters based on data density without requiring the number of clusters to be predefined. It utilizes two key hyper-parameters: 'eps', the scan radius, and 'min samples', the minimum number of neighboring points needed to form a cluster. The algorithm starts with an unvisited point, finds neighbors within 'eps', and forms a cluster if the neighbor count meets 'min samples', continuing recursively until all points are processed. A higher 'min samples' or a lower 'eps' increases the density required for cluster formation.

In addition to clustering methods, dimensionality reduction algorithms like Principal Component Analysis (PCA) and Linear Discriminant Analysis (LDA) are crucial for managing data complexity. These techniques help extract significant features while eliminating irrelevant or redundant ones. The main hyper-parameter for both PCA and LDA is 'n components', indicating the number of features to be retained. PCA specifically transforms the original n-dimensional features into k-dimensional principal components, aiming to capture the most variance in the data.
