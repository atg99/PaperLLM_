The paper discusses the complexities involved in hyper-parameter optimization (HPO) in machine learning (ML) models. It highlights that the hyper-parameter configuration space can include conditional hyper-parameters, which depend on the values of other hyper-parameters. An example is provided with support vector machines (SVM), where the polynomial kernel's degree is only relevant if the polynomial kernel type is selected.

In simpler scenarios, hyper-parameters can be treated as unrestricted real values, forming an n-dimensional vector space. However, in practice, hyper-parameters often come from various domains and have distinct constraints, leading to complex constrained optimization problems. Examples include restrictions on the number of features in decision trees and the number of clusters in k-means clustering, alongside categorical features that can assume only specific values.

The objective of HPO is to minimize a given function, for example, error rate or root mean squared error (RMSE), by finding the optimal hyper-parameter configuration within a defined search space. The paper states that model performance can be evaluated using several metrics, such as accuracy and F1-score. Additionally, it emphasizes the necessity of considering time constraints during HPO, as optimizing the objective function typically requires significant computational resources and time due to the need to retrain the entire ML model for each hyper-parameter configuration tested.
