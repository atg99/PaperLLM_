The input data for all models is derived from the last 20 hours of water level measurements, with S1 using two features and S2 and S3 utilizing five features that include meteorological data. The study aimed to analyze the performance of these models across different input data configurations and datasets.

The findings indicated that the input data size significantly impacted model performance, with sizes of 15 and 20 yielding the best results. The experiments compared three model types—multi-LSTM, multi-GRU, and LSTM-GRU—across three datasets, which included combinations of water level data and meteorological data from AWS and ASOS. Overall, the results demonstrate the effectiveness of integrating various data types in water level prediction models, highlighting the importance of input data size and model architecture in achieving optimal performance.
