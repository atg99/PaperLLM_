The paper details the parameters and performance of the Hybrid Self-Generation Optimization (HSGO) algorithm applied to COVID-19 detection from chest X-ray images. Key parameters of the HSGO algorithm include constant values N (number of persons) set to 5 and D (number of features) set to 10,000, along with a self-introspection factor c, which was optimized at 0.7 for balance between learning rate and stability. Random values r1 and r2 were set to 0.6 and 0.8, respectively.

The HSGO algorithm was tested on a dataset comprising 371 COVID-19 positive and 1341 non-COVID-19 chest X-ray images, utilizing five classifiers: KNN, Decision Tree (DT), Random Forest (RF), Linear Support Vector Classifier (L-SVC), and Support Vector Classifier (SVC). The SVC achieved the highest accuracy of 99.65%, which was corroborated by its F1-score. The study also examined the impact of dataset size on accuracy, confirming that the best results were obtained with the complete dataset.

Comparative analysis with other optimization algorithms (SGO, KPCA, PCA) indicated that HSGO outperformed these methods on the same dataset, achieving the highest accuracy. The classifiers were fine-tuned using hyperparameter tuning through a Grid Search algorithm, ensuring optimal performance metrics. Overall, the results emphasize the effectiveness of the HSGO algorithm in enhancing the accuracy of COVID-19 detection from chest X-rays.
