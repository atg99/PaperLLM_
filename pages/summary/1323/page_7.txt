The paper discusses the implementation of an algorithm for feature selection in the context of analyzing lung chest X-ray (CXR) images, specifically targeting the COVID-19 Radiography Database. The algorithm utilizes an initialization function that creates a random array of integers to represent a population of potential solutions, with dimensions based on the number of individuals and the total number of extracted features. The integer values range from 0 to 9 to ensure sufficient randomness while maintaining traceability in the learning steps.

The fitness function evaluates the classifier's performance on the selected feature subsets, assigning fitness values to each individual in the population after every generation. This function is crucial for determining the effectiveness of the feature subsets in improving accuracy.

During the mutation phase, the algorithm introduces new individuals with distinct traits to foster diversity within the population. Each generation produces a subset of the dataset by selecting columns where the corresponding feature value exceeds a specified threshold, initially set at 5 but later adjusted to 3 to enhance variety.

The algorithm effectively filtered out 98.84% of insignificant features, ultimately selecting 116 features from an original set of 10,000. This selection process is accompanied by a comparison of various feature selection methods, showcasing the accuracy achieved with the chosen feature subset and classifiers.

The implementation details and parameters of the HSGO algorithm are outlined, along with the dataset specifications, emphasizing its application in enhancing the accuracy of classifiers while minimizing computational costs.
