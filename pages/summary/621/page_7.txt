The paper discusses the architecture and functionality of a recurrent neural network (RNN) designed for predicting the conversion of individuals with mild cognitive impairment (MCI) to Alzheimer's disease (AD). The RNN utilizes weight matrices to extract task-specific features from both the previous memory state and current input, with the memory states and inputs represented as Euclidean vectors. The dynamics of the RNN are governed by a series of matrix-vector multiplications and the application of non-linear activation functions, specifically the tanh function, which enhances the network's representational power.

The predicted output, denoted as ˆyt, is derived using the softmax function, converting the network's output into a probability vector, which is essential for classification tasks. The model employs the cross-entropy loss function to assess the accuracy of predictions against ground truth labels, optimizing the parameters through Backpropagation Through Time (BPTT).

A significant challenge in training RNNs arises from the long-term dependency problem, particularly when processing lengthy input sequences. To address this, the paper introduces variants such as Long Short-Term Memory (LSTM) and Gated Recurrent Unit (GRU) networks. The proposed model specifically uses GRUs to handle multi-modal data—including cognitive performance, cerebrospinal fluid (CSF), MRI biomarkers, and demographic information—to predict MCI conversion to AD.

The model consists of two training phases: first, separate GRUs are trained for each data modality to predict AD conversion from MCI; second, the outputs from these GRUs are integrated into a single feature representation for final prediction. The integration method chosen is concatenation, allowing for the combination of various data sources into a cohesive representation. Overall, the study emphasizes the effectiveness of GRU networks in managing sequential data for clinical predictions.
