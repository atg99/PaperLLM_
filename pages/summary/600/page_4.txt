The paper introduces a novel framework for partial domain adaptation, addressing challenges faced in scenarios where the source class labels significantly overlap but are not fully shared with the target domain. The proposed method employs a two-player minimax game involving a domain discriminator and a feature extractor to learn transferable features. The domain discriminator aims to differentiate between source and target domain features, while the feature extractor is trained to minimize this distinction.

A key aspect of the framework is the introduction of a transferability weighting mechanism, which assigns a weight to each source example based on its transferability. This allows for an adaptive contribution of each example to the model, enhancing the impact of relevant examples and reducing the influence of irrelevant ones. The paper builds on previous work, notably IWAN, by incorporating these weights not just into the domain discriminator's loss but also into the source classifier's loss.

Additionally, the framework utilizes semi-supervised learning through entropy minimization to address the uncertainty stemming from unlabeled target examples. This dual approach aims to effectively manage the performance degradation typically observed in partial domain adaptation due to outlier classes in the source domain.

The overall objective integrates the weighted losses from the source classifier and domain discriminator along with the entropy loss, facilitating an end-to-end trainable system. The paper demonstrates that this approach significantly improves the model's performance in partial domain adaptation settings.
