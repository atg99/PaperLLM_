The paper discusses recent advancements in deep learning and domain adaptation, particularly focusing on Partial Domain Adaptation (PDA) where the source and target domains have different label spaces. Traditional domain adaptation methods assume that both domains share the same labels, which is not the case in PDA. The paper highlights three notable approaches to PDA: Selective Adversarial Network (SAN), Partial Adversarial Domain Adaptation, and Importance Weighted Adversarial Nets (IWAN). Each of these methods aims to mitigate negative transfer from outlier classes while enhancing positive transfer among shared classes.

Despite these advancements, existing methods still face challenges, such as the source classifier being trained on all classes, which can distract performance on shared classes. The paper introduces the Example Transfer Network (ETN), which seeks to down-weight irrelevant examples from outlier classes on the source classifier and employs a discriminative domain discriminator to assess example transferability.

Furthermore, the paper distinguishes its work from Open Set Domain Adaptation (OSDA), which deals with unknown classes during training. In contrast, the proposed approach addresses scenarios in PDA where the target classes are entirely unknown at the training stage.

The ETN's goal is to learn a deep network that effectively closes the distribution gap between source and target domains while minimizing negative transfer effects. By focusing on the transferability of examples and reducing distribution shifts, the proposed framework aims to improve classification performance in partial domain adaptation tasks.
