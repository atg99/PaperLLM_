The paper discusses the original YOLO (You Only Look Once) architecture, specifically YOLO-v1, which introduced a novel approach to object detection by overlaying a grid onto an image. Each grid cell is responsible for detecting objects whose centers fall within it, allowing for efficient detection even in cases of multiple objects. Each cell predicts multiple bounding boxes, each characterized by a confidence score that indicates the likelihood of an object being present, calculated through the product of the object's probability and the intersection-over-union (IoU) with the ground truth.

The bounding box predictions consist of five components: center coordinates (x, y), width, height, and the confidence score. The architecture divides the input image into a default grid of 7x7 cells, with each cell predicting B bounding boxes. The total output parameters are expressed mathematically, demonstrating the model's capability to handle multiple classes.

To manage overlapping bounding boxes, YOLO employs non-maximum suppression (NMS) to eliminate boxes with a low IoU, ensuring only the most accurate predictions remain. YOLO-v1 is built on the Darknet framework, featuring two sub-variants: a standard architecture with 24 convolutional layers and a 'Fast YOLO' variant with nine layers. The latter uses 1x1 convolutions to optimize feature space.

The loss function in YOLO-v1 is designed to penalize errors in bounding box predictions, with a higher penalty for boxes containing objects compared to those without. This approach, alongside the computation of prediction errors for width and height, ensures that the model effectively learns to detect and localize objects. Overall, YOLO-v1 represents a significant advancement in real-time object detection, combining speed and accuracy in a unified framework.
