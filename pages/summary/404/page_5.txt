The paper discusses the architecture and functioning of the YOLO (You Only Look Once) network, particularly its initial version, YOLO-v1. The input image is divided into a grid of s × s cells, each predicting B bounding boxes with five parameters and class prediction probabilities. The output parameters are represented mathematically as s × s × (5*B + C), where C represents the number of classes. For the example of YOLO with two bounding boxes per cell and 80 classes from the COCO dataset, the output becomes 7 × 7 × (5*2 + 80).

The primary objective of YOLO is object detection and localization using bounding boxes. It requires two bounding box vectors: one for ground truth and another for predictions. To handle the challenge of multiple bounding boxes predicting the same object or no object at all, YOLO employs non-maximum suppression (NMS). This technique removes overlapping boxes based on a defined Intersection over Union (IoU) threshold.

The original YOLO framework consists of two variants: one with 24 convolutional layers and another, 'Fast YOLO', with only nine layers and fewer filters. The architecture also incorporates 1 × 1 convolutional layers inspired by GoogleNet’s inception module to reduce the feature space.

To improve accuracy, the authors introduced a penalty system within the loss function, heavily penalizing bounding boxes predicting objects (gcoord = 5) while applying a lighter penalty for boxes predicting no objects (gnoobj = 0.5). The loss function aggregates various parameters such as coordinates, width, height, confidence scores, and class probabilities. The loss from bounding box predictions is calculated relative to the ground truth coordinates, and the chosen bounding box is the one with the highest IoU.

Further, the prediction error for width and height is computed similarly, but the error for larger boxes is weighted less than for smaller ones. Normalization ensures that smaller differences in width and height are amplified, enhancing the model's sensitivity to smaller objects. The confidence score loss is calculated based on the presence or absence of objects within the bounding boxes, with penalties applied only when the predictor is responsible for the ground truth object.
