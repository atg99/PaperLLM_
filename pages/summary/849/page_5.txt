The paper discusses the architecture and training pipeline for a vehicular edge network, specifically focusing on Federated Learning for Connected Autonomous Vehicles (FLCA V). It distinguishes between cloud servers and road (edge) servers, with cloud servers handling long-term tasks such as dataset annotation and DNN training, while edge servers manage real-time tasks like processing sensor data. To ensure security, vehicles must register with unique identifiers.

The training pipeline consists of three stages: cloud pretraining, edge federated learning (FL), and cloud FL. Initially, cloud pretraining utilizes annotated datasets to create pretrained DNNs. When a false detection occurs, a request triggers edge FL, allowing knowledge exchange among vehicles and roadside infrastructure. This is followed by cloud FL, which aggregates edge DNNs from various regions to enhance robustness through personalization.

The paper also addresses resource optimization for perception tasks, emphasizing the need for efficient communication and task generation. It outlines the process of task generation through operational design domain specification, scenario sampling, task creation, and evaluation. A multi-modal resource allocation strategy is proposed to allocate resources based on the complexity of perception tasks, particularly favoring deeper neural networks that require more communication resources.

Overall, the paper presents a comprehensive framework for training and optimizing perception systems in connected autonomous vehicles, highlighting the interplay between edge and cloud computing in enhancing vehicular intelligence and safety.
