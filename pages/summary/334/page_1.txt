This paper introduces the use of the Generative Pre-trained Transformer (GPT-2) for the generation of JavaScript code fixes.

The authors, Márk Lajkó, Viktor Csuvik, and László Vidács, highlight that the Generate and Validate (G&V) approach has gained popularity in APR, where tools create patches that are validated against predefined oracles, such as test suites. However, the strict acceptance criteria for patches—requiring them to match human-generated solutions—pose significant challenges. The recent advancements in NLP, particularly with models capable of generating coherent text, have inspired similar developments in code generation.

In their research, the authors fine-tuned the GPT-2 model on a dataset comprising 16,863 JavaScript code snippets to enable it to automatically fix JavaScript bugs. The findings indicate that while the model could consistently produce syntactically correct code, it struggled in some cases to generate effective bug fixes. Nevertheless, it achieved an overall accuracy of up to 17.25% in generating correct solutions.

The study underscores the potential of leveraging pre-trained language models in the realm of software engineering, particularly in improving the efficacy of automated bug-fixing tools. The authors conclude that while promising, further research is needed to enhance the model's ability to generate accurate and effective code repairs.
