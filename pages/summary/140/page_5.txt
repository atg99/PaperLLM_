The paper outlines a method for generating directed acyclic graphs (DAGs) using a deep variational autoencoder (D-VAE). The generation process involves two main phases: encoding and decoding. In the encoding phase, the model aggregates information from existing nodes to determine the hidden states, which represent the current state of the graph. Specific modifications are made for different types of graphs such as neural architectures and Bayesian networks, as detailed in the appendices.

During the decoding phase, the D-VAE constructs the DAG node by node using an asynchronous message passing scheme. The model first computes the type distribution for the new node and samples its type. If the type is an ending type, the generation stops; otherwise, the process continues. The hidden states of both the new and existing nodes are updated dynamically, ensuring that the model uses the most current information for predictions. The method emphasizes that edges are directed towards new nodes, maintaining acyclicity in the generated graphs.

The training process employs teacher forcing to enhance the model's learning by guiding it to generate the correct node types and edges based on the input DAG's structure. This approach allows for an effective optimization of the variational autoencoder loss function using mini-batch gradient descent.

Overall, the proposed D-VAE framework demonstrates a flexible and computation-aware approach to generating complex DAGs, suitable for various applications in neural architecture design and beyond.
