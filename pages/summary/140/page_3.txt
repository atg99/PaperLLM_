This paper discusses the learning of Bayesian network structures from observed data, a process known as Bayesian network structure learning (BNSL). BNSL aims to identify the underlying structure of a Bayesian network, which is a probabilistic graphical model that captures conditional dependencies among variables using a directed acyclic graph (DAG). The predominant method for BNSL is score-based search, where a "goodness-of-fit" score, such as BIC or BDeu, is defined to evaluate network structures. However, due to the NP-hard nature of the problem, exact algorithms are limited to small-scale issues, leading researchers to use heuristic methods like local search and simulated annealing.

The paper introduces a novel approach called the DAG variational autoencoder (D-VAE), which employs an asynchronous message passing scheme for encoding and decoding DAGs. Unlike traditional graph neural networks (GNNs) that use simultaneous message passing, D-VAE focuses on computing encodings based on the structure of computations represented as DAGs. Each computation consists of a series of elementary operations applied to an input signal, with directed edges indicating the flow of signals.

The encoding process in D-VAE begins with an encoder that utilizes GNN principles. It assumes a single starting node without predecessors and employs an update function to compute the hidden state of each node based on incoming messages from its predecessors. The hidden state is influenced by an aggregation function that combines the hidden states of the node's predecessors. This asynchronous approach ensures that message passing for a node occurs only after all its predecessors' states have been computed, effectively mirroring the actual execution of computations.

Overall, the paper presents a significant advancement in the field of BNSL and neural architecture learning through the introduction of D-VAE, highlighting its potential to improve the efficiency and effectiveness of learning complex models.
