The paper discusses the adaptation process of Self-Organizing Maps (SOM), which updates the weight values of neurons to generate a feature map from input variables. It outlines four main properties of SOM: 

1. **Approximation of the Input Space**: The feature map, represented by weight vectors, effectively estimates the input space.
2. **Topological Ordering**: The algorithm produces a feature map where neuron positions correspond to specific input data features, maintaining spatial relationships.
3. **Density Matching**: The feature map reflects the input distribution's statistical regions, with high probability samples mapped to larger output domains, ensuring higher resolution in significant areas.
4. **Feature Selection**: SOM identifies optimal features to represent the underlying distribution of data, particularly in non-linear contexts.

The paper also includes algorithmic steps of the SOM, illustrated in figures accompanying the text.
