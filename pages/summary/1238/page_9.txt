This paper discusses a method for regularizing a rank-deficient data matrix, denoted as H, by adding a small positive number multiplied by an identity matrix to it. This approach is particularly useful in the context of decision tree growth, where an axis-parallel split regularization technique is employed if the data matrix is rank-deficient at a specific node. The method utilizes heterogeneous test functions for decision tree expansion, initially applying MPSVM to generate optimal splits before transitioning to axis-parallel techniques.

To address sampling issues, the authors reference a Null space approach proposed by Manwani and Sastry, which is incorporated into the MPDRaF-N framework for matrix regularization. The paper also outlines the training phase of the Oblique Double Random Forest with MPSVM, detailing the process of generating decision trees using a training set and random feature subsets. During this phase, bootstrap sampling and feature selection are employed, and MPSVM is utilized for optimal data splits at each node until certain stopping criteria are met, such as achieving node purity or reaching a specified minimum number of samples.

Additionally, the authors propose a rotation-based double random forest ensemble model that enhances diversity among learners by applying transformations to random feature subspaces. This method aims to improve generalization performance by creating varied projections of the data at each non-leaf node. The classification phase involves using the ensemble of decision trees to predict labels for test samples, with the final class determined by majority voting among the trees.
