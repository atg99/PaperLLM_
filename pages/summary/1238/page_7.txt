The paper presents Algorithm 3, titled Double Random Forest, which outlines a method for training and classifying using an ensemble of decision trees. 

**Training Phase:**
The algorithm begins with a training dataset D consisting of N data points with feature size n. Each node i in the decision trees contains a subset of samples Di. The target labels are represented by Y, and the algorithm employs L base learners. Key parameters include "mtry," which defines the number of candidate features evaluated at each non-leaf node, and "nodesize" or "minleaf," which sets the maximum number of samples allowed in an impure node.

For each decision tree Ti (where i ranges from 1 to L), the training data D is utilized to generate a tree using a randomly selected subset of features and a bootstrapped sample of the dataset. The steps for constructing the tree at a node d include:

1. If the number of samples Nd is greater than N multiplied by 0.1, a bootstrap sample D*d is generated from Dd. If not, D*d is set to Dd.
2. The parameter "mtry" is defined as the square root of the number of features, and the best split feature and cutpoint are selected from the random feature subset D*d.
3. The dataset Dd is split into child nodes based on the optimal split feature and cutpoint.

These steps are repeated until one of the following conditions is met:
- The node reaches a pure form.
- The number of samples at the node is less than or equal to minleaf.

**Classification Phase:**
For classifying a test data point xi, the decision trees in the forest are employed to predict the label for the test sample. The final predicted class is determined through majority voting among the decision trees in the ensemble.

This concise approach effectively combines randomness in feature selection and data sampling, enhancing the robustness and accuracy of the model.
