This paper evaluates the performance of CURL in both sequential and continuous learning settings across benchmark datasets MNIST and Omniglot. The results, presented in Table 2, indicate that continuous learning with CURL generally outperforms sequential learning, particularly when using dynamic snapshots. The analysis reveals that in a continuous drift scenario, where classes are gradually introduced, the model demonstrates smoother adaptation compared to the sharp transitions observed in the sequential setting.

Additionally, the paper discusses the mixture component dynamics throughout the training process, highlighting the differences in response to class changes. In the sequential setting, component probabilities shift abruptly, while in the continuous drift setting, these probabilities change more gradually, resulting in a more stable learning process.

Furthermore, the paper extends the evaluation to supervised continual learning on the Split MNIST benchmark. The results in Table 3 show that CURL can be effectively adapted to supervised tasks, achieving competitive performance in both incremental task and class learning scenarios. While CURL performs well, it is noted that it is outperformed in incremental class learning only by iCARL, which is specifically designed for that purpose. This suggests that CURL's holistic approach, integrating generative processes and classifiers, maintains effectiveness even in supervised contexts. Overall, the findings emphasize the advantages of continuous learning frameworks in handling poorly defined task boundaries and adapting to gradual changes in data distributions.
