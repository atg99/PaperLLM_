2. Activation Layer: Following the convolutional layer, the activation layer introduces non-linearity into the model. This is crucial as it enables the network to learn complex patterns. Common activation functions include ReLU (Rectified Linear Unit), which replaces negative values with zero, and Sigmoid, which maps input values to a range between 0 and 1.

3. Pooling Layer: The pooling layer is responsible for down-sampling the feature maps, reducing their dimensionality while retaining important information. This is typically achieved through operations like max pooling, which selects the maximum value from a defined window, thereby simplifying the representation and reducing computational load.

4. Fully Connected Layer: At the end of the CNN architecture, the fully connected layer connects every neuron from the previous layer to every neuron in the current layer. This layer is often used for classification tasks, where the network outputs a probability distribution over different classes.

In summary, the architecture of a Convolutional Neural Network (CNN) comprises multiple layers, each serving distinct functions that contribute to the network's ability to process and learn from large-scale data efficiently. The convolutional layer is fundamental, employing kernels to extract features from input images, while activation, pooling, and fully connected layers further enhance the model's learning capabilities. Understanding these components is essential for leveraging CNNs in practical applications.
