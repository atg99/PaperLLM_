The paper discusses a proposed densely connected network designed for feature extraction in sensor applications. Each layer in the network is interconnected, allowing it to receive feature maps from all preceding layers, as expressed in Equation (2). The architecture incorporates the concept of residual units, utilizing a CBL module composed of convolution, Batch Normalization, and Leaky-ReLU activations. These CBL modules are combined into a Double-CBL (DCBL) module for improved performance.

The DCBL module serves as a transport layer, featuring specific configurations of convolutional layers that incrementally increase feature maps. To optimize the network, the authors limit the number of layers in DenseNet to four per module to prevent redundancy and improve detection speed. The first dense module increases feature maps by 64, while the second adds 128.

The proposed network also aims to reduce reliance on residual units by substituting some lower resolution layers with the improved dense connections.
