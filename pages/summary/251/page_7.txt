The paper presents a feature extraction network designed for multi-scale detection in remote sensing images. The network architecture consists of several convolutional layers with varying filter sizes, progressively reducing the spatial dimensions while increasing the depth of feature maps. The output feature maps from the three detection layers are sized 13x13, 26x26, and 52x52, allowing for the detection of large and small targets, respectively.

To improve detection performance, particularly for small targets prevalent in remote sensing images, the authors introduce an additional detection scale of 104x104. This fourth scale enhances the network's ability to identify smaller objects by providing a finer grid over the input image. Additionally, the authors address the issue of gradient fading by substituting five convolutional layers with three residual units in front of each detection layer, which helps maintain gradient flow during training.

Overall, the proposed algorithm aims to optimize the detection of small targets in remote sensing applications by utilizing multiple detection scales and a robust network structure.
