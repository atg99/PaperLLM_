The paper discusses advancements in the YOLO (You Only Look Once) object detection models, specifically focusing on YOLO v3, v4, and the latest YOLO v5. YOLO v3 employs a Feature Pyramid Network (FPN) for feature extraction, while YOLO v4 introduces a Spatial Attention Module (SAM) and a Path Aggregation Network (PAN), eliminating max and average pooling. YOLO v5, developed by Jocher et al., is notable for its PyTorch implementation and the use of Cross-stage Partial Networks (CSP) in both the backbone and neck, enhancing model speed and efficiency.

The architecture of YOLO v5 is structured into three main components: the backbone for feature extraction, the neck for feature map creation, and the output for object detection. YOLO v5 supports two types of CSP, with the backbone containing residual units and the neck utilizing CBL modules (Convolutional, Batch Normalization, Leaky ReLU). The Spatial Pyramid Pooling (SPP) layer is also integrated to aggregate features effectively. The model variants—YOLO v5s, v5m, v5l, and v5x—are created by adjusting the width and depth of the architecture.

Additionally, the paper highlights the development of smaller YOLO models, such as Tiny versions of YOLO v3 and v4, optimizing their network size and layer count. The study utilizes the MS COCO dataset, which comprises 1.5 million object instances across 80 categories, specifically focusing on the person category for detection tasks.

The proposed approach aims to estimate the area of a specified region within a video, addressing the challenge of converting pixel measurements to actual square meters, as pixel size can be influenced by factors like image resolution and camera angle. The paper presents a formula for area calculation in pixels and emphasizes the need for accurate conversions to represent real-world dimensions effectively.
