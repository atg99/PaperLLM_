The paper presents the architecture of the MT-DNN model designed for representation learning in natural language processing tasks. The model features a shared lower layer for all tasks and task-specific upper layers. The process begins with input sentences represented as embedding vectors in the lexicon encoder (l1), which maps the input sequence into token embeddings. The first token is always a [CLS] token, and if a sentence pair is provided, they are separated by a [SEP] token.

The next stage involves a multi-layer bidirectional Transformer encoder (l2) that transforms the input embeddings into a sequence of contextual embeddings, creating a shared semantic representation across tasks. Unlike the BERT model, which relies solely on pre-training, MT-DNN incorporates multi-task objectives for representation learning.

The paper elaborates on task-specific layers using examples from the General Language Understanding Evaluation (GLUE) benchmark. For single-sentence classification tasks, such as SST-2, the model predicts sentiment using a logistic regression with softmax applied to the contextual embedding of the [CLS] token. Similarly, for text similarity tasks like STS-B, a parameter vector computes the similarity score based on the contextual embedding of the input sentence pair.

Overall, the MT-DNN model effectively combines shared and task-specific components to enhance performance across various natural language processing tasks.
