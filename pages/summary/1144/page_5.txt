The paper discusses the implementation of a Fuzzy Logic System (FLS) for wall-following behavior in mobile robots. It emphasizes the importance of ensuring safety by considering the closest distance within the frontal region, defined as df, which is the minimum of fd0 and d1. The FLS determines the desired linear velocity (v) and angular velocity (w) required for effective wall-following based on sensor inputs. Two types of fuzzy logic systems are explored: Type 1 Fuzzy Logic System (T1-FLS) and Interval Type 2 Fuzzy Logic System (IT2-FLS).

The T1-FLS architecture is designed to process three inputs: the lateral distance from the wall error (ed), the rate of change of this error (˙ed), and the distance from the front obstacle (df). The system fuzziﬁes these inputs using membership functions to handle uncertainties, producing outputs that dictate the robot's angular and linear velocities. This approach allows the robot to navigate effectively despite the imprecision inherent in sensor data, making fuzzy logic a suitable choice for controlling robots in unknown environments.

In conclusion, the paper illustrates how fuzzy logic can model complex control problems without precise knowledge of the underlying dynamics, thereby enabling reliable wall-following behavior in mobile robots.
