The paper discusses the architecture of a modified Capsule Network (CapsNet) designed for image processing, detailing its convolution and capsule layers. The convolution layer comprises four internal layers (Conv1 to Conv4), each equipped with 256 filters of size 9x9 and a stride of 1. The input image is 512x512, and each convolution operation reduces the feature map size progressively, resulting in a final output of 480x480 with 256 channels. The number of trainable parameters in this layer is 20,737.

Following the convolution layer is the primary capsule layer, which performs convolution, reshaping, and squashing functions. It reshapes the output from the convolution into four vectors of nine dimensions for each location, applying a squash function to ensure the vector lengths remain between 0 and 1, indicating the presence of objects in the image. The feature map input to this layer is 480x480 with 256 channels, leading to an output size of 238x238 with 64 primary capsules, resulting in 3,625,216 trainable parameters.

The class capsule layer replaces the traditional max-pooling layer with dynamic routing. It consists of capsules with dimensions of 4, 8, and 16 for each class label. The routing protocol allows for communication between primary and class capsules, where outputs from the primary capsules serve as inputs to the class capsules. The dynamic routing process involves calculating the output of each capsule based on weighted inputs from the previous layer's capsules.

Overall, the proposed CapsNet architecture aims to enhance feature extraction and representation through its structured layers and dynamic routing mechanism, promoting better performance in image classification tasks.
