The paper discusses a modified Capsule Network (CapsNet) architecture, focusing on the primary and class capsule layers. It defines the contribution of each capsule in the current layer to the next layer using a weighted sum, which is computed as vj|i=Wij∗vj, where Wij represents the weight between the capsules. The output from the primary capsules is combined using a squash function to ensure that results are normalized between 0 and 1. The dynamic routing process is outlined in an algorithm that iteratively computes the softmax result and updates weights for capsule connections.

The class capsule layer involves training a significant number of parameters, calculated as the product of vectors received from the primary capsule layer and the desired output vectors. Additionally, the paper details the training of parameters when converting scalar values to vectors between capsules, with specific calculations provided for the parameters needed for transitions between different dimensional capsule layers.

Overall, the work emphasizes the complexity and intelligence of the reformed CapsNet architecture, highlighting the importance of dynamic routing and parameter training in enhancing performance.
