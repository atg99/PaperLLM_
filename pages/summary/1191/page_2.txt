The paper discusses various methods that leverage unlabeled data in the context of semi-supervised learning (SSL) and self-supervised learning (SSL). It presents three primary approaches: self-training with pseudo-labels, self-supervised learning through contrastive methods, and the CoMatch framework which combines both.

1. **Self-Training with Pseudo-Labels**: This method involves predicting class probabilities for unlabeled data to generate pseudo-labels for training. The classification head outputs a distribution over classes, while a projection head transforms features into low-dimensional embeddings. Consistency regularization is emphasized, where the model's outputs for augmented versions of the same image should remain similar. Various techniques enhance this approach, such as employing exponential moving average (EMA) models or adversarial transformations.

2. **Self-Supervised Learning**: This approach focuses on optimizing embeddings through contrastive learning to distinguish between different images. The loss function encourages similar embeddings for augmented versions of the same image while maintaining dissimilarity for different images. Methods like SimCLR and MoCo are highlighted for their effectiveness in instance discrimination.

3. **CoMatch Framework**: This framework integrates class probabilities and embeddings, allowing them to co-evolve in a training process that maintains smoothness in predictions. This is achieved by using pseudo-labels as targets for both the classification and projection heads, applying cross-entropy and contrastive losses respectively.

The paper also addresses the challenges of confirmation bias inherent in self-training, where errors in pseudo-labels can accumulate and hinder learning. It emphasizes the importance of entropy minimization techniques to refine pseudo-labels and ensure effective training. Lastly, it notes that while self-supervised learning is effective, it may conflict with task-specific objectives, necessitating careful consideration in classification tasks. Overall, the paper provides insights into how these methods can be effectively utilized to enhance learning from unlabeled data.
