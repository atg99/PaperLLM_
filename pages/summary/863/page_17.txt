The paper presents a study on the limitations of Transformer architectures in recognizing bounded depth languages, specifically Dyckk;D languages. It introduces several key concepts, including position masking, arbitrary position encoding, and a lower bound on the precision requirements for these languages. Unlike previous work by Hahn (2020), which established a broader context for depth and precision, this paper provides a more granular analysis focused on bounded depth languages.

The authors argue that the attention mechanism within Transformers is inherently limited, as it can only capture a small number of input positions when a few symbols are fixed in the input sequence. This limitation ultimately hinders the Transformer's ability to recognize the structured nature of Dyckk;D languages. The framework employs a multi-layer Transformer architecture with various types of attention heads, including those with future and past position masking.

A significant part of the proof involves fixing a small number of positions in the input sequence, ensuring that outputs from each layer depend solely on specific symbols. The authors define a well-aligned partially assigned input sequence that adheres to specific assignment rules for matching brackets. They further establish a key lemma that demonstrates how fixing additional input positions guarantees that outputs at each layer depend only on the relevant input symbol.

The analysis includes a detailed examination of the number of possible input values across layers, concluding that the output of each attention head can be controlled by fixing a limited number of positions. The authors present a systematic approach to assigning brackets in the input sequence, illustrating how to manage dependencies effectively. Overall, the paper highlights the inherent challenges in using Transformers for certain structured languages, providing a nuanced perspective on their computational limitations.
