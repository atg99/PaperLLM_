The paper discusses reinforcement learning (RL) within the framework of a Markov Decision Process (MDP). An MDP is characterized by a state space, action space, transition probabilities, a reward function, and an initial state distribution. The primary objective in RL is to learn a policy that dictates the appropriate action to take based on the current state, with the aim of maximizing the expected return from trajectories of states, actions, and rewards over time.

To formalize this, the paper presents an optimization problem where the expected return is maximized through policy search. This involves using a parameterized policy function and updating its parameters via gradient ascent. The gradient can be estimated using techniques such as Monte Carlo methods and REINFORCE, leading to a recursive update for the action-state value function, or Q-function. The convergence of this stochastic gradient approach to a locally optimal policy is contingent on appropriate choice of step sizes.

However, the paper notes that relying on single trajectories can lead to high variance in estimates, necessitating the averaging over multiple trajectories, which can be inefficient. Various methods, including baseline subtraction and actor-critic methods, have been proposed to mitigate this issue. Actor-critic methods, in particular, involve approximating the value function using a parameterized function, which can introduce instability into the learning process.
