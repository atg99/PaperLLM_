The paper presents the BoostTree algorithm for both regression and classification tasks, detailing its structure and loss functions. For regression, it employs a linear model represented as \( fm(x) = w_m^T x + b_m \) and minimizes the loss function using the squared error, incorporating a regularization term. The algorithm fits pseudo-responses to reduce the loss iteratively.

In binary classification, BoostTree utilizes a LogitBoost-like approach, updating logistic models with Newton's method while minimizing cross-entropy loss. The model also incorporates robustness measures against outliers by filtering and clipping pseudo-responses.

For multi-class classification, the algorithm adapts to handle multiple classes using a softmax function to calculate class probabilities and a corresponding loss function. Each class has its own linear model, and the overall loss is aggregated across classes.

Furthermore, the BoostForest method enhances model diversity by integrating multiple BoostTrees, utilizing techniques such as bagging and feature sub-sampling. This approach streamlines the training process by randomly selecting parameters from a predefined pool, reducing overfitting without the need for cross-validation.

The supplementary algorithms provide detailed steps for implementing BoostTree and BoostForest for various tasks, ensuring a comprehensive understanding of their functionalities.
