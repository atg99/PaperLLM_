The paper presents the BoostTree model, which is designed for predictive tasks using an additive approach similar to LMT and GBM. The model predicts output by summing the contributions from multiple nodes along a path determined by the input x. The prediction is mathematically represented as the sum of functions from nodes along the path to the leaf node q(x).

BoostTree aims to minimize a regularized loss function that combines the loss from predictions and a penalty for model complexity to avoid overfitting. The loss function is structured to accommodate various loss types suitable for regression and classification, under the condition that they are convex and differentiable.

The optimization of the loss function is not direct; instead, BoostTree constructs the model iteratively by generating trees with multiple leaves. In each iteration, the leaf node with the highest impurity is split, and a greedy learning approach is used to add branches. The algorithm calculates the loss reduction from splitting a node based on the training samples associated with it.

To refine the splitting decision, the paper applies Taylor's theorem to approximate the loss reduction, which involves the first and second derivatives of the loss function. This approximation allows the model to evaluate potential splits more effectively.

The splitting algorithm is detailed, indicating how different learning tasks influence the fitting of linear models for the child nodes. The optimization process is executed in two steps, initially focusing on the bias while ignoring coefficients to assess potential splits. This structured approach ensures that BoostTree effectively balances model complexity and predictive accuracy.
