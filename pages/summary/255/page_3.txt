This paper investigates the development of deeper capsule networks, marking what is believed to be the first effort to construct multi-layer capsule architectures. The authors highlight the unique capability of capsule networks to represent images through instantiation parameters that encode physical transformations, such as rotation and skewness. However, the specific impacts of these parameters on the reconstructed images have not yet been thoroughly examined.

The paper critiques the limitations of the existing dynamic routing mechanism, which operates only in a fully connected manner, making it inefficient for deeper architectures. To address this, the authors propose a novel dynamic routing algorithm that allows for convolutional capsule layers, similar to conventional convolutional neural networks (CNNs).

A key innovation is the introduction of a 3D convolution-based dynamic routing mechanism. The output of a capsule layer is reshaped into a single-channel tensor and convolved with a set of 3D convolutional kernels to generate intermediate votes for higher-level capsules. This approach maintains the spatial structure of the input while enabling localized feature sharing among adjacent capsules, thus reducing parameter redundancy significantly.

The proposed routing algorithm begins with initializing logits and computes coupling coefficients using a 3D softmax function. This normalization process ensures that predictions from a single capsule tensor are effectively integrated, setting the stage for more efficient routing and ultimately enhancing the performance of deeper capsule networks.
