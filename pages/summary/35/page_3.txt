The paper titled "Understanding of Convolutional Neural Network (CNN): A Review" by Purwono provides an overview of the fundamental concepts underlying convolutional neural networks. It explains the role of the convolutional layer, which utilizes a kernel filter to perform convolution on input images, thereby extracting essential features. The kernel filter is smaller in size compared to the input image, and its dimensions can vary, such as 3, 5, or 7 for a 2D scalogram of size 35×35×35. The convolution process involves sliding the filter across the image to compute a 2D activation map, which allows CNNs to learn visual features.

The paper presents the general equation for the convolutional layer, emphasizing parameters such as kernel size, stride length, and padding. The kernel size refers to the dimensions of the filter, while the stride length indicates how far the kernel moves before generating output pixels. Padding involves adding a zero-frame around the input feature map.

Additionally, the paper discusses the pooling layer, which follows the convolutional layers to reduce the number of parameters and computational load through down-sampling. It highlights the use of maximizing or averaging functions in pooling, with max-pooling being preferred for optimal performance. The pooling layer also serves to mitigate overfitting and reduce computational weights, further optimizing the CNN architecture.
