The paper introduces a Multi-scale Residual Graph Convolution Network (MSR-GCN) designed for human pose prediction. The architecture consists of a start GCN, four descending GCNs (D0, D1, D2, D3), four ascending GCNs (A0, A1, A2, A3), and four end GCNs (E0, E1, E2, E3). The process begins with the start GCN, which transforms the input poses at the coarsest scale into a feature space. 

The MSR-GCN architecture is structured to handle varying levels of pose abstraction, allowing for recursive refinement of pose representations from 22 joints to coarser representations with 12, 7, and 4 joints. This multi-level approach facilitates easier pose prediction at coarser scales before progressing to finer scales.

Each descending and ascending block comprises multiple residual GCN layers that maintain a consistent feature dimension while adjusting the pose dimension. The descending blocks reduce the pose dimension, while the ascending blocks increase it, utilizing upsampling layers. Features from both paths are concatenated before being processed by the end GCNs, which decode the combined features back into pose representations.

Residual connections are implemented after each end GCN, enabling the network to learn residuals rather than directly predicting target poses, thereby enhancing learning stability and performance. The proposed architecture emphasizes a structured approach to human pose estimation through multi-scale processing and feature combination.
