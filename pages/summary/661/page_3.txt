The paper presents a novel approach for human pose prediction using a Multi-Scale Residual Graph Convolution Network (MSR-GCN). The goal is to forecast a future sequence of poses based on a set of observed frames, which are represented as a series of 3D poses for a given number of joints. The method reformulates the prediction task by extending the last observed pose to create a longer input sequence, which aids in predicting the future poses.

The methodology begins with a description of basic Graph Convolutional Networks (GCNs) that model the spatial structure of human poses. These networks are effective in capturing the spatial dependencies between joints, which are crucial for accurate pose prediction. The GCN operates as a series of layers that process the input pose data through a learned adjacency matrix that reflects the relationships between joints.

The architecture includes a start GCN, multiple residual GCNs, and an end GCN. The start GCN transforms the input poses into a feature space, the residual GCNs refine the features, and the end GCN maps the features back to the pose space. A global skip connection is incorporated to learn the residuals, which enhances the prediction accuracy by focusing on the differences between predicted and actual poses.

Furthermore, the paper emphasizes the importance of multi-scale processing, suggesting that poses can be simplified into various scales, enabling the model to capture both fine details and broader motion patterns. This multi-scale approach is expected to improve prediction performance by leveraging the inherent characteristics of human motion.

In summary, the MSR-GCN framework enhances human pose prediction by effectively modeling spatial dependencies and utilizing multi-scale features, which is expected to yield superior results compared to existing methods.
