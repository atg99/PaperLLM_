This section of the paper discusses various designs of Self-Attention Network (SAN) architectures aimed at skeleton-based action recognition. It outlines four models: SAN-Block, SAN-V1, SAN-V2, and SAN-V3, each with distinct functionalities. 

The encoder section describes two main methods for encoding raw position and motion data: a non-linear encoder and a CNN-based encoder. The non-linear encoder uses a feed-forward neural network to project input vectors into higher dimensions, with specific adaptations for the different SAN variants. In contrast, the CNN-based encoder processes low-level features from the skeleton data using a series of convolutional layers, optimizing for local contextual information across frames.

The SAN architecture employs a SAN block that processes encoded representations of position and motion. The input to the SAN block consists of feature representations per frame, with the dimension of these features depending on the encoder type. A position embedding layer is introduced to provide order and context to the feature vectors, which is crucial for capturing the temporal dynamics of the input sequences.

Overall, this section highlights the innovative approaches taken in encoding and processing skeleton data for enhanced action recognition through self-attention mechanisms.
