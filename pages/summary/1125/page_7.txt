The L-SHADE algorithm integrates a linear population size reduction technique into the SHADE framework. This method systematically decreases the population size across generations. 

**Initialization**: The algorithm begins by randomly generating a pool of candidate solutions within specified bounds, creating a population of decision vectors. Each vector's components are initialized using a uniform random number generator to ensure they fall within defined minimum and maximum limits.

**Mutation**: Following initialization, a mutation operation generates a donor vector for each target vector in the current generation. L-SHADE employs a 'current-to-pbest/1' mutation strategy, which utilizes the best individuals from the current generation to influence the mutation process. If any components of the donor vector exceed the search range, they are adjusted to remain within bounds.

**Parameter adaptation**: Each individual in the population adapts its control parameters (scaling factor and crossover rate) for each generation. These parameters are sampled from specific statistical distributions, ensuring they remain within acceptable limits, with initial values set to 0.5.

**Crossover**: The crossover phase blends elements from the mutant vector and the target vector to create a trial vector. The crossover rate, determined for each individual, dictates which elements are selected from either vector. The process follows a binomial crossover scheme, ensuring a controlled mix of the two vectors.

Overall, L-SHADE is designed to evolve solutions effectively while managing population dynamics and parameter adaptation.
