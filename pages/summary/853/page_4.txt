The proposed SecFed scheme is designed for federated learning in the context of detecting false data injection attacks (FDIA) while keeping data local to each client. This approach merges federated learning with the Paillier cryptosystem, enabling collaborative model training without sharing raw data. The scheme consists of five key steps:

1. **Initialization**: The trustee initializes model parameters for each client, including hyperparameters and cryptographic keys based on the Paillier cryptosystem.
2. **Local Model Training**: Each client trains a Transformer-based FDIA detection model using their local data.
3. **Weight Encryption**: After training, clients encrypt their model weights and upload them to the cloud.
4. **Weight Aggregation**: The cloud server aggregates the encrypted weights from all clients and sends the aggregated ciphertext back.
5. **Model Update**: Clients decrypt the received ciphertext to update their local models with the new weights.

Three assumptions are made for analysis: all clients use the same initial global framework, have identical hyperparameters and optimization algorithms, and possess similar computing power. The cloud server does not train the model itself but aggregates local models to derive a global model.

Additionally, the paper presents a Transformer-based distributed detector for stealthy FDIA in smart grids. The model uses active and reactive power injections and branch power flows as inputs, framing the detection as a binary classification problem. Unlike traditional detection methods, this data-driven approach does not rely on the system's model or parameters, allowing the Transformer to extract features from both normal and compromised data effectively.

The architecture of the Transformer includes positional encoding, encoder blocks, and a sigmoid layer. The positional encoding helps the model understand the significance of feature positions under varying conditions, enhancing the detection performance.
