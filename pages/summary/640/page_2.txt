This paper addresses the inefficiencies of existing Graph Convolutional Networks (GCNs) training methods, particularly in terms of memory usage, computational time, and convergence speed. Traditional full-batch gradient descent suffers from high memory requirements due to the need to store intermediate embeddings, resulting in O(N FL) memory complexity. Although time per epoch is efficient, the convergence of this method is slow due to parameter updates occurring only once per epoch.

Mini-batch Stochastic Gradient Descent (SGD) improves convergence by allowing multiple updates per epoch but introduces significant computational overhead due to the neighborhood expansion problem. This issue arises because the computation of loss for a node depends on the embeddings of its neighbors across multiple layers, leading to exponential time complexity with respect to the depth of the GCN.

Variational Reduction GCN (VR-GCN) attempts to mitigate memory requirements by reducing the size of neighborhood sampling. However, it still requires storing all intermediate embeddings, leading to the same O(N FL) memory complexity as full-batch methods. 

To overcome these challenges, the authors propose Cluster-GCN, a novel GCN training algorithm that leverages graph clustering to enhance batch efficiency through increased within-batch links. By applying efficient clustering algorithms, Cluster-GCN significantly reduces memory requirements to O(bFL), where b is the batch size, which is an improvement over both VR-GCN and other SGD-based methods. Furthermore, it maintains a similar time cost per epoch as traditional gradient descent while improving convergence speed.

The paper presents several key contributions: 
1. Cluster-GCN demonstrates superior memory efficiency on large-scale graphs, using significantly less memory than VR-GCN for deep networks.
2. The training speed of Cluster-GCN is comparable to VR-GCN for shallow networks and faster for deeper networks due to its linear complexity in relation to the number of layers.
3. Cluster-GCN enables the training of deeper networks with large embeddings, achieving new benchmark accuracy on the PPI dataset.

Overall, the proposed algorithm effectively balances memory, computational efficiency, and convergence speed, making it a promising approach for scaling GCNs on large datasets.
