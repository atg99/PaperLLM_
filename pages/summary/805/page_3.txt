The paper presents a convolutional neural network (CNN) architecture designed for viral classification, utilizing one-hot encoding for input sequences. The input length is set to 3500, with zero padding applied to shorter sequences. The architecture consists of four convolutional layers and four fully connected layers, as detailed in the tables provided. The computational load is significant, with approximately 0.54 billion operations and a total weight size of about 46.62 Mbits.

The authors highlight the challenges associated with using large deep neural networks (DNNs) in bioinformatics, particularly the high computational complexity that limits throughput. To address these issues, they propose a model compression scheme aimed at accelerating inference processes. The acceleration strategies discussed include algorithm-based methods such as model compression, parallel processing, and sparsity exploitation, as well as system-based approaches that leverage hardware efficiencies.

Overall, the paper emphasizes the need for efficient DNN architectures in bioinformatics to improve processing times while managing computational demands.
