The paper discusses various approaches to addressing fairness in machine learning classification models. The first approach highlights the impact of sensitive value frequencies in the input data, which can either reduce or increase the number of positive labels generated by the model. The second approach involves creating separate models for each sensitive attribute value, where one model is trained on data with a favored sensitive value and another on data with a discriminated value. These models are integrated into a meta-model that mitigates discrimination by adjusting conditional probabilities.

The third approach introduces a latent variable corresponding to a non-biased label, optimizing model parameters through the expectation-maximization algorithm. A framework for fair classification is proposed, consisting of a task-specific metric for evaluating individual similarity in classification and an algorithm to maximize an objective function while ensuring fairness, defined by similar decisions for similar individuals. This framework also addresses statistical parity and discusses the interplay between privacy and fairness, suggesting that differential privacy tools can enhance fairness.

The paper distinguishes between procedural fairness, related to the decision-making process, and distributive fairness, which focuses on outcomes. To bridge this gap, procedural fairness metrics are introduced to account for the influence of input features and moral judgments about their use. The concept of meritocratic fairness is explored, emphasizing performance guarantees while relaxing model assumptions. A scheme for achieving meritocratic fairness in infinite linear bandit problems is presented, which ensures that no preferential treatment occurs unless a higher reward is guaranteed. This is operationalized by calculating confidence intervals around expected rewards, linking individuals based on overlapping intervals.
