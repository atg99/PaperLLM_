The paper discusses various methods for optimizing loss functions in small-scale networks, specifically focusing on the diagonal approximation of the Hessian as generalized by Hassibi and Stork in 1992. The authors provide an illustrative example using the function L(x1, x2) = 2x1^2 + 0.5x2^2, where an approximate minimum is found at (0.1, -0.3) instead of the true optimum (0, 0).

In the example, the function value at the approximation is L(0.1, -0.3) = 0.065. Different pruning methods are compared: 

1. **Magnitude pruning** evaluates the absolute values of x1 and x2, leading to a pruned function value L_MAG(0, -0.3) = 0.045.
2. **OBD (Optimal Brain Damage)** assumes a diagonal Hessian and dampens weights accordingly, resulting in L_OBD(0.1, 0) = 0.02.
3. **OBS (Optimal Brain Surgeon)** does not assume a diagonal Hessian and updates x1 after setting x2 to zero, achieving the optimal value L_OBS(0, 0) = 0.

The paper concludes that OBS provides a more flexible and effective approach to pruning by accommodating non-diagonal Hessians and adjusting for changes in the variable values, ultimately reaching the optimal solution in this scenario.
