The paper discusses the concept of long memory in Recurrent Neural Networks (RNNs) and Long Short-Term Memory (LSTM) networks, specifically through the introduction of Memory-augmented RNN (MRNN) and Memory-augmented LSTM (MLSTM) architectures. 

The MRNN structure includes a traditional hidden unit and a memory unit that operates in parallel to capture long memory patterns in time series data. The model incorporates a memory parameter, which is fractional and varies over time, thereby allowing the network to handle long-range dependencies effectively. The update equations for the MRNN are provided, demonstrating how it processes input data and maintains memory.

In contrast, the LSTM's memory property is influenced by its forget gates, which determine how much information is retained. The paper proposes modifications to the LSTM's cell states by integrating a long memory filter, allowing the memory parameter to also depend on external variables. The revised structure, referred to as MLSTM, enhances the model's ability to manage long memory while maintaining the core functionality of LSTM.

The paper concludes that the MRNN and MLSTM models possess the capability to handle long-range dependence data, a feature that traditional RNNs lack. The technical proof supporting these claims is provided in supplementary materials.
