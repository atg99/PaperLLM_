The paper discusses the memory properties of Recurrent Neural Networks (RNNs) and Long Short-Term Memory networks (LSTMs), arguing that both exhibit short memory characteristics when there is no exogenous input. The authors emphasize that the memory behavior of these networks is influenced significantly by the forget gate in LSTMs and that the conditions for short memory can be satisfied by various common output functions.

The paper then introduces the concept of long memory in network processes, referencing existing literature on long-range dependence in conditional heteroscedastic time series models. It defines long memory for a network process based on the decay rate of coefficients and proposes a new definition that reflects a network's ability to maintain long-term dependencies.

To address the limitations of RNNs and LSTMs in capturing long memory, the authors propose a new long memory filter structure that can be integrated into these networks. This filter, described as a memory-augmented RNN (MRNN), acts as a soft attention mechanism and introduces additional memory parameters to enhance the model's capability to handle long-term dependencies.

In summary, the paper concludes that while traditional RNNs and LSTMs are constrained by short memory properties, the introduction of a long memory filter allows for better modeling of long-range dependencies, thus expanding the functionality and effectiveness of these networks in various applications.
