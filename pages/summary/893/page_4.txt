This paper presents a self-attention mechanism within an autoencoder framework for image reconstruction and style transfer. The weight coefficient αij captures dependencies between regions using a softmax function, computed through a compatibility function based on a scaled dot product. The self-attention feature map, Ax, is reshaped to match the dimensions of the input feature map, fx. A self-attention residual, Rx, is generated by multiplying Ax with fx and is added back to create an output Ox, which is fed into the decoder for reconstruction.

The loss function for the model combines semantic content loss, which includes perceptual and pixel reconstruction losses, with a sparse loss on the self-attention feature map to focus attention on smaller regions. Additionally, total variation regularization is applied to encourage spatial smoothness in the generated images. The overall loss function is a weighted sum of these components.

The paper also discusses a multi-scale style swap technique, which efficiently replaces content features with style features using convolution operations and an argmax operation. It addresses limitations in patch size and receptive field by maintaining a fixed patch size while scaling activation feature maps to introduce various stroke patterns. The process involves whitening transforms to separate style information from global structure, allowing for multiple style features to be generated and swapped.

Finally, the paper introduces a multi-stroke fusion approach that leverages the self-attention mechanism to refine critical characteristics of the content feature. The residual Rc captures essential variations, focusing on non-trivial parts to enhance the reconstruction process.
