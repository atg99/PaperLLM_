The paper discusses advancements in feature network design, particularly focusing on the bidirectional feature pyramid network (BiFPN). It compares several existing architectures: the conventional feature pyramid network (FPN), the path aggregation network (PANet), and the neural architecture search feature pyramid network (NAS-FPN).

The FPN employs a top-down approach to aggregate multi-scale features, where each feature level represents a progressively reduced resolution of the input images. However, this method is limited by its one-way information flow. To enhance feature connectivity, PANet introduces an additional bottom-up pathway, which improves accuracy but increases computational demands. NAS-FPN utilizes neural architecture search to create a complex feature topology, although this approach is resource-intensive and results in networks that are challenging to interpret.

The paper identifies key limitations in these existing networks and proposes several optimizations for cross-scale connections to improve efficiency. The authors suggest removing nodes with a single input to streamline the network, adding edges to fuse features at the same level, and treating bidirectional paths as individual layers that can be repeated for enhanced feature fusion. These modifications culminate in the design of the BiFPN.

Additionally, the paper addresses the challenge of weighted feature fusion, noting that different input features contribute unequally to the output. The authors advocate for a weighted approach, allowing the network to learn the significance of each input feature, which could enhance the final output quality. The proposed methods aim to achieve better accuracy and efficiency in feature network design, demonstrating the potential benefits of BiFPN over its predecessors.
