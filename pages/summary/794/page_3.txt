The paper presents the Network of Neural Networks (NoNN), a novel approach to compress deep learning models for deployment on resource-constrained Internet of Things (IoT) devices. The primary challenge addressed is the high communication cost associated with distributed inference on devices with limited memory, which has been largely overlooked in previous research.

The key question posed is how to effectively compress a deep learning model into separate modules that fit within the memory and performance constraints of individual devices, minimize communication latency, and maintain high accuracy. NoNN tackles this by creating a system of multiple student networks, each tasked with learning a specific part of a larger teacher model's function. This method simplifies the training process and leverages parallelism to enhance overall model size and accuracy without significantly increasing communication costs, as communication occurs only at the last layer.

The contributions of the paper include: 

1. Introducing the NoNN paradigm for efficient distributed inference on memory-constrained IoT devices, where traditional student models risk excessive communication across all layers.
2. Formulating the model compression problem using network science principles, allowing for the distribution of knowledge from the teacher model into disjoint student modules.
3. Demonstrating through experiments that NoNN achieves considerable reductions in memory and computation requirements while preserving accuracy, outperforming existing methods.
4. Validating the practical application of the proposed models on devices like Raspberry Pi and Odroid, showing significant performance gains in various deployment scenarios.

Overall, NoNN represents a significant step forward in enabling deep learning on IoT devices by addressing both memory and communication constraints effectively.
