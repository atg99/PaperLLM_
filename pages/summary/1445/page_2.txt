The paper presents a Noisy Student Training (NST) algorithm for Automatic Speech Recognition (ASR) that utilizes both labeled and unlabeled data to enhance model performance. The process begins with a labeled dataset S and an unlabeled dataset U, alongside a language model (LM) trained on a separate text corpus. The NST consists of multiple iterations or generations, where each generation involves training a new ASR model, filtering generated transcripts, and balancing the dataset.

The methodology includes the following steps: 
1. Train an initial model M0 on the labeled dataset S using SpecAugment for data augmentation.
2. Fuse the model with the LM and evaluate its performance.
3. Generate a labeled dataset from the unlabeled set U using the fused model.
4. Filter the generated data based on a new scoring function that combines the fusion score and token length.
5. Balance the filtered dataset to align its token distribution with that of the supervised training set.
6. Mix the balanced dataset with the original labeled set for training the next generation model.

SpecAugment is employed to augment input data by applying adaptive time masking. The fusion of the teacher networks with the LM aims to improve transcript quality, using a coverage penalty in the scoring process. Filtering of transcripts relies on a normalized score that assesses the quality of generated outputs, while balancing employs sub-modular sampling to match the token distribution of the generated dataset to the supervised set.

The experiments are conducted on the LibriSpeech dataset, where the clean 100-hour subset serves as the supervised data and the remaining 860 hours as the unlabeled data. The models are trained over six generations, with specific configurations for SpecAugment and language modeling. The results emphasize the effectiveness of the NST approach in leveraging unlabeled data to improve ASR performance. 

Overall, the proposed NST algorithm systematically relaxes filtering criteria through iterations, enhancing the quality of the training data and the resulting ASR models.
