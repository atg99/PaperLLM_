This paper discusses the implementation of dilated convolutions within a Temporal Convolutional Network (TCN) framework, particularly focusing on their application in time series prediction and causal discovery. The dilation factor, which increases exponentially based on a chosen dilation coefficient, allows the network to maintain a large receptive field while keeping the number of parameters manageable. The formula for the receptive field in a 1D Dilated TCN demonstrates this capability.

The authors propose adaptations for two specific scenarios: discovering self-causation and multivariate causal discovery. For self-causation, the TCN architecture is modified so that the current value of the target time series is excluded from the input, enabling the model to predict past values without direct access to the current target value. This involves shifting the input data forward with zero padding.

For multivariate causal discovery, the TCN, originally designed for univariate time series, is adapted to handle multiple time series by merging them into a 2D input format. This allows the use of 2D kernels, which can effectively process the combined time series data and produce a 1D output in the initial hidden layer.

Overall, the paper highlights the flexibility of dilated convolutions in handling complex time series data and the necessary adaptations to extend TCN capabilities for specific predictive tasks.
