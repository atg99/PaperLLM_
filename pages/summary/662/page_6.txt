In the paper presented at MICRO '21, the authors introduce a method for island location in graph structures, primarily focusing on the detection of hub nodes and subsequent parallel processing using a breadth-first search (BFS) approach. The process begins with hub detection through a threshold-based algorithm that classifies nodes as either hubs or islands by progressively lowering the threshold for node degree. This classification is essential for the efficient organization of nodes into manageable tasks for processing.

Once hubs are identified, the algorithm generates BFS tasks by examining the neighbors of each hub node, which are queued for parallel processing. This strategy aims to maximize parallelism by starting searches from neighboring nodes rather than the hubs themselves, thereby enhancing scalability.

The implementation of the BFS, termed TP-BFS, utilizes multiple engines operating concurrently on different hub neighbors. Each engine tracks its visited nodes locally while maintaining a global record to prevent redundant searches. The algorithm efficiently skips nodes that have already been explored, minimizing off-chip data accesses and optimizing performance.

The authors detail the TP-BFS process, where engines iteratively explore nodes until all have been visited or certain predefined conditions are met, such as exceeding the maximum expected island size. The architecture supporting this method is designed to facilitate distributed node degree storage and efficient task management, ultimately leading to the successful identification and processing of islands within the graph.

Overall, the proposed method demonstrates significant improvements in both the scalability and efficiency of island detection in large graph structures, leveraging parallel processing and strategic task generation to achieve these goals.
