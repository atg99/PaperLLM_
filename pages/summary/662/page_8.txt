The architecture of the Island Consumer is designed to optimize the efficiency of processing islands in a distributed environment, leveraging pre-aggregation and redundancy removal to enhance performance.

The Island Consumer operates by first receiving island-related information from the Island Locator, which is then stored if deemed non-redundant. Each evaluation task is prefetched by arbiters and sent to idle processing elements (PEs). Upon receiving a task, PEs execute aggregation and combination operations, ultimately producing complete outputs for island nodes and partial results for hub nodes. These results are stored in global memory or sent to a HUB Partial Result Cache for further processing.

To ensure complete aggregation results, the Island Collector also manages inter-hub connections by maintaining an inter-hub edge map and generating tasks for these connections. The entire architecture emphasizes a ring network configuration for PEs, facilitating efficient data flow and communication, particularly for updating hub node results with in-network reduction capabilities. This comprehensive approach enables the system to effectively handle complex graph data operations while minimizing computational overhead.
