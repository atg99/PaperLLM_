The paper discusses the classification capabilities of specialist networks, which focus on the minor class level. It presents different dataset configurations, illustrated in Figure 2, highlighting the number of images and classes within each major category. The experimental framework employs various initializations for specialist networks, including a control group with random (scratch) initialization and four others using transferred weights from superset networks. This approach offers multiple advantages, such as conducting seven distinct trials across different subsets of data, which allows for comprehensive result verification and analysis of dataset types. For instance, the bird subset is characterized by a high number of classes but limited training data per class, whereas the dog dataset has fewer classes but more training data. Table 1 provides an overview of multiple class image datasets, detailing the number of images, training and testing splits, categories, and their sources. Overall, the study aims to evaluate the performance of specialist networks across varying dataset configurations.
