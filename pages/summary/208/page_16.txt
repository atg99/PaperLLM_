The paper discusses the implementation of reinforcement learning (RL) algorithms on a real hardware platform for unmanned aerial vehicles (UAVs), contrasting with the prevalent focus on simulation-based training. The authors aim to optimize UAV path-following in unknown environments, using a position controller that takes the desired position as input and generates thrust to guide the UAV.

The proposed design employs a standard PID controller to ensure stable navigation, taking various learning parameters and gain values as inputs. The controller observes the UAV's current state and updates its actions based on a reward-based learning equation. Key components of the PID controller are adjusted to optimize performance, with the derivative component reducing settling time and overshoot, while the integral component is minimized to prevent excessive overshoot.

The implementation process involved two main steps: first, a MATLAB simulation where the UAV navigated a bounded area avoiding obstacles, which took 39 episodes to optimize the action sequence; second, real-time testing using a quadrotor Parrot AR Drone 2.0 and Motion Capture System software. Due to the computational demands of real-time control, a graphical user interface (GUI) was developed in MATLAB to log data and maintain continuity in the learning process.

The experiments demonstrated that the UAV could replicate its simulated behavior in real-time, achieving optimal path-following in 38 episodes. This approach highlights the effectiveness of RL algorithms in practical UAV applications, emphasizing the balance between simulation and real-world implementation.
