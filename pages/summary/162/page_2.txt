This paper introduces a novel framework for multi-view clustering called Multi-V AE, which is based on variational autoencoders (VAE). The aim is to learn disentangled and explainable visual representations that can effectively handle large-scale data clustering problems. The proposed framework differs from existing methods by incorporating both a view-common variable and multiple view-peculiar variables within a multi-VAE architecture.

The view-common variable captures the common visual representation across all views, representing cluster information, while each view-peculiar variable focuses on unique characteristics specific to each view, such as angles, styles, and sizes. The latent variable for each view is constructed from both the view-common and view-peculiar variables, allowing for the generation of samples that reflect both common and unique aspects.

The paper emphasizes the importance of disentangling these representations to reduce interference from superfluous information across multiple views. The authors utilize different prior distributions for the common and peculiar variables: Gumbel Softmax for the discrete cluster information and Gaussian distribution for the continuous visual factors. By managing the mutual information capacity through KL divergence during training, the framework successfully separates common and peculiar representations.

Key contributions of the work include the introduction of the Multi-V AE framework, which effectively disentangles common cluster representations and peculiar visual representations, enhancing clustering performance while maintaining linear complexity relative to data size. This work represents a significant advancement in the implementation of multi-view clustering through the lens of disentangled representation learning.
