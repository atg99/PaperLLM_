In section 4.1, the performance of Restricted Boltzmann Machines (RBMs) using different activation functions on the MNIST dataset is analyzed. The learning process is tracked through the pseudo-likelihood function evaluated after each parameter update on a random subset of 100 test data points. The results, depicted in Figure 5a, indicate that for RBMs with 50 hidden nodes, the pseudo-likelihood values are consistently higher for the Linear activation function compared to other non-linear functions. Conversely, with 1200 hidden nodes, non-linear functions, excluding the Step activation function, outperform the Linear function.

Figure 5b illustrates the likelihood and pseudo-likelihood across the entire test set as a function of hidden node count and activation function. The likelihood estimation employs the Annealing Importance Sampling (AIS) method, which involves multiple annealing runs and intermediate temperatures. Error bars around the likelihood estimates are calculated based on predicted bounds from the partition function, with outliers being excluded from the mean and error bar calculations.

The findings reveal that for the Linear activation function, increasing the hidden layer beyond 100 nodes does not enhance performance, as both pseudo-likelihood and likelihood values plateau. This saturation suggests that the RBM is constrained to modeling only pairwise interactions, and enlarging the hidden layer can merely refine the representation of these interactions. Overall, the results underscore the limits of the Linear activation function in capturing complex data representations as the number of hidden units increases.
