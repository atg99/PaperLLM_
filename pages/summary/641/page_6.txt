The paper presents a method for learning node embeddings through multiple network types, specifically focusing on 1-hop, 2-hop, and k-nearest neighbors (kNN) networks. The embedding matrix for the l-th layer, denoted as H(l), is computed using a combination of the adjacency matrix, the degree matrix, and a weight matrix, along with a non-linear activation function. 

For the kNN network, the authors utilize Cosine similarity to compute a similarity matrix among nodes, defining the similarity between nodes based on the angle between their feature vectors. The adjacency matrix for the kNN network is formed by selecting the top k similar node pairs.

Node-level attention is introduced to weigh the contributions of different network types to the final embeddings. The importance coefficient for a node pair is calculated using a parameterized attention vector and a mapping matrix. The embeddings are aggregated based on these importance coefficients.

The process culminates in a discriminative aggregation step, where the contributions of 1-hop, 2-hop, and kNN neighbors are combined based on learned attention values. The final output embedding is produced by normalizing these attention values through a softmax function, allowing for a dynamic adjustment of the importance of each network type in the embedding process.
