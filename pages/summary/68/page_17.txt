The paper discusses the application of a genetic algorithm (GA) to enhance multi-class classification performance in network intrusion detection using the KDDTest dataset. The results indicate that the GA effectively reduced misclassifications, as evidenced by the confusion matrices presented for models using 122 and 99 features. 

In the analysis, the confusion matrices revealed varying levels of accuracy across different attack classes. For instance, while the Normal class achieved a high accuracy rate with 98.47%, the R2L and U2R classes demonstrated significantly lower rates of 23.78% and 25.37%, respectively, primarily due to a limited number of training records for these classes.

The evaluation metrics for models using 122 features highlighted a decrease in accuracy for R2L and U2R classes, while using 99 features and 80 neurons improved the overall classification accuracy for these classes, indicating the GA's effectiveness in enhancing classification results.

Additionally, the paper references a self-taught learning approach that achieved 88.39% accuracy for binary classification and 79.10% for five-class classification, demonstrating competitive performance compared to traditional methods. The use of Long Short-Term Memory Recurrent Neural Networks (LSTM-RNN) in previous studies yielded high accuracy, with the current research showing comparable results when integrating LSTM-RNN with a genetic algorithm.

Overall, the findings suggest that utilizing a genetic algorithm can significantly improve classification accuracy in network intrusion detection systems, particularly for underrepresented classes.
