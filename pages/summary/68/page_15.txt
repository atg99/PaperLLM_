The paper presents a performance comparison of various classifiers—LSTM-RNN, SVM, and Random Forest (RF)—in both binary and multi-class classification tasks using different feature sets. In binary classification experiments using all features, LSTM-RNN achieved a testing accuracy of 96.51% with a True Positive Rate (TPR) of 0.944, while RF outperformed others with the highest accuracy overall.

In multi-class classification using 122 features, LSTM-RNN again excelled with an accuracy of 82.68%, surpassing SVM's 67.20% and RF's 80.70%. The TPR for LSTM-RNN was notably higher at 0.707 compared to SVM and RF.

When evaluating the performance using an optimal set of 99 features, all classifiers performed similarly in binary classification, achieving accuracies around 99.9%. However, in multi-class classification with the same optimal features, LSTM-RNN stood out with a testing accuracy of 93.88%, significantly higher than SVM's 68.10% and RF's 84.90%, and also had the highest TPR at 0.896. This suggests that LSTM-RNN is particularly effective for multi-class classification tasks when employing optimal features.
