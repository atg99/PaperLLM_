The paper discusses the classification of network attacks using an LSTM-RNN classifier integrated with a Genetic Algorithm (GA). It outlines a systematic approach to data preprocessing and feature selection, which are critical for improving model performance.

In the first step, data preprocessing is divided into two main tasks: numericalization and normalization. Numericalization involves converting 38 numeric features and three non-numeric features—protocol type, service, and flag—into numeric values. This transformation results in a total of 122 features. The non-numeric features are processed using LabelEncoder to convert them to integers, followed by One-Hot-Encoding to represent them as binary features in a sparse matrix format.

Normalization is applied to address the disparity in ranges among features like duration, src_bytes, and dst_bytes. A logarithmic scaling method is utilized to map values to the range [0, 1]. While normalization is not universally required, it is particularly beneficial for datasets such as NSL-KDD, where feature ranges vary significantly. This practice enhances the convergence speed of gradient descent algorithms and can improve the accuracy of the classifier.

The second step involves feature selection, aimed at identifying the most relevant features for future model implementation. This process is essential for refining the dataset and enhancing predictive performance. The overall methodology emphasizes the importance of thorough preprocessing and feature selection in developing an effective classification model for network attack detection.
