The paper discusses the implementation and experimentation of various machine learning models, specifically focusing on the LSTM-RNN classifier for both binary and multi-class classification tasks. The authors utilized the Linear SVM and Random Forest classifiers from scikit-learn to establish a comparative baseline, employing default settings with specified parameters such as n_estimators for Random Forest.

For the LSTM-RNN model, hyper-parameters were systematically adjusted, including the number of neurons in hidden layers ranging from 5 to 100, and dropout rates. The experimental results section promises an analysis of classification performance metrics such as accuracy, precision, recall, f-score, true positive rate (TPR), and false positive rate (FPR) for varying neuron counts in the hidden layers. The classification tasks include distinguishing between normal and anomaly for binary classification, and five attack types (normal, DoS, probe, U2R, R2L) for multi-class classification. Additionally, the performance of the LSTM-RNN model is compared with traditional machine learning methods using the same feature sets, which were optimized through a genetic algorithm.
