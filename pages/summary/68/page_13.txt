The paper presents the classification performance results of an LSTM-RNN classifier using two different feature sets: all features and an optimal feature set identified through a genetic algorithm. 

In the binary classification scenario using all 122 features, the highest testing accuracy achieved was 96.51%, with a training accuracy of 99.88%, both using five neurons in the hidden layers. For multi-class classification with the same feature set, the highest testing accuracy was 82.68%, with a training accuracy of 99.87%, both achieved with 60 neurons in the hidden layers, as shown in Table 7. The performance metrics indicate a trade-off between precision, recall, and accuracy across different configurations of neurons.

When focusing on the optimal feature set, which includes 99 features, the binary classification results improved significantly. The highest testing accuracy reached 99.91% with a training accuracy of 99.99%, utilizing 40 neurons in the hidden layers, as detailed in Table 8. This improvement emphasizes the effectiveness of feature selection in enhancing classification performance.
