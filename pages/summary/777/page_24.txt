The paper discusses the importance of model weights and biases in deep neural networks, particularly in relation to class scores. It highlights how the weight vector elements signify the relevance of different input features for a specific class. Given the non-linear nature of class scores in deep networks, the authors propose using a first-order Taylor expansion to approximate class scores near a given input vector. This leads to the representation of class scores as a linear function, where the derivative with respect to the input vector helps determine which input features have the most significant impact on class scores.

The authors further argue that the magnitude of this derivative indicates which features are most discriminative for a class, allowing for a better understanding of feature importance. The feature importance for a node in a specific layer is defined mathematically, and a feature importance map is created for each class. The study evaluates the performance of the proposed network using data from the ADHD-200 dataset across three imaging sites, emphasizing the network's ability to discern feature significance in class predictions.
