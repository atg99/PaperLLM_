The paper presents the DeepFMRI architecture, which consists of multiple layers designed for processing brain imaging data. It includes 90 feature extractor networks, each tailored to individual brain regions, sharing the same weights to ensure consistency. The feature extractor networks convert time-series data from these regions into abstract representations. 

The architecture is structured into several components: a feature extractor network, a functional connectivity network, and a classification network. The feature extractor network employs convolutional layers, pooling layers, and batch normalization, with a total of 90,947 weights. The classification network consists of fully connected layers leading to a softmax output. Additionally, the functional connectivity network includes 4,005 similarity measure networks that process abstracted features from pairs of brain regions. 

Overall, the design aims to enhance the extraction and classification of functional connectivity patterns in brain data, leveraging shared parameters across networks for efficient learning.
