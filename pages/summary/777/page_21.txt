The paper discusses an end-to-end model designed for classifying Attention Deficit Hyperactivity Disorder (ADHD) using brain imaging data. It presents a model that consists of two main components: a feature extractor network and a classification network. The feature extractor comprises 90 individual networks, each corresponding to a specific brain region, which generate abstracted features. These features are then integrated into a classification network, which operates without a functional connectivity network, leading to a reduction in the number of parameters compared to the proposed model.

Additionally, the paper introduces the FCNet method, which employs a convolutional neural network (CNN) to extract functional connectivity from pre-processed fMRI signals. The method utilizes an Elastic net to identify discriminant features from the extracted connectivity, followed by support vector machine (SVM) classification to evaluate the results. This approach represents a novel application of CNNs in ADHD classification, marking a significant advancement in the field.
