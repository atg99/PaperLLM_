The paper presents a novel architecture that integrates deep learning and classical machine learning for analyzing fMRI time-series signals, structured into three main modules: feature extractor network, functional connectivity network, and classification network. 

The feature extractor network utilizes a convolutional neural network (CNN) to derive abstract features from pre-processed time-series signals of individual brain regions. This network accepts input signals of length 172 and outputs a vector of size 32, with hyperparameters inspired by existing frameworks rather than tuned on a validation set. The network employs a parametric ReLU activation function, allowing the slope to be learned during training. It consists of two consecutive convolutional layers, each with a kernel size of 3 and specific filter counts, followed by max pooling layers that pool temporally.

The functional connectivity network then processes these abstracted features, calculating the similarity strength between brain regions. Lastly, the classification network utilizes the functional connectivity values to generate final prediction labels.

The overall architecture aims to enhance the understanding of brain connectivity through a structured approach, combining deep learning techniques with traditional methods without being trained end-to-end.
