The classification network described in this paper is designed to produce final classification results based on functional connectivity features derived from brain regions. The network consists of four fully connected layers, culminating in a softmax classifier. Specifically, the layers contain 100, 50, 50, and 2 nodes respectively, leading to a total of 408602 weights, which were initialized randomly.

In the experimental section, the effectiveness of the proposed method for ADHD classification is assessed using the ADHD-200 dataset. This dataset, sourced from various imaging sites, includes separate training and testing datasets, allowing for a fair comparison with existing state-of-the-art methods. The methodology emphasizes the importance of maintaining the integrity of the dataset, avoiding cross-validation due to its limited size. The model trains on the training data from each site and tests on the corresponding test data. The subjects in the dataset are categorized into healthy controls and various ADHD types, but for this study, all ADHD types are grouped to focus on distinguishing between healthy controls and ADHD.

The implementation of the model is done using Python and the TensorFlow deep learning library, with the network being trained in an end-to-end manner.
