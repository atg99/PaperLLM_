The functional connectivity network is designed to assess the connections between different brain regions, as illustrated in Figure 1b. It consists of multiple similarity measure networks, each detailed in Figure 1e, which evaluate the similarity between pairs of features extracted from two brain regions. The calculated similarity serves as an indicator of functional connectivity. Each network processes inputs derived from the feature extractor network, enabling the neural network to identify functionally connected regions through a learned non-linear function, tailored to this specific problem rather than relying on generic measures like correlation.

The architecture of each similarity measure network includes three fully connected layers, with node counts of 32, 32, and 2, respectively. The last layer connects to a softmax layer, resulting in a total of 3202 weights. The output is a two-length vector representing the probability of functional connectivity between the regions.

In this study, all pairs of brain regions are processed through the same similarity measure network, leading to the implementation of 4005 networks due to the combination of pairs. These networks share parameters, akin to a Siamese network approach, ensuring consistent updates across all networks. The results from the functional connectivity network are then directed to a mapping layer for further analysis.
