This paper focuses on the functional connectivity between two brain regions to classify subjects as either healthy controls or those with ADHD using an end-to-end neural network. The classification network consists of multiple layers, receiving functional connectivity data from a mapping layer as input and producing predictions through a softmax layer. During training, the network optimizes parameters based on individual class labels and back-propagates errors from the output layer to the mapping layer. This process helps in learning weights that reflect the importance of functional connectivity features across 4005 pairs of brain regions.

The paper aims to analyze the weights assigned by the classification network to these mapping layer values. Drawing on methodologies used in visualizing feature importance in images and videos, the authors implement a backward pass through the neural network to determine how each mapping layer value influences the final prediction for the classes of interest. Specifically, they focus on how the mapping layer values impact the detection score for either the healthy control or ADHD class. The influence of the mapping layer values is quantified using a linear score model, where the score function is defined in terms of weights and biases associated with the mapping layer values. This approach enables the ranking of functional connectivity features based on their contribution to class prediction.
