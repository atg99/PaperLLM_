The approach involved a neural renderer that allowed the agent to decide on the position and color of each stroke while also organizing these strokes into a cohesive image. The problem was framed as a Markov Decision Process (MDP), where the state included the target image, the current canvas, and the time step. The agent's actions were defined by parameters influencing stroke characteristics, and the reward was derived from the Wasserstein GAN with gradient penalty (WGAN-GP) by evaluating the discriminator score between the target image and the canvas. The actor-critic method was employed for training the agent, utilizing a ResNet18 architecture for stroke parameter prediction.

In a separate application, researchers explored using DRL to guide medical robots through ultrasound images, treating it as a Partially Observable MDP (POMDP). The agent processed ultrasound images to estimate its state and employed Double-DQN and Duel-DQN for Q-value estimation, with a ResNet18 backbone for feature extraction and Prioritized Replay Memory for experience replay. The action space consisted of eight possible movements, while the reward system incentivized proximity to a target position, assigning different values for actions taken.
