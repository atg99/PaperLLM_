Asynchronous Advantage Actor-Critic (A3C) is a strategy for implementing an Actor-Critic agent that operates without experience replay, which can be memory-intensive. Instead, A3C runs multiple agents in parallel across different instances of the environment, allowing each worker to asynchronously update a global network. This asynchronous execution can lead to some workers using outdated parameter values, resulting in suboptimal updates. In contrast, the Advantage Actor-Critic (A2C) method synchronously updates the global network, waiting for all workers to finish their training and compute gradients before averaging and updating the parameters. This synchronous approach enhances training cohesion and efficiency.

A2C also allows each worker to share the same weights and updates them simultaneously, making it more efficient in utilizing GPU resources due to larger batch sizes. To improve the speed of training, GA3C was introduced, achieving significant speed enhancements over CPU implementations. Additionally, a method called FFE has been proposed to encourage random exploration during training, which can enhance performance.

The paper then transitions to model-based algorithms, differentiating them from the previously discussed model-free methods. Model-based approaches learn a transition model to simulate the environment, enabling interactions without direct engagement. While theoretical model-based reinforcement learning (RL) does not necessitate prior knowledge, incorporating it can expedite convergence and improve model training. Challenges arise in high-dimensional and dynamic environments, which are often addressed by using techniques like autoencoders to reduce dimensionality. The literature categorizes model-based deep reinforcement learning (DRL) into three groups, focusing on explicit planning based on transitions.
