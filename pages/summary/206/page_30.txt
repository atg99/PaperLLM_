This paper discusses advancements in active breast lesion detection using deep reinforcement learning (DRL) techniques. It highlights several approaches that utilize a Deep Q-Network (DQN) framework with various actions and states to improve localization and detection accuracy.

Key contributions include:

1. **Active Breast Lesion Detection (2017)**: The approach employs a DQN with 9 actions, including translations and scaling, using a feature vector of the current region as the state. The reward system is based on improvements in localization, achieving comparable true positive and false positive rates to existing methods with reduced mean inference time.

2. **Multitask Object Localization (2018)**: This method utilizes a DQN with 8 actions focused on size and positional adjustments, incorporating historical actions into the state representation. The reward is based on changes in Intersection over Union (IOU). It shows improved mean Average Precision (mAP) over other techniques and performs second best to R-CNN.

3. **Bounding-Box Automated Refinement (2020)**: This technique also uses a DQN with 8 actions for bounding box adjustments. The method combines offline and online implementations with different state representations and rewards based on IOU changes. It demonstrates better final IOU compared to methods like RetinaNet.

4. **Efficient Object Detection in Large Images (2020)**: This approach employs a binary action array for agent decision-making regarding sub-patch acquisition. It utilizes the REINFORCE policy with a ResNet32 policy network and YOLOv3 for object detection, achieving higher mAP and lower runtime compared to other methods.

Overall, the paper emphasizes the effectiveness of DRL in enhancing breast lesion detection and object localization, showcasing improvements in mAP and efficiency over traditional methods.
