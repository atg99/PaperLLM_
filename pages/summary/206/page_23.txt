This paper discusses the application of reinforcement learning (RL) for anatomical landmark localization in 3D medical imaging, specifically focusing on fetal ultrasound images. The RL configuration defines the agent's state at time t as an axis-aligned box of image intensities centered at a voxel position in the image. The agent can move to adjacent voxel positions, and the reward function provides feedback based on the distance to the target structure, rewarding the agent for actions that decrease this distance.

A convolutional neural network (CNN) is utilized to extract deep semantic features, starting the search at the coarsest scale and progressively moving to finer scales. The process involves maximizing the reward, which reflects the change in distance between the ground truth and the predicted landmark location after an action. Experiments conducted on 3D CT scans demonstrated a 20-30% increase in accuracy and reduced distance errors compared to existing methods like SADNN and 3D-DL.

The authors also explore various Deep Q-Network RL models to train agents for precise landmark localization. This approach formulates the problem as a Markov Decision Process (MDP), where the agent learns to make sequential decisions to reach the target landmark. The state is defined as a 3D region of interest, while the reward system reflects the change in Euclidean distance between steps.

Additionally, the paper contrasts traditional policy or value-based methods with an actor-critic based direct policy search approach. Here, the agent's state is based on its position, allowing it to observe a block of surrounding voxels. A binary reward function incentivizes movements closer to the target. The proposed method employs a multi-layer perceptron (MLP) for the non-linear policy function approximator and a separate MLP for the value function, both updated through actor-critic learning. The introduction of partial policy-based RL aims to manage the complexity of localization by learning optimal policies in smaller domains.
