In this section, the paper introduces the concept of the value function and categorizes reinforcement learning (RL) methods into model-based and model-free approaches. It highlights the challenges encountered in RL. The foundation of RL lies in the Markov Decision Process (MDP), which is an extension of the Markov process. An MDP is defined by five key components: 

1. **S**: The set of states or the observation space of the environment, with s0 as the starting state.
2. **A**: The set of actions available to the agent.
3. **T**: The transition probability function, T(st+1|st, at), which defines the probability of moving to state st+1 when action at is taken in state st.
4. **R**: The reward function, where rt+1 = R(st, st+1) represents the reward received for executing action at in state st and transitioning to st+1.
5. **γ**: The discount factor, which affects the importance of future rewards.

The agent selects actions based on a policy π(at|st), which is a strategy that maps states to actions. The interaction between the agent and the environment involves the agent taking an action, receiving a reward, and transitioning to a new state, continuing until a terminal state is reached or a maximum time step is achieved. The tuple (st, at, rt+1, st+1) is defined as a transition, with multiple transitions forming a sequence that the agent learns from.
