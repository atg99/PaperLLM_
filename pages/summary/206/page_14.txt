Value-based Deep Reinforcement Learning (DRL) methods focus on estimating the value of actions in given states to derive optimal policies. The Deep Q-Learning Network (DQN) is a prominent model in this category, utilizing Convolutional Neural Networks (CNNs) to learn from high-dimensional inputs like raw pixels. In DQN, the model outputs a quality function that estimates future rewards. The loss function for training DQN is defined using Mean Squared Error (MSE) between the target value and the predicted Q-value. The target value incorporates the immediate reward and the maximum predicted Q-value for the subsequent state, which is crucial for the learning process.

To update the model parameters, a gradient descent step is employed, minimizing the loss function to improve the accuracy of Q-value predictions. However, DQN is prone to overestimating Q-values due to its reliance on the maximum action value, which can skew the learning process. To address this issue, Double DQN was introduced, which integrates double Q-learning with DQN. This approach mitigates overestimation by decoupling action selection from the value estimation, leading to more reliable Q-value predictions and ultimately enhancing the performance of the DRL model.
