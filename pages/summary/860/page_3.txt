The paper discusses two types of self-attention mechanisms: pairwise and patchwise self-attention. 

In pairwise self-attention, the output at a position \( y_i \) is computed by aggregating features \( x_j \) from a local footprint \( R(i) \) using adaptive weights \( \alpha(x_i, x_j) \). The weights are derived from a relation function \( \delta \) that outputs a vector representing the relationship between feature vectors \( x_i \) and \( x_j \), which is then mapped to weights via function \( \gamma \). Various forms for \( \delta \) are explored, including summation, subtraction, concatenation, Hadamard product, and dot product, each with different dimensionality implications. Additionally, position encoding is introduced to provide spatial context, where normalized coordinates are transformed into position features that are incorporated into the weight computation.

In contrast, patchwise self-attention allows the weight computation to consider all feature vectors within the patch \( x_{R(i)} \). The output \( y_i \) is computed similarly, but the weight vector \( \alpha(x_{R(i)}) \) is derived from all features in the patch, making it more expressive than pairwise attention. The relation function \( \delta(x_{R(i)}) \) combines features from the patch using methods like star-product, clique-product, and concatenation, enabling a more complex interaction between the features.

Overall, patchwise self-attention is presented as a more powerful alternative to convolution, allowing for individualized weight computations that leverage information from multiple feature locations.
