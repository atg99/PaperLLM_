In this section, the paper establishes a non-positivity guarantee for the metric γS(M,N) within a composite linear data generating model. It examines a scenario where both the mapping to the latent space and the task mapping are linear functions. The function classes G and H are defined, where G represents a linear transformation of the feature vector x, and H represents a linear task mapping. The data generation process is described by a linear model, indicating that the response variable y is influenced by a linear combination of the features along with an independent error term ϵ.

The authors propose a specific case where the number of modalities M equals K and N equals K-1. In this context, they present Proposition 1, which asserts that under certain conditions, including the orthonormality of the projection matrix columns, the metric γS(M,N) is guaranteed to be non-positive. This finding implies that training with incomplete modalities diminishes the capacity to learn an optimal latent representation, subsequently leading to a decline in learning performance.

To validate these theoretical insights, the paper outlines an experimental setup using both real-world and synthetic datasets. The real-world dataset employed is the IEMOCAP database, which features three modalities—Text, Video, and Audio—across six emotional labels. The authors detail their training process, which involves a linear neural network with specific dimensional settings for feature extraction and concatenation of modalities prior to mapping. The exploration of the relationship between modality completeness and learning efficacy is a key focus, with future work suggested to further investigate the general case of γS(M,N) being non-positive.
