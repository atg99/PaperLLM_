The paper presents the NDSPI-DQN algorithm aimed at enhancing the performance of curiosity-driven agents in pentesting environments. The algorithm integrates a curiosity module (ICM) that maximizes both internal and external rewards. The ICM consists of an inverse model, which predicts actions based on feature vectors, and a forward model that forecasts the next state based on current state features and actions. Curiosity, defined as the prediction error of the state, contributes to the internal reward through a specific calculation.

The NDSPI-DQN algorithm employs a dueling network architecture with added noise for both the Q-network and the target network. It utilizes a softmax policy for action selection, moving away from the e-greedy policy, to optimize the balance between internal and external rewards. The algorithm also incorporates prioritized experience replay to enhance learning efficiency by focusing on significant transitions.

A key innovation in the approach is the decoupling of actions into two separate streams: one for estimating host values and another for operation values. This separation allows the agent to independently select a target host and the operation to execute, thereby reducing the action space from a combinatorial O(M×N) to a linear O(M+N), where M is the number of hosts and N is the number of operations. This reduction aims to decrease trial-and-error costs during exploration, ultimately improving the agent's efficiency in navigating the pentesting environment.
