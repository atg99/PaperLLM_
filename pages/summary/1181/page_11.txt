The paper discusses the categorization of semi-supervised learning methods, specifically distinguishing between inductive and transductive approaches. Inductive methods aim to create classifiers that can generalize predictions to any input in the feature space, utilizing unlabelled data during training but making predictions independently for new examples post-training. These methods are divided into three main types.

First, wrapper methods train classifiers on labelled data, then use those classifiers to pseudo-label unlabelled data, which is subsequently used to retrain the classifiers. This approach allows for the integration of unlabelled data with minimal changes to the supervised learning algorithms.

Second, unsupervised preprocessing methods focus on extracting features from unlabelled data or pre-clustering it to enhance the performance of supervised classifiers. These methods only provide originally labelled data to the supervised classifier, differing from wrapper methods.

Lastly, intrinsically semi-supervised methods directly incorporate unlabelled data into the optimization process, often extending traditional supervised learning techniques to accommodate semi-supervised settings.

The taxonomy outlined in the paper serves as a framework for understanding and discussing semi-supervised learning methods in greater detail throughout the survey.
