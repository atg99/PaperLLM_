This paper discusses various techniques for channel pruning in neural networks, focusing on methods that enhance sparsity and model efficiency. Ye et al. propose using ISTA to promote sparsity in parameters denoted as γ, leading to the pruning of channels with γ equal to zero. The γ-Wrescaling trick accelerates the sparsification process. Operation-aware Soft Channel Pruning (SCP) incorporates Batch Normalization (BN) and ReLU operations, evaluating both scaling and shifting parameters. Channels with large negative β and large γ are deemed unimportant, employing a cumulative distribution function (CDF) to optimize these parameters.

EagleEye introduces a three-stage pipeline involving random sampling, sub-network generation based on pruning strategies, and an adaptive BN-based evaluation to select the best-performing sub-network. Sparse Structure Selection (SSS) uses an extra trainable parameter θ to enforce sparsity by removing structures when θ falls below a threshold. Generative Adversarial Learning (GAL) prunes structures through a GAN framework with regularization terms to maintain sparsity and performance.

Discrete Model Compression (DMC) employs binary gates for precise pruning effects, using stochastic sampling for subnetworks. Gates with Differentiable Polarization (GDP-Guo) aim to polarize gates for better sparsity representation, while Convolutional Re-parameterization and Gradient Resetting (ResRep) separates model components into remembering and forgetting parts to maintain performance.

Scientific Control Pruning (SCOP) minimizes the influence of input variability by introducing knockoff features, using complementary scaling factors to assess filter importance. Budget-Aware Regularization (BAR) integrates a learnable dropout parameter with a prior loss function to control model budget while employing knowledge distillation to enhance accuracy. Overall, these methods present innovative approaches to improve the efficiency and performance of neural networks through effective channel pruning strategies.
