The paper discusses the advancements in deep reinforcement learning through the introduction of the M-DQN and DM-DQN networks. The M-DQN network, similar to DQN, consists of two neural networks: a Q network that is updated every iteration and a target Q network updated every fixed number of iterations. This structure aims to minimize the correlation between target and current values, thus reducing the overestimation of Q-values.

In contrast, the DM-DQN improves upon the M-DQN by employing a competitive network structure that updates the values of all actions in a state when any Q-value is updated, enhancing estimation efficiency. The DM-DQN architecture separates the value function, which depends solely on the state, from the advantage function, which relates to both state and action. The output of the network combines these two components, allowing for a more comprehensive Q-value representation.

The paper highlights that, unlike M-DQN, which updates only the Q-value of the selected action, DM-DQN prioritizes the update of the average value, leading to simultaneous adjustments of all action values in the state. This approach facilitates faster convergence and accelerates the learning of optimal decisions. The DM-DQN is specifically applied to robot path planning, focusing on scenarios where obstacles are not detected, thereby improving navigational efficiency.
