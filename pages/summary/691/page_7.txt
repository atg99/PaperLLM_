The paper discusses the design of a reward function for mobile robots based on the concept of artificial potential fields. The reward function is divided into two main components: the position reward function and the direction reward function. 

The position reward function includes two parts: the target reward function, which encourages the robot to reach the target quickly, and the obstacle avoidance reward function, which ensures the robot maintains a safe distance from obstacles. The target reward is constructed using a gravitational potential field formula, which calculates the reward based on the distance to the target. The obstacle avoidance reward is based on a repulsive potential field that decreases as the robot approaches an obstacle.

The direction reward function is focused on aligning the robot's movement direction with the expected direction, calculated using the angular difference between actual and expected movement directions.

The total reward function combines these components to guide the robot effectively towards its target while avoiding obstacles. The paper also contrasts this reward function with a simpler version that only considers the distance to the target for evaluation purposes.

Additionally, the paper outlines a path planning algorithm based on a Dueling Deep Q-Network (DM-DQN), which estimates Q values, interacts with the environment using an ε-greedy strategy, and utilizes a replay buffer to optimize learning through regression objectives.

Overall, the work demonstrates a structured approach to reward function design that enhances mobile robot navigation and path planning.
