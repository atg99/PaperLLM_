This paper presents an algorithm for debiasing machine learning models using a bias pseudo-attribute approach. The main goal is to alleviate dataset bias and improve unbiased accuracy by fairly considering all groups during optimization. The method begins with training a base model to generate feature representations, which are then clustered to define groups based on bias pseudo-attributes. The importance of each cluster is quantified using a reweighting scheme that considers both the scale and average difficulty of the clusters, particularly focusing on minority clusters that may be overlooked.

The algorithm consists of two main phases: training the base model and training the target model. The base model is trained using standard classification loss, while the target model is trained using a weighted empirical risk that incorporates the calculated importance weights for each cluster. The importance weights are updated iteratively using an exponential moving average.

Experiments conducted on the CelebA dataset, which includes various facial attributes, demonstrate the effectiveness of this debiasing approach. The proposed method differs from existing group distributionally robust optimization techniques by taking into account the complexity of each cluster rather than solely relying on average losses. The findings suggest that addressing both the size and challenge of minority clusters can significantly enhance model performance in the presence of dataset bias.
