The paper discusses the space complexity of self-attention mechanisms in comparison to traditional recurrent neural network (RNN) architectures, specifically LSTM and QRNN. The analysis builds on Merrill's 2019 work, establishing that saturated single-layer self-attention has a space complexity of Θ(log n). This is demonstrated by showing that the number of different configurations is linear in sequence length, leading to a logarithmic space requirement.

The proof highlights that the internal state of a self-attention layer can be represented by an unordered group of key-value pairs derived from the input sequence. Since the functions mapping inputs to keys and values have finite domains, the possible key-value pairs are finite, allowing for a bounded number of configurations. Consequently, the bit complexity is shown to be O(log n). However, this bound may not hold if unbounded positional embeddings or multiple self-attention layers are used, potentially increasing space complexity to Θ(n).

The paper also addresses stack RNNs, which maintain a differentiable stack for encoding binary representations. Unlike standard RNNs, the stack RNN is shown to have a space complexity of Θ(n) due to the memory demands of the stack data structure. It provides a formal definition of a geometric k-stack RNN encoder and illustrates how it can compute converging binary encoding functions, thus demonstrating its capacity to handle larger space requirements effectively. The findings suggest that while self-attention mechanisms can be efficient, the stack RNN presents a more complex memory structure that allows for richer representations.
