The paper discusses the concept of bit complexity in encoders, defining it in terms of space usage T(n). It categorizes encoders into three classes based on their asymptotic space complexity: O(1), O(log n), and O(n). Encoders with O(1) space can maintain a constant number of configurations, while those with O(log n) space can dynamically count without using complex memory structures. Encoders capable of uniquely encoding every input sequence fall into the O(n) category.

The paper also introduces saturated networks, a discrete approximation of neural networks, which are constructed by taking the limit of parameterized neural encoders as parameters approach infinity. These networks, referred to as s-M, serve as a useful model for analyzing expressive power in neural architectures.

Furthermore, the paper elaborates on recurrent neural networks (RNNs), which utilize a parameterized update function to process sequences. The initial state is defined as zero, and the RNN updates its state as it processes each input vector. Multi-layer RNNs, or "Deep" RNNs, stack multiple layers where outputs from one layer serve as inputs to the next, with only the first layer receiving the original input sequence.

The paper details various forms of RNNs, starting with the Elman RNN, which has a simple structure. It also discusses more complex gated architectures like Long Short-Term Memory (LSTM) and Gated Recurrent Units (GRU). The s-RNN is noted to have O(1) space, while the s-LSTM has O(log n) space, indicating its capability to use memory for counting. In contrast, the s-GRU has O(1) space and lacks dynamic counting capabilities. The distinctions between these architectures highlight their respective strengths in handling sequences and memory.
