This paper discusses the application of the actor-critic method for solving high-dimensional static Hamilton-Jacobi-Bellman (HJB) equations. It begins by addressing the omission of the functional derivative, a common practice in actor-critic algorithms, which can still yield an approximated gradient that aligns with performance improvement under certain conditions. The authors note that while previous work utilized the state-action value function (Q-function), their approach employs the state value function, making it more adaptable for continuous settings.

The paper then transitions to continuous optimal control problems, detailing how the proposed algorithm can be adapted. The value function for a control function is expressed as an expectation of a cost functional, leading to a partial differential equation (PDE) that governs the value function. The authors apply Itô's formula to derive a relationship that links the value function at the initial state to the expected costs over time, incorporating both the effects of the control policy and stochastic elements.

Overall, the paper emphasizes the flexibility and generalizability of the actor-critic method in the context of continuous systems, laying groundwork for further exploration of optimal control strategies.
