The paper discusses the optimization of control policies in high-dimensional systems using numerical algorithms based on the actor-critic framework. It begins by addressing the challenges associated with tracking the functional derivative of the value function with respect to the control variable, particularly in the context of temporal difference learning. The authors propose treating the optimal value function as a fixed function to derive an optimal policy function.

To analyze the optimization process, they introduce a formulation that approximates the functional derivative of the objective function. This is achieved using Itô's lemma to express the expected value of the function in terms of the value function and its derivatives. The authors then transition to the numerical algorithm section, where they present a method for solving high-dimensional Hamilton-Jacobi-Bellman (HJB) type elliptic partial differential equations (PDEs).

For function approximation, the authors propose using two neural networks to represent the value function and control policy. They employ a residual neural network architecture to enhance optimization performance. The gradient of the value function is computed using automatic differentiation, but the authors note that a separate neural network for the gradient often yields better practical results. This leads to the introduction of a third neural network to represent the gradient of the value function.

In summary, the paper outlines a novel approach to optimize control policies in high-dimensional settings, leveraging advanced neural network architectures and the actor-critic framework to effectively manage the complexities of the underlying value functions and their derivatives.
