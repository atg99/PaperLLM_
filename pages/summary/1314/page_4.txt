The paper discusses the integration of cognitive computing within edge computing to enhance the computational capabilities of Internet of Things (IoT) applications. It highlights existing research that has introduced deep learning into edge environments and proposed offloading strategies to optimize IoT deep learning performance, addressing the limited processing power of edge nodes. However, these studies primarily focus on resource allocation using intelligent algorithms, lacking the application of cognitive insights for network-resource optimization.

The proposed Edge Cognitive Computing (ECC) architecture consists of two main components: the edge network and edge cognition. The edge network manages access and resources for various devices, while edge cognition focuses on understanding and processing edge data, including service and resource information. This cognitive framework is divided into two core engines: the data cognitive engine, which employs cognitive computing technologies, and the resource cognitive engine, which utilizes edge computing technologies. 

The interaction between these two engines is crucial for optimizing communication bandwidth and reducing delays by integrating computing, communication, and storage capabilities. The resource cognitive engine is designed to learn and manage edge cloud resources dynamically, ensuring real-time optimization and allocation based on the feedback from the data cognitive engine. Key functionalities of the resource cognitive engine include the establishment of a resource data pool for secure and reliable connections between various devices, and the implementation of network software technologies to enhance the reliability, flexibility, and low latency of the edge cognitive system. 

Overall, the ECC architecture aims to improve network intelligence by effectively combining cognitive and edge computing technologies.
