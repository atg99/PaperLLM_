The paper discusses the integration of data mining, machine learning, deep learning, and artificial intelligence within an edge cognitive computing (ECC) framework. It identifies two primary data sources: external data from applications, such as physical signs and real-time disease risk levels, and internal data regarding computing, communication, and network resources in the edge cloud.

A key focus is on the intelligent enhancement of the data cognition engine, which utilizes multi-dimensional data to improve cognitive computing technology, unlike traditional data analysis methods. The data cognitive engine analyzes existing data through techniques such as deep convolutional networks for facial emotion recognition and hidden Markov models for user mobility prediction. This analysis informs the resource cognitive engine, which interprets the information to generate new insights and adjust resource allocation based on users' health risk levels.

The interaction between the data cognitive engine and the resource cognitive engine is crucial for optimizing network resource management. The paper illustrates this interaction through cognitive network slicing, where the data cognitive engine processes various service requests based on differing demands and conducts cognitive analysis using machine learning and deep learning methods. The resource cognitive engine then optimizes resource efficiency by managing admission control and dynamic resource scheduling.

Additionally, the paper introduces a dynamic cognitive service migration mechanism to address user mobility, device heterogeneity, and network resource dynamics. This mechanism aims to provide elastic cognitive services tailored to individual user demands, highlighting the need for efficient computing resource management due to the high computational demands of cognitive computing.
