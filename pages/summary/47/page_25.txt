The paper discusses the mechanics of a layered recurrent neural network, specifically focusing on the implementation of Long Short-Term Memory (LSTM) units with forget gates. The output unit's activation is defined by an equation involving the summation of gate units influencing the output. The LSTM architecture aims to maintain the integrity of memory cells over time, addressing the issue of cell state growth, which can lead to a degradation of the cell's memorizing ability, causing it to behave like a standard recurrent neural network neuron.

To mitigate this problem, the paper introduces the concept of an adaptive forget gate. This gate allows the network to reset the internal state of the memory cell when the stored information is no longer relevant. The forget gate's activation is computed similarly to other gates in the network, and its weight replaces the fixed weight of one in the self-connection of the cell. The equations governing the forget gate's function are presented, emphasizing the use of a squashing function to constrain its output within a defined range.

The internal cell state update equation is modified to incorporate the forget gate, allowing for a dynamic adjustment based on the relevance of previously stored information. The paper highlights the importance of setting the forget gate's bias to enhance LSTM performance, thereby improving the model's ability to handle continuous input streams without manual state resets. Overall, the discussion illustrates the advancements in LSTM design aimed at optimizing memory management in recurrent neural networks.
