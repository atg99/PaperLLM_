The paper discusses the structure and function of feed-forward neural networks, emphasizing the role of hidden neurons. Feed-forward networks are characterized as loop-free and fully connected, meaning each neuron in one layer connects to all neurons in the subsequent layer without any connections returning to previous layers. The simplest form is the single-layer perceptron, which consists of an input layer and an output layer, where input neurons directly connect to output neurons with weighted connections. Each perceptron computes the weighted sum of inputs and activates based on a threshold value, typically zero.

Multilayer feed-forward networks include one or more hidden layers, allowing for more complex representations. These networks can model non-linear decision surfaces effectively, especially when using sigmoid activation functions and a sufficient number of hidden units. The paper also highlights the error backpropagation algorithm as the predominant learning method for these networks, employing gradient descent to adjust weights through iterative steps from the output layer back to the input layer. A key requirement for this algorithm is that the activation function must be differentiable.
