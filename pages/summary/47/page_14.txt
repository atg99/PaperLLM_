The paper discusses a simple fully recurrent neural network illustrated in two figures. Figure a depicts the network structure with a two-neuron layer, while Figure b shows the same network unfolded over time as a feed-forward neural network. The relationship between the output and the weighted input is defined mathematically, with the output yu at time t being a function of the weighted input zu at time t+1. The weighted input is influenced by both environmental inputs and recurrent outputs from other non-input units in the network.

The paper introduces the set T(t), which includes non-input units whose output must match target values at a specific time. It defines a cost function, Etotal, which sums the errors over a specified epoch, aiming to minimize this using a learning algorithm. The error at each time step is calculated using a squared error objective function, where the error for each unit is defined based on whether it belongs to the target set T(t). This framework establishes a basis for training the recurrent neural network to align its outputs with predefined target values.
