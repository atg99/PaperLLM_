The paper discusses the initialization of bias weights in Long Short-Term Memory (LSTM) networks, specifically noting that input and output gate biases are set to negative values while the forget gate biases are initialized with positive values. This configuration leads to the forget gate activation being close to 1.0 at the start of training, causing the memory cell to function similarly to a standard LSTM without a forget gate. This design choice ensures that the memory cell retains information until it has learned sufficient patterns.

In the backward pass of training, the paper outlines how LSTM combines elements from Backpropagation Through Time (BPTT) and Real-Time Recurrent Learning (RTRL). It distinguishes between two types of units: those whose weight updates are calculated using BPTT (output units, hidden units, and output gates) and those using RTRL (input gates, forget gates, and memory cells).

The network error at a specific time step is defined, and the individual error for each unit is introduced. The weight contribution for output units is derived from the individual error, while a similar approach is taken for hidden units, incorporating the contributions from output units. This structured approach allows for effective computation of weight updates, crucial for training LSTM networks.
