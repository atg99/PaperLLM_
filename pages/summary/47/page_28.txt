The paper discusses the computation of the derivatives of the state of a Long Short-Term Memory (LSTM) network with respect to weight parameters for various types of gates. Specifically, it details how these derivatives differ based on whether the unit being considered is a memory cell, an input gate, or a forget gate. The equations provided outline the relationships and dependencies for each case, indicating how changes in weights affect the state of the LSTM.

Additionally, the paper addresses the complexity of LSTM networks, following principles from previous work. It defines a complexity measure based on the number of memory blocks, memory cells, input units, and output units. The derived complexity indicates that the operations related to connections and weight updates scale quadratically with the number of memory blocks and cells, but the computational complexity per step and weight remains constant, O(1).

Lastly, the strengths and limitations of LSTM networks are highlighted, particularly their effectiveness in tasks requiring the retention of information over extended periods due to the architecture of memory blocks and their gating mechanisms. These features enable LSTMs to manage access control to memory, enhancing their performance in sequential data processing tasks.
