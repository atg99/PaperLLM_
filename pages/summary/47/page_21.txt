Figure 10 illustrates a standard Long Short-Term Memory (LSTM) memory block. This block features a cell with a recurrent self-connection, where the weight is set to one. The cell's state is represented as sc. The read and write operations are controlled by the input gate (yin) and the output gate (yout). The internal cell state is determined by multiplying the squashed input (g) with the input gate (yin) and adding the previous time step's state (sc(t-1)). The output of the cell is then calculated by multiplying the cell state (sc) with the output gate's activation (yout).
