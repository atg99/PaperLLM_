The paper discusses an optimization problem involving the maximization of a similarity function with respect to a distribution \( q \) over classes, incorporating an entropy regularizer. The formulation leads to a closed-form solution for \( q \) based on the exponential function of the similarity between examples and class centers. This results in a relaxed similarity metric, denoted as \( S'_{i,c} \), which is used to define the Soft-Triplet loss function.

The Soft-Triplet loss is framed as a logarithmic function that distinguishes between the correct class and others, enhancing the model's ability to differentiate classes effectively. The paper illustrates how this approach differs from traditional SoftMax loss by increasing the dimensionality of the fully connected (FC) layer to accommodate multiple centers for each class and employing various operators to compute similarities.

Theorem 1 establishes that using centers to construct triplet constraints preserves the margin property of original triplet constraints. It suggests that having more centers can reduce intra-class variance while noting the trade-off between the number of centers and computational efficiency. An excessive number of centers can slow optimization and lead to overfitting.

To address the challenge of selecting the appropriate number of centers, the authors propose starting with a larger number of centers and allowing similar centers to merge, balancing the need for diversity in representation while minimizing the number of unique centers. This adaptive strategy aims to optimize the learning process while managing complexity effectively.
