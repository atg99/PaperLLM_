The paper presents ModelKB, a local software library designed to automate the modeling lifecycle, specifically focusing on services for remote sharing and deployment. Developed using Python, ModelKB integrates various tools and methods to streamline management tasks such as data visualization and model deployment. Key technical contributions include unifying lifecycle management within a single system, utilizing Python Callbacks for metadata extraction, Abstract Syntax Trees (AST) for data provenance tracking, and Jinja template language for automatic code generation.

ModelKB's architecture comprises several components, including a Metadata Extractor for automatic metadata extraction from deep learning frameworks, a Local Repository for storing metadata and artifacts, and a Visualization component for project and experiment insights. The system also includes functionalities for model sharing and publishing, with a cloud-based server that provides REST APIs for inference tasks.

The automatic metadata extraction feature is crucial, as it gathers various types of metadata essential for the modeling lifecycle, such as hyperparameters, learned parameters, and context metadata. The paper outlines the types of metadata extracted from experiments, emphasizing their importance in guiding the modeling processes. Overall, ModelKB aims to enhance user experience through an intuitive GUI and abstract APIs, facilitating easier interaction within various integrated development environments.
