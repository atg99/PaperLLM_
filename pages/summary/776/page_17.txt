ModelKB is designed to streamline the deployment of trained models, offering automatic deployment locally and semi-automatic deployment on the cloud with a user-friendly "one-click" option from the graphical user interface. The system utilizes a templating engine to automatically generate inference functions and wraps them in Docker containers for cross-platform compatibility. 

To create these inference functions, ModelKB employs a set of Jinja templates that parse collected metadata, resulting in Python functions that are aware of data types, sizes, preprocessing steps, libraries, dependencies, and model output specifications. The deployment templates accommodate various data types, including tabular, textual, and image data. 

Once an inference function is generated, ModelKB handles the parsing of necessary configurations and dependencies, such as deep learning platform versions, to build Docker containers for local and cloud deployment. The system also generates REST APIs for inference and downloading Docker images. For cloud deployment, users must provide authentication details for their hosting service. The containers are served on the Kubernetes system via remote procedure calls, and users do not need in-depth knowledge of the underlying functions, as ModelKB manages the setup of containers and protocols. However, users are responsible for verifying the accuracy of the generated inference functions, which may require additional information not included in the metadata.

In addition to deployment, ModelKB facilitates model sharing among users, accommodating both users of ModelKB and those who are not.
