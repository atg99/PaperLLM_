This paper discusses the integration of ModelKB with Keras and PyTorch for managing deep learning projects. It highlights that while the usage in Keras is straightforward, requiring only the appropriate Callback name from TensorFlowCallbacks, the management of experiments is significantly enhanced through a hierarchical organization. Users can create a project by declaring an experiment object with a project name, which groups multiple experiments related to the same modeling task.

Each project is assigned a unique identifier, timestamp, and username, allowing for the automatic management of experiments without the need for users to rename each one. For instance, a developer can initiate an experiment named 'FaceDetector' and explore various hyperparameters without changing the project name. ModelKB automates the management tasks, reducing the overhead for users.

In contrast, PyTorch requires users to implement their own training steps since it lacks a predefined function for training and evaluation. The paper explains the typical training cycle in PyTorch, which involves feeding data through the model, calculating loss, and updating weights in a loop for multiple epochs. To streamline the use of ModelKB with PyTorch, the authors developed a high-level function wrapper called fit and created the necessary Callbacks for metadata extraction. This approach simplifies the process of managing experiments in both frameworks.
