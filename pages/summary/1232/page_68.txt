The section discusses the concept of variable importance (VI) in the context of random forests (RF) and how it is affected by the presence of highly correlated variables. It highlights that masking effects can occur when a dominant group of correlated variables overshadows other informative variables. For a stable evaluation of VI, it is essential to utilize large forests with numerous trees and to conduct multiple repetitions to assess variability.

The focus then shifts to RF prediction performance, particularly through estimating generalization error using out-of-bag (OOB) error and quantifying permutation-based variable importance. The process to calculate permutation-based VI is described, requiring the inclusion of the option importance = TRUE in the randomForest function. An example is provided using the spamApp dataset, where the variable importance is visualized using the varImpPlot function. This plot reveals a primary group of significant variables, with the most critical variable, capitalLong, not appearing in any splits of the optimal tree, illustrating that a variable can still hold importance even if it does not directly minimize heterogeneity.

Remark 4.1 notes that the varImpPlot function can be used to display variable importance in descending order, specifically emphasizing the use of type = 1 for permutation-based VI and scale = FALSE for raw importance values. The work of Gregorutti et al. is referenced, extending permutation-based VI to groups of variables, indicating a strategy for variable selection in multivariate functional data by permuting entire groups of correlated variables.
