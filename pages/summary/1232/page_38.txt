The analysis focuses on the relative errors associated with pruning subtrees from a maximal tree, as illustrated in Figure 2.11. The optimal complexity parameter (cp) is identified through the minimum error, leading to the pruning of the tree to create a more compact model with only six leaves, as shown in Figure 2.12. This model emphasizes splits on two of the three significant variables, while the variable V2 may be deemed unimportant based on permutation variable importance analysis in random forests.

The dataset contains a considerable amount of missing data, which is managed effectively by the rpart() function during the learning phase without requiring imputation. The method involves eliminating observations with missing target values or those with all predictor variables missing. For node splits, impurity reductions are calculated using available data, and missing values for the split variable are handled through surrogate splits or by routing to the most frequent node. The impurity reduction weights are subsequently updated to reflect the new data routing.
