The paper discusses the performance comparison between the randomForest and ranger packages for executing random forest algorithms, particularly in the context of high-dimensional data. Table 3.3 presents median execution times from 25 runs, showing that ranger generally outperforms randomForest in both formula and x, y formats. The ranger package also supports native parallel computing by adjusting the num.threads parameter, enhancing efficiency further, especially as data dimensions increase.

The paper then shifts focus to analyzing dust pollution using the randomForest package with a dataset from the JUS station included in the VSURF package. After loading the necessary libraries and data, a dataframe is created without missing values. The random forests technique is employed to visualize the impact of various variables on PM10 pollution levels, allowing for the identification of significant pollutants and weather variables. The method for estimating the marginal effect of a variable involves approximating the expected value while holding other variables constant, using an empirical mean to represent the regression function.
