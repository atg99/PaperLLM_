In this section, the paper discusses the parameter settings for prediction in the context of random forests, specifically focusing on the mtry parameter and its effect on out-of-bag (OOB) error in spam classification. The analysis reveals that when mtry is set too low, OOB error is high, particularly when mtry equals one, leading to random variable selection at each node. As mtry increases, OOB error decreases until it reaches a minimum point, after which the error begins to rise again. This behavior contrasts with regression scenarios, where OOB error typically decreases with higher mtry values, with the default set to p/3 compared to the square root of p in classification.

The section also highlights the importance of tree diversity, using a simple example of Bagging with 100 two-leaf trees, or stumps. This setup allows for an examination of which variables were utilized to split the root node across the ensemble of trees, emphasizing the concept of variable importance in the model. For a more in-depth understanding of the mtry parameter, the authors reference additional literature, specifically Genuer et al. (2008).
