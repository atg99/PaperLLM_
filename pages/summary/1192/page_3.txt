The proposed framework, CCSSL, focuses on improving semi-supervised learning (SSL) using a structured approach to handle unlabeled images. The process begins with weakly augmented views of unlabeled images that are processed through a semi-supervised module, which generates model predictions using pseudo-labels. These pseudo-labels are then used to create a supervised contrastive matrix based solely on class-level information. To mitigate confirmation bias, a class-aware contrastive matrix is developed through image-level contrasting of out-of-distribution data. A re-weighting module is applied to prioritize learning from clean data, resulting in a final target matrix. Additionally, a feature affinity matrix is constructed using strongly augmented views, and the class-aware contrastive module is designed to minimize the cross-entropy between this affinity matrix and the target matrix.

The paper also discusses the background of self-supervised learning (SSL), tracing its evolution from noise contrastive estimation to contemporary methods like MoCo and SimCLR, which learn image representations by contrasting similar and dissimilar samples. The authors highlight that traditional contrastive learning methods can overlook the conflict between image-level feature repulsion and class-level clustering, which CCSSL addresses by integrating class-level information.

Furthermore, the paper examines challenges in learning from real-world unlabeled data, particularly the issues arising from out-of-distribution data and class imbalance, which can lead to confirmation bias and suboptimal performance compared to supervised learning. The authors reference existing open set classification methods that aim to differentiate known from unknown categories but note their limited generalization in real-world scenarios. By focusing on alleviating confirmation bias, this work seeks to bridge the gap between theoretical research and practical applications in real-world settings. 

The method is formally defined in a semi-supervised classification context, where a batch of labeled data and unlabeled data are considered, and the hyperparameter µ controls their ratio. This structured approach aims to enhance the performance of SSL in practical applications.
