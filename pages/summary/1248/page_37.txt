The paper discusses the application of XGBoost for predicting bank failure while addressing the challenge of overfitting. To prevent overfitting, the authors tuned and selected optimal model parameters using cross-validation. They employed Occam’s razor, which suggests that simpler models are preferable when explaining an event. A new XGBoost model was developed using only four key variables: P11, P9, C13, and P1. The results indicated that this parsimonious model achieved a high predictive accuracy of 94.74% and an AUC value of 0.928 when tested. This demonstrates that a simplified approach, focusing on the most significant variables, can effectively predict bank failures using the XGBoost algorithm after appropriate parameter tuning.
