The paper introduces a novel Point 4D Transformer (P4Transformer) designed for processing point cloud videos, focusing on 3D action recognition and 4D semantic segmentation. The architecture combines point 4D convolution and transformer mechanisms to effectively capture spatio-temporal structures without the need for point tracking.

Key components include:

1. **Point 4D Convolution**: This method encodes spatio-temporal local structures from point cloud videos, using parameters such as temporal radius and spatial radius to create local areas. The convolution extracts local features and reduces the number of points for subsequent processing.

2. **Transformer**: The transformer captures appearance and motion information across the entire video sequence by employing self-attention mechanisms. It enhances local features with information from related areas.

3. **Application**: The P4Transformer is applicable to both 3D action recognition and 4D semantic segmentation. For action recognition, a max pooling layer merges local features into a global representation for classification. For semantic segmentation, feature propagation layers interpolate features back to the original point cloud size, allowing for detailed point predictions.

The proposed approach utilizes the strengths of both convolutional and transformer architectures, aiming to improve performance in tasks involving complex point cloud data while maintaining efficiency and accuracy in processing.
