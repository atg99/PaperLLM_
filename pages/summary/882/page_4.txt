The paper presents a novel approach for texture transfer using a new loss function called PatchCLIP, which addresses limitations of existing CLIP losses. The goal is to apply the semantic texture of a style image to a content image effectively. The authors note that solely using the existing directional CLIP loss (Ldir) does not yield high-quality results, prompting the development of PatchCLIP.

PatchCLIP loss is inspired by the original style loss concept from Gatys et al. It minimizes CLIP loss functions over groups of randomly cropped patches from the content image, applying random geometrical augmentations to enhance texture representation. The method aims to ensure that patches maintain consistent semantic information across different perspectives, contributing to a more three-dimensional structure.

To counteract over-stylization caused by the randomness in patch sampling and augmentation, the authors introduce a threshold rejection mechanism. This mechanism nullifies the loss for high-scored patches, thereby regulating the optimization process.

The total loss function combines four components: the standard directional CLIP loss (Ldir) for global features, the proposed PatchCLIP loss (Lpatch) for local textures, a content loss (Lc) based on mean-square error from VGG-19 features, and total variation regularization loss (Ltv) to minimize irregular pixel artifacts.

Experimental settings include using a 512x512 resolution for content images, with specific parameter values for losses to achieve optimal results. The architecture employed is a lightweight U-net, and the network is trained using the Adam optimizer. Patch cropping is set to a size of 128, and a total of 64 patches are used, with perspective augmentations applied to enhance visual quality. A prompt engineering technique is also utilized to reduce noise in text embeddings.

In conclusion, the proposed PatchCLIP loss and its integration with existing loss functions demonstrate significant improvements in texture transfer quality, as supported by the experimental results. The authors provide supplementary materials for further details and a GitHub repository for implementation.
