The paper discusses a novel approach to semantic segmentation using a Recurrent Criss-Cross Attention (RCCA) module. The RCCA module enhances pixel-wise representation by aggregating contextual information in horizontal and vertical directions through a lightweight computation framework. 

Initially, feature maps are generated from input images using convolutional layers to reduce dimensions. These feature maps are then processed through the criss-cross attention module, which creates attention maps to collect contextual data relevant to each pixel. This process is repeated, allowing each pixel to gather information from all other pixels, thus enhancing the feature representation.

The attention mechanism involves generating feature maps Q and K, followed by an affinity operation to assess correlations between these features. A softmax layer is applied to derive attention maps, which guide the aggregation of contextual information. The final output combines local and contextual features, improving segmentation performance.

The design of the RCCA module aims to avoid excessive parameter addition by sharing parameters between the two attention modules. The fusion of dense contextual features with local representations is achieved through additional convolutional layers, culminating in a segmentation layer that produces the final segmentation output. The method claims to be more effective for semantic segmentation due to its ability to model full-image dependencies with efficient computational resources.
