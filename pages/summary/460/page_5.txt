The paper discusses the preprocessing steps and methodologies used to prepare images for the SegNet model in deep learning applications, specifically in the context of medical imaging. Initially, images were converted into a three-channel format resembling the RGB color space by duplicating slices and resizing them to dimensions of 360 x 480 x 3. However, these images exhibited low contrast, rendering them unsuitable for deep learning applications.

To enhance system performance, data augmentation techniques were employed, including affine transformations like flipping, rotation, and mirroring, alongside color value adjustments. Previous studies, such as those by Perez et al., have shown that traditional augmentation methods can improve classification results by approximately 7%.

The paper compares the efficacy of Convolutional Neural Network (CNN) features against traditional feature extraction methods such as Local Binary Patterns (LBP), Gray Level Co-occurrence Matrix (GLCM), Wavelet, and Spectral analysis. Although CNN training is time-intensive, it allows for effective feature extraction, proving superior in classification tasks. The training process involved batching training data, applying data augmentation, and utilizing this augmented data in the training algorithm.

Finally, the classification results were evaluated against ground truth data on a pixel-to-pixel basis, using a confusion matrix to compute key metrics such as sensitivity, specificity, and accuracy. These metrics are essential for assessing the performance of the classification model in distinguishing between different classes in the dataset.
