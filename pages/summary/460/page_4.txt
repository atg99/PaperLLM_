The paper discusses the use of semantic image segmentation techniques, particularly focusing on a fully convolutional network architecture for medical images. It highlights the SegNet model, which was proposed by Badrinarayanan et al. for scene understanding. SegNet consists of an encoder network, a decoder network, and a pixel-wise classification layer, with the encoder resembling the VGG-16 network's convolutional layers. A key feature of SegNet is that it saves the indices of selected pixels during downsampling rather than the pixel values, allowing for more efficient memory usage and performance compared to other models like Fully Convolutional Networks (FCN) and U-Net.

The methodology section outlines the steps for liver tumor segmentation using the 3D-IRCADb-01 dataset, which includes CT scans from 20 patients. Each scan has a resolution of 512 x 512, and the dataset contains labeled images for ground truth. The preprocessing phase involves converting DICOM images to PNG format to maintain image quality, as DICOM pixel values are in Hounsfield units, which can complicate display and processing. The conversion formula is provided to map Hounsfield values to a positive 1-byte integer range, facilitating further image processing tasks.
