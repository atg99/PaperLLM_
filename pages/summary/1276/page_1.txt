The paper introduces the Efficient Channel Attention (ECA) module, which enhances the performance of deep convolutional neural networks (CNNs) while maintaining low model complexity. The authors note that existing channel attention mechanisms often increase complexity without significant performance gains. Through an analysis of the channel attention module in SENet, they emphasize the importance of avoiding dimensionality reduction and promoting appropriate cross-channel interaction to preserve performance.

The proposed ECA module employs a local cross-channel interaction strategy, implemented using 1D convolution, which avoids dimensionality reduction. Additionally, the authors develop a method to adaptively select the kernel size for 1D convolution, allowing for effective local interactions. The ECA module is shown to be efficient, with significantly fewer parameters and computations compared to the ResNet50 backbone, while achieving over a 2% improvement in Top-1 accuracy.

The paper evaluates the ECA module across various tasks, including image classification, object detection, and instance segmentation, using ResNets and MobileNetV2 as backbones. Results indicate that ECA is both efficient and effective, outperforming other attention mechanisms in terms of accuracy while reducing complexity.
