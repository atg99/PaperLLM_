The sparsebn package, as detailed in the Journal of Statistical Software, implements four structure learning algorithms tailored for specific types of data: experimental Gaussian data, experimental discrete data, observational Gaussian data, and observational discrete data. This versatility allows sparsebn to manage datasets that include both observational and experimental data. The algorithms are developed in C++ using Rcpp and are part of a family of R packages that ensure cross-compatibility with minimal external dependencies.

The package includes several algorithms, such as ccdrAlgorithm, discretecdAlgorithm, and sparsebnUtils, each designed for rapid development and extensibility. This modular approach facilitates the addition of new algorithms and features without significant compatibility challenges.

Sparsebn is optimized for large, high-dimensional datasets, capable of handling thousands of variables. Comparative analyses show that it significantly outperforms other algorithms like the PC algorithm from the pcalg package and the MMHC algorithm from the bnlearn package, particularly for large graphs. For instance, sparsebn is reported to be 17 times faster than the PC algorithm and 52 times faster than MMHC for the largest graph tested (with 1090 nodes). These performance enhancements are achieved through an efficient block coordinate descent algorithm that utilizes warm starts and active set updates, contributing to its scalability and speed.
