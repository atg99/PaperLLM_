In this section, the paper discusses three examples demonstrating the functionality of the sparsebn package for learning Bayesian networks. The first example involves discrete cytometry data, utilizing a cleaned and discretized version of the original continuous dataset provided by Sachs et al. (2005). The continuous measurements were binned into three categories: low, medium, and high, resulting in a total of 5400 observations.

To analyze this discrete data, users follow similar steps as with continuous data. The data is loaded using the sparsebn library, and a sparsebnData object is created to encapsulate the necessary information for algorithm execution. The example illustrates that, despite the differences in data types, the process of estimating a directed acyclic graph (DAG) remains consistent with previous sections, highlighting the package's versatility in handling various data formats. The code snippets provided demonstrate how to convert the data and estimate the DAG using the estimate.dag function.
