The paper discusses the software and techniques used for conducting experiments on various machine learning methods. Table 4 lists the software associated with each technique, including hmmlearn for Hidden Markov Models (HMM), XGBoost for XGBoost, sklearn for AdaBoost and Random Forest, and Keras with TensorFlow for Convolutional Neural Networks (CNN) and Long Short-Term Memory (LSTM) networks. 

The authors conducted bagging and boosting experiments, which indicated that these methods can enhance the performance of the baseline techniques. Additionally, stacking experiments were performed using simple voting schemes based on previously mentioned architectures, revealing the potential advantages of combining multiple techniques.

In Section 3.5, the paper outlines the standard techniques tested, which include HMM, CNN, Random Forest, and LSTM. Table 5 details the parameters tested for each method, highlighting the best-performing parameters in bold. For example, the Random Forest model explored 2250 different parameter combinations.

The results of these experiments, evaluated using metrics such as accuracy, balanced accuracy, precision, recall, and F1 score, are summarized in Section 3.9, with confusion matrices provided in the Appendix.
