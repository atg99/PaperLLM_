The paper discusses various neural abstractive text summarization techniques, particularly focusing on sequence-to-sequence models. One key method is the Switching Generator-Pointer, which utilizes a switch to determine whether to generate a token from the vocabulary or point to a token in the source text at each decoding step. This mechanism is mathematically modeled to allow flexibility in token generation.

Another important framework is CopyNet, which features a differentiable architecture that enables end-to-end training. It combines generate-mode and copy-mode probabilities to create an extended vocabulary that includes both source tokens and unique vocabulary tokens.

The Pointer-Generator Network is also highlighted, which shares similarities with CopyNet but introduces a soft-switch mechanism to transition between generating and copying tokens. This model has been foundational for many abstractive summarization approaches.

Additionally, the paper addresses the challenge of repetition in generated sequences, particularly in attention-based models. Repetitions can occur at both the word and sentence levels, which is especially problematic in multi-sentence summaries. Techniques to mitigate these issues are critical for improving summarization quality.
