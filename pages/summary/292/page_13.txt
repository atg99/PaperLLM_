This survey paper discusses various attention mechanisms in computer vision, highlighting their evolution and applications. It begins with the Vision Transformer architecture, which processes images by dividing them into patches and utilizing a transformer encoder for feature extraction. The paper emphasizes advancements in self-attention, particularly in reducing computational complexity while maintaining accuracy.

Key contributions include CCNet, which transforms self-attention into a graph convolution approach, using criss-cross attention to improve efficiency. EMANet introduces EM attention, leveraging the expectation maximization algorithm to minimize the number of basis points used, thus enhancing performance. ANN proposes spatial pyramid pooling to focus on representative features, reducing redundancy in positional data. GCNet optimizes attention maps by using a shared map for all query points, while A2Net distinguishes between feature gathering and distribution through different attention types.

Furthermore, GloRe applies a graph learning perspective to self-attention, organizing input features into nodes and learning their interactions for global information dissemination. OCRNet introduces object-contextual representation, which aggregates representations from similar object regions, leading to gains in both speed and effectiveness.

Overall, the paper illustrates how these innovations address the limitations of traditional self-attention mechanisms, paving the way for more efficient and effective applications in computer vision.
