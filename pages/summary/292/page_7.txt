This paper surveys various attention mechanisms in computer vision, specifically focusing on novel modules that enhance network performance while addressing computational efficiency. 

The lightweight style-based recalibration module (SRM) combines style transfer with attention mechanisms, utilizing style pooling, which incorporates the mean and standard deviation of input features to capture global information effectively. SRM employs a channel-wise fully connected layer to reduce computational demands, allowing it to be integrated after each residual block.

The gated channel transformation (GCT) addresses the impracticality of using fully connected layers in excitation modules by explicitly modeling channel-wise relationships. GCT computes the l2-norm for global information, applies a learnable scaling vector, and utilizes a competition mechanism through channel normalization. It introduces a tanh activation to control the attention vector while maintaining an identity connection, making it lightweight and suitable for use after each convolutional layer.

The efficient channel attention (ECA) block offers a solution to the high model complexity associated with SENet by employing a 1D convolution to establish direct interactions between channels rather than reducing dimensionality. ECA includes a squeeze module for global information aggregation and an efficient excitation module that focuses on local cross-channel interactions, with an adaptively determined kernel size for coverage.

Overall, these attention mechanisms enhance the performance of convolutional neural networks by improving how they model relationships between features while remaining computationally efficient.
