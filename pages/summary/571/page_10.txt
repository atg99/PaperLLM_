A two-way ANOVA was conducted to evaluate the differences in final classification accuracies across six techniques, utilizing both intra-subject and inter-subject approaches. Post-hoc analysis with Tukey HSD was performed when statistical significance was established.

In the results, hyperparameters and kernels were selected based on inner-fold validation accuracy. For intra-subject optimization, the polynomial kernel was predominantly chosen for training the support vector machine (SVM), while a C value of 100 was frequently utilized. Significant effects of kernel and C value were observed for words data, contrasting with the vowels data where no significance was found. The selected hyperparameters for training across subjects included the polynomial kernel and a g value of 10, differing only in C values between words and vowels datasets.

For the random forest (RdF) classifier, the number of trees was most commonly set to 50, with the maximum split level (MSL) typically chosen as 2. Despite some tendencies towards significance in the hyperparameter variations for both words and vowels, none reached statistical significance. The inter-subject selection exhibited consistency in the number of trees and MSL across datasets, while the number of features varied between words and vowels.

Overall, the study provides insights into the effects of hyperparameter selection on classification accuracy, highlighting the importance of kernel and parameter choices in optimizing machine learning classifiers.
