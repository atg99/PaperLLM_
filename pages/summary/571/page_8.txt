The paper presents an algorithm for nested cross-validation (nCV), aimed at optimizing hyperparameters (HPs) for various classifiers using a structured approach. The input data consists of a dataset D with features and corresponding labels, and the process involves partitioning the dataset into outer and inner folds for training and validation.

Two strategies for HP optimization are compared: an intra-subject approach, where each participant’s data is used to select tailored HPs, and an inter-subject approach, which employs a single set of HPs based on averaged validation accuracies across all subjects.

The study focuses on three classifiers: Support Vector Machines (SVM), Random Forests (RdF), and a Filter Bank Common Spatial Pattern combined with Linear Discriminant Analysis (FBCSP-rLDA). For SVM, the optimization includes various kernel types and values for the regularization parameter and kernel coefficient. For RdF, the number of features, number of trees, and minimum samples at leaf nodes are evaluated. FBCSP-rLDA optimization considers the number of spatial filter pairs, mutual information quantization levels, and the number of features per trial.

Additionally, the study investigates the impact of HP optimization on three distinct Convolutional Neural Networks (CNNs), using a consistent set of HPs across all networks. The evaluated HPs for CNNs include activation functions, learning rates, training epochs, and loss functions, with a particular focus on the Exponential Linear Unit (ELU) activation function.

This comprehensive evaluation of HP optimization strategies and their effects across different classifiers provides insights into enhancing model performance in machine learning applications.
