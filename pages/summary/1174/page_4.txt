The paper addresses the FAIR(k,p)-CLUSTERING problem, which involves selecting a subset of at most k facilities from a set F and assigning clients to these facilities while adhering to fairness constraints. The primary objective is to minimize the Lp loss function Lp(S;φ) associated with the assignment φ, which maps clients C to the selected facilities S. The fairness constraints include the restricted dominance property (RD) and the minority protection property (MP), which ensure that each group i is adequately represented in the clusters formed around each facility.

The authors define a fair clustering solution as a tuple (S,φ) that satisfies these constraints. They establish a relationship between the optimal values of the FAIR and vanilla clustering problems, showing that any fair solution is also a vanilla solution, thus OPTvnll(I) ≤ OPTfair(I).

The paper introduces the concept of λ-additive violation, indicating that a solution can deviate from the fairness constraints by a margin of ±λ. The main result is that if a ρ-approximate algorithm exists for the vanilla problem, a (ρ+2)-approximate solution can be derived for the FAIR problem with a violation of (4∆+3). This approximation holds for any ℓp norm, and for the specific case of ∆ = 1, the violation is limited to +3.

The proposed algorithm consists of two steps: first, it solves the VANILLA(k,p)-CLUSTERING problem using an existing algorithm A to determine the set of facilities S. Second, it solves the FAIRp-ASSIGNMENT problem to assign clients while ensuring that the fairness constraints are met. The authors also present a reduction from the FAIR(k,p)-CLUSTERING problem to the FAIRp-ASSIGNMENT problem, enabling the use of a vanilla clustering solver as a black-box. The results indicate that this approach yields a (ρ+2)-approximation algorithm for the FAIR problem with λ-additive violation.
