The paper investigates the impact of the number of features used in Visual Question Answering (VQA) models, focusing on the differences between region and grid features. The findings indicate that the accuracy of region features saturates around 200 regions, while grid features continue to improve with an increased number of input features, achieving higher accuracy even when the number of regions is maximized.

In experiments, the authors compare the performance and inference time of both feature types on the VQA 2.0 test-dev set. Results show that grid features not only match the accuracy of region features but also significantly reduce inference time, running 48 times faster due to the elimination of additional operations required for region feature computation and selection.

The paper also includes a qualitative analysis, utilizing attention maps to visualize how each feature type captures relevant concepts in images. While region features focus on object-like areas, grid features cover broader regions, suggesting that while localization is important, precise object detection may not be essential for effective VQA.

The authors conclude that grid features, despite being previously established in vision tasks, provide a more efficient and effective alternative to region features for VQA, highlighting the need for specialized modules in cases of failure for both feature types.
