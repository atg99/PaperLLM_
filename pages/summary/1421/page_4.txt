The paper presents a comparison of region-based and grid-based features for visual question answering (VQA) using a Faster R-CNN model with a ResNet-50 backbone. The study highlights the differences between bottom-up attention methods and grid feature extraction from the same convolutional layer (C5). Key findings include that grid features from C5 yield performance close to that of bottom-up attention, while ImageNet pre-trained models perform significantly worse. The introduction of a 1×1 RoIPool variant improves VQA accuracy but reduces object detection performance on Visual Genome (VG).

The authors detail their experimental setup, including training configurations and the creation of a local validation set. Their results indicate that while region features generally perform better in object detection tasks, grid features can outperform them in VQA scenarios. The findings suggest that the original model architecture favors region features, but the modifications made enhance grid feature performance. The results underscore the potential of grid features in VQA tasks, paving the way for further exploration in combining vision and language understanding.
