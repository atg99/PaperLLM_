This paper discusses a framework for enhancing the performance of deep learning models through a dual-phase training strategy comprising generative and discriminative phases. The key concept involves the Hidden Significance (HS) metric, which quantifies the contribution of hidden units in a neural network. A lower HS indicates that a hidden unit has minimal impact on reconstructing input features, suggesting it can be pruned to reduce overfitting while maintaining model accuracy.

The pruning strategy is implemented by identifying and removing the hidden unit with the lowest HS value, thereby improving the model's generalization by reducing variance. The parameter learning strategy employs Stochastic Gradient Descent (SGD) to update network parameters after structural adjustments, using a loss function based on the sum of squared differences between noise-free and reconstructed input vectors.

The generative training phase allows the network to self-organize and learn robust features in an unsupervised manner, which can enhance performance in the subsequent discriminative training phase. This phase utilizes true class labels to craft a target vector and incorporates a softmax layer to derive classification probabilities. The framework is noted for its flexibility, enabling easy adaptation from a single hidden layer to deeper structures through a greedy layer-wise learning process. Overall, the proposed approach aims to improve model efficiency and accuracy in classification tasks.
