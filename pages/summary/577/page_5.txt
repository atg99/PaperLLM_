The paper discusses various strategies and objectives in transfer learning from a data perspective, particularly focusing on data-based approaches. The main aim is to minimize the distribution difference between source-domain and target-domain instances, primarily in homogeneous transfer learning scenarios. The authors highlight two main strategies to achieve this: instance weighting and feature transformation.

Instance weighting is emphasized in scenarios where there is a significant difference in marginal distributions between source and target domains. An example is provided where a model is created for cancer diagnosis in an elderly population, with source data from a younger demographic. To address this, instance weighting can be applied by assigning weights to source-domain instances based on their relevance to the target domain. The theoretical weighting parameter is described, although it is often unknown and challenging to calculate using traditional methods.

Kernel Mean Matching (KMM) is introduced as a solution to estimate these weights by aligning the means of the source and target instances in a Reproducing Kernel Hilbert Space (RKHS). The optimization problem presented allows for effective estimation of these weights while adhering to constraints.

Overall, the paper lays a foundation for understanding the importance of data adaptation techniques in transfer learning, focusing on how instance weighting can be utilized to bridge the gap between differing domains effectively.
