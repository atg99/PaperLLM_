This paper presents a novel approach for enhancing knowledge extraction from masked language models (MLMs) like BERT by introducing a query rewriting model. The rewriter takes an input query and generates a new query that is optimized for a downstream fixed BERT predictor, which outputs the correct answer. A key challenge addressed is the non-differentiability of discrete token outputs, which is mitigated by incorporating a loss term that aligns the rewriter's output with BERT token embeddings. 

To ensure that the rewritten query includes a [MASK] token, an auxiliary loss term is introduced to enforce the presence of one masked token, and a selection layer identifies the token index closest to [MASK] for answer completion. The training process utilizes the straight-through estimator to manage this selection.

Evaluation on the LAMA dataset demonstrates a significant improvement in knowledge extraction accuracy due to the model's ability to generate consistent and meaningful query rewrites. The findings reveal insights into effective query modifications for knowledge retrieval from BERT, and the method is deemed applicable to other MLMs as well.

The paper also discusses related work on query formulation and the impact of query variations on performance in knowledge extraction tasks. It builds on previous research by proposing an end-to-end training approach that optimizes query rewrites for enhanced knowledge extraction. 

In summary, the proposed BERTese model advances the understanding of how query rewriting can improve predictions and provide insights into knowledge representation in language models. The code for this research is made available for further exploration.
