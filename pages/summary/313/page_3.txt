This paper discusses a method for optimizing a rewriter model that generates a query sequence to be input into a BERT predictor. The rewriter outputs a sequence of vectors, which are then mapped to their nearest neighbors in a set of BERT embeddings. The main challenge arises from the non-differentiable nature of the nearest-neighbor operation and the requirement for the rewriter to include a [MASK] token at a specific position for prediction.

To address these challenges, the authors introduce two auxiliary loss functions. The "Valid Token Loss" encourages the output vectors to be close to valid BERT embeddings, minimizing the distance from each rewritten token to its nearest BERT embedding. The "Single [MASK] Loss" ensures that the output contains a single [MASK] token, using a "softmin" distribution to promote the proximity of one index to the [MASK] embedding.

The final prediction loss leverages the straight-through estimator to allow backpropagation through the non-differentiable operations. The overall training loss combines these three components, allowing the model to be optimized effectively. The rewriter is initialized with a BERT-based model and fine-tuned, ensuring that the output aligns with the requirements for accurate predictions.

In summary, the paper presents a structured approach to train a rewriter that generates valid queries with a masked token, facilitating effective predictions using a BERT model while addressing non-differentiability challenges through tailored loss functions.
