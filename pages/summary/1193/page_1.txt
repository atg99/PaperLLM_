This paper presents STAC, a simple yet effective semi-supervised learning (SSL) framework aimed at enhancing visual object detection by utilizing unlabeled data. The authors highlight the growing importance of SSL due to the limited availability of large-scale annotated datasets, especially in object detection, which has higher labeling costs compared to image classification tasks.

STAC employs highly confident pseudo labels derived from unlabeled images and reinforces model consistency through strong data augmentations. The study introduces experimental protocols for evaluating SSL performance in object detection, specifically using the MS-COCO and VOC07 datasets. Results indicate that STAC significantly improves detection performance, achieving an AP0:5 increase from 76.30 to 79.08 on VOC07, and demonstrating a 2x higher data efficiency on MS-COCO by attaining a mean Average Precision (mAP) of 24.38 using only 5% of labeled data, compared to a supervised baseline that achieved 23.86% with 10% labeled data.

The framework draws on established techniques in consistency-based self-training and advances in data augmentation, combining pseudo labeling with robust augmentation strategies to enhance model training. The authors emphasize that while SSL has progressed in image classification, its application in object detection remains limited, necessitating further development in this area. The code for STAC is publicly available, supporting further research and application in SSL for object detection.
