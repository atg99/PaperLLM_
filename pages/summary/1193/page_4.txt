The paper outlines a two-stage training process for a model called STAC, designed for object detection. In the first stage, a teacher model is trained using all available labeled data. In the second stage, STAC is trained utilizing both labeled and unlabeled data. A significant aspect of this approach is the implementation of high confidence thresholds for the generation of pseudo labels, which include bounding boxes and class labels, inspired by the FixMatch framework.

The training steps for STAC are as follows:
1. Train a teacher model on labeled images.
2. Generate pseudo labels for unlabeled images using the trained teacher model.
3. Apply strong data augmentations to unlabeled images while augmenting pseudo labels accordingly.
4. Compute both unsupervised and supervised losses to train the object detector.

The teacher model is based on the Faster RCNN framework, featuring a classifier and a region proposal network (RPN). The supervised loss for the RPN head is presented, emphasizing the predictive probability and bounding box coordinates for anchors in a mini-batch.

Pseudo label generation involves performing test-time inference through the teacher model, which includes the use of non-maximum suppression (NMS) to refine the bounding box predictions. This method improves upon traditional approaches by aggregating predictions and removing redundant detections, while confidence-based thresholding further filters out incorrect pseudo boxes.

For the unsupervised loss, a binary label is assigned to anchors based on the confidence scores of pseudo boxes. The loss function for the RPN considers strong data augmentations applied to the unlabeled images and their corresponding pseudo box coordinates.

The RPN is trained by minimizing the combined supervised and unsupervised losses, with hyperparameters to control the confidence threshold and the weight of the unsupervised loss. The framework's effectiveness is highlighted by its simple constant scheduling for these hyperparameters, contrasting with more complex methods that require dynamic adjustments.

Overall, STAC demonstrates a robust approach to semi-supervised object detection, leveraging strong data augmentation and confidence-based thresholds to enhance the quality of pseudo labels and improve model training.
