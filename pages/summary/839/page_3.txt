The paper introduces HAWQ-V3, a method for dyadic neural network quantization that addresses limitations in existing quantization approaches. It contrasts two quantization methods: the simulated (or fake) quantization, which utilizes floating-point precision during operations, and the integer-only pipeline with dyadic arithmetic. The latter merges batch normalization parameters into the quantization process, allowing for all operations to occur in integer format, thereby enhancing efficiency and speed during inference without the need for floating-point computations.

The authors highlight shortcomings in previous works, particularly Jacob et al. (2018), which do not support low-precision or mixed-precision quantization and are hardware agnostic. HAWQ-V3 improves upon this by being hardware aware and optimizing mixed-precision bit settings. It demonstrates that enabling low-precision quantization can improve inference speed by up to 50% with minimal accuracy loss. Additionally, HAWQ-V3 achieves higher accuracy for INT8 inference compared to prior methods.

The methodology section outlines the model quantization process, starting from a trained model with learnable parameters. It defines uniform quantization, which restricts neural network weights and activations to a finite set of values, and distinguishes it from non-uniform quantization, which, while potentially more accurate, poses deployment challenges. HAWQ-V3 focuses on uniform quantization, employing symmetric quantization for weights and asymmetric quantization for activations, to balance memory footprint, speed, and accuracy effectively.
