In summary, object detection can be enhanced through two main reasoning approaches: global context and region context. Global context reasoning leverages information from the entire image to aid in identifying objects, as demonstrated by methods like ION, DeepId, and improved Faster R-CNN. These approaches utilize techniques such as recurrent neural networks and semantic segmentation to capture spatial information, though obtaining pixel-level annotations can be costly. Alternatively, region context reasoning focuses on the relationships between objects and their surrounding areas. Innovations like Spatial Memory Network and Structure Inference Net treat object detection as a graph inference problem, capturing interactions without needing additional annotations. Techniques such as Gated Bi-Directional CNN further refine this by extracting and combining features from various sub-regions, improving detection performance. Overall, both global and region context reasoning contribute significantly to advancing object detection capabilities.
