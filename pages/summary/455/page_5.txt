The paper presents the architecture of BU-Net, which incorporates a wide context block for the transition from encoder to decoder. It utilizes convolution layers with batch normalization and ReLU activation functions, while the final layer employs a sigmoid activation function. The ReLU and sigmoid functions are mathematically defined, with ReLU outputting zero for non-positive inputs and the input value otherwise, while sigmoid transforms inputs into a range between zero and one.

The BU-Net is built using the Keras framework, with a dropout ratio of 0.3 determined through hyper-parameter tuning as optimal for network performance. The Adam optimizer is employed with a learning rate of 0.01 and a momentum of 0.9, using a batch size of 16. Early stopping based on validation loss is implemented with a patience level of 10 to manage training iterations effectively.

A key component of the architecture is the Residual Extended Skip (RES) block, which consists of five parallel connections. Four of these connections apply two convolution layers each, utilizing filter sizes of N-1 for the first layer and 1-N for the second. This design reduces the number of parameters while maintaining performance similar to a single layer with a higher parameter count. The last connection serves as a skip connection, directly forwarding the input. The outputs from all connections are summed to produce a single output, enhancing the architecture's efficiency.
