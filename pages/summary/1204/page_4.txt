The paper presents a novel approach called Swapped Assignments between Views (SwA V) for contrastive instance learning, which differs from traditional contrastive learning methods by focusing on a "swapped" prediction problem. Instead of directly comparing features from various transformations of the same images, SwA V first generates prototype vectors and then predicts the codes derived from one augmented view using the features from another view. This method allows for a more abstract comparison that does not rely on direct feature matching.

The loss function for the swapped prediction problem is derived from the interactions between the prototype vectors and the image features, optimized jointly with the parameters of the image encoder. To facilitate online learning, the method computes codes from the image features within a batch, ensuring distinct codes for the images to avoid trivial solutions.

The optimization process involves maximizing the similarity between the features and the prototypes while maintaining an entropy constraint to prevent all samples from collapsing into a single representation. The paper also discusses constraints that ensure each prototype is adequately represented within a minibatch, adapting previous work to this context.

Overall, SwA V aims to enhance instance classification by leveraging prototypes and a novel prediction mechanism, promoting effective feature learning while addressing the limitations of conventional contrastive learning techniques.
