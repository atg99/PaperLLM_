The paper discusses a federated learning approach involving multiple hospitals for collaborative training of a global model. In this setup, the central server aggregates local model updates from each hospital at a specified frequency, specifically after each training epoch. The Federated Averaging (FedAvg) algorithm is employed to update the global model parameters by calculating a weighted average of the local models, where weights correspond to the sample sizes from each hospital.

In this process, the central server initially distributes the global model to all participating hospitals. Each hospital then optimizes this model locally using its own dataset for a defined number of epochs, which is set to one in this implementation. After local optimization, hospitals send their model updates back to the central server. The server collects these updates and continues the cycle until the global model converges.

The paper illustrates this method with a case study involving three hospitals, denoting the number of data points at each hospital as nk. The iterative process continues until the model achieves satisfactory performance, contributing to improved lesion burden estimation from external longitudinal CT scans.
