The paper presents a novel framework called Random Distance Prediction (RDP) utilizing a weight-shared two-branch neural network. This framework aims to minimize the random distance prediction loss (Lrdp), which measures the difference between the learned distance and a predefined distance derived from an existing random mapping. The RDP framework is designed to project input data points onto a new space where the preservation of pairwise distances is crucial for various learning tasks. 

Additionally, the framework allows for the integration of a task-dependent auxiliary loss (Laux) to enhance feature learning. For instance, in clustering, a reconstruction loss may be added to capture global feature representations, while in anomaly detection, a novelty loss can help identify underlying patterns in the data. These auxiliary losses complement the proximity information provided by Lrdp, leading to improved performance in specific tasks.

The theoretical analysis section of the paper establishes that proximity information can be effectively approximated using inner products in random projection spaces, which supports the learning of genuine class structures in the data. This theoretical foundation underpins the RDP framework's capability to learn semantic-rich feature representations that optimize distance preservation in the mapped space.
