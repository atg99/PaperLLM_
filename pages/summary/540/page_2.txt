This paper addresses the limitations of existing methods like random projection and autoencoders in capturing complex class structures due to data assumptions and weak supervisory signals. The authors introduce a Random Distance Prediction (RDP) model which utilizes neural networks to predict data distances in a randomly projected space. The key insight is that when distance information reflects the intrinsic class structure, the representation learner can optimize class structure learning to minimize prediction errors.

High-dimensional spaces can make distance information less meaningful; thus, the RDP model aims to preserve distances in a projected space as a supervisory signal. Random mapping is employed for its efficiency and theoretical backing in preserving approximately accurate distances. This process helps the model learn globally consistent proximity while rectifying misleading proximity information, leading to improved representation spaces compared to the original data.

The paper outlines three main contributions: 
1. The introduction of a random distance prediction formulation that serves as an effective supervisory signal for learning expressive feature representations, which can be applied across various downstream tasks.
2. The flexibility to incorporate task-dependent auxiliary losses that enhance feature learning for specific tasks while maintaining generic proximity.
3. Demonstrating that the RDP model outperforms state-of-the-art methods in unsupervised tasks such as anomaly detection and clustering across 19 high-dimensional tabular datasets.

The RDP model operates by employing a weight-shared Siamese-style neural network to map data points into a new space, followed by a distance prediction task using a loss function that compares predicted distances with those derived from a projection method. The use of inner products in randomly projected space allows for efficient computation and preserves genuine distance information, forming the basis of the RDP approach.
