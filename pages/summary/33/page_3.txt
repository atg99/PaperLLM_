The paper presents a two-stage framework for 3D object detection that utilizes both voxelized point clouds and raw point cloud data, aiming to improve detection accuracy without relying on RGB images. The first stage involves voxelizing the point cloud and processing it through VoxelRPN, which generates a small set of initial predictions efficiently. The second stage employs RefiNet to refine these predictions by integrating features from the raw point cloud and contextual information from VoxelRPN.

VoxelRPN operates as a one-stage object detector that takes voxelized input, represented as a regular grid where each voxel contains information about the original points in its region. The authors propose a method that retains only six points per voxel, which, when processed through an 8-channel MLP layer, yields satisfactory performance. This compact representation allows for effective feature extraction using convolutional neural networks (CNNs).

The network structure combines both 2D and 3D convolutions to maintain the integrity of the 3D spatial information. Unlike previous methods that lose Z-dimension data through transformations, this approach preserves the 3D structure by employing consecutive 3D convolutions. The backbone network consists of six 3D convolutional layers, followed by three blocks of 2D convolutions, which enhance abstraction and receptive field size.

Recognizing that objects of the same category in 3D scenes typically share similar scales, the authors utilize a HyperNet structure for better scale management. They upsample feature maps from earlier layers and concatenate them to leverage both location and semantic information. Pre-defined anchors are applied to this fused feature map, facilitating the classification and regression of detected objects.

Overall, the proposed framework demonstrates a novel integration of voxel and raw point cloud data, enhancing 3D object detection capabilities while addressing the limitations of traditional 2D-based methods.
