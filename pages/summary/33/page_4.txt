The paper presents a detailed architecture for VoxelRPN, a network designed for 3D object detection using voxelized point cloud data. The network structure includes various convolutional layers with specific kernel sizes and channels, as illustrated in Figure 2. The architecture aims to enhance feature extraction while retaining localization information, which is crucial for accurate predictions.

To further improve prediction quality, the authors introduce RefiinerNet, which processes raw point cloud data directly. This approach addresses the loss of localization information during the voxelization and convolutional stages in VoxelRPN. RefiinerNet utilizes coordinates from point clouds and builds on the foundational work of F-PointNet, which regresses 3D bounding boxes from 2D detections. Unlike previous methods that rely solely on interior points, RefiinerNet incorporates context information for better accuracy.

The box feature generation in RefiinerNet is achieved by leveraging points within predicted bounding boxes from VoxelRPN. The method combines both coordinates and features extracted from VoxelRPN, allowing for a more comprehensive representation of object geometry. A max-pooling operation is applied to fuse point representations, enhancing the predictive capability of the model.

The network structure of RefiinerNet includes a feature fusion module that utilizes an attention mechanism to effectively integrate high-dimensional coordinate features with convolutional features. This design replaces basic concatenation with a more sophisticated approach, leading to improved feature generation and aggregation.

Final box refinement is conducted through a series of MLP layers that predict the refined locations of bounding box corners. The authors emphasize the importance of canonizing coordinates to ensure translation and rotation invariance, which aids in reducing the uncertainty associated with corner predictions. The experiments conducted demonstrate the effectiveness of the proposed methods, highlighting the advantages of using canonized corner loss for improved accuracy in 3D object detection.
