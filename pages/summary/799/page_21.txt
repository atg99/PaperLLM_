This paper discusses advancements in lightweight models based on the YOLO (You Only Look Once) architecture, aimed at enhancing real-time object detection on resource-constrained devices such as laptops and mobile phones. Key contributions include the development of YOLO-LITE, which demonstrates the efficacy of shallow networks in fast detection without GPUs, and YOLO Nano, created using a human-machine collaborative design strategy. Other notable models include xYOLO, which achieves faster inference speeds, and YOLO-Fastest, which combines YOLO with EfficientNet-lite for effective deployment on mobile devices.

Additionally, Scaled-YOLOv4 is introduced for scaling YOLOv4, while the YOLObile framework focuses on real-time detection on mobile devices through innovative pruning and collaborative techniques. Research also highlights the use of compressed convolutional methods in YOLOv5 for UAV applications, leading to significant reductions in GPU memory and energy consumption.

Other approaches in lightweight model development include SkipNet, which employs a gate module for layer calculations, and EfficientNet, which utilizes fixed scaling factors for image classification. EfficientDet further enhances this with a bidirectional feature pyramid network for feature extraction.

The paper also addresses challenges in quantization, particularly when training data is unavailable. It introduces zero-shot quantization techniques, notably AIT, which uses KL distance loss for weight updates. The exploration of data synthesis in zero-shot quantization is highlighted as a promising area for future research. Overall, the paper emphasizes the importance of developing efficient and effective models for real-time object detection across various platforms.
