The paper discusses the challenges associated with deploying deep neural networks (DNNs) for object detection, particularly in resource-limited environments such as autonomous vehicles and intelligent patrol systems. Current DNN models, including AlexNet, VGG, ResNet, and GoogLeNet, are noted for their high computational and storage demands. For instance, VGG-16 has 138 million parameters and requires over 15.5 billion floating-point operations per second (FLOPs) for image detection, alongside significant runtime memory usage.

The authors highlight the limitations posed by model size, runtime memory, and computational requirements, which hinder the effective deployment of these complex models on platforms with restricted computing power. While cloud deployment offers high performance, it introduces security risks due to network latency. The increasing demand for real-time detection capabilities in computer vision applications necessitates efficient DNN models that can operate under these constraints.

To address these challenges, the paper reviews various model compression strategies that have emerged since 2014. It emphasizes the importance of selecting appropriate model compression methods for object detection tasks and provides standard experimental benchmarks for assessing different techniques, such as pruning, knowledge distillation (KD), and neural architecture search (NAS), particularly in relation to the YOLO v3 model.

Overall, this survey serves as a comprehensive reference for both deep learning-based object detection models and model compression techniques, aiming to bridge the gap in existing literature that often treats these topics separately.
