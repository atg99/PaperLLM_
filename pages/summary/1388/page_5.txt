The paper introduces Fast-SCNN, a segmentation convolutional neural network designed for efficient real-time performance. The model incorporates a feature fusion module that enhances accuracy by combining features from different resolutions. It utilizes depthwise separable convolutions and pointwise convolutions in its classifier, optimizing computational efficiency while maintaining accuracy. The model can operate in two modes: Fast-SCNN cls, which uses softmax during training, and Fast-SCNN prob for probabilistic outputs.

Fast-SCNN draws inspiration from both two-branch and encoder-decoder frameworks. It features a learning to downsample module akin to the spatial paths in existing models, facilitating shallow learning from full resolution. Its global feature extractor shares initial layers with the downsampling module, reducing computational load and allowing for lower input resolutions. In contrast to traditional encoder-decoder architectures, Fast-SCNN employs a single skip connection early in the network to minimize memory usage.

The experiments were conducted using the Cityscapes dataset, leveraging a TensorFlow setup on powerful GPUs. A variety of data augmentation techniques were applied to combat overfitting, and the model was trained for 1,000 epochs with specific learning rate strategies and regularization methods. The results demonstrate that Fast-SCNN achieves competitive performance with a lower parameter count, highlighting its efficiency in semantic segmentation tasks.
