The paper presents Fast-SCNN, an efficient model for real-time semantic segmentation. It utilizes various convolutional techniques, including standard convolution, depthwise separable convolution, and inverted residual bottleneck blocks. The architecture is organized into four main modules: learning to downsample, global feature extractor, feature fusion, and classifier, as detailed in Table 1.

The motivation behind Fast-SCNN stems from the limitations of current two-branch networks that operate at different resolutions to capture global context and refine segmentation precision. Instead of separate computations for low and high-resolution inputs, Fast-SCNN employs a learning to downsample module that shares feature computation, allowing for efficient performance while maintaining accuracy.

The learning to downsample module consists of three layers: one standard convolution layer followed by two depthwise separable convolution layers. This structure ensures low-level feature sharing while optimizing computational efficiency. The global feature extractor captures image context using an efficient bottleneck block, leveraging residual connections and a pyramid pooling module to enhance contextual information.

Finally, the feature fusion module integrates features through simple addition to maintain efficiency, contrasting with more complex methods that may hinder runtime performance. Overall, Fast-SCNN aims to combine the strengths of existing methods into a streamlined architecture suitable for real-time applications.
