Transfer learning is a machine learning technique where a convolutional neural network (CNN) trained on one task is adapted for another task. This paper focuses on feature-based transfer learning, utilizing outputs from specific layers of a pretrained network as descriptors for the target task. While traditional methods often select the last fully connected layers for feature extraction, this study employs an automated feature selection approach using the Sequential Floating Forward Selection (SFFS) method.

SFFS iteratively removes features from a starting set to identify an optimal subset, thereby enhancing the selection process for layers from which to extract features. Each layer's response is treated as a descriptor for training a Support Vector Machine (SVM), and to mitigate dimensionality issues, descriptors are reduced to a maximum of 5000 dimensions using Discrete Cosine Transform (DCT).

The selection process aims to optimize classification performance through an ensemble of selected SVMs, typically resulting in the selection of 3 to 5 layers per CNN. To ensure robust evaluation, a leave-one-out testing protocol is used, training on two datasets while testing on the third. The study compares the SFFS method with traditional strategies, including using the last fully connected layer, all fully connected layers, and a manual selection approach.
