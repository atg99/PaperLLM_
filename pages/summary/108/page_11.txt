The paper presents an analysis of prediction errors using Long Short-Term Memory (LSTM) and Gated Recurrent Unit (GRU) models with different activation functions (ReLU and sigmoid) and historical window sizes. Figures illustrate the Mean Absolute Percentage Error (MAPE) and Mean Absolute Error (MAE) for various variables, highlighting performance differences based on the chosen activation function and window size.

Tables summarize the best prediction errors for both LSTM and GRU models. For LSTM, the 4-day window with ReLU activation yielded the lowest MAPE values, while the 6-day window with sigmoid activation showed higher errors. For GRU, the 12-day window with ReLU produced the best MAPE results, with the 10-day window using sigmoid also performing well.
