The paper introduces the Graph Transformer Layer and its variant with edge features, aiming to enhance the processing of graph data. The architecture is divided into two models: one without explicit edge attributes and another that incorporates edge features to maintain their representations. 

For input preparation, node and edge features are transformed into d-dimensional hidden features via linear projections. Positional encodings are added to node features at the input layer but not in subsequent layers. 

The core of the Graph Transformer Layer follows the architecture of the original transformer model, with a focus on updating node representations. Attention scores are computed using queries and keys, followed by normalization and feed-forward networks. 

The variant with edge features enhances the model's ability to utilize edge attributes by integrating them with implicit attention scores. This is achieved through a multiplication of the attention score with edge features, which is particularly beneficial in graph datasets where edge information is available. 

Both models include normalization and residual connections in their processing, ensuring stability and efficient propagation of features through the layers. Overall, the architecture is designed to effectively leverage both node and edge information for improved graph representation learning.
