5.2.3. Rectified Linear Unit (ReLU) Layer
The ReLU layer introduces non-linearity to the model, allowing it to learn complex patterns in the data. It applies the activation function max(0, x), which means that all negative values are set to zero while positive values remain unchanged. This function not only accelerates the training process but also helps mitigate the vanishing gradient problem, making it a preferred choice in CNN architectures.

5.2.4. Fully Connected Layers
Fully connected layers are typically found at the end of the CNN architecture. These layers connect every neuron from the previous layer to each neuron in the current layer, enabling the model to make final predictions based on the learned features. The output from the fully connected layer often corresponds to the classes or labels in a classification task.

In summary, CNNs leverage various layer types—convolutional, pooling, ReLU, and fully connected—to effectively analyze medical images while preserving spatial relationships. Their architecture is designed to extract high-level features and reduce dimensionality, ultimately enhancing the model's ability to make accurate predictions in medical imaging tasks.
