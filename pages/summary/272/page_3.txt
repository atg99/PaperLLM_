The paper introduces Graph Transformer Networks (GTNs), a framework designed to learn both new graph structures and node representations simultaneously. Unlike traditional approaches that rely on predefined graph structures, GTNs utilize multiple candidate adjacency matrices to enhance graph convolutions and improve representation learning.

In the context of heterogeneous graphs, where nodes and edges can have various types, GTNs identify useful meta-paths—sequences of nodes connected by heterogeneous edges. These meta-paths allow for the generation of new graph structures, represented by adjacency matrices. The paper defines a meta-path as a composite relation between nodes, which can be mathematically expressed through matrix multiplication of adjacency matrices.

The framework employs Graph Convolutional Networks (GCNs) for node classification, where the feature representations are iteratively updated through a convolution operation influenced by the learned graph structures. The convolution operation is determined by the graph's adjacency matrix, which is modified through the learning process, allowing GTNs to adaptively optimize the convolution based on the graph's structure.

Overall, GTNs represent a significant advancement in graph-based learning by enabling the generation of new graph structures while concurrently learning effective node representations, thereby enhancing the performance of various graph-related tasks.
