The paper discusses the implementation and hyper-parameter setup for machine learning models, specifically focusing on the Long Short-Term Memory Recurrent Neural Network (LSTM-RNN) for classification tasks. The authors utilized the Linear Support Vector Machine (SVM) and Random Forest (RF) classifiers from scikit-learn, with default settings including a Linear Kernel for SVM and 100 estimators for RF.

For the LSTM-RNN model, various configurations were tested using different numbers of neurons in the hidden layers, ranging from 5 to 100. The hyper-parameters for binary and multi-class classification experiments are outlined in Table 4, which includes aspects such as learning rate, dropout rates, activation functions, optimizers, epochs, batch size, and loss functions. The structure of hidden layers is detailed in Table 5, indicating the number of hidden layers corresponding to different neuron counts.

The experimental results section presents the classification performance metrics of the LSTM-RNN classifier, including accuracy, precision, recall, F-score, True Positive Rate (TPR), and False Positive Rate (FPR), for both binary and multi-class classifications. The multi-class classification involves five categories: normal, Denial of Service (DoS), probe, User to Root (U2R), and Remote to Local (R2L) attacks, while binary classification distinguishes between normal and anomaly classes. The performance of the LSTM-RNN is compared against traditional machine learning methods like SVM and RF, using feature sets derived from genetic algorithms.
