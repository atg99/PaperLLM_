The paper presents the classification performance of an LSTM-RNN classifier using both all features and an optimal feature set derived from a genetic algorithm. 

In binary classification with all 122 features, the highest testing accuracy achieved was 96.51% with a training accuracy of 99.88%, both using five neurons in the hidden layers. The results indicate that increasing the number of neurons beyond five did not significantly improve testing accuracy, with the highest training accuracy maintained around 99.90% for configurations up to 100 neurons.

For multi-class classification using the same 122 features, the highest testing accuracy was 82.68% and training accuracy was 99.87%, both achieved with 60 neurons in the hidden layers. The results show a decrease in precision and recall as the number of neurons increased, suggesting diminishing returns in performance with larger hidden layers.

When applying the genetic algorithm to select an optimal feature set of 99 features for binary classification, the classifier achieved an impressive testing accuracy of 99.91% and a training accuracy of 99.99% using 40 neurons in the hidden layers. This demonstrates the effectiveness of feature selection in enhancing classification performance. 

Overall, the findings highlight the importance of feature selection and the optimal configuration of hidden layers in improving classification accuracy in both binary and multi-class scenarios.
