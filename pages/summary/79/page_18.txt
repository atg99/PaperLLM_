This paper investigates various classifiers applied to the NSL-KDD dataset for both binary and multi-class classification tasks. The classifiers compared include Support Vector Machine (SVM), Random Forest, and Long Short-Term Memory Recurrent Neural Network (LSTM-RNN). The results indicate that the proposed model achieved a training accuracy of 99.99% and testing accuracy of 99.91% in binary classification, while in multi-class classification, it reached 99% training accuracy and 93.88% testing accuracy.

The findings reveal that the LSTM-RNN outperformed SVM in binary classification, although Random Forest yielded the highest accuracy overall. Notably, when utilizing an optimized feature set, the LSTM-RNN achieved competitive results similar to Random Forest. In multi-class classification, LSTM-RNN exhibited superior performance compared to both SVM and Random Forest, with the LSTM-RNN enhanced by Genetic Algorithm (GA) achieving a notable 10% higher accuracy than Random Forest.

The authors conclude that LSTM-RNN is effective for large datasets, while its performance on smaller datasets with fewer features is less pronounced. Future work is suggested to include executing experiments on a GPU system for faster training, using more recent datasets like UNSW-NB15, and developing a framework for real-time network data collection and labeling. Additionally, comparisons with other deep learning models such as CNN-LSTM and deep belief networks are proposed.
