The paper discusses the increasing trend of vulnerabilities in software as reported by the National Vulnerability Database (NVD). Since 2017, there has been a significant rise in vulnerabilities, with the NVD registering 189,155 vulnerabilities as of June 2022. In the current year alone, 11,644 vulnerabilities have been accepted, highlighting the urgent need for expedited vulnerability assessment to address this widespread issue.

Additionally, the paper provides an overview of the Common Vulnerability Scoring System (CVSS), an open framework developed by FIRST.Org, Inc. to characterize and quantify vulnerabilities. CVSS is divided into three metric groups: base, temporal, and environmental, with the base metric group being the most utilized as it reflects the inherent properties of vulnerabilities that remain constant over time and across different user environments. The base metric group generates scores from 0 to 10, which can be represented as a vector string. The scoring process involves selecting metric values, applying them to a quantification formula, and converting the resulting base score into a vulnerability rating. This information is crucial for understanding and mitigating vulnerabilities effectively.
