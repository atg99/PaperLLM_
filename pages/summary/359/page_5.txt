XLNet is an autoregressive language model designed to capture bidirectional contextual information through three main techniques: the permutation language model, two-stream self-attention, and a circulation mechanism. The permutation language model forms the core of XLNet, utilizing random ordering of input sequences to maintain the autoregressive model's one-way nature while allowing for bidirectional context extraction. Given a text of length n, there are n! possible permutations, but XLNet limits computation to a partial sequence to reduce arithmetic demands. The loss function is defined mathematically to reflect these permutations.

A notable challenge arises in predicting elements within sequences, where sometimes only location information is needed, and other times both semantic and location information are required. To address this, XLNet employs two-stream self-attention, which merges semantic and positional data for improved context understanding.

Additionally, XLNet incorporates key techniques from the Transformer-XL model, specifically the relative positional encoding scheme and segment recurrence mechanism, enhancing its autoregressive capabilities.
