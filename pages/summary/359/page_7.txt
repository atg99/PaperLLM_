The paper addresses the problem of predicting vulnerability metric values through a multi-label text classification approach. It begins by defining the vulnerability metric value generation model, which involves converting vulnerability descriptions into feature vectors using various word vector algorithms such as One-hot, TFIDF, word2vec, and BERT. The model predicts the probability of metric values, represented as ˆy, based on features extracted from the text.

The dataset for this study, denoted as D, contains vulnerability descriptions (X) and their corresponding truth-value labels (Y). The authors reformulate the multi-label classification problem into a binary classification framework for each metric value, simplifying the prediction process. The ultimate goal is to optimize the model parameters to minimize the loss function, thereby enhancing the model's performance in predicting vulnerability metric values.

To achieve this, the paper proposes an efficient machine learning method that utilizes the XLNet model, which is fine-tuned to improve learning efficiency and prediction accuracy. The methodology consists of three main phases: text tokenization, transfer layer token embedding, and metric value prediction, culminating in the use of a softmax function to predict the likelihood of the vulnerability metric values. The study aims to assist security analysts in rapidly analyzing CVSS metric values, thereby streamlining the vulnerability assessment process.
