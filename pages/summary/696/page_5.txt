The proposed Cross DQN framework incorporates a novel batch-level constraint that allows for differentiated ad exposure strategies based on user context. By adjusting the percentage of ads exposure (PAE) across batches rather than individual requests, the model can better tailor recommendations to user preferences. This approach enhances user experience by mitigating ad fatigue for users sensitive to advertisements while still optimizing for overall exposure targets.

In the offline training phase, the model utilizes a dataset generated by an exploratory policy, employing a loss function that balances the standard DQN loss with the auxiliary PAE loss. This dual-loss approach supports the model in learning effective action-value estimates while adhering to exposure constraints.

During online serving, the model dynamically selects actions based on the current state and can efficiently handle user interactions, caching decisions to minimize communication overhead. This design not only improves response times but also ensures that the model can adapt quickly to changing user contexts.

Overall, the Cross DQN framework presents a robust solution for optimizing ad recommendations while respecting user preferences and maintaining operational efficiency in real-time environments.
