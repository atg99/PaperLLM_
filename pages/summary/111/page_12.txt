This section discusses Temporal Convolutional Networks (TCN), a notable advancement in neural network architectures designed for sequential data, especially time series. Introduced in 2017 for action segmentation and further expanded in 2018, TCN combines the feature extraction strengths of Convolutional Neural Networks (CNN) with efficient processing capabilities for time series data.

TCN is trained to predict future values of a time series based on past observations, using only data that has been seen up to a certain time step. It has two key properties: (1) causal convolutions ensure that predictions at any time depend solely on current and past inputs, avoiding future data influence, and (2) like Recurrent Neural Networks (RNNs), TCN can handle sequences of arbitrary lengths, producing outputs of the same length as inputs. The core components of TCN include residual connections, dilated convolution, and causal convolution.

The architecture of TCN relies on maintaining input length through zero-padding and utilizing causal convolutions, which only involve past data for generating outputs. This design allows TCN to effectively capture long-range dependencies in sequential data, addressing limitations of simple causal convolutions that only consider linear history scaling.
