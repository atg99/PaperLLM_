The paper presents a comprehensive overview and comparative analysis of various deep learning models applied to the ARAS dataset for sensor event classification. The preprocessing phase involved removing outliers and employing a time-based static sliding window technique for segmenting sensor events into 90-second intervals, which was determined to be optimal for enhancing model accuracy and reducing training time.

After preprocessing, the data is fed into an input layer, followed by a feature extraction layer utilizing one of eight models: CNN, RNN, LSTM, Bi-LSTM, GRU, Bi-GRU, TCN, or Transformer. This layer is essential for identifying patterns within the data. To prevent overfitting, a dropout layer is included, which randomly deactivates some neurons during training. The subsequent flatten layer transforms the multi-dimensional data into a one-dimensional vector for compatibility with fully connected layers, which apply a Softmax function for classification.

The experimental setup involved splitting the dataset from the first resident of house B into 70% for training and 30% for testing, with 20% of the training data reserved for validation. All models were trained with consistent parameters: 30 epochs, a batch size of 64, a dropout rate of 0.2, the Categorical Crossentropy loss function, and the Adam optimizer. Specific configurations included 100 filters for the CNN model, 64 units for RNN variants, 16 filters for TCN, and 2 attention heads for the Transformer model.
