The Kolmogorov-Arnold Network (KAN) is defined as a composition of multiple transformation layers, each represented by the function Φl. This function transforms input xl into xl+1 through a series of activation functions, which are splines that allow for a flexible response to inputs. The splines are expressed as a sum of coefficients multiplied by basis functions, where the coefficients are trainable.

Several variants of KAN have been developed to address specific challenges across various applications:

1. **Convolutional KAN (CKAN)**: This variant integrates KAN's non-linear activation functions into convolutional layers, reducing parameters and optimizing neural network architectures, particularly in computer vision.

2. **Temporal KAN (TKAN)**: Combining KAN with Long Short-Term Memory networks, TKAN is designed for time series analysis. It features layers of Recurrent KANs with memory management, improving multi-step forecasting capabilities.

3. **Multivariate Time Series KAN (MT-KAN)**: MT-KAN enhances forecasting accuracy for multivariate time series data by modeling interactions between variables and capturing temporal relationships through spline-parametrized functions.

4. **Fractional KAN (fKAN)**: This enhancement incorporates fractional-orthogonal Jacobi functions into KAN, enabling effective learning and improved accuracy through their unique mathematical properties.

5. **Wavelet KAN (Wav-KAN)**: By integrating wavelet functions, Wav-KAN improves interpretability and performance, utilizing multiresolution analysis to capture complex data patterns.

6. **Graph KAN**: This model adapts KAN principles for graph-structured data, replacing traditional MLPs and activation functions in Graph Neural Networks with KAN, leading to more effective feature extraction.

These variants exemplify the versatility of KAN in tackling diverse problems, enhancing the effectiveness of neural network architectures in various domains.
