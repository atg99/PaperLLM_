The paper discusses the integration of hierarchical structures in training general-purpose semantic segmentation networks, emphasizing the need for minimal architecture changes. It highlights existing methods that often modify segmentation networks significantly to accommodate class hierarchies, primarily focusing on information aggregation through graph neural networks. The authors propose a holistic framework for Hierarchical Semantic Segmentation Networks (HSSN), which allows for the incorporation of class hierarchies into typical segmentation architectures.

The paper categorizes hierarchical classification into two types: hierarchical classification and hierarchical multi-label classification, applicable across various machine learning domains. It identifies three main approaches in computer vision for class taxonomy-aware image classification: label-embedding methods, hierarchical losses, and hierarchical architectures. The authors advocate for pixel-level hierarchical reasoning to enhance visual scene understanding.

The proposed HSSN framework treats semantic classes as interconnected within a tree-structured hierarchy, where each node represents a class and edges denote relationships. This approach allows for a pixel-wise multi-label classification task, where segmentation heads are modified to predict scores relevant to the entire class hierarchy rather than just leaf nodes. The loss function is adapted to optimize binary cross-entropy, enabling the network to predict class memberships more coherently.

In summary, the paper presents a novel framework that effectively integrates hierarchical class dependencies into semantic segmentation networks, improving representation learning and overall performance while minimizing changes to existing architectures.
