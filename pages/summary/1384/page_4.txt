The paper discusses a decoder architecture for semantic segmentation, focusing on two approaches: a linear decoder and a mask transformer. The decoder takes patch encodings from an encoder and maps them to class scores, which are then upsampled to create a pixel-level segmentation map.

In the linear decoder, a point-wise linear layer generates patch-level class logits from the patch encodings. These logits are reshaped into a 2D feature map, upsampled to the original image size, and processed with a softmax to yield the final segmentation map.

The mask transformer, on the other hand, uses learnable class embeddings to produce class masks. Each class embedding is initialized randomly and assigned to a specific semantic class. The transformer decoder, composed of multiple layers, computes class masks through the scalar product of normalized patch embeddings and class embeddings. This method allows for dynamic filter generation based on input, differentiating it from hybrid approaches that separate pixel and class embeddings due to computational constraints. The mask transformer can also be adapted for panoptic segmentation by replacing class embeddings with object embeddings.

The experimental section details the datasets used for evaluation, including ADE20K, Pascal Context, and Cityscapes, along with the metrics for performance measurement, specifically Intersection over Union (mIoU). The implementation details highlight the use of various transformer models, pre-training on ImageNet, and the specific configurations for model variants. The paper emphasizes the effectiveness of the proposed transformer architecture in semantic segmentation tasks.
