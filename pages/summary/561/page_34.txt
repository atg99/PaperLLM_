This section discusses two prominent tools for automatic model tuning in machine learning: Amazon SageMaker and Neural Network Intelligence (NNI).

Amazon SageMaker is a module within a comprehensive machine learning environment designed to streamline model building and deployment. It is user-friendly, requiring only a model and training data for hyperparameter optimization (HPO) tasks. The service supports large-scale optimization for complex models, with features such as Jupyter integration for configuration and result visualization. Users can monitor HPO progress through the SageMaker console, which also allows for early stopping and warm starts. While search algorithms are limited to random search and Bayesian optimization, users can implement their own algorithms if desired. Unlike Google Vizier, SageMaker is a fully managed service that integrates all steps of training a neural network, eliminating the need to switch tools during the process.

On the other hand, NNI is an open-source toolkit from Microsoft that facilitates both automated machine learning and HPO. It offers greater customization and flexibility compared to closed-source services like SageMaker and Google Vizier. NNI can be deployed across various environments, including local machines and remote servers. It is particularly suited for researchers with machine learning knowledge who are willing to manage deployment, test diverse algorithms, and utilize HPO or AutoML within the NNI framework. NNI also boasts a broader range of search algorithms than its counterparts, enhancing its extensibility and adaptability for different research needs.
