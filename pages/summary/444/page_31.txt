The paper discusses the encoding map that transforms data from a triangular domain into an array of values representing each 'triangular pixel' in lexicographical order. This process is visually distinct from diffusion processes on square domains, as illustrated by the plotted image. The transformation, while defined on an object of infinite resolution, exhibits discontinuity on a dense set of four points. Despite this discontinuity, it retains sufficient information for implementing a diffusion model in the triangular MNIST context, as depicted in Figure 8. The transformation remains continuous almost everywhere, implying that the negligible loss of signal information does not significantly impact function approximation in the diffusion model.
