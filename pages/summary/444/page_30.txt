In this section, the authors analyze the MNIST-Triangular dataset, which is derived from the MNIST dataset by repositioning the digits into the lower-left quadrant of a 64x64 image, leaving the upper-right quadrant as a gray background. This modification increases the pixel count over fourfold compared to the original MNIST, yet the DDPM U-Net was trained using the same hyperparameters as for MNIST, potentially leading to slightly lower sample quality.

To process the images, the authors utilize the self-similarity of the triangular domain to create a coding map that divides the image into triangular pixels. Each pixel's function value is sampled and stored in a lexicographical order corresponding to its code-space address. This process allows the authors to map function values into an array and perform projections using Haar wavelets, facilitating the encoding of the triangular structure effectively.

The encoding map, illustrated in the figures, represents the relationship between the triangular Haar wavelets and their corresponding code-space addresses, demonstrating the construction's applicability to self-similar objects adhering to specific separation properties.
