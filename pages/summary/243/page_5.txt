The paper discusses the implementation of DenseNet architecture for camera-model identification, specifically utilizing the DenseNet-201 model. This architecture comprises four dense blocks with a growth rate of 32, interspersed with transition layers that include convolution and pooling operations. The model employs Global Average Pooling to reduce the dimensionality of the output feature vector, which is then classified using a fully-connected layer with a Softmax activation function.

The choice of DenseNet is driven by the need to detect subtle camera-model features in images, which are often obscured by device-level features like Photo Response Non Uniformity (PRNU) sensor noise and post-processing alterations. DenseNet's use of dense connections allows output from each layer to be utilized by subsequent layers, mitigating the risk of losing critical information and preventing gradient vanishing during training. This design enables the extraction of intricate features that conventional CNN architectures may struggle to identify.

Additionally, the architecture incorporates a Squeeze-and-Excitation (SE) block, which enhances the network's representational capabilities by modeling interdependencies among output channels. The SE block recalibrates features by aggregating spatial dimensions to create a channel descriptor, allowing the network to emphasize informative features while suppressing less relevant ones, thereby improving overall performance without altering feature vector dimensions.
