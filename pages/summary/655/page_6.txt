The paper discusses a memory architecture designed to enhance data access latency and processing efficiency in graph convolutional networks (GCNs). It introduces embedded DRAM (eDRAM) to cache various data types, including edges, vertex features, and intermediate aggregation results, thus improving data reuse through spatial and temporal locality. The architecture employs double buffering techniques in the Edge Buffer and Input Buffer to hide DRAM access latency effectively.

A key component, the Sparsity Eliminator, is implemented to prevent redundant feature loads for vertices without edges connected to the aggregating vertex. The Combination Engine is engineered to optimize access and computations, utilizing a modified systolic array design that accommodates parallel processing and enhances data reuse. This engine employs a Weight Buffer to cache the weight matrix and an Output Buffer to consolidate write accesses for final features.

Additionally, a prefetcher is incorporated to enhance bandwidth utilization by prefetching graph and parameter data based on the current processing vertices. The Aggregation Engine introduces a vertex-disperse processing mode, which allows for parallel processing of vertex feature vector elements across SIMD cores, minimizing vertex latency and maximizing core utilization.

Static graph partitioning is utilized to group vertices and edges, facilitating enhanced data reuse and efficient memory accesses during aggregation. The data structure is based on compressed sparse column (CSC) format, which aids in organizing vertices and edges into disjoint intervals and shards. The paper further details a dynamic data-aware sparsity elimination technique that employs a sliding and shrinking window approach to reduce unnecessary data accesses, capitalizing on the sparse nature of graph connections. 

Overall, the proposed architecture aims to achieve improved processing efficiency and reduced latency in GCN operations through innovative buffering strategies, parallel processing modes, and optimized memory access patterns.
