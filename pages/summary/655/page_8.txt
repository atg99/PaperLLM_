The paper discusses the design of a Combination Engine that integrates multiple systolic modules to enhance processing efficiency in neural networks. It presents two operational modes: the independent working mode and the cooperative working mode for systolic arrays. 

In the independent mode, each module processes a small group of vertices with direct access to weight parameters from a Weight Buffer, resulting in lower vertex latency. Conversely, the cooperative mode involves assembling aggregated features from a larger group before performing Combination operations, which allows for weight reuse across modules, thereby reducing energy consumption.

The paper also introduces an inter-engine optimization strategy that includes a Ping-Pong Aggregation Buffer. This buffer allows for the reuse of aggregation results and decouples the execution of the Aggregation and Combination engines, enhancing parallelism. Two pipeline modes are proposed: 

1. **Latency-Aware Pipeline**: This mode processes vertices one at a time, reducing latency for each vertex.
2. **Energy-Aware Pipeline**: This mode processes vertices in bursts, which increases latency but decreases overall energy consumption by optimizing weight propagation.

Lastly, the paper addresses the coordination of off-chip memory access, emphasizing the need for a single memory system to avoid bandwidth waste and configuration overheads, as both engines dynamically access memory during runtime.
