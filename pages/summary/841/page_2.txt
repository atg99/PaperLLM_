The paper highlights the ongoing advancements in secure inference, particularly in the context of convolutional neural networks (CNNs), where tools like secure multiparty computation (MPC) and Garbled Circuits have shown promise. These methods allow for image classification while protecting both the input data and the model.

Despite progress, the paper identifies several challenges that hinder the practical implementation of secure inference. The machine learning development process is inherently complex, involving data acquisition, model design, parameter tuning, and training. Existing secure inference solutions often require specialized model architectures or training processes, which complicates integration into standard workflows that utilize popular frameworks like TensorFlow or PyTorch.

The authors argue that it is crucial for secure evaluation methods to seamlessly integrate with these frameworks, allowing for minimal disruption in the model development lifecycle. They emphasize that simply converting models for secure evaluation is insufficient, as this often entails changes that can degrade model accuracy. The paper ultimately seeks to explore the extent to which current frameworks can be utilized for secure inference, aiming to streamline the process while maintaining model performance.
