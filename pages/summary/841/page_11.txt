The paper presents protocols for secure evaluation of quantized neural networks, focusing on the truncation of values while maintaining privacy and security among parties involved. The primary protocol discussed, TruncPrSpZ2k, involves three parties (P1, P2, P3) and employs random bit generation and secret sharing techniques to ensure that no party learns about the input values while still computing the correct output.

The protocol operates in several steps: random bits are sampled and used to create shared values, followed by a two-party computation where P1 and P2 collaboratively process the shared data. The correctness of the output is established through mathematical relationships that link the shared values to the expected result of the truncation operation.

Additionally, the paper addresses the need for truncation by a secret value, which is crucial in scenarios where the truncation amount is not public and must remain confidential. The protocol TruncPriv R is introduced for this purpose, utilizing a secret-shared representation of the truncation amount and secure multiplication to prevent any leakage of information.

Overall, the methods ensure semi-honest security with an honest majority, guaranteeing that parties do not gain any knowledge about the inputs beyond what is necessary for the computation, while also enabling effective quantization for neural networks.
