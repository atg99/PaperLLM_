This paper discusses the concept of explanation-redundancy in decision trees and presents a method for determining it in linear time. Explanation-redundancy occurs when a literal in a path can be removed without affecting the path's ability to yield a specific prediction. The paper exemplifies this using a decision tree with paths P and Q, illustrating how certain literals can be dropped while maintaining the inconsistency of paths in Q.

The initial approach suggested for determining explanation-redundancy involves a quadratic time algorithm that checks each literal in path P against all paths in Q. However, the paper proposes a more efficient linear time algorithm. This algorithm operates by analyzing features in path P, allowing each feature to be considered universal (able to take any value). It recursively examines paths that yield different predictions, verifying if they remain inconsistent due to other literals.

The method involves starting from the deepest non-terminal node in the path and checking child nodes not included in P for consistent sub-paths leading to a terminal node with a negative prediction. If such paths exist, the feature cannot be deemed universal and thus is essential for the explanation. A path is classified as redundant if at least one of its features is identified as such. This approach ensures that each tree node is analyzed efficiently, leading to a streamlined determination of explanation-redundancy in decision trees.
