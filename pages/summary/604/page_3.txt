This paper discusses advancements in unsupervised domain adaptation (UDA) through a method called Cluster Alignment with a Teacher (CAT). The authors argue that traditional alignment procedures often fail to achieve discriminative learning objectives due to challenges like conditional distribution shifts and label distribution shifts. While previous theoretical analyses addressed these issues with limited practical solutions, CAT offers a more robust approach.

CAT utilizes a teacher model to label data, drawing inspiration from consistency-based methods in semi-supervised learning. Unlike earlier methods that focused primarily on improving classifiers for the target domain using the cluster assumption, CAT enhances both alignment and classification by leveraging discriminative class-conditional structures.

The methodology section outlines the deep UDA framework, where a classifier is trained on labeled source samples and adapted to an unlabeled target domain. The process involves minimizing a supervised loss on the source data and a discrepancy loss between the source and target feature distributions. However, existing methods neglect minimizing the disagreement between labeling functions for the target domain, potentially inflating the target classification error.

To address these shortcomings, CAT introduces two novel losses: a discriminative clustering loss to create distinct feature clusters for each class and a cluster-based alignment loss to align these clusters across domains. The optimization problem for training CAT combines these losses with the supervised loss, aiming for improved performance in adapting classifiers to the target domain while considering the intricacies of class distributions.
