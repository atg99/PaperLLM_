This paper investigates an attention-based convolutional neural network (CNN) for recognizing weakly labeled human activities using wearable sensors. The authors propose the Att-pc-tanh architecture, which addresses limitations in existing models by generating compatibility scores that are independently normalized using the pointwise tanh function rather than softmax. This approach reduces disparity in the scores and enhances the clarity of identifying labeled activity locations.

In the location experiments, the proposed model is tested on weakly labeled data sequences, where compatibility scores are converted into compatibility density. This conversion provides a clearer determination of activity locations, focusing on peak points where activities occur intensively. The experimental setup involved using sliding windows to mark locations based on local maxima in the compatibility density curve.

The results indicate that the proposed attention model performs comparably to classical methods on the UCI HAR Dataset, with notable accuracy improvements on weakly labeled data. The attention mechanism helps to streamline the data collection process by minimizing the need for extensive manual annotation while maintaining computational efficiency. Future work will involve utilizing the model's location function to extract specific segments from weakly labeled datasets for further evaluation in human activity recognition tasks.
