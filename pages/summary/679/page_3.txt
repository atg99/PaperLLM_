This paper discusses the implementation of an attention mechanism within a convolutional neural network (CNN) architecture for human activity recognition. The authors focus on enhancing the resolution of local feature maps extracted from three convolutional layers, ensuring that both local features and global features maintain the same dimensionality of 128. This design choice minimizes computational costs associated with differing feature vector dimensions.

The location function is introduced to compute a global feature descriptor, which is essential for classifying input data. The attention mechanism is employed to map the input into a high-dimensional space, making classes more linearly separable. It aims to achieve a high compatibility score between local features and global features when the corresponding patches contain significant data categories. This allows for effective recognition of labeled activities and identification of their specific locations within weakly labeled sensor data.

The authors propose a method to convert compatibility scores into compatibility density, utilizing a sliding window to sum scores around each spatial location. This results in identifying peak points in the compatibility density curve, which indicate probable activity areas. The width of the sliding window defines the coverage of these areas, acknowledging that activities typically span multiple points in time.

The experimental section is divided into three parts: validating the attention model for traditional human activity recognition using the UCI HAR dataset, evaluating performance on weakly supervised datasets, and examining the location performance of the attention model. The experiments utilize both a simple CNN model and a baseline DeepConvLSTM model, implemented on a workstation with specified hardware and software configurations. 

The UCI HAR dataset comprises 12 daily activities recorded through a smartphone's accelerometer and gyroscope, providing a robust basis for testing the proposed methods. Overall, the incorporation of attention mechanisms within CNNs shows promise for improving human activity recognition and localization in weakly labeled data scenarios.
