The paper discusses various types of DDoS attacks, specifically highlighting UDP flooding, UDP-Lag, and CharGEN flooding. UDP flooding overwhelms a victim's server by sending numerous UDP packets, exhausting the firewall's capacity. UDP-Lag disrupts the client-server connection, while CharGEN flooding involves sending spoofed small packets to devices running the Character Generator Protocol to deplete their resources.

The authors propose a methodology called DIDDOS for detecting and identifying DDoS attacks. This approach includes data normalization, feature extraction, and classification of attacks using deep learning classifiers. The methodology is outlined in a graphical representation, showing that feature normalization and extraction occur first, followed by dataset evaluation for oversampling issues. If necessary, the dataset is balanced using SMOTE through the WEKA tool before deploying algorithms to assess their performance in detecting malware.
