The document discusses various types of network attacks, particularly focusing on those that exploit vulnerabilities in protocols and services. 

1. **LDAP Injection**: This attack targets web applications that create LDAP statements from user inputs, allowing attackers to manipulate queries.
2. **NetBIOS Attack**: This exploit enables attackers to access information in a computer's memory over a network.
3. **SNMP Attack**: This involves generating excessive traffic directed at victims from multiple networks using Simple Network Management Protocol.
4. **PORTMAP Attack**: An attack on TCP/UDP port 111, which directs clients to the correct port for Remote Procedure Call services.
5. **CharGen Attack**: This flooding attack uses spoofed IP packets sent to devices running the Character Generator Protocol, exhausting their resources.
6. **NTP Attack**: An amplification attack that utilizes publicly accessible NTP servers to flood a target with UDP traffic.
7. **TFTP Attack**: Exploits buffer overflow vulnerabilities in Trivial File Transfer Protocol servers.

The document also describes exploitation-based Distributed Denial of Service (DDoS) attacks, where attackers conceal their identity by using legitimate third-party components. They send packets to reflection servers with the victim's IP address, overwhelming the target with response packets. Key types of exploitation-based attacks include:

- **SYN Flood**: Exploits the TCP three-way handshake by sending repeated SYN packets to consume server resources.
- **UDP Flood**: Initiates a large volume of UDP packets to random ports on the target, exhausting network bandwidth.
- **UDP-Lag**: Disrupts client-server connections, often used in online gaming to hinder opponents' movements.

These attacks can significantly degrade system performance and availability.
