The paper presents an optimized Deep Q-Network (DQN) algorithm for coastal ship path planning, emphasizing the importance of a well-structured training and learning process. The algorithm utilizes a sensor system to gather environmental data, ensuring safe navigation by adhering to COLREGS guidelines. The process involves defining the ship's state, actions, action strategies, and reward functions before training. The model learns to maximize future returns through interaction, refining its strategy based on the value function.

Execution of the model follows a systematic approach: it begins with environmental data collection, followed by model input to determine the appropriate action. The ship controller implements this action, after which the new state is evaluated to check if it meets the end condition. If not, the updated state is re-entered into the model for further action planning. Ultimately, the trained model enables the ship to navigate around obstacles effectively, ensuring a safe and efficient route to its destination.
