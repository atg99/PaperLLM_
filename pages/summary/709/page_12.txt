The paper discusses a coastal ship path planning model that utilizes an optimized Deep Q-Network (DQN) algorithm to navigate ships safely from a starting point to a target point while adhering to navigation rules. The model processes real marine environment data collected through sensors, including marine radar equipment, which provides the distance and angle between the ship, target point, and obstacles. The DQN algorithm aims to maximize cumulative rewards during training, ultimately determining the optimal action strategy for safe and economical navigation.

The execution process involves several steps: 
1. Processing the ship's environment to gather state information.
2. Inputting this state information into the model to determine the ship's appropriate action.
3. Executing the determined action via the ship controller.
4. Gathering the subsequent state information to assess if the target has been reached.
5. If not at the target, the process continues with the new state information; if at the target, the model's calculations conclude.

The paper also includes a pseudo code (Algorithm 1) outlining the DQN algorithm's implementation for path planning, detailing the initialization of replay memory, action-value networks, and the iterative process of selecting actions based on current state observations, calculating rewards, and updating the model through gradient descent.

Overall, the model aims to enhance the safety and efficiency of coastal navigation by effectively managing obstacles and optimizing path selection through advanced algorithmic training.
