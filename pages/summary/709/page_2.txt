The paper discusses coastal ship path planning, which aims to create a collision-free navigation route in specific environments by considering various factors. It categorizes ship path planning into static and dynamic global path planning and local path planning. Global path planning focuses on providing a macro path solution based on geographic and meteorological data, while local path planning is concerned with avoiding dynamic obstacles and ensuring real-time collision avoidance.

The primary goal of this research is to address global path planning for ships operating in coastal environments, which is vital for the advancement of autonomous intelligent ships. The authors propose a coastal ship path planning model utilizing the deep Q network (DQN) algorithm and validate its robustness and efficiency using electronic charts.

The ship path planning problem is divided into three main sub-problems:

1. **Processing of Environmental Information**: This involves categorizing the marine environment into navigable and non-navigable areas while identifying the characteristics of each location. A grid method is employed for environmental modeling to represent the environment's status.

2. **Path Search**: This step predicts a feasible collision-free route from the starting point to the target using a specific algorithm based on the established environmental model. An optimization function iteratively refines the path to select the optimal route that meets constraint conditions.

3. **Path Smoothing**: This ensures that the planned path adheres to safety standards by avoiding complex obstacles and minimizing sharp turns. The path is evaluated and optimized to align with safe navigation rules, enhancing the safety of the ship's journey.

The paper outlines the methodology for independent path planning for coastal ships, which includes processing environmental data, selecting an intelligent algorithm for optimal path searching, and applying path smoothing techniques to ensure safety and efficiency. The subsequent sections cover related works, optimization of the DQN algorithm, experimental verification, result analysis, and conclusions.
