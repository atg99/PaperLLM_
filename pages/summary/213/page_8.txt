The paper discusses an innovative improvement to the bottleneck building block previously introduced for deep neural networks, specifically focusing on computational efficiency and the capacity to learn spatial patterns. The original design features a sequence of convolutions: a 1x1 convolution for channel reduction, a 3x3 convolution for learning spatial features, and another 1x1 convolution for channel restoration. However, this approach limits the 3x3 convolution to a smaller number of input/output channels, which can hinder performance.

To address this limitation, the authors propose a new building block called the ResGroup block, which employs grouped convolution. This technique allows for the distribution of model computations across multiple GPUs and enhances accuracy by splitting input channels into groups for independent convolution operations. This method significantly reduces parameters and floating-point operations (FLOPs) based on the number of groups used.

The paper outlines two architectures based on this design: ResGroupFix-50, which maintains a fixed number of groups (64) across all stages, resulting in reduced parameters and similar FLOPs compared to the original ResNet-50, and ResGroup-50, which adapts the number of groups according to the channels, maintaining parameter count while increasing FLOPs. Overall, the proposed architectures aim to balance computational cost with enhanced learning capacity, thereby improving performance in deep learning applications.
