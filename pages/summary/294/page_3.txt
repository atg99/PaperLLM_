The paper presents the Attention Branch Network (ABN), a framework designed to enhance image recognition tasks by utilizing attention mechanisms. ABN comprises three main components: a feature extractor, an attention branch, and a perception branch. The feature extractor employs multiple convolution layers to generate feature maps from input images. The attention branch utilizes Class Activation Mapping (CAM) to output an attention map that highlights important regions in the image, while the perception branch predicts class probabilities based on the combined features and attention maps.

ABN improves upon existing attention models, such as the residual attention network and Squeeze-and-Excitation Network (SENet), by employing a supervised learning approach that allows for effective weight extraction for attention mechanisms. This is achieved by generating attention maps that provide visual explanations for the model's focus during image recognition.

The architecture of ABN is built on baseline models like VGGNet and ResNet, integrating the attention branch to enhance performance across various image recognition tasks, including image classification, fine-grained recognition, and multi-task learning. The paper details the structure of ABN and its components, emphasizing the advantages of using attention mechanisms for visual explanations in deep learning models.
