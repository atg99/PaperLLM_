The paper discusses the architecture of an Attention Branch Network (ABN) designed to enhance image classification tasks through the incorporation of attention mechanisms. The network outputs a K×h×w feature map representing attention locations for each class, which is down-sampled to a 1×1 feature map using Global Average Pooling (GAP) before passing through a fully-connected layer with a softmax function to derive class probabilities.

To visualize attention maps, the paper introduces Class Activation Mapping (CAM), which generates attention maps by multiplying the weighted sum of the K×h×w feature map with the weights from the final fully-connected layer. The authors propose replacing fully-connected layers in baseline models, such as VGGNet, with 3×3 convolution layers to maintain the ability to localize attention in convolutional layers. For ResNet models, the attention branch is built using residual blocks, maintaining the resolution of feature maps.

The attention branch generates attention maps during training by substituting fully-connected layers with K×1×1 convolution layers, allowing for real-time attention map generation. The output feature maps are aggregated into a single 1×h×w feature map, which is normalized through a sigmoid function to form the attention map.

The perception branch of ABN combines the attention maps with feature maps from the feature extractor to produce final class probabilities. Two types of attention mechanisms are utilized, with the first being a direct dot product, while the second enhances the feature map based on attention peaks, ensuring lower values do not diminish to zero.

Training of the ABN is conducted in an end-to-end manner, optimizing both branches simultaneously, using a combined loss function derived from the softmax function and cross-entropy. The architecture is adaptable for multi-task learning in image recognition, allowing for the application of the ABN framework to various tasks beyond classification.
