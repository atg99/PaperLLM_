The paper discusses a novel approach to multi-task learning in image classification, addressing the limitations of conventional methods that typically output recognition scores for each task using a single attention map. The authors highlight the challenge posed by the one-to-many relationship in multi-task learning, where multiple target locations cannot be effectively focused on using a single attention map. To overcome this, the authors propose generating multiple attention maps tailored for each task by integrating multi-task learning into both the attention and perception branches of the model.

The baseline model used for this approach is ResNet, which is enhanced to output multiple attention maps. The attention branch is designed to process feature maps through a convolution layer, resulting in a probability score for each task by applying a sigmoid function. A perception branch is also introduced, which takes the attention map and feature maps to compute probability scores for each task.

Experimental validation is conducted using various datasets, including CIFAR10, CIFAR100, SVHN, and ImageNet, with a focus on evaluating the performance of the proposed attention mechanisms. The results show that the attention mechanism significantly reduces top-1 errors compared to conventional ResNet models, with variations in performance depending on the specific attention mechanism employed.

The experiments utilize standard data augmentation techniques and optimize the networks using stochastic gradient descent with momentum. The findings indicate that the proposed method, particularly the attention mechanisms, enhances classification accuracy across different models and datasets, showcasing the effectiveness of the multi-task learning framework in image classification tasks.
