The paper discusses the implementation of a Fuzzy Inference System (FIS) using two specific rules to determine the severity of car accidents based on speed and distance. 

Rule 1 states that if speed is low and distance is large, then the severity is minor. Rule 2 indicates that if speed is high or distance is small, then the severity is major. The minimum operator is used for the AND condition in Rule 1, while the maximum operator applies to the OR condition in Rule 2. Each rule has equal weighting in this example.

For the inputs of speed at 15 mph and distance at 80 m, the firing strength for Rule 1 is calculated using membership functions, yielding a strength of 0.5, which is used to reshape the output fuzzy set for minor severity. In contrast, Rule 2 results in a firing strength of zero, meaning it does not impact the FIS output.

The aggregation of the output fuzzy sets from both rules is essential for final decision-making in the FIS. This process combines the reshaped output membership functions from the implication process of each rule into a single fuzzy set, utilizing various aggregation methods.
