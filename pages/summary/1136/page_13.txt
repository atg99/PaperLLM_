This section of the paper discusses the Adaptive Neuro-Fuzzy Inference System (ANFIS), which integrates neural network learning capabilities with fuzzy logic to handle imprecise data effectively. The learning process involves updating connection weights based on the error calculated as the difference between the desired output (d) and the actual output (y). The weight update formula incorporates a learning rate (δ) and input vector (X), iterating until the error approaches zero.

ANFIS is structured as a feedforward network with five layers, as illustrated in Figure 20. It accepts two inputs (x and y) and produces an output (f). The architecture includes adaptive nodes with adjustable parameters and fixed nodes with predetermined parameters. The operation of ANFIS is based on fuzzy IF-THEN rules using the first-order Sugeno fuzzy inference method, where the outputs of the rules depend on the fuzzy sets associated with the inputs.

Layer 1 performs fuzzification, converting crisp inputs into degrees of membership for the defined fuzzy sets, employing Gaussian membership functions. Layer 2 computes the firing strengths of the fuzzy rules using fixed parameters to execute AND operations, resulting in outputs that represent the strength of each rule's activation. This layered approach enables ANFIS to effectively model complex systems by learning from imprecise data.
