This paper discusses a non-learnable prototype-based nonparametric segmentation model, which aims to improve semantic segmentation by addressing limitations in existing parametric methods. Prototype-based classification is rooted in the concept of representing classes with prototypes, which allows for intuitive classification by comparing data samples to these prototypes.

The authors introduce a unified view of parametric prototype learning, highlighting several critical issues often overlooked in the field. They argue that existing algorithms typically use a single prototype per class, neglecting intra-class variation and thus limiting the model's representational capability. Furthermore, the number of learnable parameters increases with the number of classes, creating scalability challenges, particularly in scenarios with many classes. This can lead to a significant increase in the computational burden, making large-vocabulary segmentation difficult.

Additionally, the paper critiques the tendency of current methods to optimize pixel-wise predictions without incorporating known inductive biases, such as intra-class compactness, which can impair the discrimination ability of learned features.

In response to these challenges, the authors propose a non-learnable prototype-based framework that utilizes a set of non-learnable class prototypes for dense prediction. This method employs a prototype-anchored metric learning scheme to supervise the pixel embedding space directly. The architecture includes an encoder network that maps input images to a feature tensor, and instead of learning class weights or query vectors, it uses a predefined group of non-learnable prototypes based on sub-centers of training pixel samples.

Overall, this nonparametric approach aims to enhance semantic segmentation by leveraging the strengths of prototypes while minimizing the drawbacks associated with learnable parameters and the associated scalability issues.
