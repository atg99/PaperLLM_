Group normalization (GN) is a technique designed to address the limitations of batch normalization (BN), particularly the issues arising from varying batch sizes. Unlike BN, which normalizes features within each channel, GN divides the channels and normalizes features separately. 

Batch-instance normalization (BIN) combines the strengths of BN and instance normalization (IN) to normalize redundant styles in images. In BIN, BN retains critical information while IN eliminates irrelevant data. The process involves two stages: first, BN normalizes each example in a mini-batch using mean and variance calculations. The second stage applies IN, which normalizes each example based on instance-specific statistics.

BIN incorporates learnable parameters to maintain important style attributes. The output of BIN is influenced by a parameter ρ, which ranges from 0 to 1. This parameter determines the balance between the outputs of BN and IN, with ρ = 1 favoring BN and ρ = 0 favoring IN.

Switchable normalization (SN) addresses the need for different normalization techniques across various convolutional layers in a convolutional neural network (CNN). SN learns to select the most appropriate normalization method for each layer, enhancing the overall performance of the network.
