The paper discusses the application of support vector regression as a metamodel in optimization algorithms, particularly in conjunction with NSGA-II and other methods. In Herrera et al., the authors focus on approximating objective functions using different basis functions tailored for various variable types—discrete, continuous, and categorical. The algorithm employs dummy coding to transform categorical values into real numbers. The proposed method was tested on a real-world problem with two objectives and ten decision variables, demonstrating comparable performance to NSGA-II with fewer function evaluations.

In a separate study, the HO-MOMA algorithm utilizes support vector regression for each objective function and incorporates a local search after evaluating new individuals. This involves nondominated sorting and calculating reference points to derive fitness values, which are subsequently optimized using the CMA-ES algorithm. The metamodel is updated by adding nondominated individuals to a fixed-size archive. HO-MOMA outperformed NSGA-II and ASM-MOMA in nine out of twelve benchmark problems.

Additionally, the ELMOEA/D-DE algorithm, inspired by MOEA/D-RBF, employs extreme learning for higher-dimensional decision spaces. It constructs a metamodel for each objective function and maintains a minimum distance between selected individuals for reevaluation. The algorithm updates the metamodel by adding new individuals while removing inferior solutions, ensuring that each new solution contributes to the archive.

Overall, the paper highlights various strategies for integrating metamodels in multi-objective evolutionary algorithms, emphasizing their effectiveness in improving optimization performance.
