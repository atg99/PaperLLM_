The paper discusses a multi-objective evolutionary algorithm known as MOEA/D-RBF, which integrates an ensemble of metamodels for optimizing multiple objective functions. The algorithm employs Radial Basis Function (RBF) metamodels with three different basis functions for each objective. The weights for the predictions are determined based on the prediction error of the metamodels.

In the MOEA/D framework, a set of uniformly distributed weight vectors is defined, and a second set of weight vectors is introduced, which is smaller in size. For each weight vector in the new set, a neighborhood of the closest weight vectors from the original set is identified. An individual from this neighborhood is selected to minimize a single objective optimization problem and is subsequently added to an archive.

The algorithm utilizes a penalty boundary intersection approach for decomposing the multi-objective problem into single-objective problems. The archive size remains fixed, and the procedure also includes eliminating excess individuals to maintain this size.

MOEA/D-RBF was evaluated against five benchmark problems and one real-world problem, demonstrating superior performance in five out of six cases when compared to both MOEA/D and MOEA/D-EGO, using hypervolume as the performance metric.

Additionally, the paper presents a comparative analysis of function approximation-based algorithms, detailing the number of publications related to different metamodels, evolutionary algorithms, and evolution control strategies. It notes that some algorithms cited were not tested on computationally intensive multi-objective problems but are relevant for addressing computational burdens in general.
