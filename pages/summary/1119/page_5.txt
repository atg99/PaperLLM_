Metamodels, synonymous with surrogates, are developed through metamodelling or function approximation. The choice of what to approximate is crucial for minimizing computation time. Common techniques include neural networks, radial basis functions, support vector regression, and Kriging.

The paper highlights the concept of ensemble metamodels, which involve using multiple metamodels to further decrease computation time. Two main approaches are identified: selecting the most accurate metamodel for evaluations or employing multiple metamodels with assigned weight coefficients. The fitness value from an ensemble is computed as a weighted sum, allowing for effective integration of different metamodels.

Model management in evolutionary algorithms (EAs) is also addressed, with strategies categorized into fixed and adaptive evolution control. Fixed control uses metamodels for a predetermined number of generations, while adaptive control modifies usage frequency based on metamodel accuracy.

The paper further explores fitness inheritance and imitation methods, where offspring fitness is derived from parent values and representative individuals within clusters, respectively. 

Lastly, the general framework for function approximation is outlined, emphasizing three application methods in MOPs: problem approximation, function approximation, and fitness approximation. Each method aims to simplify the original problem, create efficient function evaluations, and derive fitness values using metamodels, ultimately facilitating faster optimization processes.
