The paper discusses the limitations of existing dialogue models, particularly the inefficiency of backpropagation through time, which requires processing the last input of a sequence before learning can occur. It highlights two related approaches: HiTrans, which utilizes BERT with multiple utterances, and DialogXL, based on XLNet. The authors propose a novel method called EmoBERTa, which employs a pretrained RoBERTa model to handle the context of dialogue more effectively by incorporating speaker information across multiple utterances.

The methodology begins with a problem definition where a dialogue consists of multiple utterances spoken by different speakers, each labeled with an emotion. The authors argue that a function predicting the emotion of an utterance should consider both past and future context, not just the current input. EmoBERTa is designed to perform this sequence classification task by adding a linear layer to the RoBERTa model, allowing it to manage more than two segments within the input sequence.

The input sequence for EmoBERTa consists of three segments representing past, current, and future utterances, with each utterance prefixed by the speaker's name. The construction of the input sequence is detailed in an algorithm that ensures the maximum token limit is respected. The training process involves calculating a loss function based on cross-entropy loss and L2 weight decay, using adaptive gradient descent and mixed precision to optimize training efficiency. The paper concludes with an emphasis on the model's ability to generalize and the empirical improvements observed when using capitalized speaker names.
