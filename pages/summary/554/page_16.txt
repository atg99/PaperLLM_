The paper presents NAS-Bench-201, a comprehensive benchmark for neural architecture search (NAS) that includes a dataset of 6219 architectures trained at least once, with an additional 1621 and 7785 architectures trained twice and three times respectively. The training is conducted using different random seeds to ensure robustness. The benchmark includes latency measurements for each architecture, computed on a GeForce GTX 1080 Ti GPU with a batch size of 256, covering datasets such as CIFAR-100 and ImageNet-16-120.

To facilitate access to NAS-Bench-201, the authors provide an easy-to-use API that can be installed via pip. The API allows users to query architecture metrics, such as accuracy, loss, FLOPs, number of parameters, and latency for specific architectures. The paper includes code snippets demonstrating how to utilize the API for various tasks, including listing architectures and retrieving metrics for specific architectures.

For further usage examples and to download the benchmark data file, the authors direct readers to their GitHub repository and a Google Drive link. This work aims to support advancements in NAS by providing a standardized and accessible set of architectures and their performance metrics.
