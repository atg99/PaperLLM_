This paper discusses the application of neural networks, specifically U-Net, in X-Ray image segmentation, emphasizing its limited use in specific scenarios. The data utilized in this study is sourced from IBEX Innovations Ltd. and comprises 3269 CT scan images and 81 standard X-Ray images, with a noted underrepresentation of thorax images. The dataset includes some images with foreign metal objects, which are classified as bone. The images underwent preprocessing, including dark correction and normalization, and were labeled using GIMP to distinguish between open beam, soft tissue, and bone regions. A key objective is to minimize false positives for soft tissue by careful labeling.

The dataset is notably small and unbalanced, containing only 150 images across various body part classes. To address this, the authors employed data augmentation techniques to increase the dataset size and balance the classes. Elastic transformations, along with translations, rotations, shear, and cropping, were found to be effective, aiming for 500 images per body part class for optimal validation accuracy.

The architecture developed for this task, named XNet, follows an encoder-decoder style common in image segmentation. The encoder consists of convolutional layers for feature extraction and max pooling layers for downsampling. This multi-stage downsampling allows for the learning of features at varying levels of granularity, facilitating the extraction of increasingly global features through successive pooling stages.
