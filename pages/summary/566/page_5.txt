The paper discusses the composition and preprocessing of datasets used for intrusion detection systems (IDS), focusing on the NSL-KDD and CSE-CIC-IDS2018 datasets. The NSL-KDD dataset comprises various attack categories, including normal traffic, DoS, Probe, R2L, and U2R, with a total of 125,973 records for training and testing. The dataset features continuous data types, with specific nominal features requiring transformation through feature encoding to prepare them for machine learning algorithms.

Data preparation involves grouping labels by attack type and converting categorical data into numeric form using one-hot encoding, which has proven more effective than ordinal encoding in initial tests. The preprocessing steps also include feature scaling, which adjusts the range of feature values to improve training efficiency. The paper employs min-max scaling for this purpose.

Performance evaluation metrics are outlined, including confusion matrix components (true positives, false positives, true negatives, and false negatives) and common performance metrics like accuracy, detection rate, false alarm rate, precision, and F1-score. 

Furthermore, hyperparameter optimization is critical for enhancing model performance. The tuning process focuses on parameters such as the number of neurons and layers in the deep neural network, learning rate, initialization weights, activation function, and loss function. The paper emphasizes that careful tuning can mitigate overfitting and optimize detection rates, ultimately improving the IDS's effectiveness.
