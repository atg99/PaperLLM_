The paper presents a deep learning architecture designed for intrusion detection systems (IDS). It emphasizes optimizing the hyperparameter values of the autoencoder (AE) model as part of the classifier model. The process involves feature extraction through the AE, followed by the development of a deep neural network (DNN) as a classifier. The DNN utilizes the encoded output from the AE, which is retrained with pre-trained weights and biases to classify inputs into multiple attack classes or binary classes based on the NSL-KDD dataset.

The architecture incorporates various activation functions, particularly variants of the rectified linear unit (ReLU) for hidden layers, and uses sigmoid and softmax functions for binary and multiclass classification, respectively. The model is initialized with parameters derived from the AE encoding process, and the loss functions are tailored to the classification type.

Experiments were conducted on a computer platform with specified hardware and software configurations, utilizing TensorFlow and Keras for deep learning processes. The performance of the proposed model was evaluated using two datasets: the NSL-KDD dataset, a benchmark for previous IDS studies, and the CSE-CIC-IDS2018 dataset, which reflects contemporary network traffic and attack scenarios.

The NSL-KDD dataset includes a variety of attack types and normal traffic, while the CSE-CIC-IDS2018 dataset consists of a comprehensive set of features derived from current network behavior. The study aims to validate the effectiveness of deep learning with different autoencoder feature extraction methods on these datasets.
