This paper discusses the architecture of an encoder-decoder model used for predicting city tours. The encoder processes input sequences and generates a representation, denoted as H`, through a series of transformations. The initial input includes a start token z, combined with another input X, and results in a concatenated representation.

The encoder output is used to compute attention scores via the softmax function, which involves the query (Q`), key (K`), and value (V`) matrices derived from the encoder's output. These matrices are computed using learned weight matrices and the representation H`.

The decoding process is auto-regressive, meaning it predicts the next city based on previously decoded cities. The first step involves encoding the last selected city, followed by initializing the decoding with a start state that incorporates positional encoding.

Figures included in the paper illustrate the encoder and the four steps of the decoding process, enhancing the understanding of the architecture and its functioning.
