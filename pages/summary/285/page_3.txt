The paper presents a proposed architecture for solving the Traveling Salesman Problem (TSP) using a transformer model. The approach frames TSP as a translation task, where the input comprises a set of 2D points and the output is a sequence representing the optimal tour with minimal length. The decoding process is sequential, utilizing a query that includes the first city, the last city in the current tour, and a global representation of all cities. 

The training leverages reinforcement learning (RL) with a deterministic baseline, where the reward is based on the length of the tour. The proposed architecture includes a standard transformer encoder featuring multi-head attention and residual connections, with a notable modification of employing batch normalization instead of layer normalization. The encoder's memory and speed complexity is quadratic in relation to the number of cities, denoted as O(n^2).

The paper also discusses related works including GraphConvNet, which predicts edge probabilities in TSP tours through supervision and generates feasible tours via beam search; 2-Opt Learning, which utilizes a transformer to select nodes for the 2-Opt heuristic through RL; and GNNs augmented with Monte Carlo Tree Search to enhance tour exploration by evaluating multiple candidate nodes. Each of these approaches aims to improve TSP solutions through various methodologies, highlighting the evolving techniques in tackling combinatorial optimization problems like TSP.
