The paper discusses advancements in neural architecture search (NAS), particularly focusing on the DARTS (Differentiable Architecture Search) approach. Traditional methods for connecting neural modules have been criticized for not being optimal and often rely on discrete search strategies that limit flexibility. DARTS innovates by continuously relaxing the discrete search strategy, allowing for gradient-based optimization in the architecture search space.

DARTS utilizes a cell-based search space, where each cell is represented as a directed acyclic graph (DAG) composed of nodes. Each cell has two input nodes and one output node, with convolutional and recurrent cells structured accordingly. The output of the cell is generated by concatenating results from all intermediate nodes, each of which is linked by directed edge operations.

The method introduces a softmax approach to select candidate operations, transforming the discrete selection into a continuous optimization process for a set of variables. This allows the architecture search to be framed as a bilevel optimization problem, where the upper-level variable represents the mixed operations and the lower-level variable corresponds to the network weights. The optimization aims to minimize validation and training losses jointly.

In contrast to DARTS, another approach called NAO (Neural Architecture Optimization) encodes the entire neural architecture into a continuous space, subsequently optimizing the performance predictor through gradient methods to achieve the best embedded coding before discretization.

Overall, DARTS represents a significant evolution in neural architecture search methodologies, enabling more efficient and flexible exploration of neural network designs.
