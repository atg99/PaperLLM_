The paper describes a novel approach for brain tumor segmentation using a pipeline that includes pre-processing and the implementation of SegNet networks. Initially, MRI scans undergo N4ITK bias field correction, and the top and bottom 1% of intensity values are removed during normalization to ensure consistency across training images. To optimize memory usage and reduce unnecessary data, black areas of the image background are trimmed, resulting in input images sized at 192 x 192 pixels.

The core of the pre-processing phase involves constructing a 3D database from the MRI dataset, which includes four modalities for each patient. Each slice's processing incorporates adjacent slices to leverage 3D information, treating them as color channels for the input images.

For segmentation, the paper employs a semantic segmentation model that takes full-size images as input to extract features in an end-to-end manner. A pretrained SegNet is utilized, with parameters fine-tuned on images that have been manually annotated to identify tumor regions, enhancing the model's accuracy for testing.
