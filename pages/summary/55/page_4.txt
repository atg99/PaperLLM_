The paper presents a novel architecture called PredRNN, which enhances the original ConvLSTM network by introducing a spatiotemporal memory flow. This architecture is designed to improve predictive learning tasks, particularly in scenarios where input frames and expected outputs share similar data distributions in both spatial and temporal domains. 

In the original ConvLSTM framework, memory states are confined within individual recurrent layers, limiting their interaction and effectiveness in making predictions. The authors propose a new memory state transition method that allows for a zigzag flow of memory states between layers, facilitating better information transfer from inputs to outputs. This approach integrates high-level global motion understanding with detailed memory of subtle variations in the input sequence.

The key equations governing this new memory flow are presented, highlighting the roles of input, forget, and output gates, which now depend on the hidden states and memory states from previous layers rather than just the previous timestep. This modification allows the network to maintain a comprehensive memory bank that supports hierarchical visual representations and reduces information loss as data progresses through the layers.

The spatiotemporal memory flow also enhances the model’s ability to capture short-term dynamics without necessitating larger convolution kernels, which are typically required in standard ConvLSTM for fast motion detection. Additionally, the authors draw parallels between their proposed memory flow and classic memory networks, noting that their mechanism allows for capturing long-term structures in sequences effectively.

Overall, the PredRNN architecture represents a significant advancement in spatiotemporal modeling, offering improved predictive capabilities through a more integrated and hierarchical approach to memory state transitions.
