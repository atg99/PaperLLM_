This paper presents an Intrusion Detection System (IDS) that utilizes Deep Belief Networks (DBN) and Multi-Layer Perceptrons (MLP) for detecting network intrusions. The architecture of the MLP consists of an input layer with 49 nodes, followed by two fully connected layers (FC1 and FC2) with 64 nodes each, culminating in an output layer (FC3) with 6 nodes. The DBN architecture involves several Restricted Boltzmann Machines (RBMs) with varying input and output sizes, ultimately leading to a fully connected output layer with 6 nodes.

The dataset used comprises 78 network features extracted from network traffic using the CICFlowMeter. Redundant features were removed, including ten with no variance and seventeen that were highly correlated. The dataset was then divided into training, validation, and testing sets in a 60-20-20 ratio. To address outliers, quantile transformation was applied to normalize the features within a uniform distribution. Class balancing techniques were explored to mitigate class imbalance, leading to the removal of the "Infiltration" class due to its minimal representation.

Additionally, Principal Component Analysis (PCA) was performed to reduce the dimensionality of the feature space while retaining 99% of the explained variance with just 25 principal components, effectively halving the feature space without significant information loss. The study highlights the importance of pre-processing and feature selection in enhancing the performance of deep learning models in intrusion detection.
