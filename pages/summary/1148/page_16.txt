The paper discusses two variants of Tree Supervision Loss: Hard Tree Supervision Loss and Soft Tree Supervision Loss. 

Hard Tree Supervision Loss operates by defining a cross-entropy term at each node of a decision tree. The loss is calculated for each internal node based on the probabilities of its child nodes, effectively creating a series of c-way cross-entropy losses. This approach allows for the optimization of a hierarchical softmax that supports trees of arbitrary depth using a single, fully-connected layer. The overall loss combines the original cross-entropy loss with the new hard tree supervision loss, ensuring both are weighted equally.

In contrast, Soft Tree Supervision Loss computes cross-entropy over all leaf probabilities, considering the product of probabilities leading to the root node. This method allows for a more nuanced representation of class probabilities across all leaves.

The paper also examines the inference strategies associated with these loss functions. Hard inference, which selects child nodes based on the highest probability, is described as more intuitive but ultimately less effective compared to soft inference. The findings indicate that while hard tree supervision loss is designed to optimize hard inference, it does not outperform soft tree supervision loss in practice.

In summary, while both loss functions aim to improve decision tree performance, the soft variant demonstrates superior results in the context of inference.
