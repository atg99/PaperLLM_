LSTM networks, a type of recurrent neural network (RNN), enhance the capabilities of simple RNNs by incorporating mechanisms that allow them to maintain and manipulate memory over time. The architecture features three primary gates: the forget gate (ft), the input gate (it), and the output gate (ot), which govern the flow of information into and out of the memory cell (ct). Each gate utilizes a sigmoid activation function, which constrains outputs between 0 and 1, enabling a nuanced control of information flow—where 0 signifies complete inhibition and 1 signifies full activation.

The equations governing these gates demonstrate their similarity to simple RNNs, differing primarily in the activation functions used. The candidate memory cell update (˜ct) is computed through a tanh transformation, akin to the approach in simple RNNs. The integration of the previous memory cell state (ct−1) with the candidate update is mediated by the forget and input gates, allowing for a dynamic adjustment of memory. The final hidden state (ht) is derived from the output gate, completing the process of memory management within the LSTM architecture. Overall, LSTMs offer a more sophisticated approach to learning temporal dependencies, addressing the limitations of simple RNNs by enabling the retention of information over longer sequences.
