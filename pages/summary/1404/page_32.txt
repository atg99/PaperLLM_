The paper presents a summary of various detectors that utilize context information to enhance object detection performance. It categorizes these detectors into two groups: global context and local context, detailing their backbone architectures, methodologies, and performance metrics.

In the global context category, notable detectors include SegDeepM, which employs additional features from enlarged object proposals as contextual information, and DeepIDNet, which utilizes image classification scores to refine detection scores. ION integrates contextual information from outside the region of interest using spatial recurrent neural networks, while CPF leverages semantic segmentation for top-down feedback.

In the local context group, MRCNN extracts features from multiple surrounding regions to enhance object proposals and integrates semantic segmentation-aware features. GBDNet focuses on learning relationships among multiscale contextual regions around an object proposal, employing a messaging mechanism among features from different context regions.

The summary includes performance metrics like mean Average Precision (mAP) at Intersection over Union (IoU) thresholds, highlighting key advancements in context-aware object detection techniques published in various conferences between 2015 and 2018.
