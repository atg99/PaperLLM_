The paper presents a comparative analysis of various object detection frameworks, highlighting their performance metrics such as mean Average Precision (mAP) at an Intersection over Union (IoU) threshold of 0.5 across different datasets including VOC07, VOC12, and COCO. Key detectors discussed include ACCNN, which utilizes Long Short-Term Memory (LSTM) networks to capture global context by concatenating features from multi-scale contextual regions; CoupleNet, which employs a combination of convolution and element-wise summation of features from different contextual regions; and SMN, which models object-object relationships through a spatial memory network. Other notable frameworks include ORN, which focuses on the interactions of object proposals, and SIN, which approaches object detection using graph-structured inference. Each framework is published in reputable conferences, indicating their contributions to advancing object detection techniques.
