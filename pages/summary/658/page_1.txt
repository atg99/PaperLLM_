The paper presents Grid-GCN, a novel method designed for fast and scalable point cloud learning by addressing the inefficiencies in existing point-based models. Traditional graph convolutional networks (GCNs) effectively preserve data granularity and exploit inter-point relationships but face challenges with data structuring, which can hinder speed and scalability. To overcome these limitations, Grid-GCN introduces a Coverage-Aware Grid Query (CAGQ) strategy that enhances spatial coverage and reduces theoretical time complexity. This approach significantly accelerates processing, achieving up to a 50-fold speed improvement compared to common sampling methods like Farthest Point Sampling (FPS) and Ball Query.

Additionally, the Grid Context Aggregation (GCA) module within Grid-GCN ensures state-of-the-art performance in point cloud classification and segmentation tasks while maintaining faster runtimes than previous models. Notably, Grid-GCN reaches an inference speed of 50 frames per second on the ScanNet dataset with 81920 points as input. The paper highlights the efficiency of Grid-GCN in processing large point clouds, addressing the cubic growth in computation and memory usage associated with high voxel resolutions in volumetric models, which often involve significant processing of empty voxels. The results indicate that Grid-GCN effectively balances speed and performance in point cloud learning applications. The supplementary materials and code are made available for further exploration.
