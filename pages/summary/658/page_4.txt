The paper discusses the Center Voxel Selection (CAS) method aimed at optimizing the coverage of occupied space by selecting a set of center voxels. The approach employs a greedy algorithm due to the complexity of iterating through all possible combinations. Initially, M voxels are randomly selected from incumbents. The algorithm then iteratively evaluates unpicked voxels as challengers against incumbents, replacing incumbents if the coverage improves based on specific heuristics.

The heuristics involve calculating coverage gains (Hadd) and losses (Hrmv) associated with adding or removing voxels. If the gain from adding a challenger exceeds the loss from removing an incumbent, the replacement occurs, ensuring improved coverage when β is set to zero.

The paper also introduces two strategies for node point querying: Cube Query, which randomly selects K points from context points for better spatial coverage, and K-Nearest Neighbors (k-NN), which optimizes search speed by limiting the search to context points only.

Furthermore, the Grid Context Aggregation (GCA) module aggregates features from node points to the group center by constructing a local graph and utilizing an edge attention function that considers both geometric relations and the coverage weight of node points. The coverage weight reflects the number of points aggregated to a node, enhancing the edge attention mechanism.

The introduction of Grid Context Pooling allows the extraction of context features from all context points, ensuring comprehensive spatial coverage while modeling the features of a virtual group center. This method aims to improve the performance of the network architecture by effectively utilizing spatial and semantic relationships in the data.
