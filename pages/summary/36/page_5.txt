The paper discusses the implementation of an Oriented R-CNN for detecting oriented objects using a novel technique called rotated RoIAlign. The process begins with the generation of parallelogram proposals by an oriented Region Proposal Network (RPN). These proposals are transformed into oriented rectangles for feature extraction, which is crucial for maintaining rotation invariance. Rotated RoIAlign extracts fixed-size feature vectors from the feature maps, and these vectors are processed through two fully-connected layers. The output includes class probabilities and offsets for object detection.

The rotated RoIAlign process involves adjusting the parallelogram proposals into oriented rectangles, defined by their parameters, and projecting them onto the feature map. The rectangles are divided into grids to obtain a fixed-size feature map. The feature values for each grid are computed based on the localized samples.

The Oriented R-CNN is trained end-to-end, optimizing both the oriented RPN and the detection head. During inference, a Non-Maximum Suppression (NMS) strategy is employed to minimize redundancy among proposals, ensuring only the most relevant proposals are retained for further classification.

The paper evaluates the proposed method using two datasets: DOTA and HRSC2016. DOTA consists of a large number of images with various object classes, while HRSC2016 focuses on arbitrary-oriented ship detection. Both datasets are used to assess detection accuracy, with DOTA using an evaluation server and HRSC2016 employing mean average precision as the evaluation metric.
