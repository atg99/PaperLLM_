This paper investigates the limitations in the efficiency of region proposal-based oriented detectors, identifying proposal generation as a key bottleneck. To address this, the authors propose a novel oriented region proposal network (oriented RPN) as part of a two-stage oriented object detection framework called oriented R-CNN. This framework aims to improve detection accuracy while maintaining competitive efficiency compared to one-stage oriented detectors.

In the first stage, the oriented RPN is introduced as a lightweight fully convolutional network with fewer parameters than existing methods, which reduces the risk of overfitting. This is achieved by modifying the output parameters of the regression branch from four to six, utilizing a new representation scheme called midpoint offset representation. This representation efficiently captures the characteristics of oriented objects using six parameters, combining a horizontal regression mechanism with bounded constraints for oriented proposals.

The second stage consists of the oriented R-CNN detection head, which extracts features from each oriented proposal through rotated RoI alignment, followed by classification and regression tasks. The method is evaluated on two benchmarks, DOTA and HRSC2016, achieving state-of-the-art detection accuracy with 75.87% mAP on DOTA and 96.50% mAP on HRSC2016, while maintaining a processing speed of 15.1 FPS on a standard GPU.

The authors hope that their findings will encourage reevaluation of the design of oriented object detectors and regression schemes, serving as a solid baseline for future research in this area. The paper also provides access to their code for public use.
