The paper presents the oriented R-CNN, a two-stage detector designed for oriented object detection, which consists of an oriented Region Proposal Network (RPN) and an oriented R-CNN head. The framework is built on a Feature Pyramid Network (FPN) that generates five levels of feature maps. 

In the first stage, the oriented RPN generates a sparse set of high-quality oriented proposals efficiently, using lightweight fully-convolutional networks. It processes the multi-level features from the FPN by applying a head that includes a 3x3 convolutional layer and two sibling 1x1 convolutional layers at each feature level. The RPN utilizes three horizontal anchors with different aspect ratios at each spatial location, with specific pixel areas assigned to each feature level. Each anchor is represented by a four-dimensional vector denoting its center coordinates, width, and height. 

The regression branch of the RPN outputs offsets for the proposals relative to the anchors, allowing for the decoding of these proposals. The decoding process involves calculating the center coordinates, width, height, and orientation offsets for the predicted proposals. Additionally, the other sibling layer estimates the objectness score for each generated proposal.

The paper emphasizes the efficiency of the oriented RPN as a means to overcome computational bottlenecks in generating oriented proposals, setting the stage for the subsequent classification and refinement of spatial locations in the oriented R-CNN head.
