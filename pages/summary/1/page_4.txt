This paper discusses the distinctions between deep learning (DL) and shallow machine learning (ML), emphasizing their respective capabilities and applications. Deep learning, characterized by its ability to handle complex, high-dimensional data, outperforms shallow ML in tasks involving text, images, video, speech, and audio. However, shallow ML can excel in low-dimensional data scenarios, particularly when training data is limited, and often provides better interpretability.

The paper outlines an analytical model-building framework that encompasses explicit programming, shallow ML, and DL, focusing on key aspects such as data input, feature extraction, model building, and assessment. It highlights the importance of algorithmic support for processing large datasets, particularly unstructured data from electronic markets, which include time series, images, and text.

Data input from various sources generates significant volumes of versatile data, necessitating automated pattern detection. Time series data is used for forecasting, image data for object recognition, and text data for sentiment analysis and translation. Recent advancements in DL enable cross-modal learning, allowing for the integration of different data types, enhancing tasks like retrieval and recommendation.

Feature extraction is a critical process for identifying patterns within large datasets, where features serve as informative representations derived from raw data. Shallow ML relies heavily on effective feature extraction, utilizing various techniques tailored to specific data types. Examples include time-domain and frequency-domain features for time series, histogram of oriented gradients for images, and term frequency-inverse document frequency for natural language processing.

Overall, the paper illustrates the nuanced relationship between DL and shallow ML, providing insights into their respective strengths and applications in analytical model building.
