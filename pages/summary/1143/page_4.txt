The paper discusses the design of an A2-C1 type interval TSK fuzzy logic system integrated with a fuzzy neural network, utilizing an improved Ant Colony Optimization (IACO) method for parameter adjustment and rule selection. 

Section 4.1 outlines the structure of the fuzzy neural network, consisting of five layers: an input layer for variables, a membership function layer using Gaussian functions, a rule firing layer to compute rule strengths, a weight layer for rule weights, and an output layer generating the system's final output. 

In Section 4.2, the paper describes the parameter adjustment process based on IACO. This involves calculating the total number of parameters, constructing a search paths matrix, and iteratively determining optimal parameters by minimizing the root mean square error (RMSE). The steps include calculating the number of parameters, defining IACO variables, assigning ants to nodes, calculating RMSE for selected parameters, and updating pheromone trails to guide future iterations.

Section 4.3 focuses on rule selection within the fuzzy logic system. It emphasizes the importance of eliminating low-efficiency rules, as they can negatively impact the system's performance and increase complexity. The IACO method is again employed, treating the RMSE of rules as search paths, with steps mirroring those in parameter adjustment, including the calculation of RMSE for each rule and updating pheromone trails based on the product of path lengths.

Overall, the paper presents a systematic approach to enhance the efficiency and effectiveness of the A2-C1 type interval TSK fuzzy logic system through the integration of fuzzy neural networks and advanced optimization techniques.
