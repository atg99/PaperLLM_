This paper presents a novel approach to designing type-2 fuzzy logic systems using an Improved Ant Colony Optimization (IACO) technique. The design process is outlined through a series of steps, starting from the initialization of the ant colony to the output of optimal paths that form the rule base for an A2-C1 type interval Takagi-Sugeno-Kang (TSK) fuzzy logic system. The flowchart in Figure 1 illustrates this design methodology.

To validate the proposed method, the authors apply it to forecast the Mackey-Glass chaotic time series. The dataset consists of 1000 data points, with the first 500 used for system design and the remaining for testing. The fuzzy logic system is structured as a Multiple Input Single Output (MISO) system, utilizing two fuzzy sets for each antecedent, resulting in a total of 16 rules. The integration of the A2-C1 type interval TSK fuzzy logic system with a neural network yields a five-layer fuzzy neural network employing various techniques for fuzzification, inference, and defuzzification.

The parameter adjustment process involves constructing a random symmetrical matrix to optimize 416 parameters. Key parameters for the IACO algorithm include an information elicitation factor of 0.5, expected heuristic of 1.2, and pheromone evaporation coefficient of 0.7, with a maximum of 2000 iterations. The training results demonstrate the effectiveness of the IACO-based system, as shown in Figure 2.

The authors also compare the performance of the IACO-based system with a traditional Ant Colony Optimization (ACO) system, maintaining the same structure and parameters. This comparison emphasizes the benefits of updating global pheromone trails in enhancing system performance, as illustrated in Figure 4. Overall, the study showcases the superiority of the IACO method in designing efficient type-2 fuzzy logic systems.
