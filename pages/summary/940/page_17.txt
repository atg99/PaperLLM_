The document presents two algorithms, PullUpdate and UpdateBackward, for managing a decision-making process based on a tree structure. 

Algorithm 4, PullUpdate, begins by initializing parameters and entering a loop that continues as long as the current node is not a leaf and the threshold condition is met. It identifies the best child node based on a reward structure, updates the state, and pulls an action to receive a reward. The algorithm then updates estimates of the mean and variance, computes a utility value, and calls UpdateBackward to adjust the tree.

Algorithm 5, UpdateBackward, processes the tree in reverse from each leaf. It updates the utility values for each node based on whether it is a leaf or not, and adjusts the threshold for each node accordingly.
