The paper presents a function implementing the Q-learning algorithm with linear function approximation, referred to as QLearningLinFApp. This function is invoked after each transition and takes the last state X, the next state Y, the immediate reward R, and a parameter vector ϕ as inputs. The algorithm updates the parameter vector based on the maximum expected reward for the next state and the current state-action pair.

The extension of Q-learning to include function approximation is discussed, where the update rule incorporates the parameter vector ϕ. However, the paper notes that the convergence properties of this update rule are not well-established, particularly when off-policy sampling or nonlinear function approximation is involved. It references a convergence result by Melo et al. (2008) under restrictive conditions on sample distribution, and highlights the greedy gradient Q-learning algorithm proposed by Maei et al. (2010b), which guarantees convergence independent of the sampling distribution, but may encounter local minima due to the non-convex nature of its objective function.

To enhance convergence, the paper suggests employing state aggregation methods. If the value function approximation is restricted to a state and action aggregator and the process is stationary, the algorithm can behave similarly to tabular Q-learning, leading to convergence towards an approximation of the optimal action-value function. This approach is supported by references to established literature, indicating its theoretical foundation.
