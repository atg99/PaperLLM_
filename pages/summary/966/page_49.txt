The paper presents algorithms for action selection and updating in the Upper Confidence Bound (UCB1) framework, particularly focusing on a context where rewards are bounded between 0 and 1. 

Algorithm 8 describes the UCB1 action selection function, which operates under the assumption that the initial counts of actions (n[a]) and the rewards (r[a]) are both set to zero. The algorithm calculates an upper confidence bound (U) for each action by combining the average reward (r[a]) and a confidence term that accounts for the number of times an action has been selected. The action with the maximum U value is selected for execution.

Algorithm 9 outlines the UCB1 update routine, which is called after each interaction. This function updates the count of times an action has been taken and adjusts the average reward estimate based on the received reward. 

The paper further discusses active learning within the context of bandit problems, specifically in scenarios with a single state Markov Decision Process (MDP). The objective is to identify the action that yields the highest immediate reward over a specified number of interactions (T). The approach involves calculating upper and lower confidence bounds for each action to determine which actions should be explored further, ensuring that actions deemed suboptimal are not selected without sufficient evidence.

Overall, the algorithms and concepts outlined aim to efficiently balance exploration and exploitation in decision-making processes under uncertainty.
