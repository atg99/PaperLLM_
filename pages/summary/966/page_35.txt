The paper presents the GTD2 algorithm, which is a function used to update parameters after state transitions in reinforcement learning contexts. The GTD2 function takes inputs including the last state X, the next state Y, the immediate reward R, a parameter vector ϕ, and an auxiliary weight w. The algorithm computes the updated parameters by following a series of steps that involve calculating the function approximations for the states and adjusting the parameters based on the rewards received and the differences between the approximated values.

The update rule for the weight w remains unchanged, but the update for the parameter vector ϕ is modified slightly in the TDC variant. The paper notes that TDC requires larger step sizes for the weight updates compared to the parameter updates, which classifies it as a two-timescale stochastic approximation algorithm. When both step-size sequences satisfy standard RM conditions, convergence of the parameter vector to a stationary point is almost certain.

Furthermore, the paper discusses extensions of these algorithms to accommodate nonlinear function approximations and the use of eligibility traces. It highlights that while these algorithms are derived from an objective function's gradient, they are categorized as pseudo-gradient methods, as the expected direction of weight updates may not align with the negative gradient direction. The distinction between the two methods lies in their gradient approximation techniques, leaving open the question of which method may perform better in practice.
