The paper presents the RLSTD algorithm, which implements the recursive least-squares temporal difference learning. The algorithm is invoked after each transition, starting with a diagonal matrix C initialized with small positive elements. The function takes inputs including the last state X, next state Y, immediate reward R, the matrix C, and the parameter vector θ.

The algorithm proceeds through several steps: it calculates the feature vectors for the current and next states, computes a vector g, and updates the parameter vector θ and matrix C based on the derived values. The RLSTD algorithm minimizes the empirical approximation of the projected squared Bellman error over a linear function space. It is related to sample average approximation in stochastic programming and belongs to the Z-estimation family in statistics.

The paper also discusses the derivation of an incremental version of LSTD using the Sherman-Morrison formula, leading to a computational complexity of O(d²) for updates. Additionally, Boyan's extension of LSTD incorporates the parameter of TD(λ), resulting in LSTD(λ), which requires that the next state matches the subsequent observation for λ > 0.
