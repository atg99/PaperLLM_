The paper discusses the algorithm ϕ-LSPE, which employs a fitted value iteration approach for policy evaluation using linear function approximation. At each time step t, the algorithm minimizes a least-squares problem to estimate parameters that approximate the value function, denoted as TVϕt(x). The algorithm's performance improves with larger sample sizes and richer function spaces, leading to a close approximation of the true regression function.

Smoothing updates is a key feature of the algorithm, which serves to stabilize parameters in small sample scenarios and facilitates gradual policy changes when used within control algorithms. The paper also highlights that when ϕ > 0, the multi-step version of ϕ-LSPE requires the next state to be equal to the next reward, and increasing ϕ reduces bias while increasing variance. Notably, ϕ-LSPE can bootstrap even with ϕ = 1, with diminishing effects as sample size increases.

Under standard assumptions, ϕ-LSPE converges almost surely to a solution of a projected fixed-point equation, with convergence guaranteed for specific step-size conditions. The algorithm is shown to be competitive with LSTD, as the parameter distance between the two methods diminishes faster than the statistical inaccuracies associated with finite samples. Experimental results in training a Tetris-playing program confirm the competitiveness of ϕ-LSPE.

The paper also contrasts least-squares methods with temporal-difference methods, noting the trade-off between stability and computational complexity. While least-squares techniques are more stable and accurate, they incur higher computational costs, with straightforward implementations of LSTD requiring O(nd² + d³) complexity compared to O(nd²) for RLSTD and LSPE.
