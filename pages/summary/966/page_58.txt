The paper discusses a framework for modeling operations research problems using the relation P(x;a;y) = PA(f(x;a);y), where f is a known transition function and PA is a probability kernel. This structure is prominent in various applications, such as inventory control, where the deterministic effect of actions is modeled by f, while PA captures their stochastic effects. 

The concept of post-decision states, referred to as "afterstates," allows for a more efficient approach to learning the immediate reward function and the post-decision state optimal value function, denoted as V_A. This function is defined as V_A(z) = Σ_y∈X PA(z;y)V_A(y). The advantage of this approach lies in the relationship Q_A(x;a) = r(x;a) + V_A(f(x;a)), which simplifies the computation process.

When transition probabilities are available, approximating the state-value function can be complex due to the need for stochastic optimization. However, using the post-decision state value function VA streamlines this process, as finding the greedy action reduces to maximizing r(x;a) + VA(f(x;a)), avoiding the need for expectation calculations. 

This simplification is particularly beneficial in scenarios with large state or action spaces, where traditional methods may become computationally challenging. The use of post-decision state value functions may also require less storage and fewer samples for learning than action-value functions. Overall, the paper highlights the potential advantages of using post-decision states in operations research problems, as detailed in Powell (2007).
