This section discusses a method for implementing policy updates in reinforcement learning through compatible function approximation, as proposed by Sutton et al. and Konda and Tsitsiklis. It begins by defining a linear-in-the-parameters function approximation to estimate the action-value function Q, using a score function aligned with the policy class. This approach is termed "compatible" due to its dependence on the parameters of the policy.

The text outlines a process for determining suitable parameter values, introducing a system of equations to minimize the mean-squared error between the estimated and true action-value functions. A closed-loop learning algorithm is then proposed, which involves three key steps: following the current policy, updating the parameter vector on a faster timescale using an adaptation of SARSA(1), and adjusting the policy parameters on a slower timescale based on the difference between the estimated action-value and a target function.

Furthermore, Konda and Tsitsiklis provided theoretical results confirming that under certain conditions, the average cost associated with the policy updates approaches zero almost surely when the average-cost version of SARSA(1) is employed. They also noted that using SARSA with a specific parameter leads to similar convergence results. Lastly, an alternative update rule for the policy parameters is suggested, simplifying the update process.
