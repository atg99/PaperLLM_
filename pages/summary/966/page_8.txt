Markov Decision Processes (MDPs) are used to model sequential decision-making scenarios where a decision maker interacts with a system over time. In this context, a countable MDP is defined as a triplet M = (X, A, P0), where X represents a countable set of states, A is a countable set of actions, and P0 is the transition probability kernel. This kernel assigns a probability measure to each state-action pair (x, a), indicating the probability of transitioning to the next state and receiving a corresponding reward.

For any state-action pair, the transition probability kernel P0(U | x, a) gives the likelihood that the next state and reward belong to a specific set U, given the current state x and action a. Additionally, a discount factor between 0 and 1 is introduced, which plays a significant role in evaluating rewards over time.

The transition probability kernel leads to the state transition probability P, which calculates the probability of moving from state x to state y when action a is chosen. Furthermore, P0 helps define the immediate reward function r: X × A → R, which represents the expected immediate reward for taking action a in state x. It is assumed that rewards are bounded by a constant R, ensuring that the expected rewards do not exceed this bound.

MDPs can be finite if both the state and action sets are finite. Overall, MDPs are crucial for analyzing and solving problems involving sequential decision-making under uncertainty.
