The paper defines a norm as a function that assigns a nonnegative number, referred to as the "length" or "norm" of a vector, denoted by kvk. It presents several examples of norms in the vector space V = (Rd; +; ·):

1. **p-norms**: For p ≥ 1, the p-norm is defined as kvkp = (Σ |vi|^p)^(1/p).
2. **1-norm**: This is the maximum absolute value of the components of the vector, given by kvk1 = max |vi|.
3. **Weighted norms**: These are defined with weights wi > 0, where:
   - For 1 ≤ p < ∞, kvkp = (Σ |vi|^p wi)^(1/p).
   - For p = 1, kvk1 = max |vi|/wi.
4. **Matrix-weighted 2-norm**: Defined as kvk2P = vTPv, where P is a fixed, positive definite matrix.

The paper also discusses norms for function spaces, specifically defining the 1-norm for bounded functions as kfk1 = sup |f(x)| for x in the domain X.

The concept of convergence in normed vector spaces is introduced, stating that a sequence of vectors (vn) converges to a vector v in the norm k·k if lim (n→∞) kvn - vk = 0, denoted as vn →k·kv. It highlights that in finite-dimensional spaces, this convergence implies component-wise convergence, but this does not necessarily hold in infinite-dimensional spaces, illustrated with an example involving the space of bounded functions on the interval [0,1].
