The paper presents Algorithm 2, which implements the every-visit Monte-Carlo method for estimating value functions in episodic Markov Decision Processes (MDPs). This algorithm is called at the end of each episode using the collected state-reward sequence. It operates with linear time and space complexity relative to the episode length. 

The function takes as input the sequence of states and rewards, as well as the current value function estimate. It computes a cumulative sum of rewards in reverse order, updating the value function based on the computed target for each state visited. This approach exemplifies stochastic approximation, where the dynamics are described by an ordinary differential equation (ODE) that converges to the true value function.

The paper contrasts the performance of the Monte-Carlo method with the Temporal Difference (TD(0)) method, highlighting scenarios where each may converge faster. For instance, in an example where TD(0) accelerates convergence, the algorithm utilizes past state estimates to refine predictions, leading to lower variance in updates. Conversely, in scenarios where bootstrapping is not beneficial, such as deterministic rewards, the Monte-Carlo method's reliance on direct rewards may hinder convergence.

Overall, the paper underscores the utility of both methods in different contexts, emphasizing the trade-offs between bootstrapping and direct reward estimation in achieving accurate value function estimates.
