The paper describes the implementation of the SARSA(λ) algorithm using linear function approximation, specifically detailing the function SARSALambdaLinFApp. This function is invoked after each transition and takes as input the last state, action, immediate reward, next state, next chosen action, parameter vector, and eligibility traces. The algorithm updates the parameter vector based on the observed reward and the difference between the expected and actual rewards.

The paper also discusses the evaluation of the value function Vt+1 under a stochastic policy, where it is expressed as the expected action-value Q. For large action spaces, direct evaluation may be impractical, and sampling actions from the policy is suggested to approximate Vt+1. The authors propose using state features to improve estimates, which allows for a bias-free computation of the value function, potentially reducing variance.

Furthermore, the paper introduces the pseudocode for LSTD-Q(λ), noting that the inverse in the algorithm may not always exist, and discusses the derivation of a recursive version of LSTD-Q(λ). The section concludes by highlighting that various temporal-difference errors defined can also be utilized within the SARSA algorithm.

The implementation of policy improvement is briefly mentioned, indicating a strategy to adjust the current policy towards a greedy policy derived from the approximate action-value function. This reflects a common approach in reinforcement learning to enhance performance by refining the policy based on learned value estimates.
