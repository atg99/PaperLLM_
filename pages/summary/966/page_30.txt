The paper presents Algorithm 4, which implements the TD(λ) algorithm with linear function approximation. This algorithm is designed to be executed after each transition in a reinforcement learning context. The function takes as inputs the last state (X), the next state (Y), the immediate reward (R), a parameter vector (θ) for linear function approximation, and an eligibility trace vector (z).

The core of the algorithm involves updating the reward prediction error (δ), the eligibility trace vector (z), and the parameter vector (θ). The updates are derived from the tabular TD(λ) method and are adapted for linear function approximation. Specifically, the reward prediction error is calculated as the immediate reward plus the difference between the estimated values of the next and current states. The eligibility traces are updated based on the current state, and the parameters are adjusted using the product of the reward prediction error and the eligibility trace.

The paper also discusses the conditions under which this algorithm generalizes the tabular TD(λ) approach and highlights the differences when using off-policy sampling. In off-policy scenarios, convergence is not guaranteed and can lead to divergence, particularly when the distributions of sampled states do not align with the stationary distribution of the Markov Reward Process (MRP). The authors reference previous works that document instances of instability in the algorithm's performance under certain conditions, including the use of nonlinear function approximation.

Despite these challenges, the paper notes that almost sure convergence can be assured when using linear function approximation and under specific conditions related to the stochastic process of the states. Overall, the algorithm offers a structured approach to implementing TD(λ) with linear function approximation while acknowledging potential pitfalls in off-policy contexts.
