The paper discusses the value function V and the action-value function Q associated with Markov Reward Processes (MRP) and Markov Decision Processes (MDP). The value function V is defined as the expected return starting from state x, while the action-value function Q under a policy π represents the expected return when starting in state x and taking action a. The paper establishes that the optimal action-value function Q* is the maximum expected return for a given state-action pair. 

The relationship between the optimal value function V* and the optimal action-value function Q* is articulated through two key equations: V* is the supremum of Q* across all actions, and Q* can be derived from the immediate reward and the expected value of the next state. The paper asserts that an optimal stationary policy exists for the considered class of MDPs and highlights the condition under which a policy is optimal. Specifically, a stationary policy is optimal if it satisfies a certain equality involving the action-value function Q*. 

The concept of greedy actions is introduced, where an action is deemed greedy with respect to Q if it maximizes Q for a given state. A policy that consistently selects such greedy actions is optimal, indicating that knowledge of Q* alone is sufficient to derive an optimal policy. Additionally, knowing the value function V*, the reward function r, and the transition probabilities P also suffices for decision-making in the MDP framework.
