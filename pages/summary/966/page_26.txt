The paper discusses feature extraction methods in the context of state representation. It defines basis functions as individual functions that construct features from state inputs. Various function approximation methods are highlighted, such as polynomial, Fourier, and wavelet bases, which can be employed depending on the dimensionality of the state space.

For one-dimensional state spaces, polynomial bases can be represented as a vector of powers of the input. When dealing with multidimensional state spaces, the tensor product construction is commonly used, which combines features from individual components to create a comprehensive feature extractor. This method allows for indexing using multi-indices and facilitates the construction of features across multiple dimensions.

Radial basis function (RBF) networks are discussed as a popular choice for multidimensional inputs, where the basis functions are derived from Gaussian functions centered at specified points. Kernel smoothing is presented as an alternative, providing a means to create a smooth approximation of the state representation.

The concept of "averagers" is introduced, which are functions that compute a weighted average of basis functions, ensuring that the mapping maintains certain properties beneficial in reinforcement learning. The paper also mentions binary features as a computationally efficient option for feature extraction, where the output is limited to binary values.

Overall, the paper emphasizes the importance of selecting appropriate feature extraction methods and functions to enhance convergence and performance in reinforcement learning applications.
