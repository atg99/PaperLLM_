The paper discusses the computation of state values in systems where the feature representation is sparse, specifically when using state aggregation. In such cases, the feature vector has non-zero components that correspond to non-overlapping regions of the state space, allowing for efficient computation through direct indexing of these components. This method effectively discretizes the state space, making it manageable for function approximation.

Tile coding is introduced as another method that produces binary features through multiple shifted partitions of the state space. While tile coding can be effective, it faces challenges in high-dimensional spaces, leading to an exponential growth in feature and parameter vectors, which can become intractable.

The paper highlights the "curse of dimensionality," where high dimensional state spaces can complicate problem-solving. However, it suggests that the complexity of actual problems may be lower than expected due to the potential irrelevance of certain state variables or the existence of low-dimensional submanifolds within the high-dimensional space. An example provided is an industrial robot arm with a high intrinsic dimensionality, where a more manageable state representation can be achieved through high-resolution imaging, illustrating the relationship between state representation and dimensionality.
