The paper discusses the UNSW-NB15 and CIC-IDS2017 datasets, which are utilized for testing network security intrusion detection models. The UNSW-NB15 dataset, created in 2015, comprises 47 attribute features and two category features, encompassing nine attack types such as DoS, Backdoors, and Fuzzers. The dataset includes a training set of 56,000 samples and a testing set of 37,000 samples, with a total of 93,000 samples. The distribution of attack behaviors is detailed in the paper.

In contrast, the CIC-IDS2017 dataset, collected from July 3 to 7, 2017, includes 78 attributes and one category feature, covering 15 attack types. The dataset is larger, containing over 2.3 million samples, with a training set of approximately 1.65 million and a testing set of around 709,000. The final dataset represents nine attack types, merging similar anomalous behaviors.

The evaluation metrics for the intrusion detection models include precision, accuracy, recall, and F1-score, based on a confusion matrix that categorizes the results into true positives (TP), true negatives (TN), false positives (FP), and false negatives (FN). These metrics are critical for assessing the model's performance in correctly identifying normal and abnormal data. The confusion matrix is presented to illustrate the classification results of the model.
