This transformation is essential for preparing the data for model input, as it ensures all feature values are numeric, which aids the model in learning the underlying data characteristics.

The paper emphasizes the importance of data normalization following this transformation. By normalizing the features, the variance is reduced to a specific range, which mitigates the influence of outliers on the clustering of sample points. This process is crucial as it allows the model to better understand the relationships between different features, rather than being biased by individual feature values.

In addition to these steps, the paper employs a hybrid sampling algorithm, ADRDB, which combines ADASYN and RENN methods for effective data sampling. Afterward, a feature selection algorithm, RFP, is utilized to refine the selected features further. The final output of the pre-processing stage is a grey-scale map of the data, which prepares it for subsequent analysis using a CNN and GRU-based network intrusion detection model.
