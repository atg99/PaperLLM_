The paper presents an intrusion detection model that integrates convolutional neural networks (CNN) and gated recurrent units (GRU) to effectively analyze and classify network traffic. The model employs a three-part architecture: first, it utilizes a convolutional block attention module (CBAM) to assign varying weights to features derived from pre-processed grayscale maps. This is followed by spatial feature extraction through a CNN, which combines Maxpooling and Averagepooling for enhanced spatial aggregation. Lastly, temporal features are captured using GRU, culminating in classification via a Softmax activation function.

The CNN component uses multiple convolutional layers—1x1 and 3x3—to extract spatial features, which are then fused to create processed feature maps. The model's structure is visually represented in the provided figures, illustrating the flow from input features to output classifications.

The experimental setup involves a series of tests to evaluate the model's performance, including feature selection analysis and comparisons of various methods and pooling techniques. The experiments were conducted on a high-performance machine utilizing TensorFlow for implementation. The datasets chosen for evaluation—UNSW-NB15, NSL-KDD, and CIC-IDS2017—are well-established in the field of intrusion detection.

Key parameters for the model include a batch size of 1024, a loss function of SparseCategoricalCrossentropy, and an optimizer with a learning rate of 0.001, among others. The comprehensive testing aims to validate the effectiveness of the proposed hybrid approach in improving intrusion detection accuracy.
