The paper discusses advancements in intrusion detection models, highlighting various approaches to enhance detection accuracy and efficiency. A study introduced sample-weighted and class-weighted algorithms into support vector machines, demonstrating benefits such as reduced time consumption, high recognition accuracy, and low false alarm rates. Additionally, Xiaokang Zhou et al. developed a few-shot learning model using a Siamese convolutional neural network to effectively identify cyber-physical attack types through optimized feature representation and a robust cost function incorporating three specific losses. 

To address security challenges in large-scale data streams, they proposed a variational long short-term memory network model with reconfigured feature representation, which effectively handles imbalance and high-dimensional data while improving detection results. 

The paper also presents a novel network intrusion detection model combining convolutional neural networks (CNN) and gated recurrent units (GRU), termed the CNN-GRU model. This model integrates spatial and temporal feature extraction, improving classification accuracy. It consists of three main stages: preprocessing the data to create numerical features and balance the dataset, training the model using a Convolutional Block Attention Module to assign feature weights, followed by feature extraction through CNN and GRU units, and finally, testing the model for classification. The proposed model aims to leverage the strengths of both CNN and GRU to enhance intrusion detection capabilities.
