The paper discusses the composition function used in various parameter-efficient tuning methods for neural networks, particularly focusing on how modified vectors are combined with original hidden representations to create new ones. It highlights different techniques such as adapters, prefix tuning, and LoRA, which utilize additive or scaled compositions. The authors propose a unified framework that allows for the exploration of these methods, emphasizing the potential for transferring design elements across different approaches.

Three novel methods derived from this framework are introduced: the Parallel Adapter, which integrates the parallel insertion concept from prefix tuning into adapters; the Multi-head Parallel Adapter, which enhances the capacity of adapters by modifying head attention outputs; and the Scaled Parallel Adapter, which applies LoRA's composition style to adapters. The paper raises several questions about the distinct properties of these methods and their performance.

In the experimental section, the authors evaluate their methods across four downstream tasks: summarization, translation, natural language inference, and sentiment classification. They employ models like BART and RoBERTa, varying the bottleneck dimensions for analysis. The results indicate that adapters, prefix tuning, and LoRA significantly outperform simpler methods such as bitfit and prompt tuning. The evaluation metrics used include ROUGE scores for summarization, BLEU scores for translation, and accuracy for classification tasks, with a focus on the number of tunable parameters relative to full fine-tuning. The implementation was performed using the Hugging Face transformers library, ensuring reproducibility by comparing results with original code releases.
