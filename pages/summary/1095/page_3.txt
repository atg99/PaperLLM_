The paper discusses the architecture of transformers, focusing on multi-head self-attention and fully connected feed-forward networks. It outlines the conventional attention mechanism, which involves queries, keys, and values, and describes how multi-head attention operates in parallel across multiple heads, projecting inputs into lower-dimensional spaces for efficiency.

The paper then reviews several state-of-the-art parameter-efficient tuning methods that modify only added parameters while keeping pre-trained language models frozen. Notable methods include:

1. **Adapters**: These are small modules inserted between transformer layers, using a down-projection to a lower-dimensional space, a nonlinear activation, and an up-projection, all surrounded by residual connections.

2. **Prefix Tuning**: This method involves appending tunable prefix vectors to the keys and values in the multi-head attention at each layer, enhancing the input without modifying the original architecture significantly.

3. **Prompt-Tuning**: A simplified version of prefix tuning that only modifies input word embeddings in the first layer.

4. **LoRA (Low-Rank Adaptation)**: This technique injects trainable low-rank matrices into transformer layers to approximate weight updates, specifically applied to the query and value projection matrices in the multi-head attention.

Overall, the paper emphasizes the importance of these tuning methods in enhancing the performance of transformers while maintaining efficiency in parameter usage.
