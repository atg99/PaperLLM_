This paper discusses three mechanisms for implementing contrastive loss in machine learning, particularly in the context of maintaining key representations during training. The mechanisms are illustrated in Figure 2, which compares an end-to-end update approach, a memory bank approach, and the Momentum Contrast (MoCo) method.

In the end-to-end approach, both query and key encoders are updated through back-propagation, allowing for consistent encoding but limiting the dictionary size to the mini-batch size. The memory bank approach allows for a larger dictionary by sampling key representations from a static set of data samples, but it does not benefit from back-propagation, potentially leading to less effective learning.

The MoCo method introduces a dynamic dictionary maintained as a queue, which allows for the reuse of encoded keys from previous mini-batches. This approach decouples the dictionary size from the mini-batch size, enabling the use of a larger dictionary while ensuring that the most outdated keys are systematically replaced. The authors propose a momentum update mechanism for the key encoder, where its parameters evolve more smoothly compared to the rapidly updated query encoder. This is achieved through a momentum coefficient, which stabilizes the key representations and improves the consistency of the learning process.

The paper argues that a larger, consistently encoded dictionary enhances the learning of good features, as it effectively covers a rich set of negative samples. The experiments show that a large momentum coefficient, such as 0.999, significantly improves performance compared to smaller values. MoCo is positioned as a versatile mechanism for utilizing contrastive losses, with advantages over both the end-to-end and memory bank methods in terms of dictionary size and consistency.
