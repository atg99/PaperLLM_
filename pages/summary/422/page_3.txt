In recent years, object detection has greatly benefited from the advancements in Convolutional Neural Networks (CNN). CNN-based methods are primarily categorized into two groups: region proposal-based two-stage methods and proposal-free one-stage methods.

The two-stage methods, including R-CNN, Fast R-CNN, Faster R-CNN, R-FCN, and Mask R-CNN, have played a significant role in the evolution of object detection. R-CNN marked a pivotal point by classifying each region proposal separately but was criticized for being time-consuming. Fast R-CNN improved efficiency by sharing computations between proposal extraction and classification through ROI-Pooling. Faster R-CNN further enhanced speed and precision by introducing a Region Proposal Network (RPN) for generating proposals. R-FCN improved both speed and accuracy by removing fully connected layers and using position-sensitive score maps. Mask R-CNN extended Faster R-CNN to facilitate object instance segmentation alongside bounding box detection.

Recent innovations have focused on improving object detection through multi-scale technologies, such as the Inside-Out Net (ION) which concatenates multiple convolutional features, and the Multi-scale Location-aware Kernel Representation (MLKP) that captures high-order statistics of deep features. Other approaches include the Zoom-out-and-In network for object proposals (ZIP) which integrates a Map Attention Decision unit to enhance neuron activation searches. Additionally, leveraging knowledge has been explored, with methods like CoupleNet combining global structure with local parts, DeNet refining bounding boxes using corner distribution, and CRFNet utilizing contextual information among multiple images.

On the other hand, one-stage detectors like You Only Look Once (YOLO), Single Shot MultiBox Detector (SSD), and CornerNet have emerged as computationally efficient alternatives. YOLO processes the input image in a single pass to predict object classes and locations, making it extremely fast. SSD employs dense anchor boxes and pyramid features for direct classification, while CornerNet uses an hourglass network to detect bounding boxes as pairs of keypoints. Other one-stage detectors, such as the Deeply Supervised Object Detector (DSOD) and RetinaNet, share structural similarities with SSD, focusing on feature extraction and addressing class imbalance during training.

Overall, both two-stage and one-stage methods continue to evolve, integrating various strategies to enhance the performance of object detection systems.
