The paper presents AoANet, an encoder-decoder framework designed for image captioning. It introduces a reﬁning module within the encoder that models object relationships in images, enhancing feature representation. The reﬁning module employs an Attention over Attention (AoA) mechanism, utilizing multi-head attention to refine the feature vectors. This process involves several linear projections of the input vectors, followed by layer normalization and residual connections to maintain dimensional consistency.

The AoA module focuses on the interactions among objects, updating the feature vectors without altering their dimensions, allowing for multiple stacking of the reﬁning module. Notably, the paper departs from the traditional transformer encoder by omitting the feed-forward layer, which is justified by the AoA's capacity to achieve non-linear representations while simplifying the architecture without degrading performance.

In the decoder, the model generates captions by computing conditional probabilities based on a context vector, which integrates the attended feature vectors and the LSTM output. This structure aims to enhance the caption generation process by incorporating refined image features and contextual information. Overall, AoANet seeks to improve image captioning by effectively modeling relationships within visual data and employing a streamlined architecture.
