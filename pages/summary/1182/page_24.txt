The Variational Autoencoder (VAE) framework consists of two main components: an encoder that models the conditional distribution of latent variables given the input data, and a decoder that reconstructs the input from the latent representation. The objective function combines the reconstruction loss and a KL-divergence term to ensure the latent space approximates a Gaussian distribution.

In the context of semi-supervised learning (SSL), VAEs can be adapted to leverage both labeled and unlabeled data to enhance classification performance. The first model (M1) incorporates a pretraining phase where the VAE is trained on both labeled and unlabeled data, allowing for dimensionality reduction and improved separability in the latent space. The second model (M2) integrates class labels into the training process, treating them as latent variables alongside the original latent variables. This approach enables the model to better utilize available labels during training.

A combined model (M1+M2) can further enhance performance by concatenating the outputs of both models, using the latent variables from M1 as inputs for M2. This joint model allows for a more comprehensive representation of the data.

Additionally, the Variational Auxiliary Autoencoder introduces auxiliary variables to improve the flexibility of the model, allowing it to capture more complex posteriors while maintaining the generative capabilities of the original VAE framework.
