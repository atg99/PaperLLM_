Virtual Adversarial Training (VAT) addresses the limitations of previous methods that apply random perturbations to inputs, which can leave models vulnerable to specific adversarial directions. VAT enhances model robustness by training it to produce similar outputs for perturbed inputs, specifically in adversarial directions. This is achieved without label information, making it suitable for semi-supervised learning (SSL).

The process involves computing an adversarial perturbation that maximally alters predictions. This is done by sampling Gaussian noise, calculating gradients with respect to the loss, and normalizing these gradients to obtain the perturbation. The unsupervised loss is then defined as the mean squared error between the model's predictions with and without the perturbation.

In addition, Adversarial Dropout (AdD) is introduced as an alternative approach, where dropout masks are optimized to change model predictions, creating a sparse neural network structure. This contrasts with VAT's additive noise approach, which does not alter the network's structure directly.
