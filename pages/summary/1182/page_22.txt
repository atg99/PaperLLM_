ReMixMatch is a semi-supervised learning method that enhances model training through two key techniques: distribution alignment and augmentation anchoring. 

Distribution alignment aims to ensure that the predictions made on unlabeled data conform to the class distribution of the labeled data. This is achieved by maintaining a running average of model predictions on unlabeled data and normalizing the output probabilities based on the estimated marginal class distribution.

Augmentation anchoring improves upon the augmentation strategies used in previous methods like MixMatch. Instead of weak augmentations, ReMixMatch employs strong augmentations derived from a control theory-based approach. The predictions from weakly augmented images serve as proxy labels for the strongly augmented versions, which are then used in a cross-entropy loss computation.

The training process incorporates both labeled and unlabeled batches, applying distribution alignment and leveraging weakly augmented examples for generating proxy labels for strongly augmented counterparts. The overall loss function combines supervised and unsupervised losses.

Additionally, ReMixMatch introduces a self-supervised loss by creating a new batch of unlabeled examples through rotation. The model then predicts the applied rotation alongside the standard classification task.

FixMatch is another semi-supervised learning algorithm that integrates consistency regularization and pseudo-labeling. It computes losses for both labeled and unlabeled data using cross-entropy loss. For unlabeled examples, a weakly augmented version is created, and predictions are made to generate pseudo-labels, which are then used in the loss calculation.
