The paper presents an end-to-end learning network for 3D point cloud registration called DeepVCP. The architecture consists of several key layers, starting with a deep feature extraction layer that processes both source and target point clouds. It extracts N keypoints from the source point cloud using a weighting layer, followed by the selection of N×C candidate corresponding points from the target point cloud. These points undergo a deep feature embedding operation to generate corresponding keypoints in the target point cloud.

The model employs a three-layer 3D CNN to learn a similarity distance metric between the extracted feature descriptors of the source and target point clouds. This CNN helps smooth the matching volume and reduces noise, converting matching costs into probabilities through a softmax operation. The target corresponding points are computed via a weighted sum operation based on these probabilities.

Unlike traditional Iterative Closest Point (ICP) algorithms, which rely on iterative optimization and RANSAC for outlier rejection, the proposed method leverages the generalization capability of CNNs to directly predict corresponding points, thereby eliminating the need for RANSAC and reducing computation time significantly. A bidirectional matching strategy is used during inference to enhance registration accuracy.

The loss function for the network consists of two components: the first calculates the L1 distance between the estimated and ground truth corresponding points, ensuring local matching; the second incorporates global geometric constraints through a singular value decomposition step to optimize the relative transformation of keypoint pairs. This dual loss approach is crucial for improving the overall registration performance, ensuring both local and global context are considered during the matching process.
