This paper presents a novel deep learning architecture for point cloud registration, focusing on extracting features and establishing correspondences between source and target point clouds. 

In the method section, the authors detail the architecture of their proposed network. The first step involves deep feature extraction using a Feature Extraction (FE) Layer, specifically employing PointNet++ to process the source point cloud and produce local feature descriptors. These descriptors are designed to capture semantic meanings, enhancing the network's ability to filter out interference from dynamic objects. The authors demonstrate the effectiveness of this feature extraction in avoiding dynamic objects during the registration process.

Next, the paper introduces a point weighting layer inspired by attention mechanisms. This layer assesses the importance of each point based on its features, assigning higher weights to points with distinct characteristics on static objects. The weighting layer utilizes a multi-layer perceptron (MLP) and a top-k operation to select keypoints, which differ from previous methods by directly extracting semantic features instead of local patches.

The Deep Feature Embedding (DFE) Layer follows, which aims to find corresponding points in the target point cloud. This layer employs a mini-PointNet structure to extract detailed feature descriptors from the neighborhood of each keypoint, incorporating local coordinates and intensity information. The output is a refined 32-dimensional feature vector that significantly enhances registration precision.

Finally, the authors propose a Corresponding Point Generation (CPG) layer, which addresses the challenges of finding exact correspondences in the sparse target point cloud. This layer generates candidate corresponding points by transforming keypoints based on the predicted transformation and dividing the surrounding space into 3D grid voxels. This innovative approach allows for a more effective backpropagation process and better alignment between the source and target point clouds.

Overall, the proposed method integrates deep learning techniques for feature extraction, weighting, embedding, and correspondence generation to achieve accurate and robust point cloud registration.
