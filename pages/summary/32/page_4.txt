The paper discusses a feature fusion mechanism for grid points in a Grid R-CNN framework, focusing on enhancing spatial information transfer among grid points. The authors propose a two-level feature fusion approach: first-order and second-order feature fusion.

In the first-order feature fusion, the features of a grid point are enhanced by incorporating features from its adjacent grid points. For example, the top left grid point's y-coordinate is calculated as a probability-weighted average of its neighboring points. The authors highlight the importance of utilizing local features from neighboring grid points' feature maps to reduce overall deviation and improve calibration.

To achieve this, a feature map level information fusion mechanism is introduced, which employs N×N groups of filters to extract features for each grid point individually. Each grid point’s features are denoted as Fi, and the source points, defined as those within a unit distance, contribute to the fusion process. The fusion operation is performed using a simple sum of processed features from the source points, resulting in a new feature map F′i.

Following the first-order fusion, a second-order fusion is executed using new convolutional layers that do not share parameters with the first-order layers. This allows for information transfer over a greater distance, enhancing the reliability of the calibration process.

Additionally, the paper addresses the issue of extended region mapping, which ensures that the output heatmaps correspond to the spatial regions of the input proposals. This is crucial as proposals may not cover the entire object, leading to some ground truth grid points being unlabelled during training and potentially resulting in incorrect predictions during inference. The authors emphasize the need for a strategy to improve coverage of ground truth locations in the output heatmaps.

Overall, the proposed feature fusion mechanism aims to leverage spatial correlations among grid points to enhance prediction accuracy in object detection tasks.
