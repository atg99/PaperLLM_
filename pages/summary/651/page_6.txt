This paper discusses the development of a binarized Graph Convolutional Network (Bi-GCN) aimed at reducing memory consumption and accelerating computations in deep Graph Neural Networks (GNNs). As the number of layers in GNNs increases, memory savings become more pronounced. The primary contributor to memory usage is the loaded data, particularly node features. The authors propose binarizing these features, which significantly decreases memory requirements. Specifically, the data size can be reduced by a factor of approximately 30x, allowing larger attributed graphs to be processed without exceeding memory limits.

In terms of acceleration, the Bi-GCN offers significant improvements over traditional GCNs. The feature extraction step in Bi-GCN requires fewer operations due to the use of binary values, leading to a substantial acceleration ratio that depends on the dimensions of the node features. The paper presents equations demonstrating how the acceleration ratios can be calculated, showing that the computational costs for the aggregation step become negligible, particularly in datasets with low average node degrees.

The evaluation of the Bi-GCN on benchmark datasets indicates its effectiveness in both reducing memory consumption and increasing computational speed. For instance, on the Cora dataset, the first layer of a two-layered Bi-GCN achieves acceleration ratios of approximately 59x, while the second layer achieves around 21x, resulting in an overall acceleration ratio of about 53x. This demonstrates the potential of Bi-GCNs for efficient processing in node classification tasks.
