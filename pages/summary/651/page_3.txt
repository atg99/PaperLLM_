This paper focuses on reducing computation costs in Convolutional Neural Networks (CNNs) through binarization techniques. It discusses various approaches, including BinaryConnect, BinaryNet, and XNOR-Net, which aim to optimize the performance of CNNs by replacing floating-point multiplications with simpler operations such as additions and XNOR operations.

The paper introduces key notations for understanding the structure of graphs used in Graph Convolutional Networks (GCNs). It defines an undirected attributed graph with vertices, edges, and associated features, alongside the adjacency and degree matrices. The GCN framework is briefly explained, emphasizing the graph convolution operation, which consists of an aggregation step and a feature extraction step. The loss function used for training, particularly in node classification tasks, is also outlined.

A novel Binary Graph Convolutional Network (Bi-GCN) is proposed, which focuses on binarizing the feature extraction step while maintaining the original GCN's aggregation step. This approach aims to reduce memory consumption and computational complexity by utilizing XNOR operations and bit counting, rather than traditional floating-point multiplications. The paper details the binarization process for both the network parameters and node features, employing a bucketing method to facilitate efficient binary matrix multiplication. The design includes a back-propagation algorithm tailored for the binarized graph convolution layer, aiming for effective training of the Bi-GCN.
