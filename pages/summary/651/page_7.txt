The paper presents experiments conducted on four widely used datasets—Cora, PubMed, Flickr, and Reddit—aimed at evaluating the performance of a binarized Graph Convolutional Network (Bi-GCN) in both transductive and inductive learning tasks. 

In the transductive learning task, Cora and PubMed citation networks were analyzed using a 2-layered GCN as a baseline, with Bi-GCN being derived from it. The results indicate that Bi-GCN performs comparably to full-precision GCN while achieving approximately 47 times faster inference speed and 30 times lower memory consumption. 

For inductive learning tasks, using datasets like Flickr and Reddit, the binarized GNNs demonstrated significant reductions in memory requirements and computational load without sacrificing performance. The original Reddit dataset size was reduced from 534.99M to 17.61M through binarization, showcasing the efficiency of this method.

An ablation study further validated the effectiveness of binarization on both node features and parameters. The results revealed that binarizing only node features maintained effective information for classification, while binarizing both features and parameters achieved comparable performance to full-precision models. This suggests that the binarization approach is efficient and can be successfully applied across different GNN architectures, highlighting its potential for resource-constrained environments.
