The paper discusses a novel 3D brain segmentation model, BrainSegNet, designed for brain tumor and stroke lesion segmentation from multi-modality MRI data. The model utilizes various MRI modalities, treating each as a distinct 3D channel, which allows for flexible input combinations. To ensure accurate predictions, the output maps are aligned to the input MRI's spatial resolution, achieved through a specialized 3D refinement module. The architecture includes four convolutional blocks comprising a total of 17 convolutional layers with residual units. Each block employs an adaptive layer and a refinement layer to compute multi-level convolutional features, enhancing the model's capacity to aggregate fine-scale volumetric information. The output layer employs a multi-class soft-max function to classify the segmentation tasks, which include multiple classes for brain tumors and a binary classification for stroke lesions, incorporating background information as well. Overall, this model aims to improve the accuracy and density of predictions in brain imaging analysis.
