The paper evaluates the performance of an Autoencoder-Gated Recurrent Unit (AE-GRU) model for predicting Remaining Useful Life (RUL) using the Turbofan Engine Degradation Simulation Data Set from NASA's C-MAPSS tool. This dataset includes time series data from 218 turbofan engines, comprising 45,918 records with 26 features and customized RUL values. The research is structured into sections that detail data collection, model parameter settings, and performance optimization.

In the data collection phase, the variability in sensor parameters across different engines is highlighted, emphasizing that each engine begins with a unique wear level. The study compares various activation functions and optimizes model performance by adjusting parameters such as the number of hidden layers and neurons. To ensure model stability, k-fold cross-validation is employed.

The results focus on predicting RUL based on sensor parameter changes, with performance evaluated using root mean square error (RMSE). The findings aim to enhance predictive accuracy in monitoring engine health through advanced modeling techniques.
