In this paper, the authors focus on predicting the Remaining Useful Life (RUL) of engines using sensor data. They introduce several key variables, including the number of engines (N), the number of sensors (S), and the length of sensing data (n). The study emphasizes the importance of data pre-processing to transform raw engine data into a suitable format for supervised learning.

The authors define RUL as the time remaining before an engine fails, calculated by determining the difference between the maximum recorded time and the current time for each engine. This approach allows for the application of predictive models based on the variations in parameters captured by the sensors. 

To standardize the different scales of sensor measurements, the authors convert the original data into Z-scores, making it easier to analyze and compare. They calculate the average value and standard deviation of the sensor data to facilitate this transformation.

Overall, the paper outlines a systematic approach to handling engine data, ensuring that it is prepared for effective RUL prediction through machine learning techniques.
