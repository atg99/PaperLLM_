The paper discusses a method for feature extraction and data processing in sensor data analysis, particularly in predicting Remaining Useful Life (RUL). It begins by standardizing sensor values through the calculation of the mean and standard deviation, which allows the transformation of data into a normalized form. The average and standard deviation are computed using established equations, leading to the derivation of a standardized sensor value.

The core of the feature extraction process utilizes an Autoencoder (AE) to reduce the dimensionality of the data. The encoder transforms original data into a new feature space, which is more concise and descriptive than the original features. The feature values are calculated by applying a weight matrix and an error vector, using the ReLU activation function.

The paper highlights a limitation in traditional models that rely solely on current sensor values for RUL predictions, neglecting the significance of historical data. To address this, the authors propose a novel data processing approach that reformats the data from a two-dimensional to a three-dimensional structure, incorporating time steps. This transformation preserves the integrity of the data, and when historical data is lacking, zero-padding is employed to maintain dimensionality without losing information. This method aims to enhance the predictive capability by including historical sensor value changes in the analysis.
