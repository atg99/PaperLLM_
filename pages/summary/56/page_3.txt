In this section, the paper derives the Recurrent Neural Network (RNN) framework using differential equations. The evolution of a d-dimensional state signal vector, denoted as ⃗ s(t), is described by a general nonlinear first-order non-homogeneous ordinary differential equation. This equation is represented as d⃗ s(t)/dt = ⃗f(t) + ⃗ϕ, where ⃗f(t) is a vector-valued function of time and ⃗ϕ is a constant vector.

The function ⃗f(t) can be expressed in a canonical form as ⃗f(t) = ⃗h(⃗ s(t), ⃗ x(t)), where ⃗ x(t) represents the input signal vector. The resulting system of equations has applications across various fields including physics, chemistry, biology, and engineering.

The paper also discusses a specific case of ⃗f(t), termed the "Additive Model," which combines several d-dimensional vector-valued functions of time to determine the rate of change of neuronal activities. This model has been influential in neural network research and has numerous applications in areas such as vision, decision-making, and memory processes. The Additive Model is noted for its biological plausibility and its role in linking nonlinear dynamical systems to computational problems in engineering.

Furthermore, the section introduces a saturating version of the Additive Model, detailing the definitions of its constituent terms, which include functions of previous states, readout signals, and input signals. The readout signal vector is described as a transformed version of the state signal vector, employing an activation function that is commonly used in neural networks.
