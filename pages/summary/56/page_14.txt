The paper presents a formulation of a standard recurrent neural network (RNN) system that is unrolled for Km steps across multiple segments indexed by m. The equations define the state signal, readout signal, and input signal for each segment, highlighting their mutual independence. 

Initially, the state signal is set to zero for n equals negative one, and for n ranging from zero to Km minus one, it is computed based on the previous state, the current input, and a bias term. The readout signal is derived from the state signal using a function G, while the input signal takes values from the input sequence based on the segment index.

The key insight is that the input signal is the only variable dependent on the segment index, allowing the system to process each segment independently. This independence enables parallel computation across segments, enhancing efficiency. The prototype formulation simplifies the representation of the RNN system, allowing for the sequential processing of segments by initializing state signals and evaluating the equations for each segment iteratively. 

Overall, the approach maintains the essential properties of RNNs while allowing for flexibility in handling variable-length input sequences across multiple segments.
