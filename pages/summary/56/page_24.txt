The notation section of the paper defines key components of the Vanilla LSTM cell, including indices, dimensionalities, and various signals used within the cell. Specifically, it introduces variables such as 'n' for step indices, 'K' for the number of steps in a segment, and 'Gc' and 'Gd' as warping functions for control and data purposes. It describes input and state signals, observable value signals, accumulation nodes, update candidates, and readout candidates, alongside mathematical operations like inner and outer products.

The section on Control/Throttling outlines the function of three gate types in the LSTM, which regulate the contributions of update candidate signals, previous state signals, and readout candidate signals to the current state and observable output.

In the Data Set Standardization section, the paper emphasizes the need to preprocess external training data by standardizing it to have a mean of zero and a standard deviation of one. This is accomplished through specific equations that calculate the sample mean and auto-covariance matrix, ensuring that both test and validation sets are standardized using training set metrics.
