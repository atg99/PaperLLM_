The experiment aimed to evaluate the effectiveness of fog computing in enhancing the performance of a monitoring framework. Conducted on a personal computer with specified hardware and running Ubuntu, the experiment utilized Network Simulation version-2 (NS2.35) to simulate sensor networks. The integration of fog computing involved three main steps: initializing the network topology using Tool Command Language (TCL) with a varying number of nodes, modifying certain sensor nodes to function as fog nodes according to the Fog Hierarchical Deployment Model from the OpenFog Reference Architecture, and allowing the remaining sensor nodes to operate as ordinary nodes for data exchange.

Key parameters for the fog experiments included the number of nodes, simulation time, channel type, routing protocol, MAC protocol, traffic source, and energy model. The simulation demonstrated a network comprising ordinary sensor nodes and two fog nodes, with fog nodes programmed in C++ to facilitate event exchange. The network topology dimensions were specified, along with the simulation settings.

To assess the overall efficiency, a comparative analysis was conducted between systems using and not using fog computing. Results indicated that the fog-enabled scenario significantly outperformed the traditional network by reducing data transmission rates, thereby improving network bandwidth and power consumption.
