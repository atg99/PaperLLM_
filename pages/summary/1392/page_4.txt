The proposed CFNet architecture extracts convolutional feature maps from an input image using a pre-trained CNN. These feature maps are then transformed into target and co-occurrent vector representations via feed-forward networks. The Co-occurrent Feature Model computes the probability of co-occurrent features based on pairwise similarities in vector spaces. The ACF Module aggregates the co-occurrent context with the co-occurrent probability, while another branch captures global features through global average pooling.

The contextual prior is modeled as a Mixture of Softmaxes (MoS), which allows for learning a prior distribution for co-occurrent features conditioned on contextual information. This enables different priors for co-occurrent features under varying semantic contexts. The ACF Module employs a self-attention or non-local approach to aggregate contextual information across spatial locations using co-occurrent probabilities.

To enhance model performance and generalization, dropout is applied to co-occurrent features, preventing overfitting by training on “thinned” networks. Additionally, a multi-head strategy is utilized to create in-network ensembles by concatenating outputs from different modules with varying weights. Global pooling features further strengthen the model's capacity to distinguish between categories in challenging areas by providing a broad receptive field.
