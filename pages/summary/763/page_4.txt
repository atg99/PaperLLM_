The paper by Ronak Pradeep, Rodrigo Nogueira, and Jimmy Lin presents a multi-stage ranking architecture for document retrieval that includes a document expansion phase termed H-1. Initially, the model augments documents by generating relevant queries using a pretrained T5 model, referred to as doc2query-T5. This process enriches the original content, enhancing its relevance for a broader range of queries.

In the first stage, H0, the system receives a user query and retrieves the top k0 candidates using the BM25 algorithm, which treats the query as a bag of words. This stage serves as the foundation for candidate generation. The relevance of each document is then evaluated in the second stage, H1, where the monoT5 model scores the relevance of each candidate document relative to the query. The top k1 candidates are selected based on these scores.

The final stage, H2, involves a pairwise evaluation using the duoT5 model, which computes relevance scores for each combination of the query and the top document pairs. The candidates are then reranked based on these pairwise scores to produce the final output, R2.

The overall methodology leverages the strengths of document expansion and advanced ranking models to improve retrieval effectiveness, demonstrating significant improvements over traditional approaches. The authors highlight the importance of the document expansion step, which allows for better matching of queries by enhancing the content of the documents.
