The paper introduces the "Expando-Mono-Duo" design pattern for text ranking using pretrained sequence-to-sequence models, marking the first comprehensive presentation of this approach. While previous works have discussed components of this framework separately, this paper provides a cohesive end-to-end explanation, including evaluation results and analyses of various components.

The proposed architecture consists of multiple stages, denoted as H0 to HN. The initial stage H0 retrieves candidates based on keyword searches, while subsequent stages (H1 and H2) refine the ranking using the monoT5 and duoT5 models, respectively. Each stage outputs a ranked list of candidates, with the final output from stage HN intended for user consumption or further application.

A key innovation in this design is the document expansion stage (H-1), which enriches the input corpus by adding representative keywords to each document. This is achieved using a sequence-to-sequence model trained on pairs of queries and relevant passages, allowing the model to generate potential queries based on the content of the documents. The enriched documents are indexed for retrieval, aiming to provide a more robust set of candidates for the reranking process.

The paper outlines the overall design and functionality of the architecture while promising detailed experimental settings in a subsequent section. To promote replicability, the authors have made their implementations available through the Pyserini IR toolkit and the PyGaggle neural reranking library.
