The FlexMatch algorithm is designed to effectively utilize both labeled and unlabeled data in a semi-supervised learning context. The algorithm begins by initializing predictions for unlabeled data as unused, indicated by -1. It operates iteratively, computing the estimated learning effect for each class and adjusting thresholds based on the presence of unused data. If the maximum estimated learning effect is low, a warm-up threshold is calculated to facilitate learning when unused data predominates.

The algorithm employs a flexible threshold determined by normalized estimated learning effects, which is enhanced through a non-linear mapping function. This function allows the thresholds to adjust more sensitively based on the learning state of the model, particularly in early training phases where predictions may be unstable. The proposed mapping function is designed to be monotonically increasing and bounded to ensure thresholds do not exceed a specified limit.

The choice of a convex mapping function, specifically M(x) = x^2 - x, allows for gradual threshold growth at lower learning effects and increased sensitivity as learning improves. The algorithm concludes by computing the loss and updating model parameters, ensuring a robust approach to leveraging unlabeled data while adapting to the learning dynamics of the training process.
