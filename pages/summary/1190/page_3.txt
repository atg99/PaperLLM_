In this section, the authors outline the framework for semi-supervised learning (SSL), detailing the classification problem, various loss functions, and a transductive learning method that informs their approach. The problem involves a dataset consisting of labeled examples (XL) and unlabeled examples (XU), with the aim of training a classifier to predict labels for previously unseen samples using both labeled and unlabeled data.

The classifier architecture includes a feature extraction network and a fully connected layer that outputs class confidence scores. The supervised loss function is based on minimizing the cross-entropy between the predicted scores and true labels for the labeled examples. Additionally, the authors introduce pseudo-labeling, where predicted labels are assigned to unlabeled data, contributing to an additional loss term.

Unsupervised loss functions, such as consistency loss, encourage the model to produce similar outputs for different transformations of the same input. The authors also highlight the transductive learning approach, which focuses on inferring labels for unlabeled examples based on the relationships between labeled and unlabeled data. This is achieved through a diffusion process using a graph-based methodology, where a similarity matrix is constructed to facilitate label propagation.

Overall, this section establishes the foundational concepts and methodologies that will be utilized in the subsequent experiments and discussions.
