This paper presents FlexCNN, an FPGA-based CNN accelerator designed to enhance performance in machine learning frameworks, particularly TensorFlow. It contrasts two tiling approaches for CNN processing: uniform tiling, which uses a single set of tiling factors across the network, and dynamic tiling, which optimizes tiling factors for each layer. Results indicate that dynamic tiling improves overall network performance by 1.7 times.

The paper highlights a significant challenge in integrating FPGA with TensorFlow, emphasizing that prior works primarily focused on optimizing CNN kernels while neglecting integration overheads. The integration introduces communication overheads between TensorFlow and the FPGA, as well as between the host and the FPGA kernel. The experimental results reveal that CNN processing accounts for only 11.8% of the total runtime, underscoring the necessity for end-to-end software and hardware co-optimization. The proposed optimizations lead to an increase in performance from 4.8 frames per second (FPS) to 23.8 FPS, achieving a 5× speedup.

FlexCNN employs dynamic tiling and data layout transformations, addressing performance disparities across CNN layers. It also integrates a two-level software pipeline to overlap the integration overheads with computation. Performance evaluation using OpenPose, a pose detection application, shows that FlexCNN processes images in 24.7 milliseconds, yielding a 1.7× speedup compared to previous FPGA implementations.

The paper's contributions include:
1. The development of FlexCNN, a flexible accelerator architecture supporting dynamic tiling and data layout transformation.
2. A runtime environment for executing TensorFlow-defined CNNs on FPGA, along with an optimized software/hardware pipeline to reduce integration overheads.
3. A fully automated compilation system for the FlexCNN architecture.
4. The identification of FlexCNN as the fastest FPGA accelerator for OpenPose, achieving a 2.3× speedup through dynamic tiling and an overall performance of 23.8 FPS, which is 3.8× more energy efficient than GPU alternatives. 

Additionally, the paper discusses the structure of OpenPose-V2, highlighting its irregular architecture and the use of depthwise separable convolutions to optimize performance further.
