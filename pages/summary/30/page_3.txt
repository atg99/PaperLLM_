The paper presents Mesh R-CNN, an extension of Mask R-CNN that integrates 3D shape inference into the object detection framework. Mesh R-CNN enhances the capabilities of state-of-the-art 2D perception by predicting 3D shapes for detected objects in a single RGB image. The system consists of two main components: a voxel branch and a mesh refinement branch.

The voxel branch generates a coarse 3D voxel representation for each detected object, which is then transformed into an initial triangle mesh. This coarse shape is refined in the mesh refinement branch, which uses graph convolution layers to adjust the vertex positions of the mesh. This two-branch architecture parallels the existing box and mask branches of Mask R-CNN, ensuring that features remain aligned throughout the processing stages.

Key to the system's performance is the use of RoIAlign and a novel operator, VertAlign, which maintain feature alignment between the input image and the predicted shapes. The goal is to achieve instance-specific topology and geometry for each object, allowing for a diverse representation of complex real-world shapes.

The voxel branch functions similarly to Mask R-CNN's mask prediction branch but outputs a 3D grid of voxel occupancy probabilities, representing the object's shape in three dimensions rather than two. The final output of Mesh R-CNN includes bounding boxes, object scores, segmentation masks, and 3D shapes, effectively merging 2D and 3D perception in a unified framework.
