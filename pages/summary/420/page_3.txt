This paper presents a novel approach for few-shot domain adaptation in object detection, addressing the challenge posed by insufficient target domain samples. The proposed method introduces a feature pairing mechanism using split pooling and instance ROI sampling, which facilitates domain-adversarial learning at both image and object-instance levels. This dual-level adaptation aims to mitigate global domain shifts while aligning object appearance shifts semantically, thereby reducing class confusion.

The problem setup involves a large source domain dataset and a small target domain dataset, with the goal of adapting a detection model trained on the source data to the target domain with minimal performance degradation. The approach leverages loose bounding box annotations to ease the annotation burden.

A key innovation is the split pooling technique, which extracts local feature patches from images at various scales and aspect ratios. This method allows for effective domain adversarial alignment by pairing local features from the source and target domains. The paper details how local patch features can capture image-level domain shifts, which are particularly relevant in object detection due to the size of input images.

The adaptation process employs a domain-adversarial learning framework, where a discriminator distinguishes between source and target features, while a generator aims to make them indistinguishable. This adversarial setup allows for effective alignment of data distributions across domains without requiring supervision, making it suitable for unsupervised domain adaptation.

Overall, the proposed few-shot adaptive Faster R-CNN (FAFRCNN) model is designed to adapt to new domains using minimal target domain examples, leveraging innovative techniques to enhance performance in challenging scenarios.
