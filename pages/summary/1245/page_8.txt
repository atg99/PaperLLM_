The paper discusses the parameter settings for three machine learning ensemble methods: Random Forest, Gradient Boosting, and XGBoost. It details the default values for key parameters and the specific grid search values for tuning these parameters, as shown in Table 2. 

For Random Forest, parameters include max_depth, min_samples_split, min_samples_leaf, and max_features, with default values and options for tuning. Gradient Boosting parameters include learning_rate, max_depth, min_samples_split, max_features, and subsample, also with specified grid search values. XGBoost parameters include learning_rate, gamma, max_depth, colsample_bylevel, and subsample, with similar tuning options.

The paper emphasizes that all ensembles comprised 200 decision trees, noting that the size of the ensemble itself does not require tuning. It mentions that while Random Forest ensembles typically achieve a stable generalization error with more trees, Gradient Boosting may face performance deterioration with an increasing number of models, particularly at higher learning rates. To mitigate this, it suggests fixing the number of models and tuning the learning rate as the best regularization strategy.

Moreover, the paper states that, although XGBoost can handle missing values, the authors opted not to use this feature for a fair comparison with Random Forest and Gradient Boosting, which do not inherently address missing values. Instead, a mean imputation method was employed to handle missing data.
