The paper discusses the implementation and performance of a sparsity-aware algorithm in XGBoost, which effectively handles missing values during the computation of loss gains for split candidates. Key parameters tuned for XGBoost include the learning rate, minimum loss reduction, maximum depth of the tree, fraction of features evaluated at each split, and subsampling rate. 

An extensive comparative analysis was conducted among random forest, gradient boosting, and XGBoost models using 28 diverse datasets from the UCI repository, each varying in attributes, classes, and instances. The analysis utilized the scikit-learn package for random forest and gradient boosting, while XGBoost was implemented using its dedicated package. 

The methodology involved stratified 10-fold cross-validation. For each dataset, the optimal parameters for each model were estimated through a grid search. The study explored a wide range of parameter values, with results summarized in accompanying tables. The best parameter sets were used to train ensembles, and additional combinations were tested for XGBoost. Default parameters for all methods were also evaluated. The overall goal was to assess the generalization accuracy of the ensembles derived from both tuned and default parameter configurations.
