To build the random forest RF, steps 1 and 2 are repeated independently B times, producing trees T*1, ..., T*B. The choice of B can depend on the training dataset Cn, ensuring that the Monte Carlo variation in the construction process does not significantly affect the predictions. A sufficiently large B is recommended so that random forests built from the same dataset yield consistent predictions across different target x vectors. 

The point prediction of the response Y for a given predictor value X is calculated as the average of predictions from all trees in the forest, represented as bY = (1/B) * Σ(b=1 to B) bY* b, where bY* b is the prediction from tree T* b. Each tree's prediction is determined by its respective splitting rules and the collection of cases in its terminal nodes. By applying the splitting rules to the predictor variables in X, the terminal node associated with X is identified. The average response of the cases in this node provides the prediction bY* b.

Two key tuning parameters that influence the performance of the regression trees are mtry and nodesize. The mtry parameter specifies how many variables are considered for splitting at each node, while nodesize defines the maximum size for terminal nodes, impacting when the tree construction process ends. If the number of cases exceeds nodesize and there is variation, the node will continue to split; otherwise, it becomes a terminal node.
