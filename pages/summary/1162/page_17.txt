The section discusses the challenges of training Support Vector Machines (SVM) on imbalanced datasets, where instances of the target (positive) class are significantly outnumbered by the non-target class. This issue is exacerbated in multi-class classification scenarios, particularly when employing a one-versus-all strategy, leading to a situation where the number of examples in each class is often minimal compared to the majority class. The imbalance can range from ratios of 1:10 to 1:106.

The growth of support vectors during SVM training is linear with respect to the number of examples, which results in the majority class dominating the support vectors. This imbalance manifests in the dual problem, where most support vectors are from the majority class. The equality constraint in the SVM formulation complicates matters further, leading to irregular solutions where the dual variables for the minority class are constrained to lower values. This effect shifts the decision boundary towards the minority class due to insufficient support vectors close to the ideal boundary, as illustrated by experiments on datasets like the 2D Checkerboard.

The authors note that existing formulations, such as BM-SVM and BP-SVM, suffer from similar issues due to their flawed implementation of asymmetric margins. A proposed solution to this imbalance is to regularize the less sparse vector associated with the majority class using an `1-norm regularizer, resulting in a more balanced and regularized solution. The CS-SVM framework employs this approach by adjusting the regularization coefficient, which can be fine-tuned to improve performance on imbalanced datasets.
