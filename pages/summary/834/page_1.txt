The paper presents HAWQ-V2, an advanced method for quantizing neural networks, which aims to reduce memory usage and inference time while maintaining model accuracy. Traditional quantization techniques can significantly degrade accuracy when using ultra-low precision. To mitigate this, mixed-precision quantization keeps more sensitive layers at higher precision. However, the search space for mixed-precision configurations is exponentially large, making it challenging to optimize.

The authors build upon a previous Hessian-based framework that uses second-order information to reduce the search space but identify three primary limitations in that approach: reliance on a heuristic sensitivity metric based solely on the top Hessian eigenvalue, the need for manual selection of mixed-precision settings, and the exclusion of mixed-precision activation quantization.

HAWQ-V2 addresses these issues by proposing a new sensitivity metric based on the average Hessian trace, which is theoretically proven to be more effective than the top eigenvalue. The method also automates the bit precision selection process through a Pareto frontier approach, removing the need for manual adjustments. Additionally, HAWQ-V2 introduces a Hessian-based analysis for mixed-precision activation quantization, particularly beneficial for object detection tasks.

The results demonstrate that HAWQ-V2 achieves state-of-the-art performance across various tasks, including quantization results for models like InceptionV3, ResNet50, and SqueezeNext, all achieved without manual bit selection. Notably, for object detection on the Microsoft COCO dataset, HAWQ-V2 outperforms direct uniform quantization and a recent method (FQN) while maintaining a smaller model size.
