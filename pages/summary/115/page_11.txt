The proposed SDN defense system focuses on enhancing the security of central controllers by detecting various intrusion and DDoS attacks through multi-dimensional IP flow analysis. Centralized management offers advantages; however, it necessitates the allocation of security resources to ensure the controller's functionality and service quality.

Unlike traditional methods that analyze traffic data across time windows, this system examines individual flows for heightened detection accuracy and quicker mitigation responses. While analyzing vast amounts of data poses challenges, it enables rapid threat identification, thereby reducing the attack impact on end users and facilitating user identification through qualitative IP flow records.

The defense system comprises two main components: the Detection and Mitigation modules, which interact through a central system logic. Data analysis is automated, with network administrators receiving alerts for detected attacks. The Detection module employs a Gated Recurrent Units (GRU) approach, a supervised learning method that utilizes historical labeled data for training. This module assesses flow records, categorizing them as normal or abnormal traffic.

The analysis of various IP flow features enhances traffic insights, revealing critical information about communication participants. The integration of these features is pivotal for comprehensive traffic analysis and effective attack detection.
