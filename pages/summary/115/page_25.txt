In Scenario 2, the study utilized the CICIDS 2018 dataset, which simulates IP flows representing legitimate and malicious network behaviors. The dataset includes traffic generated by 500 machines, 420 legitimate users, 30 server nodes, and 50 attacking nodes, reflecting various attack types such as network infiltration, HTTP denial of service, web application attacks, brute force attacks, and last updated attacks. Unlike the previous dataset, CICIDS 2018 does not pre-divide data into training and testing sets; thus, 66% of the data was randomly chosen for training, and 34% for testing. The research employed the .csv format of the dataset, which contains 79 features suitable for machine learning applications, omitting qualitative dimensions like IP addresses.

The scenario poses a challenge for anomaly detection methods due to the larger volume of legitimate communications and the requirement for intrusion attacks to have minimal impact on network behavior to evade detection. Results from various tested methods are presented, showing a heterogeneous performance across metrics, with the exception of the Deep Neural Network (DNN) approach. Overall, the findings indicate the complexities and challenges in effectively detecting anomalies in this particular dataset.
