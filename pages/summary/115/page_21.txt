The paper discusses the performance evaluation of various anomaly detection methods utilizing the CICIDS 2018 and CICDDoS 2019 datasets. Key metrics used for analysis include accuracy, precision, recall, and F-measure, which assess the effectiveness of the detection methods. The accuracy metric indicates the percentage of correctly classified flow records, while precision measures the ratio of correctly identified abnormal IP flows. Recall evaluates the correctness of identifying anomalous flows, and F-measure provides a balance between precision and recall.

In the experiments, different configurations of the fully connected layer were tested, specifically varying the number of neurons to observe its impact on accuracy and throughput, measured in flows per second. The k-Nearest Neighbors (kNN) method was utilized with three neighbors, and logistic regression (LR) and gradient descent (GD) were set with default values from Sklearn. A total of 100 epochs were run for convergence analysis.

The first test scenario involved the CICDDoS 2019 dataset, which provided simulated IP flows for a realistic evaluation of the anomaly detection techniques. The results from these tests are intended to inform the efficiency and effectiveness of the methods in processing network traffic for anomaly detection.
