This paper discusses the derivation and properties of the binary cross-entropy loss function (LCE) in the context of autoencoders. It begins by exploring the first derivative of LCE with respect to a specific input, demonstrating that the condition for a minimum occurs when the input equals the output (xj = ~xj). This leads to the conclusion that for the cost function to reach its minimum, the output must match the input exactly.

To confirm that this point is indeed a minimum, the paper evaluates the second derivative of LCE. The analysis shows that both the denominator and numerator are positive, indicating that the second derivative is also positive when xj = ~xj. This proves that the minimum of the cost function is achieved under the stated conditions.

The paper emphasizes that for the binary cross-entropy loss function to be applicable, inputs must be normalized to the range of 0 to 1, and the activation function in the final layer should be either sigmoid or softmax. This ensures that the model can effectively learn to reconstruct the input data through the autoencoder framework.
