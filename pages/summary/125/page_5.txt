The paper introduces Feed-Forward Autoencoders (FFA), a type of neural network characterized by a specific architecture involving dense layers. In a typical FFA, the number of neurons decreases as the input progresses toward the middle layer and then increases again, ultimately matching the input dimensions at the output layer. This symmetrical architecture often features an odd number of layers, with the first layer containing a number of neurons equal to the input size. The middle layer, which has the fewest neurons, serves as a bottleneck, emphasizing the compression of input data. Dense layers are defined as groups of neurons where each neuron receives inputs from all neurons in the preceding layer.
