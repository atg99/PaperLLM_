This paper discusses the architecture and functionality of Recurrent Neural Networks (RNNs), specifically focusing on Long Short-Term Memory (LSTM) and Gated Recurrent Units (GRU). The key components include the use of sigmoid activation functions, which output values between 0 and 1, playing a crucial role in the functioning of various gates within these neural networks.

In LSTMs, the cell state acts as a conveyor belt for information flow. The forget gate determines which information to discard, while the input gate decides what new information to store. The equations governing these gates utilize sigmoid and tanh activation functions to manage the flow of information effectively. The cell state is updated through a Hadamard product, integrating both the old and new information.

GRUs simplify the LSTM architecture by combining the forget and input gates into a single update gate, leading to a more computationally efficient design. GRUs consist of two gates: the reset gate and the update gate, which control the memory cell state and hidden state.

The paper provides detailed equations for each gate's operation, illustrating the mathematical foundation of these advanced neural network architectures. Overall, the paper emphasizes the importance of these mechanisms in enabling RNNs to learn from sequential data.
