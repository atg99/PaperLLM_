This section of the paper discusses the data standardization process applied to input features for model training, specifically using z-score normalization. The mean and standard deviation of the training set are utilized to normalize the validation and test sets, ensuring consistency in data handling. The formula for normalization is provided, emphasizing that the normalization should only reference the training set statistics.

Figures referenced illustrate the typical production history in a well block and a heatmap showing the Pearson correlation coefficients among various variables. Table 1 summarizes the statistical properties of the input features, including oil production rate, tubing pressure, shut-in period, and choke size, with their respective means, standard deviations, and ranges.

The normalized features are then reshaped into a three-dimensional tensor to align with the requirements of the model's layers. The dimensions of this tensor include the number of samples, the length of the historical window (HW), and the number of input features. The paper notes that HW is a critical parameter that influences the prediction of outputs for subsequent time steps, with an example assuming a HW of 3 days.
