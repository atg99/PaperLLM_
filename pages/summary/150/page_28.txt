The paper describes the architecture of a first-stage Variational Autoencoder (VAE) used for generating samples and reconstructions, as illustrated in Figure 16. The network consists of a series of Scale Blocks, each containing two Residual Blocks. The encoder takes an input image and initially applies a convolutional layer to convert it into 32 channels. This output is processed through multiple Scale Blocks followed by downsampling using convolutional layers with a stride of 2, effectively doubling the number of channels at each scale. The number of Scale Blocks (N) used varies depending on the dataset, with N=4 for the CelebA dataset and N=3 for others. After flattening the feature map, it is passed through another Scale Block, where convolutional layers are replaced with fully connected layers of 512 dimensions, producing a 64-dimensional latent code.

The decoder operates by first processing the latent code through a fully connected layer, with dimensions set to 4096 for CelebA and 2048 for other datasets. This output is reshaped to a 2x2 resolution and subsequently upsampled via a transposed convolution layer while halving the number of channels. The feature map undergoes additional Scale Blocks and upsampling layers until it reaches the desired output size. Finally, a convolutional layer transforms the feature map to 3 channels for RGB datasets or 1 channel for grayscale datasets.

The paper also mentions a simpler second VAE, where both the encoder and decoder consist of three hidden layers with 2048 dimensions each. Training details for the network are provided in the appendix.
