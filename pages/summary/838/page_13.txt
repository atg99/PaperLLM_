The paper discusses post-processing techniques for trained models in machine learning, focusing on Keras and PyTorch frameworks. It highlights the removal of the SoftMax layer in Keras models when performing inference, as facilitated by the RemoveKerasSoftmax module. Additionally, it details the incorporation of quantization-aware training as a post-processing step, which acts as fine-tuning following general training. However, this training does not convert weights from floating-point to integer types; rather, this conversion is handled by tools like KerasCNN2C.

The deployment of trained models is addressed through MicroAI, which supports inference on STM32 platforms using STM32Cube.AI, TensorFlow Lite for Microcontrollers, and KerasCNN2C. While STM32Cube.AI is limited to STM32 microcontrollers, TensorFlow Lite is more portable, though initial integrations are specific to the SparkFun Edge platform. KerasCNN2C allows for the generation of portable C libraries from trained Keras models.

The paper notes that PyTorch models cannot be directly deployed; they must first be converted to Keras models. A semi-automatic conversion module aids this process by copying weights from the PyTorch model to the Keras model, contingent on matching structures and layer names.

KerasCNN2C is presented as a standalone tool for generating C libraries from trained Keras models, with current support limited to 1D models, although work on 2D models is ongoing. Supported layers include Add, AveragePooling1D, BatchNormalization, Conv1D, Dense, and Flatten.
