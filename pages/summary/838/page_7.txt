The paper discusses various methods for quantizing convolutional neural network weights to optimize memory usage and computational efficiency. It begins by presenting the distribution of weights in a convolutional layer, highlighting the mean, standard deviation, maximum, and minimum values. 

The authors explore scaling and offset techniques for quantization. They propose a scale factor that is not necessarily a power of two, allowing the use of all bits for representing fractional parts, exemplified by the Q1.15 format for 16-bit numbers. While this approach can reduce quantization error through a more flexible scaling method, it introduces additional computational complexity due to the need for multiplications and shifts.

The paper also discusses the trade-offs between using a single scale factor for the entire network versus different scale factors for each layer or filter. Although using a unique scale factor for each weight value would provide optimal quantization, it is impractical due to memory constraints. The authors suggest a per-layer scale factor as a balance between quantization accuracy and memory efficiency, while noting their implementation currently supports only per-network and per-layer scale factors.

Finally, the conversion method from floating-point to fixed-point representation is detailed, emphasizing the calculation of required bits to represent the unsigned integer part based on the maximum value in the floating-point vector. This method allows for greater precision, especially for vectors with smaller numbers, thus enhancing the overall quantization process.
