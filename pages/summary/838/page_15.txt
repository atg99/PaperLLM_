The paper discusses an efficient approach to implementing a convolutional neural network (CNN) in a constrained environment using code generation and memory optimization techniques. The inference function and layer weights are derived from Jinja2 templates, which helps eliminate runtime overhead associated with interpreters like TensorFlow Lite for Microcontrollers. This method allows for better compiler optimizations, such as loop unrolling and improved register allocation, by generating constants directly in the code with GCC’s -Ofast optimization level enabled.

An allocator module is introduced to minimize RAM usage by efficiently managing output buffers for each layer. It allocates buffers in the smallest number of pools while ensuring there are no conflicts, though it does not yet optimize the total RAM usage.

The quantization process is handled by a dedicated module that computes scale factors for each layer, allowing for both post-training and quantization-aware training. During quantization-aware training, weights remain in floating-point representation, necessitating a conversion to fixed-point representation post-training. The computation on the target device utilizes regular integer arithmetic, with precautions taken to prevent overflows by using larger data types for intermediate results.

The paper also briefly outlines the operations required for main layers in a residual neural network and highlights the impact of compiler optimizations on performance, particularly through the use of specific ARM instructions that enhance execution efficiency. Overall, the approach aims to balance resource constraints with computational efficiency in deploying CNNs.
