The paper discusses the limitations of existing frameworks for deploying quantized neural networks on microcontrollers, particularly focusing on the lack of support for convolutional neural networks with non-sequential topologies, proprietary complexities, and insufficient quantization options. To address these issues, the authors propose a new framework called MicroAI. 

MicroAI is designed to provide an open-source solution that is easy to modify and extend, facilitating a comprehensive pipeline from neural network training to deployment on microcontrollers. The framework consists of two main components: a neural network training code that utilizes Keras or PyTorch, and a conversion tool, KerasCNN2C, which converts trained Keras models into portable C code for inference. Both components are developed in Python, leveraging its popularity and compatibility with existing tools.

The framework offers an automated interface for training, deploying, and evaluating neural network models, utilizing a configuration file written in TOML to outline the experiment parameters, including iterations, dataset specifications, preprocessing steps, training framework, model configurations, optimizer settings, post-processing steps, and target deployment configurations. The paper outlines the general workflow of MicroAI and highlights its aim to achieve performance comparable to existing solutions while providing a lightweight runtime for microcontrollers.
