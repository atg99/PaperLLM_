The paper discusses advancements in neural architecture search (NAS) techniques, focusing on DenseNAS and FBNetV2. DenseNAS introduces a densely-connected block-based search space that allows for the exploration of varying block widths and numbers per layer. This architecture employs routing blocks, which include shape-alignment layers and basic layers that blend outputs from different candidate operations. The operations are relaxed into continuous forms using softmax, similar to the DARTS method. A chained cost estimation algorithm is integrated to manage computational costs and latency, utilizing a lookup table for basic layer operation costs. DenseNAS demonstrates improved performance over previous methods, achieving a 2.8% increase in top-1 accuracy on ImageNet compared to DARTS while effectively controlling FLOPS and latency.

FBNetV2 addresses limitations found in earlier DNAS approaches like DARTS and FBNet, which featured constrained search spaces. By introducing new hyperparameters related to channel numbers and input resolution, FBNetV2 expands the search space significantly, accommodating 10^35 candidate architectures, which is 10^14 times larger than that of FBNet. This enhancement allows for more comprehensive architecture exploration, enhancing the potential for optimized neural network designs.
