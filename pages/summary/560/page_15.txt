The paper discusses advancements in Differentiable Neural Architecture Search (DNAS), particularly focusing on EnTranNAS, which enhances search efficiency and accuracy in neural network design. EnTranNAS innovatively incorporates architecture discretization at the end of each search iteration, using Transit-cells to manage the derived architecture and improve operational confidence. A feature-sharing strategy is introduced, allowing operations from node i to node j to consistently share features, which reduces computational costs by computing feature maps only once per cell.

Despite these improvements, EnTranNAS still faces an optimization gap, leading to the development of EnTranNAS-DST. This method introduces trainable parameters for intermediary nodes to perform operation pruning, further refining the architecture derivation process.

The experimental results indicate that EnTranNAS surpasses previous models, achieving higher accuracy on CIFAR-10 and ImageNet compared to DARTS. Additionally, CDARTS is mentioned for its cyclic feedback mechanism, enhancing the performance evaluation of the architecture by integrating a search network and an evaluation network, thereby addressing the optimization gap more effectively. Overall, the paper highlights significant strides in automating neural network design through efficient architecture search techniques.
