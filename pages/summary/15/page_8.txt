The section discusses the critical role of activation functions in convolutional neural networks (CNNs), which are essential for enabling the model to learn complex features. Activation functions determine the information passed between neurons, and without them, a neural network would effectively behave as a linear model, limiting its learning capacity. The paper highlights various activation functions, including sigmoid, tanh, and Rectified Linear Unit (ReLU), each with unique properties and advantages.

The sigmoid function maps inputs to a range between 0 and 1, making it suitable for binary classification. The tanh function, which outputs values between -1 and 1, normalizes the output, facilitating easier learning in subsequent layers. ReLU is noted for its efficiency in accelerating learning, as it avoids the slow convergence issues associated with sigmoid and tanh by maintaining a constant derivative for positive inputs.

However, ReLU can lead to dead neurons when inputs are negative, prompting the development of variants like Leaky ReLU and Parametric ReLU (PReLU), which address this issue by allowing a small, non-zero gradient for negative inputs. The Exponential Linear Unit (ELU) is another alternative that aims to improve convergence speed by outputting negative values, although it introduces computational complexity.

The experimental evaluation compares these activation functions using two CNN models, LeNet-5 and VGG-16, across four benchmark datasets: MNIST, Fashion-MNIST, CIFAR-10, and CIFAR-100. This analysis aims to assess the performance differences among the activation functions in practical applications.
