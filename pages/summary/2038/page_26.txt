The paper presents experiments utilizing i-vector features and a neural network (NN) classifier for language identification (LID). The NN employed the Adam optimizer and ReLU activation function, varying hidden neuron counts between 650 and 900. Results indicate that the highest accuracy for the NN was 90.55% at 700, with variable precision, recall, F-measure, and G-mean values across different neuron counts.

Further experiments were conducted using the basic Extreme Learning Machine (ELM) and Fast Learning Network (FLN) on the same benchmark dataset. The basic ELM achieved its highest accuracy of 89.38% with 875 neurons, while the FLN reached an accuracy of 92.50% with 725 neurons. Evaluation metrics for both models varied, with the FLN generally outperforming the basic ELM in all measures. The findings suggest that model architecture significantly influences performance in LID tasks.
