This paper presents a novel approach to Visual Question Answering (VQA) through a deep co-attention learning framework. The model processes image features and question features by creating a question feature matrix and employing zero-padding to standardize input sizes. This is crucial for dealing with variable object counts and question lengths. The authors introduce a deep co-attention model composed of multiple layers of Multi-Channel Attention (MCA), where input features are iteratively refined to enhance the representation of both images and questions.

Two primary architectures for deep co-attention are proposed: a stacking model and an encoder-decoder model, both of which utilize cascading MCA layers. The stacking model directly combines features, while the encoder-decoder model modifies the input at each layer to use the output from the final MCA layer, allowing for a more dynamic interaction between image and question features.

Following the co-attention learning phase, the output features are processed through a two-layer Multilayer Perceptron (MLP) to extract attended features. These features are then fused using a linear combination, followed by normalization to stabilize training. The final fused representation is used to create a classifier that predicts answers to the questions based on the visual input.

The experiments are conducted on the VQA-v2 dataset, a widely recognized benchmark in the field. The authors perform ablation studies to analyze the impact of different model configurations on performance and ultimately compare their best model against existing state-of-the-art methods, demonstrating the effectiveness of their approach.
