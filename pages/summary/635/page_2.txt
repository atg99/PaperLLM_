The topology of this network is constructed to have a strong correlation with the node labels, while the node features bear no meaningful correlation. In this scenario, we apply GCN to assess its ability to leverage the network topology for classification.

Similar to the first case, we conduct experiments by training GCN with 20 nodes per class and testing on 200 nodes. We also employ an MLP for classification based solely on the node features. The classification accuracies for GCN and MLP are recorded, revealing that GCN struggles to achieve satisfactory performance due to the lack of informative node features, while MLP, relying solely on random features, performs poorly.

These experiments illustrate the limitations of GCNs in effectively fusing topological structures and node features, even when correlations exist. The findings reveal that GCNs may not adaptively learn from the available information, leading to suboptimal classification outcomes.

In response to these weaknesses, this study introduces the Adaptive Multi-Channel Graph Convolutional Networks (AM-GCN), which aims to improve the fusion of topological structures and node features. AM-GCN operates by simultaneously learning from the node features, topological structures, and their combinations. The approach incorporates a k-nearest neighbor graph derived from node features to enhance the feature structural graph, allowing for the propagation of node features across both topological and feature spaces.

Key innovations of AM-GCN include a common convolution module that shares parameters across both spaces, as well as an attention mechanism that learns the importance weights for different embeddings. This enables the model to adaptively fuse the most relevant information, supervised by node labels, while maintaining consistency and disparity in the learned embeddings.

The paper concludes by demonstrating through extensive experiments that AM-GCN outperforms existing GCN models, effectively extracting the most correlated information for classification tasks. The organization of the paper includes a thorough examination of GCN fusion capabilities, development of the AM-GCN framework, reporting of experimental results, and a review of related work.
