This paper presents an evaluation of the proposed AM-GCN model for semi-supervised multi-class classification using various real-world datasets. The datasets used include Citeseer, UAI2010, ACM, BlogCatalog, Flickr, and CoraFull, each characterized by distinct nodes, edges, classes, and features. The optimization objective leverages a softmax function to calculate class predictions based on node embeddings, employing a cross-entropy loss function for training.

The overall objective function combines the node classification loss with consistency and disparity constraints, allowing for effective model optimization through backpropagation. The experiments compare AM-GCN against state-of-the-art methods, including network embedding algorithms like DeepWalk and LINE, as well as graph neural network approaches such as Chebyshev, GCN, kNN-GCN, GAT, DEMO-Net, and MixHop.

For evaluation, three label rates of training nodes are tested alongside a consistent test set of 1000 nodes. The model's parameters, including learning rates, dropout rates, and coefficients for constraints, are meticulously tuned to ensure optimal performance. The results are assessed using Accuracy and macro F1-score metrics, with reproducibility ensured by providing detailed parameter settings in the supplementary material.
