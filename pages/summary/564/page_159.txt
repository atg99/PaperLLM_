The paper discusses the operation of tree-based pipelines, which involve storing three key variables for each dataset record: the "class" variable representing the true label, the "guess" variable containing the latest prediction from the pipeline, and the "group" variable indicating whether the record is part of the training or testing set. The training data is further divided into a stratified 75% for training and 25% for testing.

To optimize these pipelines, the authors employ a genetic programming (GP) algorithm using the DEAP Python package. This GP process begins with the generation of 100 random tree-based pipelines, which are evaluated for balanced cross-validation accuracy. Each generation selects the top 20 pipelines based on the NSGA-II selection scheme, aiming to maximize classification accuracy while minimizing the number of operators. Selected pipelines produce offspring through crossover and mutation processes, with the algorithm updating a Pareto front of non-dominated solutions throughout 100 generations. The highest-accuracy pipeline from the Pareto front is designated as the "best" pipeline.

Additionally, the authors compiled 150 supervised classification benchmarks from various sources, including the UCI machine learning repository and other established datasets, to evaluate the performance of the pipelines.
