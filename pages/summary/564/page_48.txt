This section discusses task-independent recommendations in meta-learning, focusing on how to recommend model configurations without access to evaluations on new tasks. It introduces a function that learns configurations independent of the new task, allowing for a ranking of configurations based on evaluations from previous tasks. The ranking can be determined through methods like success rates or AUC, with considerations for both accuracy and training time. When data is insufficient for a global ranking, recommendations can be made based on the best configurations from prior tasks.

To find the best configuration for an unseen task, a straightforward method is to evaluate the top configurations sequentially until a set threshold is met. Multi-objective rankings have shown to converge to optimal models more quickly in time-constrained scenarios. An alternative approach involves fitting a differentiable function to prior evaluations and using gradient descent to optimize configurations for similar tasks, which can aid in Bayesian optimization.

Additionally, the design of the configuration space can be improved using prior evaluations to focus on more relevant areas, which is especially beneficial when computational resources are limited. The functional ANOVA method identifies important hyperparameters by assessing their impact on performance variance across tasks, demonstrating the effectiveness of this approach through extensive experiments.
