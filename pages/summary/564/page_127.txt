Auto-sklearn is an automated machine learning framework that efficiently combines various models and preprocessing methods to optimize machine learning tasks. Key features include the ability to create ensembles from models evaluated at different times, which enhances model performance without significant additional effort. Auto-sklearn employs a range of data preprocessing techniques, such as rescaling, imputation, one-hot encoding, and class balancing, alongside 14 feature preprocessing methods that include feature selection and polynomial feature expansion.

To optimize computational resources and avoid lengthy evaluations, Auto-sklearn implements measures such as limiting evaluation time and memory usage. Evaluations exceeding these limits are automatically terminated, and the worst possible score is returned. Certain combinations of preprocessing and algorithms, particularly those that could lead to inefficiencies, are also restricted.

When addressing hyperparameter optimization, Auto-sklearn balances the need for robust validation against the risk of overfitting, particularly when dividing data into training and validation sets. For time-constrained tasks, simple train/test splits are used, while more extensive evaluations employ ten-fold cross-validation.

Moreover, Auto-sklearn adapts to the properties of new datasets by preselecting suitable algorithms, transforming categorical features into numerical values through one-hot encoding while managing the number of resulting dummy features. This ensures that Auto-sklearn remains versatile across various supervised learning tasks.
