The paper discusses the advancements in Auto-Net 2.0, an automated machine learning framework that builds upon the previous version, Auto-Net 1.0. One key feature of Auto-Net 2.0 is its ability to adjust the learning rate during training using the OnPlateau scheduler, which decreases the learning rate by a factor when performance metrics cease to improve over a specified number of epochs.

Auto-Net 2.0 expands its capabilities by incorporating various pre-processing techniques, including Nyström, Kernel PCA, fast independent component analysis, random kitchen sinks, and truncated singular value decomposition. Users can customize the pre-processing methods and apply different strategies for balancing and normalization, although the current balancing strategy is limited to loss weighting.

Unlike Auto-Net 1.0, Auto-Net 2.0 does not create an ensemble at the end of the training process, although this feature may be added in the future. The framework utilizes BOHB (Bayesian Optimization with HyperBand) as its optimizer, which enhances efficiency by combining Bayesian optimization with the bandit-based strategy Hyperband. BOHB employs Successive Halving to focus training resources on promising models while terminating poorly performing ones early. It uses a kernel density estimator to navigate the hyperparameter space, balancing exploration and exploitation effectively.

The framework allows users to set budgets based on either epochs or wall-clock time, with a default focus on runtime. Auto-Net 2.0 is designed as a plugin for scikit-learn, requiring users to provide a training dataset and a performance metric for model evaluation. An example of its implementation is also provided, demonstrating how to initialize and fit the Auto-Net classification model.
