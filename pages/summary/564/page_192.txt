The paper presents a detailed analysis of datasets used in the AutoML Challenge Series from 2015 to 2018. It includes a comprehensive table summarizing various characteristics of the datasets from the 2015/2016 challenge, highlighting key metrics such as task type, performance metrics, and dataset properties. 

Key aspects covered in the table include the number of classes (C), class balance (Cbal), sparsity (Sparse), fraction of missing values (Miss), number of categorical variables (Cat), fraction of irrelevant variables (Irr), and the number of examples in training (Ptr), validation (Pva), and test (Pte) sets. Additionally, it documents the number of features (N) and the aspect ratio of the dataset (Ptr/N).

The datasets encompass a variety of tasks, including multilabel, multiclass, binary classification, and regression, with performance metrics such as F1 score, AUC, R², and Balanced Accuracy (BAC) being employed for evaluation. The analysis reveals insights into the complexity and diversity of the datasets, contributing to understanding the challenges faced in automated machine learning during this period.
