In this chapter, Olson and Moore discuss the development and evaluation of the Tree-based Pipeline Optimization Tool (TPOT), an automated machine learning tool designed to create and optimize machine learning pipelines through genetic programming. TPOT aims to eliminate the need for human intervention in the design of these pipelines, effectively enhancing their efficiency and accuracy.

The chapter builds on previous work by demonstrating TPOT's effectiveness across 150 supervised classification tasks, showcasing its versatility in various domains, including genetic analysis and image classification. TPOT employs Pareto optimization in conjunction with genetic programming to construct pipelines that outperform traditional machine learning methods.

The authors provide a detailed overview of TPOT version 0.3, highlighting the machine learning operators that serve as genetic programming primitives, the tree-based structure used to integrate these operators into functional pipelines, and the genetic programming algorithm that evolves these pipelines. TPOT functions as a wrapper for the scikit-learn machine learning library, utilizing various algorithms such as Decision Tree, Random Forest, and XGBoost for supervised classification tasks.

Overall, the chapter presents TPOT as a significant advancement in automated machine learning, emphasizing its open-source nature and accessibility for further research and development.
