The Auto-Weka project demonstrated the potential of searching an entire library of machine learning approaches within a single run of hyperparameter tuning. However, due to the limitations of Weka, which is a GPL-licensed Java library not designed for scalability, there is a need for alternatives. Scikit-learn, a widely used BSD-licensed Python library, offers a more scalable option for machine learning applications.

This chapter introduces Hyperopt-Sklearn, a project that enables automated algorithm configuration for users of scikit-learn by utilizing the Hyperopt library. Hyperopt-Sklearn allows users to search through possible configurations of scikit-learn components, including preprocessing, classification, and regression modules. A key feature of Hyperopt-Sklearn is its user-friendly interface, which requires minimal changes to existing code for hyperparameter search implementation. The chapter provides background on Hyperopt and its configuration space within scikit-learn, along with usage examples and experimental results.

Hyperopt offers optimization algorithms suitable for algorithm configuration, accommodating various variable types and conditional structures. Users must define a search domain, an objective function, and an optimization algorithm. The search domain is established using random variables with distributions that prioritize promising combinations. The objective function evaluates these combinations, providing a scalar score for the optimization algorithm to minimize. This chapter serves as an extended version of a previous paper presented at the 2014 ICML Workshop on AutoML.
