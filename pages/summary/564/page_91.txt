This chapter discusses Auto-WEKA, a framework for automatic model selection and hyperparameter optimization, building on prior research presented at KDD 2013 and in the Journal of Machine Learning Research in 2017. 

The fundamental task involves learning a function from input space X to output space Y, where Y can be either finite for classification tasks or continuous for regression tasks. A learning algorithm A is responsible for mapping training data points to such a function, often characterized by model parameters and hyperparameters. Hyperparameters, which dictate the behavior of the learning algorithm, require optimization through an "outer loop" that typically employs cross-validation to assess performance for different configurations.

Model selection aims to identify the algorithm A* from a set of algorithms A that provides the best generalization performance on limited training data D. This is achieved by partitioning D into training and validation sets, allowing for the evaluation of algorithms based on their predictive performance. The model selection process is formalized as minimizing the loss function L, calculated over the training and validation sets through k-fold cross-validation, which divides the data into k equal parts to ensure robust performance estimation. Other validation methods were also explored, yielding comparable results.
