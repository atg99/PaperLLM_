Auto-WEKA is an automatic system designed to address the Combined Algorithm Selection and Hyperparameter tuning (CASH) problem within the WEKA machine learning framework. It primarily focuses on classification algorithms, although it can be extended to other types of learning tasks. The system integrates various learners and feature selectors available in WEKA, allowing for flexible model selection and hyperparameter optimization.

The framework supports a diverse range of learning algorithms, including meta-methods that utilize a single base classifier and ensemble methods that can incorporate multiple base learners. Each algorithm has a defined number of hyperparameters that can be tuned. For example, algorithms such as Random Forest and Multilayer Perceptron have seven and eighty-two hyperparameters, respectively.

In addition to classification, some learners also accommodate regression tasks, as indicated by those marked with an asterisk. The architecture of Auto-WEKA is similar to that of auto-sklearn, demonstrating its adaptability and potential for broader applications in machine learning. Overall, Auto-WEKA provides a comprehensive and efficient solution for automating model selection and hyperparameter tuning in machine learning tasks.
