The paper presents I-BERT, a method for integer-only quantization of BERT models, focusing on uniform symmetric quantization. The reverse mapping from quantized values to real values is achieved through a dequantization operator, which maintains constant spacing between quantized values. While non-uniform quantization could better capture parameter distributions, it is less feasible for hardware implementation due to overhead from look-up tables. Therefore, the authors concentrate on uniform quantization, utilizing static quantization to avoid runtime scaling factor computation.

A significant challenge in integer-only quantization arises with non-linear functions like GELU and Softmax, as previous methods relied on linear properties that do not hold for these operations. To circumvent this, the authors propose approximating non-linear activation functions with polynomials that can be computed using integer arithmetic. This allows for complete inference without floating-point calculations, which is essential for efficient hardware like ARM Cortex-M.

The paper also discusses the use of interpolating polynomials to approximate functions. By selecting appropriate interpolating points and degrees for the polynomial, the authors can minimize approximation errors while managing computational and memory overhead. High-order polynomials can reduce error but may lead to overflow issues in low-precision arithmetic. The proposed solution aims to balance accuracy and efficiency for effective implementation in integer-only environments.
