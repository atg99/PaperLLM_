The paper presents I-BERT, a method for quantizing the BERT model using integer-only arithmetic, focusing on key functions such as GELU, Softmax, and LayerNorm. The approach aims to maintain model performance while reducing computational complexity and memory usage.

The integer-only GELU function is introduced through Algorithm 2, which utilizes integer arithmetic to approximate the error function (erf). The results show that the proposed i-GELU method achieves lower L2 and L1 distances compared to other approximation methods, indicating a more accurate representation of the GELU function.

Softmax, a critical function for normalizing input vectors into probability distributions, is challenging to implement using integer arithmetic due to the exponential function. The paper proposes a novel approach that stabilizes the exponential calculation by subtracting the maximum input value, allowing for the decomposition of non-positive numbers into a manageable form. The authors derive a second-order polynomial approximation for the exponential function within a limited range, resulting in an integer-only computation method for Softmax.

LayerNorm, used for normalizing activations in Transformers, involves multiple non-linear operations. The authors discuss the challenges of implementing LayerNorm with integer arithmetic but do not detail a specific integer-only approximation within the provided text.

Overall, I-BERT aims to facilitate efficient inference of BERT models on resource-constrained devices by leveraging integer-only computations, thereby mitigating the limitations associated with floating-point arithmetic while preserving model accuracy.
