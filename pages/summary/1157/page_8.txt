The paper discusses the application of non-linear Support Vector Machines (SVMs) in recognition problems that cannot be solved linearly. It introduces the kernel trick, which allows for the creation of a non-linear decision function by defining a kernel function that computes the inner product of feature vectors in a non-linear feature space. This approach avoids the need for explicitly calculating the mapping from the input space to the feature space, making it efficient.

The kernel function satisfies Mercer's conditions and enables the transformation of feature vectors into a higher-dimensional space where they can become linearly separable. The decision function for the SVM is expressed in terms of the kernel function, Lagrange multipliers, and a bias term. The optimization problem of determining the SVM decision hyperplane is framed as a constrained quadratic programming (QP) problem, which can be solved efficiently.

An illustrative example is provided, demonstrating how two classes of feature vectors that are not linearly separable in a two-dimensional space can be separated by a hyperplane when mapped into a higher-dimensional space. The paper highlights the effectiveness of non-linear SVMs in addressing complex classification tasks.
