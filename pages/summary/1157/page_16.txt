The paper discusses methods for refining training sets in the context of Support Vector Machines (SVMs) using Mahalanobis distance and the β-skeleton algorithm. The Mahalanobis distance is employed to assess the proximity of data points to class centroids, where a negative value indicates misclassification and suggests that the point should be included in a refined training set. The refined set is constructed by selecting points with the lowest Mahalanobis distance values, ensuring balanced representation from both classes.

The β-skeleton algorithm, as introduced by Zhang and King in 2002, is a neighborhood graph technique that facilitates the extraction of useful training vectors. It defines a neighborhood for points based on the intersection of two spheres and establishes connections between points if no other points from the training set lie within their neighborhoods. This method aims to identify support vectors and reduce the training set size while maintaining geometrical relationships within the data.

The paper also references Angiulli and Astorino's 2010 work on integrating the fast nearest neighbor condensation classification rule (FCNN) with SVMs, termed FCNN-SVM. This approach emphasizes vector selection based on the decision boundary rather than clustering, starting with centroids as an initial training set and iterating to include misclassified vectors until no further additions are possible.

Overall, the techniques discussed leverage geometric properties of data to enhance the effectiveness of SVMs in classification tasks while addressing the challenge of dataset size and class representation.
