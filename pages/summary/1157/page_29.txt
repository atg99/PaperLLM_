The paper reviews various algorithms used for selecting training sets in support vector machines, focusing on evolutionary methods such as genetic algorithms. It highlights several key contributions from 2007 to 2015, detailing different iterative wrapper approaches. These approaches include initial genetic algorithms, enhancements through random sampling and crossover, and advancements in adaptive genetic algorithms. Notable algorithms mentioned are GASVM, AGA, DAGA, and MASVM, each designed to improve training set selection efficiency. The review also discusses the application of multi-objective evolutionary algorithms, particularly for imbalanced data. The table provides specific metrics like the type of source, whether random sampling is used, dependency, and data size for each method, illustrating the evolution and effectiveness of these techniques in optimizing support vector machine training.
