In summary, the proposed approach, ConceptBert, incorporates three key input representations: image features extracted using Faster R-CNN, question embeddings generated through BERT, and knowledge graph embeddings derived from ConceptNet. The model utilizes a vision-language module that facilitates interaction between visual and textual modalities through transformer blocks and co-attentional layers. Additionally, it integrates a concept-language representation that enriches the question understanding with contextual knowledge from the knowledge graph. This comprehensive representation allows the model to better address questions that require deeper insights beyond the immediate visual and textual inputs.
