The paper discusses the concept of optimality in stationary policies within the framework of Dynamic Programming (DP). A deterministic stationary policy is defined as a function that selects an action based on the current state, denoted as µ:S → A, where at time t, the action is determined by the state at that time. The set of all such policies is represented as Πµ.

The expected return for a stationary policy starting from an initial state s0=s is formulated as Jµ(s), which is the limit of the expected cumulative rewards over time, discounted by a factor γ. An optimal deterministic stationary policy, denoted as µ∗, is characterized by achieving the maximum expected return across all stationary policies for every state s. The paper asserts that the expected return for an optimal stationary policy is equal to that of the optimal history-dependent policy, π∗, which suggests that focusing solely on stationary policies does not lead to suboptimal outcomes. This highlights the effectiveness of stationary policies in achieving optimal returns in a dynamic programming context.
