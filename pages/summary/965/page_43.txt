The Q-learning algorithm is designed to directly learn the Q-function, which represents the expected utility of taking a certain action in a given state, without the need to define the structure of a Markov Decision Process. The algorithm operates through the following steps:

1. Initialize the estimated Q-values, ˆQ(s, a), to zero for all state-action pairs and set the iteration count, k, to zero.
2. Update the Q-value for the current state-action pair (sk, ak) using the formula: ˆQ(sk, ak) ← (1−αk)ˆQ(sk, ak) + αk(rk + γmax a∈A ˆQ(sk+1, a)), where αk is the learning rate, rk is the reward received, and γ is the discount factor that accounts for future rewards.
3. Increment the iteration count k. If k equals the total number of time steps t, the algorithm returns the estimated Q-values and terminates. If not, it repeats step 2.

This process enables the algorithm to progressively refine its estimates of the Q-function based on experiences.
