The paper characterizes a reinforcement learning (RL) problem by defining the dynamics of the environment and the reward signal. The environment's dynamics are described by the equation st+1=f(st, at, wt) for t=0,1,2,..., indicating that the state st transitions to the next state st+1 based on the current state, action taken, and a random disturbance wt. The state st belongs to a state space S, the action at belongs to an action space A, and the disturbance wt is drawn from a time-invariant conditional probability distribution Pw(·|s, a).

The reward signal is defined by the function r(s, a, w), which is bounded between 0 and a constant Br≥0. The transition from time t to t+1 is associated with a reward signal represented as γtrt=γtr(st, at, wt), where the reward function is also bounded by the constant Br. The discount factor γ, which ranges from 0 to 1, is used to calculate the present value of future rewards. This framework establishes the foundational elements of the RL problem being addressed.
