The paper defines a Markov Decision Process (MDP) structure based on system dynamics and a reward function. It introduces two key equations: the first, r(s, a), represents the expected reward given a state s and action a, calculated using the probability distribution Pw of the uncertain parameters w. The second equation, p(s'|s, a), defines the transition probabilities from state s to state s' based on the same distribution.

These equations establish that the expected return of any policy in the original control problem aligns with the expected return in the defined MDP, indicating equivalence between the two systems. Furthermore, the paper reformulates the recurrence equation for the action-value function QN, which captures the expected return for taking action a in state s and following the optimal policy thereafter. The initial condition for this function is set at Q0(s, a) = 0 for all state-action pairs. This structured approach allows for a systematic analysis of decision-making processes under uncertainty.
