The paper discusses the resolution of an optimization problem by identifying an optimal policy ˆµ∗ within a set of policies Πµ. For each state s in the state space S, the value function Jˆµ∗(s) is determined as the maximum of the modified value functions ˆJµ(s), which are defined using alternative parameters ˆf, ˆPw, and ˆr instead of the original f, Pw, and r.

Following the identification of the optimal policy, the paper introduces a strategy for action selection, where policy ˆπ chooses actions based on ˆµ∗ with a probability of 1 - ε(ht) and randomly with a probability of ε(ht). This approach aims to balance exploration and exploitation in decision-making. The design of the function ε, which maps historical data to a probability range, is noted but not explored in detail. It is commonly set as a small constant, such as 0.05, in various applications.
