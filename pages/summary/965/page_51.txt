The fitted Qiteration algorithm's performance is contingent upon the choice of supervised learning method. Notably, it demonstrates excellent and stable results when paired with ensemble regression tree methods and deep neural networks, particularly with image inputs. The algorithm can be applied to any set of one-step system transitions, which include the current state, action taken, observed reward, and next state reached. Consistency, or convergence to an optimal solution, is achievable as the number of one-step transitions approaches infinity, provided that certain assumptions are met regarding the supervised learning method, the sampling process, system dynamics, and the reward function.
