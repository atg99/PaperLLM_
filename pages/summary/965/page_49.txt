The Fitted Q-iteration algorithm is a method used to approximate the Q-functions Q1, Q2, ..., QN in a reinforcement learning context. At each iteration N greater than 1, the algorithm utilizes the previously computed function ˆQN−1 along with a training set ht to generate a new training set. This new set is then used by a supervised learning (SL) algorithm to output the next approximation ˆQN.

In the first iteration, the algorithm focuses on creating a model ˆQ1 for the function Q1(s, a), which represents the expected reward for taking action a in state s. This is achieved by applying a supervised learning algorithm to the training set TS, which consists of pairs of states and actions along with their corresponding rewards.

The underlying motivation for this approach is to relate the components of the problem to a structured representation, where the state-action pairs (S×A) correspond to inputs (I), rewards (R) to outputs (O), and the stochastic elements (W) to a set of variables (Ξ). By applying a supervised learning algorithm to the defined training set, the algorithm effectively generates a model for Q1, which can then be iteratively improved in subsequent steps.
