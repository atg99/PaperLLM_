The paper discusses algorithmic models for computing a fixed point through iterative updates of a variable R using a transformation G. The first model updates R entirely at each stage k, leading to convergence towards a fixed point R*. This is derived from a previously established equation. The second model focuses on refreshing individual elements of R, where at each stage, a specific element e is updated while the others remain unchanged. If every element is selected infinitely often, this model also converges to the fixed point R*. The results highlight the robustness of the convergence properties of these algorithms under different update schemes.
