To compute the Q-function Q4(s, a) for the given policy π(s) = 1 for all states s in S, we first need to understand the reward function and the dynamics of the state transitions based on the specified action a.

### Definitions:
- **State Space:** S = {1, 2, 3, 4}
- **Action Space:** A = {-1, 1}
- **State Transition Function:** f(s, a) = min(max(s + a, 1), 4)
- **Reward Function:** 
  - r(s, a) = 1 if f(s, a) = 4
  - r(s, a) = 0 otherwise

### Steps to Compute Q4(s, a):
1. **Identify Possible Actions:** For each state s, the available actions are -1 and 1.
2. **Compute Next State and Rewards:**
   - For each state-action pair (s, a), calculate the next state f(s, a) and the associated reward r(s, a).
3. **Calculate Q-Values:** Since the policy π(s) = 1, we will consider only the action a = 1 for each state when calculating Q-values.

### Calculations:

1. **For s = 1:**
   - a = 1: 
     - f(1, 1) = min(max(1 + 1, 1), 4) = min(max(2, 1), 4) = 2
     - r(1, 1) = 0 (since f(1, 1) ≠ 4)
   - Q4(1, 1) = r(1, 1) + γ * Q4(2, π(2))

2. **For s = 2:**
   - a = 1: 
     - f(2, 1) = min(max(2 + 1, 1), 4) = min(max(3, 1), 4) = 3
     - r(2, 1) = 0 (since f(2, 1) ≠ 4)
   - Q4(2, 1) = r(2, 1) + γ * Q4(3, π(3))

3. **For s = 3:**
   - a = 1: 
     - f(3, 1) = min(max(3 + 1, 1), 4) = min(max(4, 1), 4) = 4
     - r(3, 1) = 1 (since f(3, 1) = 4)
   - Q4(3, 1) = r(3, 1) + γ * Q4(4, π(4))

4. **For s = 4:**
   - a = 1: 
     - f(4, 1) = min(max(4 + 1, 1), 4) = min(max(5, 1), 4) = 4
     - r(4, 1) = 1 (since f(4, 1) = 4)
   - Q4(4, 1) = r(4, 1) + γ * Q4(4, π(4)) = 1 + γ * Q4(4, π(4))

### Summary of Q-Values:
- Q4(1, 1) = 0 + γ * Q4(2, π(2))
- Q4(2, 1) = 0 + γ * Q4(3, π(3))
- Q4(3, 1) = 1 + γ * Q4(4, π(4))
- Q4(4, 1) = 1 + γ * Q4(4, π(4))

These equations can be solved recursively if the discount factor γ and the terminal condition for Q4(4, π(4)) are defined. If we assume a terminal state where Q4(4, π(4)) converges to a constant, we can calculate specific Q-values.
