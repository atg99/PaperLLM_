The document provides a technical glossary of key concepts related to data analysis and databases. 

- R is a programming language designed for statistical computing and graphics, primarily used as a data mining tool.
- Impala is an open-source, massively parallel processing database for Apache that allows querying data from HDFS or HBase.
- Matlab is a programming language favored by university students for fast prototyping and includes a comprehensive machine learning repository.
- A matrix is defined as an array used for data representation.
- MongoDB is identified as a NoSQL database for storing unstructured data without a specific schema.
- Model selection refers to the process of choosing a statistical model for machine learning from a set of known models.
- NewSQL databases combine the integrity of traditional relational SQL databases with the scalable performance of NoSQL systems.
