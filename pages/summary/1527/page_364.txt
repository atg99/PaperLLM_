This technical glossary defines key concepts in data processing and machine learning. 

- Sqoop: An open-source tool for transferring data between Hadoop and traditional relational databases.
- Spark: A programming model supporting Java, Scala, Python, and R, designed for rapid development of large-scale data processing applications.
- SQL: A structured query language used for managing data in traditional database management systems.
- Tensor: An N-dimensional array that generalizes a matrix, used to hold data in multiple dimensions.
- TensorFlow: An open-source library for data computations, optimized for machine learning, facilitating multilayered neural networks and efficient training.
- True negative: A correct prediction by a model indicating a false outcome.
- True positive: A correct prediction by a model indicating a true outcome.
