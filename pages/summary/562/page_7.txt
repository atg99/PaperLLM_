The paper discusses an efficient approach to hyperparameter optimization in deep learning using a variable length genetic algorithm. It illustrates how chromosomes evolve over different phases, with each new phase building upon the previous phase's best model. Specifically, Figure 4 shows the encoding for phases following Phase 0, where the chromosome is extended to include new fields that represent additional layers, allowing for flexibility in model complexity. The inclusion of new convolutional layers is controlled by an "Include Layer b?" field, enabling the algorithm to determine whether to add one or two layers. Figure 5 highlights the growth of model depth as new phases commence, with models in subsequent phases being derived from the best-performing models of earlier phases. The experiments were conducted using the CIFAR-10 dataset, which consists of 60,000 color images across 10 classes, with a training set of 50,000 images and a test set of 10,000 images.
