This paper discusses an efficient approach to hyperparameter optimization in deep learning using a variable length genetic algorithm. It highlights the exponential growth of the search space as the number of layers in a deep learning model increases. For instance, with just two layers, the search space is 156,800, but it escalates to approximately 10^35 when the model reaches 14 layers.

The paper outlines the default search space parameters for the genetic algorithm, including choices for the number of output channels, convolutional filter sizes, activation functions, pooling types, skip connections, normalization, and the number of layers.

The authors compare their variable length genetic algorithm to other methods, including random search, classical genetic algorithms, and large scale evolution. A key distinction is that their method allows for a dynamic search space that adapts as the model deepens, while random search requires a fixed search space with a predetermined maximum number of layers. In the experiments, the random search was limited to a layer range of [2,10]. 

The classical genetic algorithm was implemented with smaller population sizes due to the extensive time required for model evaluation, as the fitness score is based on test accuracy after 4000 iterations. A 30-hour evaluation limit significantly restricts the number of models that can be assessed, which hampers the evolutionary process.

Overall, the paper emphasizes the advantages of the variable length genetic algorithm in efficiently navigating the increasingly complex search space associated with deeper neural networks.
