The paper presents an experimental study on the performance of various capsule network architectures applied to the MNIST dataset. The architecture consists of several convolutional layers followed by max pooling layers, as detailed in Table 1. The experiments utilized 90% of the training set for training and reserved 10% for validation, with the test performance evaluated on the complete test set.

Key findings include improvements in test error rates when utilizing fan-in routing in CapsNet, which decreased the error from 0.48% to 0.42%. Similar enhancements were noted for PathCapsNet-5, where the test error fell from 0.54% to 0.47%. The introduction of DropCircuit showed no benefit for PathCapsNet-5 but led to a significant reduction in error for PathCapsNet-10, achieving a test error of 0.42% with only 21% of the parameters compared to the standard CapsNet.

For the reconstruction setting, while CapsNet achieved the lowest validation error at 0.35%, PathCapsNet-16 with DropCircuit closely followed at 0.38%, utilizing only 44% of the parameters.

The results are summarized in Table 2, which details the architecture, routing paths, DropCircuit application, parameter counts, and test errors for both no reconstruction and reconstruction settings. The paper concludes by discussing interpretations and hypotheses regarding the techniques that contributed to the observed performance improvements.
