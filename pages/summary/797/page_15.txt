The paper presents TT-Rec, a method for tensor train compression in deep learning recommendation models. It addresses the challenge of managing large models by introducing efficient algorithms for both backward propagation and initialization of Gaussian parameters.

Algorithm 2 outlines the backward propagation process for TT-Rec embeddings. It operates within specified index ranges, recomputing necessary values for tensor operations. The algorithm utilizes batched General Matrix Multiplication (GEMM) calls to optimize computations at each layer, ensuring efficient gradient updates for the model parameters.

Algorithm 3 describes the sampled Gaussian initialization process. It initializes tensor elements with random values from a normal distribution, ensuring that values remain within a specified range to maintain stability during training. This technique is crucial for setting up the model effectively, allowing for better convergence during the learning process.

Overall, the proposed algorithms aim to enhance the efficiency of deep learning recommendation models through tensor train decomposition, enabling faster computations and reduced memory usage while maintaining performance.
