The paper presents TT-Rec, a novel approach for compressing deep learning recommendation models using Tensor Train (TT) decomposition. This method addresses the challenge of managing large embedding tables in recommendation systems, which can lead to significant memory requirements and computational inefficiencies. The study focuses on the seven largest embedding tables from Kaggle's dataset, providing a detailed analysis of their dimensions, TT-core shapes, number of parameters, and memory reductions achieved through TT decomposition.

Key components of TT-Rec include a caching mechanism that stores frequently accessed embedding vectors on the GPU, which allows for efficient retrieval and reduces the computational load during training. The cache is semi-dynamic, updating every 100 to 1000 iterations, and is designed to minimize training overhead while maintaining model accuracy. The paper outlines a two-step process for handling cached and TT-indexed vectors during forward and backward propagation, ensuring that weights are learned separately for both sets.

The experimental setup involves training TT-Rec using the MLPerf reference implementation of the Deep Learning Recommendation Model (DLRM) architecture on two datasets: the Criteo Kaggle Display Advertising Challenge Dataset and the Criteo Terabyte Click Logs. These datasets consist of numerical and categorical features, with the latter represented through embedding tables in the TT-Rec framework. The paper emphasizes the efficiency of TT-Rec, especially as embedding dimensions increase, which can exceed GPU memory limits in conventional setups.

The results indicate that TT-Rec effectively reduces memory requirements while enabling efficient training on GPUs with data parallelism, as opposed to relying on CPU or multi-GPU setups that introduce additional communication overhead. Accuracy evaluations, including test accuracy and binary cross-entropy loss, are reported for both datasets, demonstrating the effectiveness of the proposed method in maintaining model performance while optimizing resource utilization.
