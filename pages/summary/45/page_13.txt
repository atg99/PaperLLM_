The seq2seq model with attention enhances the traditional seq2seq framework by transmitting all hidden states from the encoder to the decoder, rather than just the final hidden state. In the initial step, an input sentence, such as "I am a student," is encoded to produce a translation in French, "je suis un étudiant." This process is illustrated in Figure 12, where the encoder's hidden states H1, H2, and H3, along with the embedding from the <End> token and an initial decoder hidden state Hinit, are passed to the attention decoder.

In the subsequent step, an output and a new hidden state vector H4 are generated, but the output is not retained, as shown in Figure 13. The attention mechanism then utilizes the hidden state vector H4 and the encoder's hidden states to create a context vector C4, depicted in Figure 14. Each encoder hidden state corresponds to specific words in the input sentence, and by scoring these hidden states and applying a softmax function, probability values are generated. The resulting pink vector indicates the likelihood of each hidden state contributing to the context vector, with lighter values representing higher probabilities and darker values indicating lower probabilities.
