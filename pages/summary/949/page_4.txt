The paper presents iNNvestigate, a library designed to simplify the analysis of neural networks' predictions through a modular implementation. It allows developers to easily create algorithms that perform back-propagation from model outputs to inputs, minimizing complex handling of graph structures. The library supports the extension of analyzers using wrappers, exemplified by SmoothGrad, which smooths analysis results by averaging outcomes with added Gaussian noise.

iNNvestigate introduces PatternNet and PatternAttribution, novel analysis methods that consider data distribution by identifying signal and noise directions for neurons. The library demonstrates efficient training capabilities, allowing for the processing of large datasets like Imagenet within an hour using a single GPU, and offers reference implementations for these methods.

To ensure objective comparisons of analysis methods, iNNvestigate incorporates perturbation analysis, which evaluates the impact of perturbing recognized important regions on classification tasks. This approach helps assess the effectiveness of various analysis methods.

The library is open-source under the BSD-2 license, compatible with Python 2 or 3, and built on the Keras framework, currently supporting the TensorFlow backend. Its user-friendly installation makes it accessible across multiple platforms.

In conclusion, iNNvestigate provides a comprehensive toolset for analyzing neural networks, facilitating research in areas such as drug design and medical image analysis by offering a common interface and implementations for numerous analysis methods.
