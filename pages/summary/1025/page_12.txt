The paper discusses the development of real-time electromyography pattern recognition (EMG-PR) systems for hand prosthetics using embedded systems. These systems, based on microcontrollers or microprocessors, aim to enhance the reliability, performance, and cost-effectiveness of prosthetic devices. The process involves several stages: recording surface EMG (sEMG) signals from the muscles using electrodes, acquiring the signals, applying pre-processing techniques, extracting and selecting features, and classifying these features to send commands to the embedded controller for controlling the prosthetic end effector.

Historically, the use of embedded myoelectric pattern recognition systems dates back to 1963, when a robotic arm was developed using discriminant analysis for classification. Subsequent advancements included a 1996 proposal of a real-time EMG-PR system utilizing a digital signal processor, which achieved a response time of 0.17 seconds and a 95% mean discrimination rate for distinguishing five motions among subjects. Other developments mentioned include a wireless transmission system for physiological signals and an Evolvable Hardware chip created in 1999 for myoelectric artificial hands, which served as a tool for hardware validation.
