The paper discusses the implementation of sparsity in autoencoders (AEs) through the use of KL divergence and a specific cost function designed to achieve sparse representations. The KL divergence is calculated between Bernoulli random variables, where the mean of one variable is set to a sparsity parameter r, which is kept close to zero to encourage many hidden units to activate minimally or not at all, resulting in sparse connections.

The overall cost function incorporates three main components: the reconstruction loss between the input and the output of the network, a term for inducing representational sparsity using KL divergence, and a regularization term to prevent overfitting by controlling the weight magnitudes. The latter is calculated based on the connections between neurons across layers.

To enhance sparsity, the authors propose adding a term to the loss function that penalizes active code units, promoting a distribution of activations that peaks at zero. However, this method may lead to a situation where only a few units remain active while others become inactive.

An alternative strategy introduced is the "Sparsifying Logistic," which acts as a non-linear module between the encoder and decoder. This module transforms the activations of the code units based on exponentially decaying weights from previous training samples, effectively creating a weighted "softmax" function for the code units. The parameter h controls the level of sparsity, and a larger value of b makes the non-linearity approach a binary state, providing a temporal aspect to the sparsity of the code. This approach allows for a more dynamic representation of sparsity, differentiating it from traditional spatial sparsity methods.
