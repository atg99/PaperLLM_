The paper discusses AutoEncoder-based methods for graph representation learning, highlighting their ability to extract high-dimensional vectors and generate low-dimensional embeddings. The encoder module's dependence on the input vector allows these methods to incorporate local structural information, which shallow embedding approaches cannot achieve. However, AutoEncoder-based methods face challenges, particularly high computational costs for large-scale graphs and a rigid structure that limits adaptability to evolving graphs.

Key methods include:

1. **SDNE**: Proposed by Wang et al., it uses deep autoencoders to maintain first and second-order proximities. It consists of an unsupervised autoencoder for node embeddings and a supervised component using Laplacian Eigenmaps to ensure connected nodes remain close in the embedding space.

2. **DNGR**: This model combines random surfing with autoencoders to create node embeddings. It involves generating a co-occurrence probability matrix, converting it to a PPMI matrix, and using stacked denoising autoencoders to achieve robust embeddings that capture high-order proximity.

3. **S2S-AE**: Developed by Taheri et al., this method uses LSTM autoencoders to embed graph sequences from random walks. It supports variable-length sequences, overcoming limitations of fixed-length inputs in previous models.

4. **DRNE**: This approach posits that a node's embedding should reflect the aggregation of its neighbors' embeddings. It utilizes LSTM to achieve this, allowing for permutation invariance in the node sequences.

5. **GAE & VGAE**: GAE uses Graph Convolutional Networks (GCN) to incorporate both structural and feature information of nodes. It has potential overfitting issues when reconstructing the adjacency matrix. VGAE enhances this by learning data distributions and optimizing a variational lower bound.

The paper emphasizes the advancements made through these methods while acknowledging the limitations that persist in handling large and dynamic graphs.
