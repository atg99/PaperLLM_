To enhance real-time object detection capabilities, this paper proposes a fast object detection method using YOLOv4-tiny as a foundation. The authors introduce two ResBlock-D modules in place of CSPBlock modules, which decreases computational demands. Additionally, an auxiliary residual network block is designed to extract more feature information, improving detection accuracy. This auxiliary network employs two consecutive 3x3 convolutions to create 5x5 receptive fields for capturing global features, complemented by channel and spatial attention mechanisms to further refine the information extracted.

The integration of the auxiliary network with the backbone network results in an improved YOLOv4-tiny architecture. Simulation results indicate that this novel approach yields faster object detection rates compared to both YOLOv4-tiny and YOLOv3-tiny, while achieving a comparable mean average precision to YOLOv4-tiny. Therefore, the proposed method is particularly well-suited for real-time object detection applications on embedded devices.

In summary, this work highlights advancements in deep learning object detection methods, emphasizing the balance between speed and accuracy, and presents a viable solution for resource-constrained environments.
