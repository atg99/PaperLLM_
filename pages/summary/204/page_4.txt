Markov decision processes (MDPs) provide a framework for modeling sequential decision-making problems involving a single reinforcement learning (RL) agent. An MDP is defined by a tuple consisting of a set of states, a set of actions, a transition function, and a reward function. When an agent selects an action in a given state, it transitions to a new state with certain probabilities and receives a reward. The objective is to find an optimal policy that maximizes the expected sum of discounted rewards.

The stochastic policy maps states to probabilities over actions, with the optimal policy maximizing the expected return from any initial state. The value function estimates the expected return following a specific policy, while the action-value function, or Q-function, evaluates the utility of state-action pairs. The discount factor influences how future rewards are valued, and the horizon defines the number of time steps in the decision-making process.

MDPs adhere to the Markov property, meaning that transitions depend only on the current state and action. In cases where not all state features are observable, the problem is framed as a partially-observable Markov decision process (POMDP). Solving an RL task involves finding a policy that maximizes expected rewards, with various learning methods available, including dynamic programming, Monte Carlo methods, and temporal difference methods.

Q-learning, a widely used model-free TD algorithm, learns the utility of state-action pairs and can converge to optimal values under certain conditions. The update rule for Q-learning adjusts estimates based on observed rewards and future value estimates. Deep Q-Networks (DQN) enhance Q-learning by employing deep neural networks to approximate Q-values in high-dimensional spaces, leveraging techniques such as experience replay for better sample efficiency and stability.
