The paper discusses various Graph Data Augmentation (GraphDA) techniques aimed at enhancing the performance of graph-based models by preserving task-relevant information. 

Node Dropping, also referred to as node masking, involves removing specific nodes and their associated edges from a graph, which also leads to the loss of corresponding node features. Conversely, Node Insertion enhances the graph's connectivity by adding virtual nodes and edges, requiring the initialization of new node features.

Graph Generation is another strategy that involves creating new graphs from observed ones, which can include techniques like graph coarsening and edge mixing. 

Feature-oriented augmentations focus on transforming the node feature matrix. Key methods include:

1. **Feature Corruption**: Involves adding noise to node features or learned representations to create variations.
2. **Feature Shuffling**: Randomly rearranges the feature matrix to disrupt contextual information.
3. **Feature Masking**: Sets certain entries in the feature matrix to zero, often using a Bernoulli distribution to determine which features to drop.
4. **Feature Addition**: Introduces additional features to enhance the existing node features, aiding in the integration with graph neural networks.
5. **Feature Rewriting**: Aims to recover clean node features by adjusting them based on neighbors or using optimization techniques.
6. **Feature Mixing**: Combines features from different nodes to generate synthetic node representations.
7. **Feature Propagation**: Distributes node features across the graph structure, allowing for interpolation of features.

Each of these methods contributes to the overall goal of improving graph-based learning and model performance by effectively augmenting both the graph structure and the node features.
