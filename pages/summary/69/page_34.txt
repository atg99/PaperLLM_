The paper discusses extensions to the Vanilla LSTM network, focusing on enhancing its architecture to improve its functionality. Three main avenues of evolution are proposed: expanding the input to include multiple samples within a context window, introducing a new gate to manage this richer input, and incorporating a recurrent projection layer, which has shown benefits in sequence modeling tasks.

The first extension, External Input Context Windows, involves representing these context windows using linear filters with matrix-valued coefficients that operate on the sequence of input samples. The standard matrix-vector products are replaced by convolutions of context window filters with the input signal, allowing the model to incorporate information from future input samples without significantly increasing the number of learnable parameters. This is achieved by ensuring that the context window filters are non-causal, thus enabling the model to leverage additional input data to better understand the context of each step in the sequence.

The paper emphasizes the potential advantages of this approach, drawing an analogy to how humans sometimes read ahead to grasp the meaning of earlier parts of a sentence. It suggests that exploring the trade-offs between adding a small number of parameters for context windows versus the computational costs of training a bi-directional LSTM could provide insights into optimizing sequence modeling architectures. The proposed extensions aim to enhance the model's ability to discern context and improve overall performance in various applications.
