The paper discusses the mechanism of Vanilla Long Short-Term Memory (LSTM) networks, focusing on the computation of control signals at each step indexed by n. Three key control signals are defined: gcs[n] for the state signal from the previous step, gcu[n] for the update candidate signal from the current step, and gcr[n] for the readout signal from the current step. The data signals utilized for these computations include s[n-1], v[n-1], and x[n], with specific combinations for each control signal.

The inputs to each gate are expressed as linear combinations of available data signals, facilitating the application of the backpropagation through time (BPTT) method. The model parameters are trained to allow the gate functions to adapt to the training data, enabling the LSTM gates to modulate the data signals during inference, thereby addressing issues like artificial boundaries in input sequences.

The LSTM cell maintains an internal state signal s[n], which is not externally observable, while allowing the next step to access it. The dual objectives of the LSTM cell involve data preparation and control of data, where the candidate data signals are modulated by control signals that determine the fraction of data propagated. The paper concludes with a description of the LSTM's internal structure, which includes update, state, and readout stages, emphasizing the model's robustness in generating high-quality output sequences despite imperfections in the input data.
