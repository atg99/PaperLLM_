The paper discusses the functionality of the "control readout" gate in the Vanilla Long Short-Term Memory (LSTM) network, highlighting its role in determining the observable value signal for the cell at each time step. The cell state at the current step is defined as a weighted combination of the previous cell state and current update information. An example illustrates the "Constant Error Carousel" (CEC) mode, where specific gate settings allow for the unattenuated propagation of the error gradient, enabling the cell state to refresh continuously. This mechanism facilitates better accommodation of Gradient Descent in LSTM networks compared to standard Recurrent Neural Networks (RNNs). Under certain conditions, the LSTM can operate in CEC mode, allowing for effective back-propagation of parameter updates over extended sequences, thus addressing long-range dependencies. However, while the LSTM design mitigates the vanishing gradient problem, it does not explicitly tackle the exploding gradient issue, which can still occur during training. To manage this, derivatives are renormalized within a predefined range. The LSTM's gate functionality offers a differentiable alternative to traditional static random access memory cells.
