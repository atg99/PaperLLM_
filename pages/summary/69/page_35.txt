The paper discusses modifications to the Vanilla LSTM cell by introducing a Recurrent Projection Layer and a new control input gate to enhance its functionality. 

In the modified LSTM, the cell's value signal is redefined as the product of an additional weight matrix with the cell's qualifier signal. This adjustment allows for dimensionality reduction of the observable value signal, enabling faster training by reducing the number of columns in matrix multipliers. This flexibility allows for a trade-off between the representational capacity of the LSTM cell and the computational cost associated with learning its parameters.

Additionally, the paper critiques the treatment of external input signals within the Vanilla LSTM cell, noting that while the readout candidate signal is controlled by a gate, the external input is always fully injected. To address this, a new control input gate is introduced, which regulates the contribution of the external input to the data update accumulation node. This new gating mechanism allows for better adaptation to variations in training data by enabling fine-tuning of both the readout and external input components at each step. 

Equations are provided for the new control input gate and the modified data update accumulation node, illustrating how these modifications can be integrated into the LSTM architecture. Overall, these enhancements aim to improve the adaptability and efficiency of LSTM networks in processing sequential data.
