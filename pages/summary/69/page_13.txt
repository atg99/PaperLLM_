This paper discusses the process of segmenting an input sequence using a sampling window in the context of a recurrent neural network (RNN). The element-wise multiplication of the input sequence, represented as x[n], with a sampling window, w_m[n], results in a segment-level input sequence x_m[n]. This sequence has non-zero values only within a specified range determined by the segment index m.

In an RNN, the state signal sequence s_m[n] generally depends on the entire input sequence. However, the paper emphasizes that the state signal subsequences from different segments are independent and thus s_m[n] should only depend on its corresponding input subsequence x_m[n]. A transformation map is defined to convert the segment-level input signal into the segment-level state signal.

The paper establishes that to maintain the independence of state signal subsequences across different segments, certain conditions must be met, particularly at the boundary of segments. If these conditions are satisfied, the equations governing the RNN for an individual segment are derived. These equations outline how the segment-level state signal and the RNN's output are calculated based on the input signals.

Additionally, the paper introduces an index substitution that shifts the segment-level subsequences, allowing for a clear representation of the RNN's calculations within the defined segment boundaries. This shift facilitates the formulation of the segment-level state and output signals in a structured manner, ensuring that the computations remain within the specified segment indices.
