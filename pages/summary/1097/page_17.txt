In the paper "Exploring the Limits of Transfer Learning," the authors discuss the mechanisms of the Transformer model, particularly focusing on the decoder's self-attention operations that utilize a causal masking pattern. This causal masking ensures that when generating the ith output token, the model does not consider any future tokens, allowing for autoregressive output generation. The decoder can function independently as a language model trained for next-step prediction, a method established in earlier work on transfer learning for natural language processing.

Language models traditionally serve purposes like compression and sequence generation. They can be adapted for text-to-text tasks by concatenating input and target sequences. For instance, in English to German translation, the model is trained on a combined sequence that includes both the input and the expected output. However, a significant limitation arises from the causal masking, which restricts the model's representation of the input to only prior tokens, potentially impairing its predictive capabilities.

To address this limitation, the authors propose a "preﬁx LM" approach that employs fully-visible masking for the input prefix while still using causal masking for the output predictions. This allows the model to have a more comprehensive understanding of the input context, thereby enhancing its performance in text-to-text tasks. The paper advocates for this modified masking strategy as a means to improve the effectiveness of Transformer-based language models in various applications.
