The paper by OKSUZ et al. reviews imbalance problems in object detection, focusing on feature-level imbalance within architectures like Feature Pyramid Networks (FPN). It highlights the need for a balanced integration of low- and high-level features to enhance prediction consistency. The authors discuss the Scale Aware Trident Networks, which leverage dilated convolutions to create scale-specific feature maps, improving accuracy without the inefficiencies of multiple branches.

To address feature-level imbalance in FPNs, the paper categorizes solutions into two groups: those utilizing pyramidal features and those based on backbone features. The Path Aggregation Network (PANet) enhances FPN by allowing low-level features to influence predictions more directly, using bottom-up path augmentation and adaptive feature pooling, which associates regions of interest (RoIs) with all feature levels.

Conversely, Libra FPN integrates all features at once, combining them through a two-step process of integration and refinement, enhancing the use of pyramidal features. The Scale-Transferrable Detection Network (STDN) shifts focus to backbone features, using DenseNet blocks to propagate lower-level information through pyramidal feature generation, employing mean pooling for size adjustment.

In summary, the paper examines various advanced techniques to mitigate feature-level imbalance in object detection frameworks, emphasizing the importance of effective feature integration for improved performance.
