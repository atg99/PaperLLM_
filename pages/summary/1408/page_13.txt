The paper by OKSUZ et al. reviews the issue of scale imbalance in object detection, emphasizing how certain object sizes are over-represented in datasets, which adversely impacts detection performance. The authors illustrate this imbalance using data from common datasets like MS-COCO, highlighting that smaller objects dominate the distributions of bounding box width, height, and area.

Scale imbalance is defined as the disproportionate representation of object sizes in datasets, leading to challenges in accurately estimating Regions of Interest (RoIs). Traditional deep object detectors often rely on backbone convolutional neural networks pre-trained for image classification, which may not effectively handle this scale diversity.

To address scale imbalance, the paper categorizes solutions into four main approaches: 

1. **Predicting from Feature Hierarchy**: This method utilizes predictions from various levels of the backbone network to account for different scales. For instance, the Single Shot Detector (SSD) makes predictions based on features from multiple layers, allowing for better detection of small objects.

2. **Feature Pyramid Networks**: These networks combine intermediate features from different scales before making predictions, enhancing the model's ability to detect objects at various sizes.

3. **Image Pyramids**: This approach involves scaling the input image and processing multiple versions, allowing the detector to recognize objects of different sizes.

4. **Combining Image and Feature Pyramids**: This method integrates both image and feature pyramids to maximize the detection capabilities for objects of varying scales.

The paper highlights that while backbones are crucial for feature extraction, they are insufficient on their own to manage the diversity of scales present in input bounding boxes. Overall, the review underscores the need for advanced techniques to improve object detection performance across varying object sizes.
