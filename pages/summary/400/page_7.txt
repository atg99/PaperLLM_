The paper discusses the methodology used to implement and train the YOLO-UA model for object detection. The process begins with the creation of a three-dimensional label format for images, which includes confidence scores, central coordinates, and object class serial numbers. The coordinates of target objects are extracted from XML files and scaled according to a 448x448 image size. This involves converting the coordinates into a central point format and determining the corresponding grid index using specific equations.

To enhance the dataset, horizontal flips of the images are employed, and a dictionary is created to store the paths and labels of the images. These dictionaries are then compiled into lists and saved as pkl files for future use.

For network training, the YOLO-UA model is initialized with pre-trained weights from the VOC2007 dataset. The training involves normalizing pixel values and executing 15,000 iterations using stochastic gradient descent with an initial learning rate of 0.0001. The loss function for YOLO-UA incorporates four components: coordinate loss, confidence loss, class loss, and GIOU loss, as outlined in a detailed equation. The parameters in the loss function are adjusted to account for the sensitivity of small targets.

The experimental setup utilized an Ubuntu 16.04 system with TensorFlow 1.8, Python 3.5, an Intel Core i7-7700 CPU, and a GeForce GTX1080 GPU to facilitate the training process.
