The paper discusses the fuzzy inference system (FIS) and its extension, the adaptive neuro-fuzzy inference system (ANFIS). 

The fuzzy inference system is designed to manage imprecise and fuzzy data, producing outputs in the range of 0 to 1 using fuzzy logic. It functions similarly to human decision-making by relying on a knowledge base of IF-THEN rules. The FIS consists of four main components: 

1. Fuzzifier: Converts input data into fuzzy values.
2. Fuzzy Knowledge Base: Stores facts and rules.
3. Inference Engine: Matches rules to inputs to generate results.
4. Defuzzifier: Converts the inference results into crisp values.

The adaptive neuro-fuzzy inference system is a neural network variant of the FIS, utilizing the Sugeno fuzzy inference model. ANFIS blends the strengths of neural networks and fuzzy logic to enhance problem-solving capabilities. It features a training phase where it automatically generates rules and membership function values without using synaptic weights. Error calculation in ANFIS is based on the difference between target and observed values, allowing it to produce accurate results for unseen data. ANFIS comprises five layers:

1. Fuzzification Layer
2. Rule Layer
3. Normalization Layer (Membership Function Layer)
4. Defuzzification Layer
5. Summation Layer

Overall, ANFIS demonstrates superior performance compared to traditional systems, as validated during its testing phase.
