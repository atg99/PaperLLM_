The paper presents performance evaluations of a fuzzy inference system and an adaptive neuro-fuzzy inference system (ANFIS) for classifying renal cancer through a series of k-fold cross-validation tests. Key findings from the study include performance metrics derived from confusion matrices for multiple folds.

For the fuzzy inference system, true positive, false negative, false positive, and true negative values were extracted across four folds, with the overall performance parameters summarized in Table 16. The calculated metrics include sensitivity (true positive rate), specificity, precision, and classification accuracy. The sensitivity values ranged from 95.23% to 95.65%, while specificity varied between 93.10% and 100%. Overall classification accuracy averaged 96%.

For the ANFIS model, confusion matrices for each fold, as shown in Tables 17-20, illustrate the number of test cases classified correctly versus incorrectly across different severity levels of renal cancer. This comprehensive evaluation highlights the effectiveness of both systems in accurately diagnosing renal cancer, with the fuzzy inference system demonstrating consistently high sensitivity and classification accuracy.
