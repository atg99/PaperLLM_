The paper discusses various components of Convolutional Neural Networks (CNNs), focusing on average pooling, activation functions, and fully connected layers.

In average pooling, a kernel of size n x n moves across the input matrix, calculating the average of the values within the kernel for each position and placing it in the corresponding output matrix position. This process reduces the spatial dimensions of the image while maintaining the number of channels, thus decreasing computational load and the number of required weights. Various pooling functions are mentioned, including the average of the neighborhood, L2 norm, and weighted averages, with maximum pooling being the most commonly used method.

The activation function is crucial in CNNs, as it determines the output of the neural network. The most prevalent activation function is the Rectified Linear Unit (ReLU). Activation functions can be categorized into linear and non-linear types. Linear activation functions provide outputs proportional to inputs, while non-linear functions enable the network to learn complex mappings, making them essential for handling intricate data types like images and audio.

Finally, the fully connected layer, located at the bottom of the network, operates as a feed-forward neural network. It receives input from the flattened output of the last pooling or convolutional layer, transforming the multi-dimensional output into a vector format for further processing.
