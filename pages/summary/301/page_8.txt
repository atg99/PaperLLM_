The paper discusses the architecture of the DBDA network, which is designed for processing spectral and spatial data in remote sensing applications. The network consists of two main branches: the Spectral Branch and the Spatial Branch. The input data is processed through both branches to extract spectral and spatial feature maps, which are then fused to produce classification results.

The Spectral Branch employs a series of 3D convolutional neural network (CNN) layers, beginning with a kernel size of 1x1x7 to reduce the number of spectral bands and capture feature maps of size (9x9x97, 24). A dense spectral block is integrated, which consists of multiple 3D CNN layers that increase the number of channels in the feature maps to 60. A channel attention block is then applied to refine these spectral features by emphasizing informative channels while diminishing those lacking relevant information. Subsequent layers, including batch normalization and dropout, enhance stability and mitigate overfitting, culminating in a global average pooling layer that outputs feature maps in the shape of 1x60.

The paper provides implementation details for each layer in the Spectral Branch, including kernel sizes and output dimensions, facilitating an understanding of the architecture's operational flow. The Indian Pines dataset is used as a case study, highlighting the network's application in remote sensing classification tasks.
