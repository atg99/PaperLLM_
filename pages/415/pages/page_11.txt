Finally, YOLO applies Non -Maximum Suppression (NMS) to clean all bounding boxes which do not 
contain any object or contain the same object as other bounding boxes  (Figure 1 ). By picking a 
threshold value, NMS removes all the overlap  bounding  boxes which have intersection over union 
(IOU) value higher than the threshold value . (ODSC Science, 2018)  
2.2 YOLOv1 architecture  
The Y OLO  model is designed to encompass an architecture that processes all image features (the 
authors called it Darknet architecture) and followed by 2 fully connected layers performing bo unding 
box prediction for objects  (Figure 5 ). This model was evaluated in the Pascal VOC dataset, where 
the authors used 𝑆=7, 𝐵=2 and 𝐶=20. This explains why the final feature maps are 7×7, 
and the output size was  (7×7×(2∗5+20)).
