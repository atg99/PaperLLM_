The CSP  (Cross Stage Partial)  is based on the same principle of the above DenseNet except that 
instead of using the full -size input feature map at the base layer, the input will be separated into 2 
portions. A portion  will be forwarded through the dense block as usual and another one will be sent 
straight on to the next stage  without processed  (Figure 20). This will result in different dense layers 
repeatedly learn copied gradient information . (Wang, et al., 2019)

Combining these ideas with Darknet -53 architecture in YOLOv3, the residual blocks were replaced 
by the dense blocks. CSP maintains features throu gh propagation, encourages the network to 
reuse features, and reduces the number of network parameters, helps to preserve fine -grained 
features for forwarding to deeper layers more efficiently.  Considering that excessive increase of 
the densely connected c onvolutional layers may lead to a decrease in detection speed, only the 
last convolutional block which can extract the richer semantic features in the Darknet -53 backbone 
network is improved to be a dense block  (Figure 2 1). (Huang, e t al., 2019)
