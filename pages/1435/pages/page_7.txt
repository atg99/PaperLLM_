3.2.2 Real-time factor
The real-time factor (RTF) is the most commonly used metric for calculating the speed of a
proposed model. The RTF can be computed by using the following formula:
RTF ¼P
I
where P is the time taken by the system to process the input and I is the duration of the input
audio. If RTF equals 1, then the input audio was processed in “Real-Time ”. RTF is a highly
hardware-dependent value and it is not only limited to calculating the speed of a speech
recognition model. It can be used to calculate the speed of any model that can process an audio
or video input.
