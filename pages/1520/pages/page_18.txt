H. Experimental Settings
Computing infrastructure. We leverage Pytorch Geometric and Pytorch for model development. All experiments are
conducted on an Nvidia A40 GPU on a Linux server.
Baselines. We directly use the results reported in (He et al., 2021). JacobiConv and linear GNN with other bases have fewer
parameters than baselines, as linear GNN have a fixed number of parameters given the node feature dimension and output
dimension.
Model hyperparameter for Synthetic Datasets. We use optuna to perform random searches. Hyperparameters were
