D. Metrics Monitored
All of the seven models were quantized and tested on
MacBook Pro 2019 powered by 2.3 GHz 8 core Intel i9-
9880H [35] processor and 16GB 2400MHz DDR4 memory.
To test the deployability of a model the important parameters
to know are its inference time, performance and the size.
Hence, we monitored the changes in these parameters for
different quantized models. Along with this we also observed
the time it takes to optimize the models using different
quantization methods and load these models to local memory
for computations. For model pruning, we retrained the models
on Azure NC6s V3 [36] instance with 6 vCPUs, RAM of
112GiB and a single GPU of 16GiB [36]. For compression
of GPT-2 small we used Azure NC12s v2 instance with 12
vCPUs, RAM of 224 GiB and two GPUS of 16GiB.
