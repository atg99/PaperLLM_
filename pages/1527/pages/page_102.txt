79 Performance
Performance is the measure used to evaluate the behavior of the agent 
in the environment. It answers the question, Does the agent do what it’s 
supposed to do in the environment?
 Goals
Goals refer to what the agent is trying to achieve. In the field of machine 
learning, the goal is not to be able to get the agent to “learn. ” Instead, this 
refers to the overall goal or objective.
Goals can be broken down into smaller tasks. For example, to 
accomplish the goal of a Caesarean section, the tasks could be considered 
cutting open the abdomen, bringing the baby out, checking the baby is 
healthy, and stitching the abdomen back up again.
 Utility
Utility refers to the agent’s own, internal performance assessment—that 
is, the agent’s own measure of performance at any given state. This may 
differ from the performance of the agent. It is noteworthy that the utility 
function is not necessarily the same as the performance measure, although 
it can be. An agent may have no explicit utility function, whereas there 
is always some performance measure. A utility function is used to map a 
state to a real number, which describes the associated degree of happiness 
or progress toward a goal or objective. This allows rational decisions in 
cases where there are several paths to the same goal, allowing an agent to
