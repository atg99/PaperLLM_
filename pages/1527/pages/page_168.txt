Naïve Bayes uses Bayes’ theorem to calculate the probability an event 
will occur given another event has already occurred. The algorithm is 
acknowledged as naïve because it assumes all variables are independent 
of each other, which is atypical of real-world examples. The Bayesian 
classifier is often used when input dimensionality is high.
For example, given a specified threshold, this method can be used to 
probabilistically classify whether a vector is in one class or another:
