 Prediction
Technologies already exist that monitor data to predict disease outbreaks. 
This is often done using real-time data sources such as social media as well 
as historical information from the Web and other sources. Malaria outbreaks 
have been predicted with artificial neural networks, analyzing data including 
rainfall, temperature, number of cases, and various other data points.
