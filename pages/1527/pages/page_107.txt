84 How Is Machine Learning Different 
from Traditional Software Engineering?
Traditional software engineering and machine learning share a common 
objective of solving a problem or set of problems. The approach to 
problem-solving is what distinguishes the two paradigms.
Traditional software engineering or programming refers to the task of 
computerizing or automating a task such that a function or program, given 
an input, provides an output. In other words, writing a function f, such 
that given input x, output y = f(x). This is done with logic, typically if-else 
statements, while loops and Boolean operators.
Machine learning differs from conventional programming in that 
rather than providing instructions about the function f, the computer 
is provided input x and output y and expected to determine or predict 
function f (see Figure  3-2). Whereas traditional programs have been 
written by humans to solve a problem, machine learning programs 
learn through reasoning to solve a problem from examples, rules, and 
information. Many classifiers in machine learning assist with prediction. 
Machine learning programs can also learn to generalize and help with 
issues of uncertainty due to the use of statistics and probability-driven 
techniques. Models can learn from previous computations or experience
