340• NoSQL
A modern approach to databases that is useful for 
managing data that changes frequently, or data that is 
unstructured or semi-structured in nature. Rows can 
all have their own set of unique column values. NoSQL 
has been driven by the requirements to provide better 
performance in storing big data. The architecture has 
better write performance, takes less storage space with 
compression, and reduces operational overhead.
• Overfitting
Overfitting occurs when a machine learning model 
performs well on a training dataset but does not 
perform as well on a validation set. The model 
essentially learns the training data.
• Parameters
Attribute values that control the output and behavior of 
a machine learning system.
• P value
On the basis the null hypothesis is true, the P value 
refers to the probability of receiving a value equal to or 
greater than the observed value.
• Ranger
A data management and monitoring framework to 
ensure data security.
• Regression
