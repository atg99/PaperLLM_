142Logistic regression uses the sigmoid function, an S-shaped curve 
(see Figure  4-5) that can take any continuous value and map it into a 
probability value between 0 and 1 for a default class.
Sigmoid function: 1/(1 + e^–value), where e Euler’s number and value 
is the value requiring transformation.
Logistic regression uses an equation P(x) = e ^ (b0 + b1 *x)/(1 + e^(b0 + 
b1*x)), which can be transformed into ln(p(x)/1–p(x)) = b0 + b1 *x). As with 
linear regression, b0 and b1 are values learned from the training data.
As an example, take a model that determines whether a growth on 
the skin surface is benign or not. The input variable, x, could be the size, 
depth, or texture of the growth; and the default variable y = 1 indicates a 
benign growth. As depicted, the logistic function transforms the x-value 
of the various instances into a probability value between 0 and 1. If the 
probability crosses the threshold of 0.5, the tumor is classified as benign.
Logistic regression seeks to learn values of b0 and b1 through 
training that minimize the error between predicted and actual outcomes.
