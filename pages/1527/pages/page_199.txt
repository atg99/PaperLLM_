N-grams preserve the sequences of N items from the text input. 
N-grams can have a different N value: unigrams for when N = 1, bigrams 
when N = 2, and trigrams when N = 3.
N-grams are used extensively for spelling correction, word 
decomposition, and summating texts.
 TF IDF Vectors
A document can be represented as a high-dimensional vector in the space 
of words. Each entry in the vector corresponds to a different term within 
the documents and the number of its occurrences. The TF-IDF (Term 
Frequency-Inverse Document Frequency) vector scheme assigns each 
term within the document a weight using the following formula:
