164Dimension reduction is extremely useful in machine learning tasks, 
with a plethora of benefits:
• Fewer dimensions result in quicker computations 
when compared to the original dataset.
• By default, dimension reduction algorithms reduce the 
space required for storage.
• Reducing data into less than three dimensions enables 
visualization and easier understanding.
• Redundant data is removed, which improves the 
performance of the machine learning model.
• Noise is removed, which improves model performance.
