 Regression
Regression involves predicting an output that is a continuous variable. As 
a regression-based system predicts a value, performance is measured by 
assessing the number of prediction errors.
The coefficient of determination, mean absolute error, relative 
absolute error, and root mean square error are statistical methods used for 
evaluating regression models.
Regression algorithms include linear regression, regression trees, 
support vector machines, k nearest neighbor, and perceptrons.
It is often possible to convert a problem between classification and 
regression. For example, patient HbA1c can also be useful if stored as a 
continuous value. A continuous value of HbA1c = 6.9% can be classified 
into a discrete category, diabetic, on rules defined on HbA1c as Diabetic 
(Set 1): HbA1c ≥ 6.5%, Non-diabetic (Set 2): HbA1c < 6.5%.
